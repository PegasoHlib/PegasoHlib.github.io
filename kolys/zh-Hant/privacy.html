Kolys

隱私權政策

最後更新：2026年11月6日

Kolys 是一款用來寫信給未來的自己（「時空膠囊」）的 Android 應用程式。本政策說明應用程式如何處理你的資料。簡而言之：你的信件留在你的手機上，如果你開啟了，也會儲存在你自己的 Google 雲端硬碟中。禮物、群組膠囊和信件檔案是你自己傳送的檔案，本頁會如實說明它們是如何被鎖定的。

總覽

  • 你的信件、相片、影片和語音訊息都儲存在你的手機上。
  • Kolys 沒有自己的伺服器。開發者從不接收你的信件、相片或任何其他資料。
  • 沒有廣告，沒有數據分析，沒有追蹤，不出售資料。位置資訊只在你要求取得城市和天氣時才使用，而且只是大約位置，不會儲存。
  • Google 雲端硬碟是選用的，而且只能存取應用程式自己的隱藏資料夾。
  • 封存的信是由應用程式鎖定的，而不是加密的。突破了 Android 應用程式保護的人可以讀取它，Google 也可以讀取雲端硬碟中的副本。
  • 禮物、群組膠囊和信件檔案都是由你自己傳送的檔案。開發者永遠不會收到它們。它們包含你填寫的「此刻」，但不包含手機的名稱或電量。

哪些內容留在你的手機上

應用程式會在你的手機上儲存：

  • 你的膠囊和草稿：名稱、信件內文、寫信日期、開啟日期、封印顏色、是否已開啟，以及它回覆的是哪一封之前的信；
  • 你新增的相片和影片的副本（相片會被縮小），以及你錄製的語音訊息；
  • 「此刻」：你的心情、歌曲、城市和天氣（如果你加入了的話），以及在寫給自己的信中，手機的名稱（你替它取的名稱，沒有的話則為製造商和型號）和電量；
  • 朋友傳給你的膠囊，以及對於你召集的群組膠囊，到目前為止蒐集到的信；
  • 你的設定（語言、主題、你用於某個膠囊的生日、已連結 Google 帳戶的電子郵件地址）。

相片和影片透過 Android 內建的相片挑選器選取，所以應用程式只會看到你選的那些，絕不會看到你的整個相簿。麥克風只在你錄製語音留言期間使用。所有這些都儲存在應用程式的私有儲存空間中，其他應用程式無法讀取，但這些檔案本身沒有加密。應用程式會關閉 Android 的自動備份。你在 Kolys 中拍攝的相片和影片由手機的相機應用程式拍攝；Kolys 本身沒有相機權限。

封存的信是如何受到保護的

封存的信是由應用程式鎖定的：Kolys 在到期那天之前不會開啟或顯示它，並且日期是連網核對的。這是應用程式裡的一把鎖，而不是加密。

在你的手機上，信件、相片和錄音是應用程式私有儲存空間中的一般檔案和資料庫項目。突破了 Android 應用程式保護的人，例如在已取得 root 權限的手機上，或用特殊工具開啟的手機上，可以讀取它們。你 Google 雲端硬碟中的 zip 同樣沒有加密，所以 Google 可以讀取它，就像它可以讀取存放在雲端硬碟上的任何內容一樣。

禮物檔案和群組膠囊的運作方式不同，見下文「作為禮物的膠囊」。請不要把任何必須對他人保密的內容放進膠囊。

Google 雲端硬碟（選用）

如果你使用 Google 登入，Kolys 只要求一項權限：drive.appdata。它只允許應用程式在你 Google 雲端硬碟的隱藏應用程式資料夾中建立、讀取和刪除它自己的檔案。應用程式無法查看或變更你雲端硬碟中的任何其他檔案。

每個封存的膠囊都會作為一個一般的 zip 檔案儲存在那裡，檔名使用膠囊的隨機 ID（信件、它的相片、影片、語音留言和「此刻」），沒有加密。開啟日期和實際開啟的日期也會作為該檔案的屬性儲存。草稿不會上傳。有網路時，變更幾秒鐘後會開始同步，此外大約每天同步兩次。這就是在新手機上找回你的封存膠囊的方式。應用程式還會讀取你帳戶的電子郵件地址，僅用於告訴你連接的是哪個帳戶。

資料透過加密連線在你的手機和 Google 之間直接傳輸，中間沒有其他伺服器。儲存在你雲端硬碟中的內容適用 Google 自己的隱私權政策。

檔案備份（如果你建立了）

在設定裡，你可以把所有膠囊和草稿存進一個檔案，存到你選擇的地方，不用 Google。應用程式不會把這個檔案傳送到任何地方。如果你把它存到雲端資料夾，就由那個服務來保存。

沒有暗號，檔案不會加密：拿到檔案的人能讀到所有的信，包括已封存的。有暗號，檔案會加密，安全程度取決於暗號有多難猜。如果你忘了暗號，誰也打不開這個檔案。

還原會放回手機上沒有的膠囊，已封存的仍然封存。仍在為群組收集的信，以及你送出的禮物的暗號，不在檔案裡。

如何使用 Google 資料

Kolys 對從 Google API 取得的資訊的使用及向任何其他應用程式的傳輸，將遵守 Google API 服務使用者資料政策，包括其中的「限制使用」規定。

  • 來自你 Google 雲端硬碟的資料只用來儲存你的膠囊，並把它們還原到你的手機上。
  • 這些資料從不出售，從不用於廣告，也從不與任何人分享。
  • 沒有任何人會閱讀它們：開發者無法存取你的雲端硬碟或你的信件。

核對日期

為了防止有人透過調整手機時鐘提前開啟膠囊，應用程式會向網路伺服器（www.google.com 或 www.cloudflare.com）詢問目前時間，並從回覆中讀取日期。膠囊到期那天，在通知你之前，它會再詢問一次。不會傳送任何關於你或你的膠囊的資訊。和任何網路請求一樣，這些服務看得到你的 IP 位址。

城市和天氣（選用）

只有當你在寫信時點選「加入城市和天氣」，應用程式才會向 Android 請求一次你的大致位置（絕不是精確位置）。Android 的定位服務（通常是 Google）把它轉換成城市名稱，應用程式再向 MET Norway（挪威氣象研究所，api.met.no）請求目前天氣，並傳送取整到約一公里的位置。膠囊中只儲存城市名稱和天氣；位置本身不會被儲存。你隨時可以不加入這些。

歌曲搜尋（選用）

當你搜尋此刻的歌曲時，你輸入的文字會傳送到開放音樂資料庫 MusicBrainz（musicbrainz.org），以尋找相符的歌曲名稱。膠囊中只保留歌曲名稱、藝人和年份，從不儲存封面或錄音。「收聽」會把歌曲名稱傳給你手機上的音樂應用程式（或開啟 YouTube Music 搜尋），該應用程式依其自身的規則運作。你也可以不搜尋，直接自己輸入一首歌。

當作禮物的膠囊

寫給他人的膠囊會變成一個檔案，由你自己透過你選擇的應用程式（即時通訊應用程式、電子郵件、Google 雲端硬碟）傳送。開發者永遠不會收到它。檔案中包含信件及其相片、影片、語音訊息和「此刻」（不含手機的名稱或電量），如果你提供了名字，還包含你的名字。檔案名稱裡包含你為收件人或群組輸入的名稱，即時通訊應用程式或郵件服務看得到它。影片會以原樣傳送，其中可能包含拍攝地點。

沒有暗語時，檔案是加密的，但金鑰就儲存在檔案裡面。這只能防止朋友不小心提前解開它，防不住任何拿到檔案並且有些本事的人。如果你用暗語鎖定它，金鑰由暗語產生，不在任何檔案中，所以檔案的安全程度取決於暗語有多難猜。暗語只儲存在你的手機上，這樣你可以再次查看，它絕不會進入檔案、你的 Google 雲端硬碟或傳給開發者。只有你寫下的提示可以在解鎖前被讀取。

群組膠囊還會帶有群組的名稱和你列出的名字。當一個群組共同寫一個膠囊時，邀請檔案會以未加密的方式包含群組的金鑰，所以任何拿到邀請的人都可以讀取寄回的信。每個人的信會作為檔案傳送給蒐集的人，並用該金鑰加密。在膠囊封存之前，蒐集到的信作為一般檔案存放在召集人的應用程式儲存空間中；應用程式只顯示誰寫了，不顯示寫了什麼，它們也不會被複製到雲端硬碟。

收件人在 Kolys 中開啟檔案後，他們的副本就存放在他們的應用程式裡，和任何膠囊一樣沒有加密，如果他們使用的話，也會存放在他們自己的 Google 雲端硬碟中。你已傳出的檔案會留在收件人那裡，以及即時通訊應用程式或郵件服務裡；在 Kolys 中刪除膠囊無法把它們收回。

通知、日曆和小工具

開啟當天的通知是在你的手機上排定的，並且要等待網路連線，因為要先核對日期；關於它的任何資訊都不會傳送到任何地方。「新增到日曆」會開啟你手機的日曆應用程式，並帶有一個現成的活動（膠囊的名稱和開啟日期）。是否儲存由你決定，儲存後它由你的日曆應用程式保管。Kolys 無法讀取你的日曆。主畫面小工具顯示離你最近的膠囊的名稱和剩餘天數；大尺寸最多顯示三個膠囊，附有進度列和開啟日期。

更新

如果自動檢查已開啟（預設為開啟），來自本網站的 Kolys 版本會在你開啟應用程式時檢查 Kolys 網站（pegasohlib.github.io）是否有新版本，最多每 30 分鐘一次。不會在背景檢查。只有當你點「更新」時，它才會從 GitHub 下載更新，並在安裝前檢查檔案的 SHA-256。和任何網站一樣，GitHub 看得到你裝置的 IP 位址；不會傳送其他任何內容，也不會傳送應用程式中的任何資料。

你可以在「設定」中關閉自動檢查。如果應用程式來自 Google Play，則由 Google Play 負責更新。

GitHub 也會統計每個檔案被下載的次數。這只是一個數字，不包含任何關於下載者的資訊；網站會把它顯示為大略的下載量。

Kolys 不會做的事

  • 沒有開發者帳號，也沒有自己的伺服器；
  • 沒有分析，沒有廣告，沒有追蹤，不向任何地方傳送當機報告；
  • 不出售資料，也不向開發者傳送任何內容；
  • 不存取你的聯絡人、檔案或相簿，也不在背景取得位置。

刪除你的資料

  • 在應用程式中刪除膠囊，會立即從你的手機上移除這封信、它的檔案、「此刻」、它的提醒和儲存的禮物暗語，無論你是否已登入。只會留下一個帶有膠囊隨機 ID 的空白列，直到下一次同步。舊版本遺留的內容會在新版本啟動時被清空。
  • 在 Google 雲端硬碟上，膠囊的 zip 會被刪除，並留下一個以 .gone 結尾、以膠囊 ID 命名的小檔案。它只包含「gone」這個詞，用來告訴你的其他手機也刪除該膠囊。在那之後你在另一支手機上變更過的膠囊會保留。一封回信會保留它所回覆的那些信的副本，所以即使刪除原件，它們也不會遺失。
  • 解除安裝應用程式會刪除它存在手機上的所有內容，但不會刪除你 Google Drive 裡的備份、你儲存的備份檔案，也不會刪除你傳給別人的檔案。
  • 如需在不使用應用程式的情況下刪除雲端硬碟中的副本：在網頁上開啟 Google 雲端硬碟 → 設定 → 管理應用程式 → Kolys → 選項 → 刪除隱藏的應用程式資料。
  • 你可以隨時在 myaccount.google.com/connections 撤銷應用程式的存取權。

如果應用程式開始以新的方式處理資料，本頁面會先行更新，並在頂端標註新的日期。
