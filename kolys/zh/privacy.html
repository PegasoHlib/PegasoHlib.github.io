Kolys

隐私政策

最后更新：2026年11月4日

Kolys 是一款用来给未来的自己写信（“时间胶囊”）的 Android 应用。本政策说明应用如何处理你的数据。简而言之：你的信件保留在你的手机上，如果你开启了，也会保存在你自己的 Google 云端硬盘中。礼物、群组胶囊和信件文件是你自己发送的文件，本页会如实说明它们是如何被锁定的。

概览

  • 你的信件、照片、视频和语音消息都保存在你的手机上。
  • Kolys 没有自己的服务器。开发者从不接收你的信件、照片或任何其他数据。
  • 没有广告，没有数据分析，没有跟踪，不出售数据。位置信息只在你要求获取城市和天气时才使用，而且只是大致位置，不会保存。
  • Google 云端硬盘是可选的，并且只能访问应用自己的隐藏文件夹。
  • 封存的信是由应用锁定的，而不是加密的。突破了 Android 应用保护的人可以读取它，Google 也可以读取云端硬盘中的副本。
  • 礼物、群组胶囊和信件文件是你自己发送的文件。开发者永远不会收到它们，但它们带有“此刻”，其中包括手机的名称或型号和电量。

哪些内容留在你的手机上

应用会在你的手机上保存：

  • 你的胶囊和草稿：名称、信件正文、写信日期、开启日期、封印颜色、是否已开启，以及它回复的是哪一封之前的信；
  • 你添加的照片和视频的副本（照片会被缩小），以及你录制的语音消息；
  • “此刻”：你的心情、一首歌，以及你添加的话还有城市和天气，还有始终会包含的手机名称（你给它起的名称，否则是它的厂商和型号）和电量；
  • 朋友发给你的胶囊，以及对于你组织的群组胶囊，到目前为止收集到的信；
  • 你的设置（语言、主题、你用于某个胶囊的生日、已连接 Google 账号的电子邮件地址）。

照片和视频通过 Android 自带的照片选择器选取，所以应用只会看到你选的那些，绝不会看到你的整个相册。麦克风只在你录制语音留言期间使用。所有这些都保存在应用的私有存储空间中，其他应用无法读取，但这些文件本身没有加密。应用会关闭 Android 的自动备份。你在 Kolys 中拍摄的照片和视频由手机的相机应用拍摄；Kolys 本身没有相机权限。

封存的信是如何受到保护的

封存的信是由应用锁定的：Kolys 在到期那天之前不会打开或显示它，并且日期是联网核对的。这是应用里的一把锁，而不是加密。

在你的手机上，信件、照片和录音是应用私有存储空间中的普通文件和数据库条目。突破了 Android 应用保护的人，例如在已获取 root 权限的手机上，或用特殊工具打开的手机上，可以读取它们。你 Google 云端硬盘中的 zip 同样没有加密，所以 Google 可以读取它，就像它可以读取存放在云端硬盘上的任何内容一样。

礼物文件和群组胶囊的工作方式不同，见下文“作为礼物的胶囊”。请不要把任何必须对他人保密的内容放进胶囊。

Google 云端硬盘（可选）

如果你使用 Google 登录，Kolys 只请求一项权限：drive.appdata。它只允许应用在你 Google 云端硬盘的隐藏应用文件夹中创建、读取和删除它自己的文件。应用无法查看或更改你云端硬盘中的任何其他文件。

每个封存的胶囊都会作为一个普通的 zip 文件保存在那里，文件名使用胶囊的随机 ID（信件、它的照片、视频、语音留言和“此刻”），没有加密。开启日期和实际开启的日期也会作为该文件的属性保存。草稿不会上传。有网络时，更改几秒钟后会开始同步，此外大约每天同步两次。这就是在新手机上找回你的封存胶囊的方式。应用还会读取你账号的电子邮件地址，仅用于告诉你连接的是哪个账号。

数据通过加密连接在你的手机和 Google 之间直接传输，中间没有其他服务器。存储在你云端硬盘中的内容适用 Google 自己的隐私政策。

如何使用 Google 数据

Kolys 对从 Google API 获取的信息的使用及向任何其他应用的传输，将遵守 Google API 服务用户数据政策，包括其中的“有限使用”要求。

  • 来自你 Google 云端硬盘的数据只用于保存你的胶囊，并把它们恢复到你的手机上。
  • 这些数据从不出售，从不用于广告，也从不与任何人分享。
  • 没有任何人会阅读它们：开发者无法访问你的云端硬盘或你的信件。

校验日期

为了防止有人通过调整手机时钟提前打开胶囊，应用会向网络服务器（www.google.com 或 www.cloudflare.com）询问当前时间，并从回复中读取日期。胶囊到期那天，在通知你之前，它会再询问一次。不会发送任何关于你或你的胶囊的信息。和任何网络请求一样，这些服务能看到你的 IP 地址。

城市和天气（可选）

只有当你在写信时点击“添加城市和天气”，应用才会向 Android 请求一次你的大致位置（从不请求精确位置）。手机会把它转换成城市名称，应用再向 MET Norway（挪威气象研究所，api.met.no）查询当前天气，发送的位置精确到约一公里。胶囊中只保留城市名称和天气；位置本身不会被保存。你随时可以不添加这些信息。

歌曲搜索（可选）

当你搜索此刻的歌曲时，你输入的文字会发送到开放音乐数据库 MusicBrainz（musicbrainz.org），以查找匹配的歌曲名称。胶囊中只保留歌曲名称、艺人和年份，从不保存封面或录音。“收听”会把歌曲名称传给你手机上的音乐应用（或打开 YouTube Music 搜索），该应用按其自身的规则运行。你也可以不搜索，直接自己输入一首歌。

作为礼物的胶囊

给别人的胶囊会变成一个由你自己通过所选应用（即时通讯应用、电子邮件、Google 云端硬盘）发送的文件。开发者永远不会收到它。该文件包含信件及其照片、视频、语音留言和“此刻”（含手机的名称或型号和电量），以及你的名字（如果你提供）。文件名包含你为收件人或群组输入的名称，即时通讯应用或邮件服务可以看到它。

没有暗语时，文件是加密的，但密钥就保存在文件里面。这只能防止朋友不小心提前解开它，防不住任何拿到文件并且有些本事的人。如果你用暗语锁定它，密钥由暗语生成，不在任何文件中，所以文件的安全程度取决于暗语有多难猜。暗语只保存在你的手机上，这样你可以再次查看，它绝不会进入文件、你的 Google 云端硬盘或发给开发者。只有你写下的提示可以在解锁前被读取。

群组胶囊还会带有群组的名称和你列出的名字。当一个群组共同写一个胶囊时，邀请文件会以未加密的方式包含群组的密钥，所以任何拿到邀请的人都可以读取寄回的信。每个人的信会作为文件发送给收集的人，并用该密钥加密。在胶囊封存之前，收集到的信作为普通文件存放在组织者的应用存储空间中；应用只显示谁写了，不显示写了什么，它们也不会被复制到云端硬盘。

收件人在 Kolys 中打开文件后，他们的副本就存放在他们的应用里，和任何胶囊一样没有加密，如果他们使用的话，也会存放在他们自己的 Google 云端硬盘中。你已发出的文件会留在收件人那里，以及即时通讯应用或邮件服务里；在 Kolys 中删除胶囊无法把它们收回。

通知、日历和小组件

开启当天的通知是在你的手机上安排的，并且要等待网络连接，因为要先核对日期；关于它的任何信息都不会发送到任何地方。“添加到日历”会打开你手机的日历应用，并带有一个现成的事件（胶囊的名称和开启日期）。是否保存由你决定，保存后它由你的日历应用保管。Kolys 无法读取你的日历。主屏幕小组件显示离你最近的胶囊的名称和剩余天数；大尺寸最多显示三个胶囊，带有进度条和开启日期。

更新

如果自动检查已开启（默认开启），来自本网站的 Kolys 版本会在你打开应用时检查 Kolys 网站（pegasohlib.github.io）是否有新版本，最多每 30 分钟一次。不会在后台检查。只有当你点“更新”时，它才会从 GitHub 下载更新，并在安装前检查文件的 SHA-256。和任何网站一样，GitHub 能看到你设备的 IP 地址；不会发送其他任何内容，也不会发送应用中的任何数据。

你可以在“设置”中关闭自动检查。如果应用来自 Google Play，则由 Google Play 负责更新。

GitHub 还会统计每个文件被下载的次数。这只是一个数字，不包含任何关于下载者的信息；网站会把它显示为大致的下载量。

Kolys 不会做的事

  • 没有开发者账号，也没有自己的服务器；
  • 没有分析，没有广告，没有跟踪，不向任何地方发送崩溃报告；
  • 不出售数据，也不向开发者发送任何内容；
  • 不访问你的通讯录、文件或相册，也不在后台获取位置。

删除你的数据

  • 在应用中删除胶囊，会立即从你的手机上移除这封信、它的文件、“此刻”、它的提醒和保存的礼物暗语，无论你是否已登录。只会留下一个带有胶囊随机 ID 的空白行，直到下一次同步。旧版本遗留的内容会在新版本启动时被清空。
  • 在 Google 云端硬盘上，胶囊的 zip 会被删除，并留下一个以 .gone 结尾、以胶囊 ID 命名的小文件。它只包含“gone”这个词，用来告诉你的其他手机也删除该胶囊。在那之后你在另一部手机上更改过的胶囊会保留。一封回信会保留它所回复的那些信的副本，所以即使删除原件，它们也不会丢失。
  • 卸载应用会移除它在手机上存储的所有内容，但不会移除你 Google 云端硬盘中的副本，也不会移除你发给别人的文件。
  • 如需在不使用应用的情况下删除云端硬盘中的副本：在网页上打开 Google 云端硬盘 → 设置 → 管理应用 → Kolys → 选项 → 删除隐藏的应用数据。
  • 你可以随时在 myaccount.google.com/connections 撤销应用的访问权限。

儿童

Kolys 不收集任何人的个人数据，包括儿童。它没有账号，也没有聊天；你发给别人的文件是由你自己发送的。

本政策的变更

如果应用开始以新的方式处理数据，本页面会先行更新，并在顶部标注新的日期。
