コリス

プライバシーポリシー

最終更新: 2026年11月4日

コリスは、未来の自分に宛てて手紙(「タイムカプセル」)を書く Android アプリです。このポリシーは、アプリがあなたのデータをどう扱うかを説明します。要するに、手紙はあなたのスマホに残り、オンにすれば、あなた自身の Google ドライブにも保存されます。贈り物、グループカプセル、手紙のファイルは、あなた自身が送るファイルであり、このページでは、それらがどのようにロックされるかを率直に説明します。

概要

  • 手紙、写真、動画、ボイスメッセージは、あなたのスマホに保存されます。
  • コリスには独自のサーバーがありません。開発者があなたの手紙や写真、その他のデータを受け取ることは一切ありません。
  • 広告も、分析も、トラッキングも、データの販売もありません。位置情報は、都市と天気を求めたときだけ、おおまかに使われ、保存されません。
  • Google ドライブは任意で、アプリが使うのは専用の非表示フォルダだけです。
  • 封をした手紙は、アプリがロックしているだけで、暗号化されてはいません。Android のアプリ保護を突破した人は読めてしまいますし、Google は Drive のコピーを読めます。
  • 贈り物、グループカプセル、手紙のファイルは、あなた自身が送るファイルです。開発者がそれらを受け取ることはありませんが、スマホの名前または機種名と電池残量を含む「瞬間」が付いています。

スマホに保存されるもの

アプリは次のものをスマホに保存します。

  • カプセルと下書き：名前、手紙の本文、書いた日、開封日、封の色、開封済みかどうか、どの過去の手紙への返信か
  • 追加した写真と動画のコピー（写真は縮小）と、録音したボイスメッセージ
  • 「この瞬間」: あなたの気分、曲、追加した場合は都市と天気、そして常にスマホの名前(あなたが付けた名前、なければメーカーと機種名)と電池残量。
  • 友人があなたに送ったカプセルと、あなたが主催するグループカプセルについては、これまでに集まった手紙。
  • 設定（言語、テーマ、カプセルに使う場合は誕生日、接続している Google アカウントのメールアドレス）

写真と動画は Android 標準のフォトピッカーで選ぶため、アプリが見るのは選んだものだけで、ギャラリー全体を見ることは決してありません。マイクは、音声メッセージを録音している間だけ使われます。これらはすべて、ほかのアプリが読み取れないアプリ専用ストレージに保存されますが、ファイル自体は暗号化されていません。アプリは Android の自動バックアップをオフにします。コリスで撮る写真や動画は、スマホのカメラアプリが撮影するもので、コリス自体にはカメラの権限がありません。

封をした手紙はどのように守られるか

封をした手紙は、アプリがロックします。コリスはその日より前には開いたり表示したりせず、日付はオンラインで確認されます。これはアプリの中のロックであり、暗号化ではありません。

スマホ上では、手紙、写真、録音は、アプリ専用ストレージにある通常のファイルとデータベースのエントリです。たとえばルート化されたスマホや特殊なツールで開かれたスマホで、Android のアプリ保護を突破した人は、それらを読めてしまいます。あなたの Google ドライブにある zip も暗号化されていないため、Drive に保存されたほかのものと同じように、Google が読めます。

贈り物のファイルとグループカプセルは仕組みが異なります。下の「贈り物としてのカプセル」をご覧ください。他の人に読まれてはならないものは、カプセルに入れないでください。

Google ドライブ（任意）

Google でログインすると、コリスは drive.appdata という 1 つの権限だけを求めます。この権限により、アプリは Google ドライブ内の非表示のアプリ用フォルダで、自分のファイルだけを作成、読み取り、削除できます。ドライブ内のほかのファイルを見たり変更したりすることはできません。

封をしたカプセルは、1つずつ、カプセルのランダムな ID を名前にした通常の zip ファイル1つ(手紙、写真、動画、音声メッセージ、「この瞬間」)として、そこに保存され、暗号化されません。開封日と、開封された日付も、ファイルのプロパティとして保存されます。下書きはアップロードされません。同期は、インターネットがあれば変更の数秒後と、1日に2回ほど始まります。これにより、新しいスマホで封をしたカプセルが戻ってきます。アプリは、どのアカウントが接続されているかを表示するためだけに、アカウントのメールアドレスも読み取ります。

データは暗号化された接続で、スマホと Google の間で直接やり取りされます。間にほかのサーバーはありません。ドライブに保存された内容には、Google 自身のプライバシー ポリシーが適用されます。

Google データの使い方

Google API から受け取った情報のコリスによる使用、およびほかのアプリへの転送は、限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

  • Google ドライブのデータは、カプセルを保存し、あなたのスマホに戻すためだけに使われます。
  • 販売されることも、広告に使われることも、誰かと共有されることも決してありません。
  • 人がデータを読むことはありません。開発者はあなたのドライブにも手紙にもアクセスできません。

日付の確認

スマホの時計を動かしてカプセルを早く開けられないように、アプリはウェブサーバー(www.google.com または www.cloudflare.com)に現在時刻を問い合わせ、返答から日付を読み取ります。カプセルの日が来ると、お知らせする前にもう一度問い合わせます。あなたやカプセルに関する情報は送信されません。どのウェブリクエストとも同じく、これらのサービスはあなたの IP アドレスを見ることができます。

都市と天気（任意）

書いている途中で「都市と天気を追加」をタップしたときだけ、アプリは Android におおよその位置情報を 1 回だけ求めます（正確な位置情報は決して求めません）。スマホがそれを都市名に変換し、アプリは約 1 キロメートル単位に丸めた位置情報を MET Norway（ノルウェー気象研究所、api.met.no）に送って、現在の天気を問い合わせます。カプセルに保存されるのは都市名と天気だけで、位置情報そのものは保存されません。この項目はいつでも省略できます。

曲の検索（任意）

その瞬間の曲を探すとき、入力した言葉は、一致する曲名を見つけるために、オープンな音楽データベース MusicBrainz（musicbrainz.org）に送信されます。カプセルに保存されるのは曲名、アーティスト名、年だけで、ジャケット画像や音源が保存されることはありません。「聴く」は曲名をスマホの音楽アプリに渡し（または YouTube Music の検索を開き）、そのアプリは独自のルールに従って動作します。検索せずに、曲を自分で入力することもできます。

カプセルを贈る

他の人に宛てたカプセルは、あなたが選んだアプリ(メッセンジャー、メール、Google ドライブ)で、あなた自身が送るひとつのファイルになります。開発者がそれを受け取ることはありません。ファイルには、写真、動画、音声メッセージ、「この瞬間」(スマホの名前または機種名と電池残量を含む)を伴う手紙と、入力した場合はあなたの名前が入っています。ファイル名には、受取人またはグループについて入力した名前が含まれ、メッセンジャーやメールのサービスはそれを見ることができます。

合言葉がない場合、ファイルは暗号化されますが、鍵はファイルの中に保存されています。これは、友人が誤って早く開いてしまうのを防ぐだけで、ファイルを持っていて多少の技術がある人を防ぐものではありません。合言葉でロックすると、鍵はその言葉から作られ、どのファイルにも入りません。そのため、ファイルは合言葉が推測されにくいほど安全です。合言葉はあなたのスマホにだけ残るので、再び確認でき、ファイル、あなたの Google ドライブ、開発者には決して渡りません。ロック解除の前に読めるのは、あなたが書いたヒントだけです。

グループ宛てのカプセルには、グループの名前と、あなたが挙げた名前も含まれます。グループで一緒にカプセルを書く場合、招待ファイルにはグループの鍵が暗号化されずに入っているため、招待を持っている人は、送り返された手紙を読めます。各人の手紙は、その鍵で暗号化されて、集める人にファイルとして届きます。カプセルに封がされるまで、集まった手紙は、主催者のアプリのストレージに通常のファイルとして置かれます。アプリは誰が書いたかだけを表示し、何を書いたかは表示せず、これらは Drive にコピーされません。

受取人がコリスでファイルを開くと、そのコピーは受取人のアプリの中に、ほかのカプセルと同じく暗号化されずに保存され、使っている場合は、その人自身の Google ドライブにも保存されます。あなたが送ったファイルは、受取人と、メッセンジャーやメールのサービスに残ります。コリスでカプセルを削除しても、それらを取り戻すことはできません。

通知、カレンダー、ウィジェット

開封日の通知は、あなたのスマホ上で予約され、先に日付を確認するため、インターネット接続を待ちます。それに関する情報はどこにも送信されません。「カレンダーに追加」は、用意された予定(カプセルの名前と開封日)とともに、スマホのカレンダーアプリを開きます。保存するかどうかはあなたが決め、保存するとカレンダーアプリがそれを保持します。コリスはあなたのカレンダーを読み取れません。ホーム画面のウィジェットは、いちばん近いカプセルの名前と残り日数を表示し、大きいものは、進捗バーと開封日とともに最大3つのカプセルを表示します。

アップデート

自動確認がオン(初期設定ではオンです)の場合、このウェブサイトのコリスのバージョンは、アプリを開いたときに、コリスのウェブサイト(pegasohlib.github.io)で新しいバージョンを確認します。30分に1回以下です。バックグラウンドでの確認はありません。アップデートは、「更新」をタップしたときだけ GitHub からダウンロードされ、インストール前にファイルの SHA-256 が確認されます。どのウェブサイトとも同様に、GitHub はデバイスの IP アドレスを見ることができます。それ以外は何も送信されず、アプリのデータも送信されません。

自動確認は「設定」でオフにできます。Google Play から入手したアプリの場合は、Google Play がアップデートを行います。

GitHub は各ファイルがダウンロードされた回数も数えています。これは数字だけで、誰がダウンロードしたかは含まれません。ウェブサイトではおおよそのダウンロード数として表示します。

コリスがしないこと

  • 開発者側のアカウントも、独自のサーバーもありません。
  • 分析、広告、トラッキングはなく、クラッシュレポートもどこにも送信しません。
  • データの販売はなく、開発者に送信されるものもありません。
  • 連絡先、ファイル、ギャラリーにはアクセスせず、バックグラウンドで位置情報を取得することもありません。

データの削除

  • アプリでカプセルを削除すると、ログインしているかどうかにかかわらず、手紙、そのファイル、「この瞬間」、リマインダー、保存された贈り物の合言葉が、すぐにスマホから削除されます。カプセルのランダムな ID が入った空の行だけが、次の同期まで残ります。古いバージョンが残したものは、新しいバージョンの起動時に空にされます。
  • Google ドライブでは、カプセルの zip が削除され、カプセルの ID と拡張子 .gone が付いた小さなファイルが残ります。このファイルには「gone」という言葉だけが入っていて、ほかのスマホにもカプセルを削除するよう伝えます。そのあと別のスマホで変更したカプセルは残ります。返信は、返信先の手紙のコピーを自分で保持するため、元の手紙を削除しても残ります。
  • アプリをアンインストールすると、アプリがスマホに保存したものはすべて削除されますが、あなたの Google ドライブにあるコピーと、他の人に送ったファイルは削除されません。
  • アプリを使わずにドライブのコピーを削除するには：ウェブで Google ドライブを開く → 設定 → アプリの管理 → コリス（Kolys） → オプション → 非表示のアプリデータを削除。
  • アプリのアクセス権は myaccount.google.com/connections でいつでも取り消せます。

お子さま

コリスは、子どもを含め、誰からも個人データを収集しません。アカウントもチャットもありません。誰かに送るファイルは、あなた自身が送るものです。

ポリシーの変更

アプリがデータに関して新しいことを始める場合は、まずこのページを更新し、上部の日付を新しくします。
