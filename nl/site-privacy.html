Privacy van de site

Laatst bijgewerkt: 6 november 2026

Deze pagina gaat over de website pegasohlib.com: de hoofdpagina en de apppagina’s. Kort gezegd: geen accounts, geen cookies, geen advertenties en geen analyse. Wat elke app of elk spel met gegevens doet, wordt uitgelegd in zijn eigen privacybeleid, hieronder vermeld.

In het kort

  • De site plaatst geen cookies en heeft geen advertenties, analyse of knoppen voor sociale media.
  • Je gekozen taal en thema blijven in je eigen browser en worden nergens naartoe verstuurd.
  • Cloudflare levert de site af en ziet de IP-adressen van bezoekers. GitHub bewaart de bestanden en ziet je IP-adres alleen bij een download of op het oude adres.
  • Bestanden worden van GitHub gedownload, dus GitHub ziet en telt elke download.
  • Als je een e-mail stuurt, wordt die alleen gebruikt om je te antwoorden.

Wat er in je browser wordt opgeslagen

Als je een taal kiest of het thema wisselt, slaat de site die keuze op in de lokale opslag van je browser, zodat de pagina’s de volgende keer op dezelfde manier openen. Er wordt niets opgeslagen voordat je een keuze maakt.

siteLang
De taal die je hebt gekozen.
pegasohlib-theme
Het lichte of donkere thema dat je hebt gekozen.

Waarom er geen toestemmingsbanner is

Deze twee items zijn geen cookies. Ze bevatten geen identificatiecode, worden naar geen enkele server verstuurd en volgen je niet naar andere websites. Ze bewaren alleen een instelling die je zelf hebt gekozen, dus de site vraagt niet om toestemming. Om ze te verwijderen, wis je de gegevens van deze site in de instellingen van je browser.

Hosting

De site draait op GitHub Pages, een dienst van GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub legt om veiligheidsredenen het IP-adres vast van iedereen die er rechtstreeks verbinding mee maakt, ook zonder GitHub-account. PegasoHlib heeft geen toegang tot deze logs. GitHub is verantwoordelijk voor deze gegevens: zie de GitHub Privacy Statement.

Bezoekers van pegasohlib.com bereiken de site via Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA: je browser maakt verbinding met Cloudflare, dat de pagina bij GitHub ophaalt. Daarom ziet Cloudflare je IP-adres, de pagina die je opent en de technische gegevens die elke browser verstuurt. Het verwerkt die namens PegasoHlib, onder zijn verwerkersovereenkomst, om de site via een beveiligde verbinding af te leveren en tegen aanvallen te beschermen (gerechtvaardigd belang). PegasoHlib ziet alleen algemene totalen, plus de gegevens van een verzoek dat Cloudflare blokkeert. Cloudflare plaatst hier geen cookies, tenzij zijn beveiliging een bezoeker vraagt een veiligheidscontrole te doorstaan: dan toont het een eigen controlepagina en kan het een strikt noodzakelijke cookie plaatsen, cf_clearance. Bij deze bezoeken krijgt GitHub je IP-adres niet: het ziet alleen Cloudflare. Je browser maakt alleen rechtstreeks verbinding met GitHub bij downloads en op het oude adres pegasohlib.github.io. Zie de Cloudflare Privacy Policy.

Downloads en aantallen

Downloadknoppen leiden naar bestanden die op GitHub staan. Als je erop drukt, maakt je browser verbinding met GitHub, en GitHub verhoogt de teller van dat bestand met één. PegasoHlib ziet alleen het totaal per bestand, nooit wie het heeft gedownload.

Downloadtotalen, waar een pagina ze toont, worden toegevoegd wanneer de site wordt gebouwd, dus je browser neemt er geen contact met de API van GitHub voor op. Versienummers en bestandsgroottes worden gelezen uit bestanden op diezelfde site.

Wat de site niet gebruikt

  • cookies;
  • advertenties;
  • analysetools of het volgen van bezoekers;
  • knoppen voor sociale media of ingesloten video’s;
  • lettertypen of scripts van andere bedrijven: de lettertypen worden door deze site zelf geleverd;
  • accounts of formulieren.

Als je een e-mail stuurt

E-mail naar het contactadres gaat via Cloudflare, dat de DNS en mailroutering van dit domein beheert. Een klein programma daar leest de headers van het bericht en kan je een automatisch antwoord sturen. Het bericht wordt doorgestuurd naar een Gmail-postvak, dus Google verwerkt het ook. PegasoHlib kan een AI-assistent, Claude van Anthropic, gebruiken als hulp bij het lezen van e-mail. PegasoHlib gebruikt je adres en je bericht alleen om je te antwoorden en om op te lossen wat je meldt (gerechtvaardigd belang), en deelt ze met niemand anders. Je kunt op elk moment vragen om ze te verwijderen.

Je rechten en de juridische details

Wie verantwoordelijk is. PegasoHlib, een particulier die deze apps ontwikkelt, is verantwoordelijk voor de gegevens die hier worden beschreven. Contact: support@pegasohlib.com.

Wie gegevens ontvangt, en doorgifte buiten de EU. GitHub host de bestanden van deze site en ziet het IP-adres van iedereen die er rechtstreeks verbinding mee maakt. Cloudflare beheert de DNS van dit domein en stuurt e-mails naar het contactadres door, Google bewaart ze in een Gmail-postvak en Anthropic kan ze verwerken als de AI-assistent helpt ze te lezen. Alle vier zijn gevestigd in de Verenigde Staten. Die doorgiften berusten op het EU-VS-kader voor gegevensprivacy, als het bedrijf eraan deelneemt, of op de standaardcontractbepalingen van het bedrijf. Dezelfde waarborgen gelden voor Cloudflare wanneer het deze site aflevert en de IP-adressen van bezoekers ziet.

Hoe lang ze worden bewaard. E-mails die je stuurt worden bewaard tot de kwestie is afgehandeld, en niet langer dan 2 jaar. GitHub bewaart zijn logbestanden volgens zijn eigen regels. Dat geldt ook voor Cloudflare.

Je rechten. Je kunt vragen om inzage in je gegevens, correctie, verwijdering, beperking van de verwerking en een kopie om elders mee naartoe te nemen (overdraagbaarheid), en je kunt bezwaar maken tegen de verwerking. Schrijf naar het adres hierboven. Je krijgt binnen een maand antwoord. PegasoHlib bewaart alleen persoonsgegevens over jou als je een e-mail hebt gestuurd of ZORYT speelt; wat het spel opslaat, staat in het privacybeleid ervan. Neem voor hosting- en downloadgegevens contact op met GitHub. Schrijf voor gegevens die Cloudflare bewaart bij het afleveren van de site naar het adres hierboven, dan geeft PegasoHlib je verzoek door.

Klachten. Je kunt een klacht indienen bij de toezichthouder voor gegevensbescherming in je land.
