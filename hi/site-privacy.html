साइट की निजता

अंतिम अपडेट: 5 नवंबर 2026

यह पेज वेबसाइट pegasohlib.com के बारे में है: मुख्य पेज और ऐप के पेज। संक्षेप में: कोई अकाउंट नहीं, कोई कुकी नहीं, कोई विज्ञापन नहीं और कोई एनालिटिक्स नहीं। हर ऐप या गेम डेटा के साथ क्या करता है, यह उसकी अपनी गोपनीयता नीति में समझाया गया है, जो नीचे सूचीबद्ध है।

एक नज़र में

  • साइट कोई कुकी नहीं रखती, और इसमें विज्ञापन, एनालिटिक्स या सोशल मीडिया बटन नहीं हैं।
  • आपकी चुनी हुई भाषा और थीम आपके अपने ब्राउज़र में ही रहती हैं और कहीं नहीं भेजी जातीं।
  • Cloudflare साइट पहुँचाता है और आने वालों के IP पते देखता है। GitHub फ़ाइलें रखता है और आपका IP पता केवल डाउनलोड के समय या पुराने पते पर देखता है।
  • फ़ाइलें GitHub से डाउनलोड होती हैं, इसलिए GitHub हर डाउनलोड देखता और गिनता है।
  • अगर आप ईमेल भेजते हैं, तो उसका इस्तेमाल सिर्फ़ आपको जवाब देने के लिए होता है।

इस पेज पर

आपके ब्राउज़र में क्या सेव होता हैसहमति बैनर क्यों नहीं हैहोस्टिंगडाउनलोड और आँकड़ेसाइट क्या इस्तेमाल नहीं करतीअगर आप ईमेल भेजते हैंऐप और गेम की गोपनीयता नीतियाँआपके अधिकार और कानूनी ब्यौरेबदलाव और संपर्क

सहमति बैनर क्यों नहीं है

ये दोनों प्रविष्टियाँ कुकी नहीं हैं। इनमें कोई पहचानकर्ता नहीं होता, ये किसी सर्वर को नहीं भेजी जातीं, और ये दूसरी वेबसाइटों पर आपके पीछे नहीं जातीं। ये सिर्फ़ वह सेटिंग रखती हैं जो आपने खुद चुनी है, इसलिए साइट सहमति नहीं माँगती। इन्हें हटाने के लिए अपने ब्राउज़र की सेटिंग में इस साइट का डेटा साफ़ करें।

होस्टिंग

साइट GitHub Pages पर चलती है, जो GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA की सेवा है। GitHub सुरक्षा के उद्देश्य से उससे सीधे जुड़ने वाले हर व्यक्ति का IP पता लॉग करता है, चाहे उसका GitHub अकाउंट हो या नहीं। PegasoHlib की इन लॉग तक कोई पहुँच नहीं है। इस डेटा की ज़िम्मेदारी GitHub की है: देखें GitHub Privacy Statement।

pegasohlib.com पर आने वाले लोग Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA के ज़रिए साइट तक पहुँचते हैं: आपका ब्राउज़र Cloudflare से जुड़ता है, और Cloudflare पेज GitHub से लाता है। इसलिए Cloudflare आपका IP पता, आपके खोले गए पेज और वे तकनीकी जानकारियाँ देखता है जो हर ब्राउज़र भेजता है। वह अपने डेटा प्रोसेसिंग समझौते के तहत PegasoHlib की ओर से इन्हें प्रोसेस करता है, ताकि साइट सुरक्षित कनेक्शन पर पहुँचे और हमलों से बची रहे (वैध हित)। PegasoHlib केवल कुल आँकड़े देखता है, और Cloudflare द्वारा रोके गए अनुरोध का विवरण। Cloudflare यहाँ कुकी नहीं लगाता, जब तक कि उसकी सुरक्षा किसी आने वाले से सुरक्षा जाँच पूरी करने को न कहे: तब वह अपना जाँच पेज दिखाता है और एक अनिवार्य कुकी cf_clearance लगा सकता है। ऐसी विज़िट में GitHub को आपका IP पता नहीं मिलता: वह केवल Cloudflare को देखता है। आपका ब्राउज़र सीधे GitHub से केवल डाउनलोड के समय और पुराने पते pegasohlib.github.io पर जुड़ता है। देखें Cloudflare Privacy Policy।

डाउनलोड और आँकड़े

डाउनलोड बटन GitHub पर रखी फ़ाइलों तक ले जाते हैं। जब आप कोई बटन दबाते हैं, तो आपका ब्राउज़र GitHub से जुड़ता है, और GitHub उस फ़ाइल के काउंटर में एक जोड़ देता है। PegasoHlib को हर फ़ाइल का सिर्फ़ कुल योग दिखता है, यह कभी नहीं कि उसे किसने डाउनलोड किया।

डाउनलोड की कुल संख्या, जहाँ कोई पेज उसे दिखाता है, साइट बनते समय जोड़ी जाती है, इसलिए आपका ब्राउज़र उसके लिए GitHub के API से संपर्क नहीं करता। वर्ज़न नंबर और फ़ाइल के साइज़ इसी साइट की फ़ाइलों से पढ़े जाते हैं।

अगर आप ईमेल भेजते हैं

संपर्क के पते पर भेजा गया मेल Cloudflare से होकर जाता है, जो इस डोमेन का DNS और मेल रूटिंग चलाता है। वहाँ एक छोटा प्रोग्राम संदेश के हेडर पढ़ता है और आपको स्वचालित जवाब भेज सकता है। संदेश एक Gmail मेलबॉक्स में फ़ॉरवर्ड किया जाता है, इसलिए उसे Google भी संभालता है। मेल पढ़ने में मदद के लिए PegasoHlib एक AI सहायक, Anthropic के Claude, का इस्तेमाल कर सकता है। PegasoHlib आपका पता और आपका संदेश सिर्फ़ आपको जवाब देने और आपके बताए मुद्दे को ठीक करने के लिए इस्तेमाल करता है (वैध हित), और इन्हें किसी और से साझा नहीं करता। आप किसी भी समय इन्हें हटाने के लिए कह सकते हैं।

आपके अधिकार और कानूनी ब्यौरे

कौन ज़िम्मेदार है। इन ऐप्स को बनाने वाला निजी व्यक्ति PegasoHlib यहाँ बताए गए डेटा के लिए ज़िम्मेदार है। संपर्क: support@pegasohlib.com।

डेटा कौन पाता है, और EU के बाहर ट्रांसफ़र। GitHub इस साइट की फ़ाइलें होस्ट करता है और उससे सीधे जुड़ने वाले हर व्यक्ति का IP पता देखता है। Cloudflare इस डोमेन का DNS चलाता है और संपर्क के पते पर भेजा गया मेल आगे पहुँचाता है, Google उसे Gmail मेलबॉक्स में रखता है, और जब AI सहायक उसे पढ़ने में मदद करता है तब Anthropic उसे प्रोसेस कर सकता है। चारों संयुक्त राज्य अमेरिका में स्थित हैं। ये ट्रांसफ़र EU–US डेटा प्राइवेसी फ़्रेमवर्क (Data Privacy Framework) पर आधारित हैं, जहाँ कंपनी उसमें भाग लेती है, या कंपनी की मानक संविदात्मक धाराओं पर। जब Cloudflare यह साइट पहुँचाता है और आने वालों के IP पते देखता है, तब उस पर भी यही सुरक्षा उपाय लागू होते हैं।

कितने समय तक रखा जाता है। आपके भेजे ईमेल मामला बंद होने तक रखे जाते हैं, और 2 साल से अधिक नहीं। GitHub अपने लॉग अपने नियमों के अनुसार रखता है। Cloudflare भी ऐसा ही करता है।

आपके अधिकार। आप अपने डेटा तक पहुँच, सुधार, हटाने, प्रसंस्करण पर रोक, और कहीं और ले जाने के लिए कॉपी (पोर्टेबिलिटी) माँग सकते हैं, और आप प्रसंस्करण पर आपत्ति कर सकते हैं। ऊपर दिए पते पर लिखें। आपको एक महीने के भीतर जवाब मिलेगा। PegasoHlib के पास आपके बारे में निजी डेटा तभी होता है जब आपने ईमेल भेजा हो या आप ZORYT खेलते हों; वह क्या सहेजता है, यह उसकी गोपनीयता नीति बताती है। होस्टिंग और डाउनलोड के डेटा के लिए GitHub से संपर्क करें। साइट पहुँचाते समय Cloudflare के पास रहने वाले डेटा के लिए ऊपर दिए पते पर लिखें, PegasoHlib आपका अनुरोध आगे भेज देगा।

शिकायतें। आप किसी डेटा सुरक्षा प्राधिकरण से शिकायत कर सकते हैं, जैसे फ़्रांस का CNIL या आपके अपने देश का प्राधिकरण।
