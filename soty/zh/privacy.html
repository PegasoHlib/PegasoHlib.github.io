隐私政策

更新于2026年11月12日

SOTY: Honeycomb Kingdoms 是一款在你的浏览器中运行的策略游戏，网址为 pegasohlib.com/soty/play/，由一位开发者（PegasoHlib）制作。游戏没有账号、广告和数据分析。它只把你的游戏保存在你自己的浏览器里，不会发送到任何地方。本政策适用于当前版本：与电脑对战，以及和朋友在同一台设备上游玩。

概览

  • 你的存档和设置保留在你的浏览器中，就在你的设备上。开发者永远不会收到它们。
  • 没有账号、广告、数据分析或跟踪，游戏也不设置 Cookie。
  • 在你游玩期间，游戏完全不发出任何请求。只有页面本身会从 pegasohlib.com 加载，和本网站的其他页面一样。
  • 暂停菜单中的清除游戏数据会删除游戏在你设备上保存的所有内容。
  • 此版本没有在线游戏。在线游戏推出之前，本政策会先作出修改。

游戏在你的设备上保存了什么

游戏会把你的游戏进度和设置保存在浏览器为 pegasohlib.com 提供的本地存储中，这样你可以关闭页面，稍后继续。每个条目的名称都以 soty. 开头：

soty.save
正在进行的游戏：地图、各个国家及其民族、部队、城市、条约、回合数和最近一次保存的时间。游戏会在你游玩时写入它，在你开始新游戏时将其替换，并在一局游戏结束时将其删除。
soty.prefs
设置：提示是否开启以及你已经看过哪些提示、电脑行动速度、画质等级（或自动选择的等级）、是否显示小地图，以及上一局的设置。
soty.sound
声音是否开启。
soty.lang
游戏语言，只有在你于游戏中切换语言时才会保存。
soty.test
游戏启动时写入并立即删除，用来检查浏览器是否允许保存。

没有任何关于你的信息

这些条目不包含姓名、电子邮件、位置或其他关于你的信息。各个国家以颜色命名（蓝方、红方……）。唯一可以输入内容的地方是地图代码：游戏保存的是从代码中读取的地图设置，而不是你输入的内容。游戏还会读取 siteLang，也就是你可能在本网站上选择的语言，以便用该语言打开；游戏从不更改它。

开发者永远不会收到其中任何内容，其他网站也无法读取：浏览器会把每个网站的存储彼此分开。任何在你的设备上使用同一浏览器的人，都可以打开游戏并看到存档。

为什么游戏不征求同意

上述条目不是 Cookie，也从不发送到任何地方。它们是提供你所打开的游戏绝对必需的：没有它们，你一关闭页面，游戏进度和设置就会丢失。根据欧盟规则，这类存储无需征得同意（《电子隐私指令》第 5(3) 条）。

清除你的数据

在游戏中：暂停菜单 → 清除游戏数据。游戏会先请你确认，然后删除这台设备上所有 soty. 条目，并重新加载页面。

在浏览器中：清除本网站的数据（pegasohlib.com 的 Cookie 和网站数据）也会删除游戏的条目，连同你在网站上选择的语言和主题。

在隐私浏览窗口中，浏览器会在你关闭窗口时删除所有内容。

游戏会联系什么

打开游戏时，会从 pegasohlib.com 加载游戏页面。它是一个内置了所有内容的文件，包括开源 3D 库 three.js：不会从其他公司加载任何内容，因此没有外部的字体、脚本、图片、广告或数据分析。页面还会从 pegasohlib.com 加载它的应用清单和一个图标，以便浏览器可以提示你安装游戏。此后在你游玩期间，游戏不会发出任何请求：地图、电脑对手和声音都在你的设备上计算。

页面通过 Cloudflare 传送给你，Cloudflare 能看到你的 IP 地址和你打开的页面，正如网站隐私页面所说明的。在旧地址 pegasohlib.github.io 上，则改由 GitHub 传送页面，GitHub 能看到你的 IP 地址。游戏本身不会发送任何自己的数据：没有存档，没有设置，也没有标识符。

安装游戏

你的浏览器可能会提示你安装游戏，或将其添加到主屏幕。这只会创建一个快捷方式，以不带地址栏的方式打开同一个页面。游戏仍然使用你设备上的同一存储空间，也不会向任何地方发送任何内容。

在线游戏

此版本没有在线游戏。通过链接与朋友一起玩的模式已在计划中。在其推出之前，本政策会说明在线游戏发送和保存哪些内容，页面顶部的日期也会随之更改。
