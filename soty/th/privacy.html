SOTY: Honeycomb Kingdoms เป็นเกมกลยุทธ์ที่เล่นในเบราว์เซอร์ของคุณได้ที่ pegasohlib.com/soty/play/ สร้างโดยผู้พัฒนาคนเดียว (PegasoHlib) เกมไม่มีบัญชี โฆษณา หรือระบบวิเคราะห์ ตัวเกมเก็บเกมที่บันทึกไว้ของคุณในเบราว์เซอร์ของคุณเองเท่านั้น และไม่ส่งไปที่ใดเลย นโยบายนี้ครอบคลุมเวอร์ชันปัจจุบัน: การเล่นกับบอตและการเล่นกับเพื่อนบนอุปกรณ์เครื่องเดียว

สรุปสั้น ๆ

  • เกมที่บันทึกไว้และการตั้งค่าของคุณอยู่ในเบราว์เซอร์ของคุณ บนอุปกรณ์ของคุณ ผู้พัฒนาไม่เคยได้รับข้อมูลเหล่านี้
  • ไม่มีบัญชี ไม่มีโฆษณา ไม่มีระบบวิเคราะห์ ไม่มีการติดตาม และเกมไม่ตั้งคุกกี้ใด ๆ
  • ระหว่างที่คุณเล่น เกมไม่ส่งคำขอใด ๆ เลย มีเพียงตัวหน้าเว็บเท่านั้นที่โหลดจาก pegasohlib.com เหมือนหน้าอื่น ๆ ของเว็บไซต์
  • ปุ่ม ลบข้อมูลเกม ในเมนูหยุดชั่วคราวจะลบทุกอย่างที่เกมบันทึกไว้บนอุปกรณ์ของคุณ
  • เวอร์ชันนี้ไม่มีการเล่นออนไลน์ ก่อนที่การเล่นออนไลน์จะมาถึง นโยบายนี้จะเปลี่ยนแปลง

ในหน้านี้

สิ่งที่เกมเก็บไว้บนอุปกรณ์ของคุณไม่มีข้อมูลเกี่ยวกับตัวคุณทำไมเกมจึงไม่ขอความยินยอมการลบข้อมูลของคุณเกมติดต่อกับอะไรการติดตั้งเกมการเล่นออนไลน์สิทธิของคุณและรายละเอียดทางกฎหมายการเปลี่ยนแปลงและการติดต่อ

ข้อมูลอะไร อยู่ที่ไหน ใครเห็น

ข้อมูลเก็บไว้ที่ไหนใครเห็นได้
เกมที่บันทึกไว้: แผนที่ รัฐต่าง ๆ หน่วยของแต่ละรัฐ ตาปัจจุบัน และเวลาที่บันทึกล่าสุดพื้นที่เก็บข้อมูลของเบราว์เซอร์คุณสำหรับเว็บไซต์นี้ (soty.save)คุณคนเดียว บนอุปกรณ์นี้
การตั้งค่า: เคล็ดลับ ความเร็วของบอต ระดับกราฟิก แผนที่ย่อ การตั้งค่าของเกมล่าสุดพื้นที่เก็บข้อมูลของเบราว์เซอร์คุณสำหรับเว็บไซต์นี้ (soty.prefs)คุณคนเดียว บนอุปกรณ์นี้
การเปิดหรือปิดเสียง ภาษาของเกมพื้นที่เก็บข้อมูลของเบราว์เซอร์คุณสำหรับเว็บไซต์นี้ (soty.sound, soty.lang)คุณคนเดียว บนอุปกรณ์นี้
ที่อยู่ IP ของคุณและหน้าที่คุณเปิด ระหว่างที่หน้ากำลังโหลดระบบของ Cloudflare ซึ่งส่งมอบเว็บไซต์Cloudflare; PegasoHlib เห็นเพียงยอดรวมโดยรวมและคำขอที่ Cloudflare บล็อก
อีเมลที่คุณส่งมากล่องจดหมาย GmailPegasoHlib เพื่อตอบกลับคุณ

สิ่งที่เกมเก็บไว้บนอุปกรณ์ของคุณ

เกมบันทึกเกมและการตั้งค่าของคุณไว้ใน local storage ของเบราว์เซอร์สำหรับ pegasohlib.com เพื่อให้คุณปิดหน้าเว็บแล้วกลับมาเล่นต่อได้ภายหลัง ชื่อของแต่ละรายการขึ้นต้นด้วย soty.:

soty.save
เกมที่กำลังเล่นอยู่: แผนที่ รัฐต่าง ๆ และชนชาติของรัฐเหล่านั้น หน่วย เมือง สนธิสัญญา หมายเลขตา และเวลาที่บันทึกล่าสุด เกมเขียนรายการนี้ระหว่างที่คุณเล่น เขียนทับเมื่อคุณเริ่มเกมใหม่ และลบเมื่อเกมจบลง
soty.prefs
การตั้งค่า: เปิดเคล็ดลับอยู่หรือไม่และคุณเห็นเคล็ดลับใดไปแล้วบ้าง ความเร็วของบอต ระดับกราฟิก (หรือระดับที่เลือกให้โดยอัตโนมัติ) แสดงแผนที่ย่อหรือไม่ และการตั้งค่าของเกมล่าสุด
soty.sound
เปิดเสียงอยู่หรือไม่
soty.lang
ภาษาของเกม บันทึกเฉพาะเมื่อคุณเปลี่ยนภาษาในเกม
soty.test
เขียนแล้วลบทันทีเมื่อเกมเริ่มทำงาน เพื่อตรวจสอบว่าเบราว์เซอร์อนุญาตให้บันทึกได้หรือไม่

ไม่มีข้อมูลเกี่ยวกับตัวคุณ

รายการเหล่านี้ไม่มีชื่อ อีเมล ตำแหน่ง หรือรายละเอียดอื่นใดเกี่ยวกับตัวคุณ รัฐต่าง ๆ ถูกเรียกตามสี (น้ำเงิน แดง…) ช่องเดียวที่คุณพิมพ์ได้คือรหัสแผนที่ เกมจะเก็บการตั้งค่าแผนที่ที่อ่านได้จากรหัส ไม่ใช่สิ่งที่คุณพิมพ์ เกมยังอ่าน siteLang ซึ่งเป็นภาษาที่คุณอาจเลือกไว้บนเว็บไซต์นี้ เพื่อเปิดเป็นภาษานั้น โดยไม่เคยเปลี่ยนค่านี้

ผู้พัฒนาไม่เคยได้รับข้อมูลใด ๆ เหล่านี้ และเว็บไซต์อื่นอ่านข้อมูลนี้ไม่ได้ เพราะเบราว์เซอร์แยกพื้นที่เก็บข้อมูลของแต่ละเว็บไซต์ออกจากกัน ใครก็ตามที่ใช้เบราว์เซอร์เดียวกันบนอุปกรณ์ของคุณสามารถเปิดเกมและเห็นเกมที่บันทึกไว้ได้

ทำไมเกมจึงไม่ขอความยินยอม

รายการข้างต้นไม่ใช่คุกกี้และไม่เคยถูกส่งไปที่ใด รายการเหล่านี้จำเป็นอย่างยิ่งต่อการให้บริการเกมที่คุณเปิด หากไม่มีรายการเหล่านี้ เกมและการตั้งค่าของคุณจะหายไปเมื่อคุณปิดหน้าเว็บ การจัดเก็บลักษณะนี้ไม่ต้องได้รับความยินยอมตามกฎของสหภาพยุโรป (คำสั่งว่าด้วยความเป็นส่วนตัวทางอิเล็กทรอนิกส์ หรือ ePrivacy Directive มาตรา 5(3))

การลบข้อมูลของคุณ

ในเกม: เมนูหยุดชั่วคราว → ลบข้อมูลเกม เกมจะถามยืนยันก่อน แล้วจึงลบรายการ soty. ทั้งหมดบนอุปกรณ์นี้และโหลดหน้าเว็บใหม่

ในเบราว์เซอร์: การล้างข้อมูลของเว็บไซต์นี้ (คุกกี้และข้อมูลเว็บไซต์ของ pegasohlib.com) จะลบรายการของเกมด้วย พร้อมกับภาษาและธีมที่คุณเลือกไว้บนเว็บไซต์

ในหน้าต่างส่วนตัว เบราว์เซอร์จะลบทุกอย่างเมื่อคุณปิดหน้าต่าง

เกมติดต่อกับอะไร

เมื่อเปิดเกม หน้าเว็บของเกมจะโหลดจาก pegasohlib.com ซึ่งเป็นไฟล์เดียวที่รวมทุกอย่างไว้ในตัว รวมถึงไลบรารี 3D แบบโอเพนซอร์ส three.js ไม่มีอะไรโหลดจากบริษัทอื่น จึงไม่มีฟอนต์ สคริปต์ รูปภาพ โฆษณา หรือระบบวิเคราะห์จากภายนอก หน้าเว็บยังโหลด manifest ของแอปและไอคอนหนึ่งรายการจาก pegasohlib.com เพื่อให้เบราว์เซอร์เสนอให้ติดตั้งเกมได้ หลังจากนั้นเกมจะไม่ส่งคำขอใด ๆ ระหว่างที่คุณเล่น แผนที่ บอต และเสียงล้วนคำนวณบนอุปกรณ์ของคุณ

หน้าเว็บมาถึงคุณผ่าน Cloudflare ซึ่งเห็นที่อยู่ IP ของคุณและหน้าที่คุณเปิด ตามที่อธิบายไว้ในหน้าความเป็นส่วนตัวของเว็บไซต์ ส่วนที่ที่อยู่เดิม pegasohlib.github.io นั้น GitHub เป็นผู้ส่งมอบหน้าเว็บแทนและเห็นที่อยู่ IP ของคุณ เกมไม่ส่งข้อมูลของตัวเองใด ๆ ไม่มีเกมที่บันทึกไว้ ไม่มีการตั้งค่า และไม่มีตัวระบุ

การติดตั้งเกม

เบราว์เซอร์อาจเสนอให้ติดตั้งเกมหรือเพิ่มเกมลงในหน้าจอหลัก ซึ่งเป็นเพียงการสร้างทางลัดที่เปิดหน้าเดิมโดยไม่มีแถบที่อยู่ เกมยังคงใช้พื้นที่เก็บข้อมูลเดิมบนอุปกรณ์ของคุณ และไม่มีอะไรถูกส่งไปที่ใด

การเล่นออนไลน์

เวอร์ชันนี้ไม่มีการเล่นออนไลน์ มีแผนจะเพิ่มการเล่นกับเพื่อนผ่านลิงก์ ก่อนที่จะมาถึง นโยบายนี้จะอธิบายว่าเกมออนไลน์ส่งและเก็บอะไรบ้าง และวันที่ด้านบนจะเปลี่ยน

ผู้ที่ได้รับข้อมูล และการโอนข้อมูลออกนอกสหภาพยุโรป ไม่มีใครได้รับสิ่งที่เกมบันทึกไว้ เพราะสิ่งนั้นอยู่ในเบราว์เซอร์ของคุณ Cloudflare ส่งมอบหน้าเว็บของเกมและเห็นที่อยู่ IP ของคุณ ส่วนที่ที่อยู่เดิม pegasohlib.github.io จะเป็น GitHub อีเมลที่ส่งมาจะผ่าน Cloudflare และ Google เก็บไว้ในกล่องจดหมาย Gmail และ Anthropic อาจประมวลผลเมื่อผู้ช่วย AI ช่วยอ่าน บริษัทเหล่านี้บางแห่งตั้งอยู่ในสหรัฐอเมริกาหรือประเทศอื่นนอกสหภาพยุโรป การโอนข้อมูลดังกล่าวอาศัยกรอบความเป็นส่วนตัวของข้อมูลสหภาพยุโรป–สหรัฐอเมริกา (EU–US Data Privacy Framework) หากบริษัทนั้นเข้าร่วม หรืออาศัยข้อสัญญามาตรฐาน (standard contractual clauses) ของบริษัทนั้น

ระยะเวลาที่เก็บข้อมูล สิ่งที่เกมบันทึกไว้จะอยู่ในเบราว์เซอร์ของคุณจนกว่าคุณจะลบในเกมหรือล้างข้อมูลของเว็บไซต์นี้ Cloudflare เก็บบันทึกของตนตามกฎของตนเอง อีเมลที่คุณส่งมาจะเก็บไว้จนกว่าเรื่องจะเสร็จสิ้น และไม่เกิน 2 ปี

สิทธิของคุณ คุณขอเข้าถึงข้อมูลของคุณ ขอแก้ไข ลบ จำกัดการประมวลผล ขอสำเนาเพื่อนำไปใช้ที่อื่น (การโอนย้ายข้อมูลได้) และคัดค้านการประมวลผลหรือถอนความยินยอมได้ทุกเมื่อ เขียนมาที่ที่อยู่ข้างต้น คุณจะได้รับคำตอบภายในหนึ่งเดือน ข้อมูลส่วนใหญ่อยู่บนอุปกรณ์ของคุณเท่านั้น คุณจึงมักทำเรื่องเหล่านี้เองได้ในแอป

การร้องเรียน คุณร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลในประเทศของคุณได้
