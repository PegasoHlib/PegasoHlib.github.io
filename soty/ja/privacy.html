SOTY: Honeycomb Kingdoms は、pegasohlib.com/soty/play/ であなたのブラウザ上で動く戦略ゲームで、開発者ひとり(PegasoHlib)が作っています。ゲームにはアカウントも、広告も、分析もありません。あなたのゲームは、あなた自身のブラウザの中だけに保存され、どこにも送信されません。このポリシーは現在のバージョン、つまり CPU との対戦と、1台の端末での友だちとの対戦に適用されます。

概要

  • 保存したゲームと設定は、あなたの端末の、あなたのブラウザの中に残ります。開発者がそれを受け取ることはありません。
  • アカウントも、広告も、分析も、トラッキングもありません。また、ゲームは Cookie を設定しません。
  • プレイ中、ゲームはリクエストを一切送りません。pegasohlib.com から読み込まれるのは、サイトのほかのページと同じく、ページそのものだけです。
  • ポーズメニューのゲームデータを消去を押すと、ゲームがあなたの端末に保存したものがすべて削除されます。
  • このバージョンにはオンラインプレイがありません。オンラインプレイが始まる前に、このポリシーは変更されます。

ゲームがあなたの端末に保存するもの

ページを閉じても後で続きから遊べるように、ゲームはあなたのゲームと設定を、ブラウザの pegasohlib.com 用ローカルストレージに保存します。各項目の名前は soty. で始まります:

soty.save
進行中のゲーム: マップ、国々とその民族、ユニット、都市、条約、ターン数、最後に保存した時刻。ゲームはプレイ中にこれを書き込み、新しいゲームを始めると置き換え、ゲームが終わると削除します。
soty.prefs
設定: ヒントがオンかどうかと、すでに表示されたヒント、CPU の速度、グラフィック品質(または自動で選ばれた品質)、ミニマップを表示するかどうか、前回のゲームの設定。
soty.sound
サウンドがオンかどうか。
soty.lang
ゲームの言語。ゲーム内で切り替えたときだけ保存されます。
soty.test
ブラウザが保存を許可しているかを確かめるため、ゲームの起動時に書き込み、すぐに削除します。

あなたに関する情報はありません

これらの項目には、名前、メール、位置情報など、あなたに関する情報は含まれません。国は色で呼ばれます(青、赤…)。何かを入力できる欄はマップコードだけで、ゲームが保存するのは、入力された文字ではなく、コードから読み取ったマップの設定です。また、ゲームはこのサイトであなたが選んだかもしれない言語 siteLang を読み取り、その言語で開きます。これを変更することはありません。

開発者がこれらを受け取ることはなく、ほかのウェブサイトが読むこともできません。ブラウザはサイトごとにストレージを分けているからです。あなたの端末で同じブラウザを使う人は誰でも、ゲームを開いてセーブデータを見ることができます。

ゲームが同意を求めない理由

上の項目は Cookie ではなく、どこにも送信されません。あなたが開いたゲームを提供するために必要不可欠なものです。これがないと、ページを閉じたときにゲームと設定が失われてしまいます。この種の保存は、EU のルール上、同意を必要としません(eプライバシー指令 第5条(3))。

データの消去

ゲーム内: ポーズメニュー → ゲームデータを消去。ゲームは先に確認してから、この端末のすべての soty. 項目を削除し、ページを再読み込みします。

ブラウザ: このサイトのデータ(pegasohlib.com の Cookie とサイトデータ)を消去すると、ゲームの項目も、サイトで選んだ言語やテーマと一緒に削除されます。

プライベートウィンドウでは、ウィンドウを閉じるとブラウザがすべてを削除します。

ゲームが接続するもの

ゲームを開くと、そのページが pegasohlib.com から読み込まれます。オープンソースの 3D ライブラリ three.js も含め、すべてが組み込まれた1つのファイルです。ほかの会社から読み込むものはないため、外部のフォント、スクリプト、画像、広告、分析はありません。ブラウザがゲームのインストールを提案できるように、ページは pegasohlib.com からアプリのマニフェストとアイコンも読み込みます。その後、プレイ中にゲームがリクエストを送ることはありません。マップも CPU もサウンドも、すべてあなたの端末で計算されます。

ページは Cloudflare を経由して届きます。サイトのプライバシーのページで説明しているとおり、Cloudflare はあなたの IP アドレスと開いたページを見ることができます。旧アドレスの pegasohlib.github.io では、代わりに GitHub がページを配信し、あなたの IP アドレスを見ることができます。ゲームが自分のデータを送ることはありません。セーブデータも、設定も、識別子も送りません。

ゲームのインストール

ブラウザが、ゲームのインストールやホーム画面への追加を提案することがあります。これは、同じページをアドレスバーなしで開くショートカットを作るだけです。ゲームは引き続きあなたの端末の同じストレージを使い、どこにも何も送信されません。

オンラインプレイ

このバージョンにはオンラインプレイがありません。リンクを使った友だちとの対戦を予定しています。それが始まる前に、オンラインのゲームが何を送信し、何を保存するかをこのポリシーで説明し、上部の日付も変わります。
