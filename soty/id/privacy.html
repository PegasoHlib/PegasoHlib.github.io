SOTY: Honeycomb Kingdoms

Kebijakan privasi

Diperbarui 13 November 2026

SOTY: Honeycomb Kingdoms adalah game strategi yang berjalan di browsermu di pegasohlib.com/soty/play/, dibuat oleh satu pengembang (PegasoHlib). Game ini tidak punya akun, iklan, atau analitik. Permainan melawan bot dan bersama teman di satu perangkat hanya tetap di browsermu, kecuali kamu sendiri menyimpan salah satunya ke file. Permainan online bersama teman disimpan di room-nya di server milik game sendiri, tanpa nama, email, atau alamat IP kamu, dan room itu menghapus dirinya sendiri setelah beberapa waktu.

Sekilas

  • Permainan tersimpan dan pengaturanmu tetap di browsermu, di perangkatmu, kecuali kamu sendiri menyimpan permainan ke file. Pengembang tidak pernah menerimanya.
  • Permainan online disimpan di room-nya: langkah-langkah, waktunya, dan nama bawaan seperti “Blue Hetman”. Room tidak pernah menyimpan nama, email, atau alamat IP kamu.
  • Room menghapus dirinya sendiri 30 hari setelah langkah terakhirnya, atau 7 hari setelah permainannya berakhir.
  • Permainan di perangkatmu sendiri tidak mengirim permintaan apa pun. Mode online hanya berkomunikasi dengan server room milik game sendiri di pegasohlib.com.
  • Tanpa akun, iklan, analitik, atau pelacakan, dan game tidak memasang cookie.
  • Hapus data game di menu jeda menghapus semua yang disimpan game di perangkatmu.

Apa yang disimpan game di perangkatmu

Game menyimpan permainan dan pengaturanmu di penyimpanan lokal browsermu untuk pegasohlib.com, agar kamu bisa menutup halaman dan melanjutkan nanti. Nama setiap entri diawali dengan soty.:

soty.save
Permainan yang sedang berjalan di perangkat ini: peta, negara dan bangsanya, pasukan, kota, perjanjian, nomor giliran, dan waktu penyimpanan terakhir. Game menulisnya saat kamu bermain, menggantinya saat kamu memulai permainan baru, dan menghapusnya saat permainan berakhir. Permainan online tidak pernah disimpan di sini: permainan itu disimpan di room-nya.
soty.slots
Hingga tiga permainan yang kamu simpan sendiri di Permainan tersimpan, masing-masing dengan isi yang sama seperti soty.save. Permainan tersebut tetap ada sampai kamu menggantinya, mengosongkan slotnya, atau menghapus data game. Permainan yang kamu simpan ke file dibuat di perangkatmu dan hanya pergi ke tempat kamu menyimpan atau membagikannya; game hanya membaca file ketika kamu membukanya, dan Hapus data game tidak menyentuh file semacam itu.
soty.prefs
Pengaturan: apakah tips aktif dan tips mana yang sudah kamu lihat, kecepatan AI, tingkat grafis (atau tingkat yang dipilih otomatis), ukuran teks, apakah kamu memilih untuk mengurangi gerakan, apakah peta mini ditampilkan, seberapa keras musik dan suara permainan, konfigurasi permainan terakhirmu, dan untuk permainan online, nama bawaanmu serta timer giliran yang terakhir kamu pilih.
soty.sound
Apakah suara aktif.
soty.lang
Bahasa game, yang hanya disimpan saat kamu menggantinya di dalam game.
soty.rooms
Permainan online tempat kamu punya kursi, sepuluh yang terbaru: kode setiap room, kursimu, kunci kursi itu, nama bawaanmu, kapan terakhir kamu membuka room itu, dan apa yang terakhir kamu lihat di sana (apakah permainan sedang menunggu, berlangsung, atau sudah selesai, giliran siapa, nomor giliran, dan kapan langkah terakhir masuk). Kuncinya adalah kode acak yang memungkinkan perangkat ini kembali ke kursinya, seperti kata sandi untuk satu permainan itu saja.
soty.test
Ditulis dan langsung dihapus saat game dimulai, untuk memeriksa apakah browser mengizinkannya menyimpan.

Tidak ada apa pun tentang dirimu

Entri ini tidak berisi nama, email, lokasi, atau data lain tentang dirimu. Negara-negara dinamai menurut warnanya (Biru, Merah…), dan dalam permainan online kamu memilih salah satu nama bawaan, seperti “Blue Hetman”: tidak ada teks bebas. Kolom tempat kamu bisa mengetik adalah kode peta dan kode room: game menyimpan pengaturan peta yang dibacanya dari kode peta, dan memakai kode room hanya untuk menemukan room itu. Game juga membaca siteLang, yaitu bahasa yang mungkin kamu pilih di situs ini, agar terbuka dalam bahasa itu; game tidak pernah mengubahnya.

Hanya mode online yang mengirim sesuatu dari entri ini, dan hanya ke server room milik game sendiri: kode room, kursimu, dan kuncinya (lihat Permainan online bersama teman). Situs web lain tidak bisa membacanya: browser memisahkan penyimpanan setiap situs. Siapa pun yang memakai browser yang sama di perangkatmu bisa membuka game, melihat permainan tersimpan, dan melanjutkan permainan online-mu.

Mengapa game tidak meminta persetujuan

Entri di atas bukan cookie. Sebagian besar tidak pernah meninggalkan perangkatmu, dan kode room serta kunci kursi hanya dikirim ke server room milik game sendiri, saat kamu bermain online. Semuanya benar-benar diperlukan untuk menyediakan game yang kamu minta: tanpanya, permainan, pengaturan, dan kursimu dalam permainan online akan hilang saat kamu menutup halaman. Penyimpanan semacam ini tidak memerlukan persetujuan menurut aturan UE (Direktif ePrivacy, Pasal 5 ayat (3)).

Permainan online bersama teman

Saat kamu membuat room, atau membuka room temanmu lewat tautan atau kodenya, game terhubung ke server room-nya di pegasohlib.com/soty/api/. Server ini adalah program kecil yang dijalankan Cloudflare untuk PegasoHlib: satu room untuk setiap permainan, yang meneruskan langkah-langkah di antara perangkat para pemain dan menyimpan permainan, agar semua orang bisa kembali ke permainan itu. Perangkat-perangkat itulah yang menjalankan aturan; server hanya memeriksa giliran siapa dan apakah langkah-langkah masuk sesuai urutan. Sebuah room menyimpan:

  • kodenya, versi game, pengaturan (ukuran dan jenis peta, kursi mana yang diisi teman atau bot, tingkat dan bangsa bot, timer giliran), dan posisi awal;
  • untuk setiap kursi: nama bawaan, apakah pemainnya sudah siap, kapan kursi itu diambil, dan sidik jari (hash SHA-256) dari kunci kursi. Kuncinya sendiri tetap di perangkat pemain;
  • setiap langkah, beserta sidik jari permainan setelah langkah itu dan waktu langkah itu masuk, serta cuplikan permainan, yang diperbarui setiap ronde, agar perangkat bisa menyusul;
  • apakah permainan sedang menunggu, berlangsung, atau sudah selesai, kapan permainan berakhir, dan kode room berikutnya saat host memulai permainan baru dengan pemain yang sama.

Room tidak menyimpan alamat IP, data browser, nama, email, atau teks yang kamu ketik. Emote (👍 🤝 ⚔ 😅 GG) diteruskan ke pemain lain dan tidak disimpan. Siapa yang sedang online hanya diketahui selama room digunakan dan tidak pernah dicatat.

Waktu langkah-langkah menunjukkan kapan langkah terakhir masuk (“3 jam yang lalu”). Waktu itu juga memungkinkan perangkat pemain lain memainkan negara pemain yang sedang tidak ada, dengan cara berpikir bot, sampai pemain itu kembali: setelah 3 hari tanpa langkah, atau setelah 2 menit offline jika host memasang timer giliran.

Siapa yang melihatnya. Para pemain di room melihat nama bawaan dan warna setiap kursi, apakah kursi itu online dan siap, langkah-langkahnya, dan emotenya. Siapa pun yang punya kode atau tautan room bisa melihat room itu sebelum bergabung (kursi, nama bawaan, giliran siapa, dan kapan langkah terakhir masuk) dan mengambil kursi yang kosong, jadi bagikan tautannya hanya kepada teman yang ingin kamu ajak bermain.

Di mana disimpan. Cloudflare menyimpan room di Uni Eropa (Durable Objects dalam yurisdiksi UE) dan memprosesnya untuk PegasoHlib berdasarkan perjanjian pemrosesan datanya. Cloudflare mungkin menyimpan catatan teknis, seperti nomor internal room untuk penagihan, di luar UE. Seperti halaman mana pun di situs ini, Cloudflare melihat alamat IP kamu saat perangkatmu terhubung; server room itu sendiri tidak menyimpan log. PegasoHlib bisa membuka room melalui dasbor Cloudflare, dan melakukannya hanya untuk menjawab permintaanmu atau memperbaiki kesalahan.

Permainan online hanya berfungsi di pegasohlib.com, tidak di alamat lama.

Berapa lama room disimpan

Room menghapus dirinya sendiri, beserta semua yang disimpannya, 30 hari setelah langkah terakhirnya (atau setelah dibuat, jika permainannya tidak pernah dimulai), dan 7 hari setelah permainannya berakhir. Perangkatmu menyimpan entrinya sampai kamu menghapusnya; room yang sudah tidak ada akan hilang dari daftar permainan online-mu lain kali game memeriksa room itu.

Menghapus datamu

Di dalam game: menu jeda → Hapus data game. Game bertanya dulu, lalu menghapus setiap entri soty. di perangkat ini, termasuk kunci permainan online-mu, dan memuat ulang halaman.

Keluar dari permainan online: di menu jeda permainan itu, Keluar dari permainan online. Perangkatmu melupakan room dan kuncinya, jadi tidak ada lagi yang menghubungkanmu dengan kursi itu; pemain lain melanjutkan, bot memainkan negaramu begitu kamu dianggap tidak ada, dan room menghapus dirinya sendiri sesuai jadwal. Di lobi room sebelum permainan dimulai, Keluar dari room juga mengosongkan kursimu dan menghapus nama bawaan serta sidik jari kunci kursi itu dari room (pemain yang membuat room tetap memegang kursinya). Lupakan room ini di daftar permainan online-mu hanya menghapusnya dari perangkat ini.

Agar room dihapus lebih cepat, atau untuk menanyakan apa yang disimpan room tentang kursimu, tulislah ke support@pegasohlib.com dengan menyertakan kode room. Menghapus room mengakhiri permainan itu bagi semua orang di dalamnya.

Di browsermu: membersihkan data situs ini (cookie dan data situs untuk pegasohlib.com) juga menghapus entri game, bersama bahasa dan tema yang kamu pilih di situs.

Di jendela pribadi, browser menghapus semuanya saat kamu menutup jendela itu.

Apa yang dihubungi game

Saat kamu membuka game, halamannya dimuat dari pegasohlib.com. Halaman ini adalah satu file yang sudah memuat semuanya, termasuk pustaka 3D sumber terbuka three.js: tidak ada yang dimuat dari perusahaan lain, jadi tidak ada font, skrip, gambar, iklan, atau analitik dari luar. Halaman ini juga memuat manifes aplikasinya dan sebuah ikon dari pegasohlib.com, agar browser bisa menawarkan pemasangan game. Setelah itu, permainan melawan bot atau bersama teman di satu perangkat tidak mengirim permintaan apa pun: peta, bot, dan suara semuanya dihitung di perangkatmu.

Mode online hanya berkomunikasi dengan server room milik game sendiri di pegasohlib.com/soty/api/: saat kamu membuat room, membuka tautan room atau mengetik kodenya, membuka Main bersama teman saat kamu punya permainan online (untuk menampilkan giliran siapa di masing-masing permainan), dan selama permainan online atau lobinya terbuka (langkah-langkah, dan sinyal singkat setiap 30 detik yang menjaga koneksi tetap hidup). Mode ini mengirim apa yang disimpan room dan kunci kursimu, tidak lebih: tanpa permainan tersimpan, tanpa pengaturan lain, tanpa pengenal perangkatmu. Bagikan memakai menu berbagi bawaan perangkatmu atau menyalin tautannya; game tidak tahu ke mana kamu mengirimnya.

Halaman ini dan server room sampai kepadamu melalui Cloudflare, yang melihat alamat IP kamu dan alamat yang kamu buka, seperti dijelaskan di halaman privasi situs. Di alamat lama, pegasohlib.github.io, halaman ini diantarkan oleh GitHub sebagai gantinya, dan GitHub melihat alamat IP kamu.

Memasang game

Browsermu mungkin menawarkan untuk memasang game atau menambahkannya ke layar utama. Itu hanya membuat pintasan yang membuka halaman yang sama tanpa bilah alamat. Game tetap memakai penyimpanan yang sama di perangkatmu, dan tidak ada yang dikirim ke mana pun.
