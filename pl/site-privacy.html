Ta strona dotyczy witryny pegasohlib.github.io: strony głównej i stron aplikacji. W skrócie: bez kont, bez plików cookie, bez reklam i bez analityki. To, co każda aplikacja lub gra robi z danymi, wyjaśnia jej własna polityka prywatności, wymieniona poniżej.

W skrócie

  • Witryna nie ustawia plików cookie i nie ma reklam, analityki ani przycisków mediów społecznościowych.
  • Wybrany przez ciebie język i motyw zostają w twojej przeglądarce i nigdzie nie są wysyłane.
  • GitHub hostuje witrynę i ze względów bezpieczeństwa zapisuje adresy IP odwiedzających.
  • Pliki pobierane są z GitHub, więc GitHub widzi i liczy każde pobranie.
  • Jeśli wyślesz e-mail, posłuży on wyłącznie do odpowiedzi na niego.

Dlaczego nie ma banera ze zgodą

Te dwa wpisy nie są plikami cookie. Nie zawierają identyfikatora, nie są wysyłane na żaden serwer i nie podążają za tobą na inne strony. Przechowują tylko ustawienie, które sam(a) wybrałeś(-aś), dlatego witryna nie prosi o zgodę. Aby je usunąć, wyczyść dane tej witryny w ustawieniach przeglądarki.

Hosting

Witryna działa na GitHub Pages, usłudze GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub ze względów bezpieczeństwa zapisuje adres IP każdego odwiedzającego, niezależnie od tego, czy ma on konto GitHub. PegasoHlib nie ma dostępu do tych logów. GitHub odpowiada za te dane: zobacz GitHub Privacy Statement.

Pobrania i liczby

Przyciski pobierania prowadzą do plików przechowywanych na GitHub. Gdy go naciskasz, twoja przeglądarka łączy się z GitHub, a GitHub zwiększa licznik tego pliku o jeden. PegasoHlib widzi tylko sumę dla każdego pliku, nigdy tego, kto go pobrał.

Łączne liczby pobrań, tam gdzie strona je pokazuje, są dodawane podczas budowania witryny, więc Twoja przeglądarka nie łączy się w tym celu z API GitHub. Numery wersji i rozmiary plików są odczytywane z plików na tej samej witrynie.
