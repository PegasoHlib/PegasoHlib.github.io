Khronometr

Kebijakan Privasi

Diperbarui 4 November 2026

Khronometr menunjukkan berapa lama kamu menghabiskan waktu di aplikasi dan game, di ponsel, tablet, dan PC sekaligus. Aplikasi ini dibuat agar datamu tetap milikmu: Khronometr tidak punya server, tanpa iklan, dan tanpa pelacakan.

Singkatnya

  • Tetap di perangkatmu
    Riwayatmu disimpan di dalam aplikasi di ponsel dan PC-mu. Tidak ada server Khronometr, dan cadangan otomatis Android tidak menyalin data aplikasi.
  • Hanya Google Drive milikmu
    Sinkronisasi bersifat opsional dan masuk ke folder aplikasi tersembunyi di Drive milikmu yang hanya bisa dilihat oleh Khronometr.
  • Tanpa iklan, tanpa pelacakan
    Tanpa analitik, tanpa SDK iklan. Tidak ada yang dijual atau dibagikan.
  • Waktu, bukan isi
    Aplikasi ini tidak membaca pesan, foto, apa yang kamu ketik, atau apa pun di dalam aplikasi dan jendela lain.
  • Hapus kapan saja
    Hapus aplikasi untuk menghapus data di perangkat itu. “Hapus salinanku dari Google Drive” menghapus salinan di cloud.
  • Tiga permintaan ke luar
    Google Drive (hanya jika kamu menyinkronkan), GitHub (pengecekan pembaruan) dan, di aplikasi Windows, hanya jika kamu mengaktifkannya, toko Steam untuk nama sebuah game. Masing-masing melihat alamat IP-mu.

Apa yang dibaca aplikasi di ponsel

  • Penggunaan aplikasi — aplikasi mana yang dibuka, berapa lama, dan berapa kali layar dibuka kuncinya. Hanya setelah kamu mengaktifkan “Akses penggunaan” untuk Khronometr di setelan Android.
  • Penggunaan jaringan per aplikasi — berapa byte Wi-Fi dan data seluler yang dipakai setiap aplikasi, dari izin yang sama.
  • Nama dan ikon aplikasi terpasang — untuk menampilkannya di daftar. Versi dari situs web memegang izin untuk melihat semua aplikasi terpasang demi keperluan ini.
  • Model perangkat dan nama yang kamu berikan untuknya — untuk membedakan perangkatmu.
  • Pengenal perangkat — nomor yang diberikan Android kepada Khronometr di ponsel ini (Android ID). Ini bagian dari nama file di folder Drive-mu, dan hanya jika kamu mengaktifkan sinkronisasi.
  • Tanggal lahirmu, hanya jika kamu memasukkannya — disimpan hanya di ponsel ini dan tidak pernah disinkronkan, untuk menunjukkan sejak usia berapa riwayatmu dimulai.

Aplikasi ini tidak membaca pesan, kontak, lokasi, foto, mikrofon, kamera, apa yang kamu ketik, atau apa pun di dalam aplikasi lain.

Aplikasi Windows (opsional)

Jika kamu memasang Khronometr untuk Windows, di PC itu aplikasinya membaca:

  • nama program yang jendelanya sedang di depan, dan berapa lama;
  • kapan layar dikunci dan dibuka kuncinya;
  • waktu bermain game di akun Steam-mu sendiri, dari file Steam di PC ini (dan, jika kamu mengaktifkannya, nama game dari toko Steam, lihat di bawah);
  • waktu dan lalu lintas data yang lebih lama per program dari catatan penggunaan Windows sendiri, hanya untuk pengguna Windows-mu — hanya setelah kamu mengizinkannya sekali.

Aplikasi menyimpan ini di foldernya sendiri, %LOCALAPPDATA%\Khronometr, bersama alamat Google-mu (sebagai teks biasa) dan, jika kamu masuk, token masuk terenkripsi. Aplikasi tidak membaca isi jendela, ketikan keyboard, tangkapan layar, atau riwayat browser.

Steam. Kira-kira sehari sekali aplikasi membaca waktu bermain akun Steam-mu dari file Steam di PC ini: akun yang dipakai di pengguna Windows-mu atau, jika tidak bisa dipastikan, akun yang terakhir dipakai di PC ini. Bertanya ke toko publik Steam dimatikan secara default. Jika kamu mengaktifkannya di Pengaturan, maka untuk game yang sudah tidak terpasang dan namanya tidak ditemukan di sana, aplikasi menanyakan nama ke store.steampowered.com dan menyimpan yang ditemukan. Steam lalu melihat ID game itu dan alamat IP PC-mu. Ini berfungsi tanpa masuk dengan Google.

Saat sinkronisasi aktif, aplikasi juga mengunduh data perangkat lainmu dari folder Drive tersembunyi yang sama, untuk ditampilkan di jendelanya. File Drive-nya diberi nama dengan pengenal PC ini (w- dan ID mesin Windows), dan nama PC disimpan sebagai nama perangkat. Aplikasi juga memeriksa pembaruannya sendiri setiap 6 jam di pegasohlib.github.io dan hanya memasang file dengan tanda tangan digital dari pembuatnya; tidak ada data pribadi yang dikirim, tetapi server melihat alamat IP-mu.

Apa yang diletakkan aplikasi Windows di PC-mu

Aplikasi dipasang hanya untuk penggunamu dan tidak memerlukan hak administrator. Aplikasi menambahkan:

  • program, di %LOCALAPPDATA%\Programs\Khronometr;
  • pintasan menu Start dan entri di Aplikasi terpasang Windows;
  • mulai otomatis (entri Run untuk penggunamu, diaktifkan saat pertama dijalankan dan bisa dimatikan di Pengaturan);
  • tugas terjadwal atas nama penggunamu, “Khronometr Watchdog”, yang setiap 10 menit menjalankan aplikasi lagi jika tidak sedang berjalan.

Hanya jika kamu memilih mengimpor jurnal Windows, Windows meminta hak administrator satu kali. Aplikasi lalu membuat tugas “Khronometr Journal”, yang berjalan sebagai SYSTEM setiap 6 jam. Tugas ini hanya menjalankan cmd.exe dan esentutl.exe bawaan Windows serta skrip C:\Program Files\Khronometr\journal-copy.cmd. Folder itu hanya bisa diubah oleh SYSTEM dan administrator, dan salinan jurnal di dalamnya hanya bisa dibaca oleh mereka dan pengguna yang menyiapkannya.

Pencopotan menghapus program, pintasan, mulai otomatis, tugas Watchdog, dan entri Aplikasi terpasang. Tugas jurnal menyadari bahwa folder aplikasi sudah hilang dan menghapus dirinya sendiri beserta foldernya di Program Files, biasanya langsung dan paling lambat pada eksekusi berikutnya, tanpa konfirmasi. Folder datamu tetap ada; lihat “Kendali dan penghapusan”.

Di mana datamu disimpan

Semuanya disimpan di perangkatmu: di basis data aplikasi sendiri pada ponsel, di folder aplikasi sendiri pada PC dan, hanya jika kamu mengaktifkan sinkronisasi, di folder Drive milikmu sendiri. Pengembang tidak punya server dan tidak pernah menerima datamu. Di Android, pencadangan otomatis dimatikan, sehingga data tidak masuk ke cadangan ponsel Google.

File ekspor (zip) dibuat hanya saat kamu memintanya, dan disimpan di tempat yang kamu pilih. File ini tidak dienkripsi dan berisi seluruh riwayatmu, aplikasi yang kamu gabungkan, dan id perangkat.

Sinkronisasi Google Drive (opsional)

Jika kamu memilih “Hubungkan Google Drive”, aplikasi menyimpan riwayatnya di folder aplikasi tersembunyi di Google Drive-mu sendiri. Izinnya adalah drive.appdata: aplikasi hanya bisa melihat file yang ia buat sendiri di sana dan tidak ada yang lain di Drive-mu.

Yang ditulis di sana: waktu dan lalu lintas harian per aplikasi, sesi, nama dan ikon aplikasi, nama perangkat, batasmu beserta grupnya (ditambah berapa banyak dari setiap batas bersama yang sudah terpakai hari ini) dan daftar aplikasi yang kamu gabungkan (pengenal aplikasi dan kapan digabungkan). Nama file memuat pengenal perangkat yang menulisnya (a- dan Android ID, atau w- dan id mesin Windows). Begitulah perangkat lainmu menampilkan riwayat yang sama dan batas bekerja di beberapa perangkat.

Data berpindah terenkripsi (HTTPS) antara perangkatmu dan Google. Pengembang tidak bisa mengakses Drive-mu. Aplikasi membaca email Google-mu satu kali dari Drive untuk menampilkannya; email itu disimpan di perangkat tersebut dan tidak dikirim ke tempat lain.

Mematikan sinkronisasi menghentikan pengiriman dan penerimaan, tetapi yang sudah ada di Drive tetap di sana, dan perangkat lama tetap tercantum. Untuk menghapus salinan cloud, gunakan “Hapus salinanku dari Google Drive” di aplikasi (lihat “Kendali dan penghapusan”).

Penggunaan dan transfer informasi yang diterima Khronometr dari Google API mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Pembaruan (versi dari situs)

Versi dari situs web ini memeriksa pegasohlib.github.io sekitar dua kali sehari (aplikasi Windows setiap 6 jam) untuk versi yang lebih baru dan mengunduhnya dari GitHub. Android memeriksa bahwa pembaruan ditandatangani oleh pengembang yang sama sebelum memasang; aplikasi Windows hanya memasang file yang tanda tangan digitalnya cocok dengan kunci pembuatnya. Tidak ada data tentangmu yang dikirim, tetapi seperti situs web mana pun, GitHub melihat alamat IP-mu.

Dengan “Perbarui otomatis” aktif (default), aplikasi memasang pembaruan sendiri; di Android hanya jika kamu mengizinkan “Instal aplikasi tidak dikenal”, dan Android mungkin tetap meminta konfirmasi. Mematikannya menghentikan pemasangan, bukan pemeriksaan: aplikasi hanya memberi tahu bahwa ada versi baru. Versi Google Play diperbarui oleh Google Play.

GitHub juga menghitung berapa kali setiap file diunduh. Itu hanya angka, tanpa informasi apa pun tentang siapa yang mengunduh; situs web menampilkannya sebagai perkiraan jumlah unduhan.

Siapa yang menerima datamu

Pengembang tidak menerima apa pun: tidak ada server, tidak ada analitik, dan tidak ada pelaporan error. Datamu tidak dijual, dibagikan, atau dipakai untuk iklan. Aplikasi berkomunikasi langsung dengan tiga layanan luar, yang melihat apa yang ditampilkan permintaan biasa:

  • Google — Drive milikmu sendiri, hanya jika kamu mengaktifkan sinkronisasi.
  • GitHub dan pegasohlib.github.io — pemeriksaan dan unduhan pembaruan di versi dari situs web; mereka melihat alamat IP-mu.
  • Steam (Valve) — hanya aplikasi Windows, dan hanya jika kamu mengaktifkannya di Pengaturan: untuk game yang namanya tidak ditemukan di PC, aplikasi bertanya ke store.steampowered.com saat pengecekan Steam harian, tanpa masuk dengan Google. Steam melihat ID game dan alamat IP PC-mu.

Kendali dan penghapusan

  • Sinkronisasi: matikan kapan saja di tab Perangkat. Ini menghentikan pengiriman dan penerimaan; yang sudah ada di Drive tetap ada.
  • Salinan cloud: “Hapus salinanku dari Google Drive” di aplikasi menghapus setiap file yang disimpan aplikasi di Drive-mu, untuk semua perangkatmu. Setelah itu ponsel mematikan sinkronisasi, dan PC keluar dari Google. Perangkat yang sinkronisasinya masih aktif akan mengunggah datanya lagi kecuali kamu mematikan sinkronisasi di sana juga. Yang sudah ada di setiap perangkat tetap ada. Kamu juga bisa memakai Google Drive → Pengaturan → Kelola aplikasi → Khronometr → Hapus data aplikasi tersembunyi.
  • Ponsel: hapus penyimpanan aplikasi atau copot pemasangannya — semua yang ada di ponsel hilang. Cadangan Android tidak menyimpan salinan.
  • PC: Pengaturan Windows → Aplikasi → Aplikasi terpasang → Khronometr → Copot pemasangan. Folder data %LOCALAPPDATA%\Khronometr (riwayat, pengaturan, alamat Google-mu) tetap ada: hapus secara manual jika kamu ingin menghilangkannya. Tugas jurnal menghapus dirinya sendiri.
  • File ekspor adalah file milikmu: hapus seperti file lainnya.

Keamanan

Semua trafik ke Google memakai HTTPS. Di ponsel, proses masuk ditangani oleh layanan Google Play; di PC, token masuk dienkripsi dengan Windows (DPAPI) hanya untuk akun penggunamu. Aplikasi ini tidak pernah meminta atau menyimpan kata sandi.

Tugas jurnal di Windows berjalan dengan hak SYSTEM, jadi hanya menjalankan program bawaan Windows dan satu skrip di folder yang hanya bisa diubah administrator. Folder data di PC dan file ekspor tidak dienkripsi.

Perubahan kebijakan ini

Tanggal di bagian atas menunjukkan versi terbaru. Perubahan penting juga disebutkan di catatan pembaruan aplikasi.
