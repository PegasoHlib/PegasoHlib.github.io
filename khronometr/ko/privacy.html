Khronometr

개인정보처리방침

2026년 11월 6일 업데이트

Khronometr는 휴대폰, 태블릿, PC에서 앱과 게임에 쓴 시간을 한꺼번에 보여 줘요. 내 데이터가 내 것으로 남도록 만들어졌어요. Khronometr 서버도, 광고도, 추적도 없어요.

요약

  • 내 기기에만 남아요
    기록은 휴대폰과 PC의 앱 안에 보관돼요. Khronometr 서버는 없고, Android 자동 백업은 앱 데이터를 복사하지 않아요.
  • 내 Google Drive만
    동기화는 선택 사항이고, 내 Drive의 숨겨진 앱 폴더에 저장돼요. 다른 앱은 이 폴더를 열 수 없고, Google이 내 계정에 보관해요.
  • 광고도 추적도 없어요
    분석 도구도, 광고 SDK도 없어요. 아무것도 판매하거나 공유하지 않아요.
  • 내용이 아니라 시간만
    Khronometr는 메시지, 사진, 입력한 내용, 다른 앱과 창 안의 어떤 것도 읽지 않아요.
  • 언제든 삭제할 수 있어요
    앱을 삭제하면 그 기기의 데이터가 삭제돼요. “Google Drive에서 내 사본 삭제”를 누르면 클라우드 사본이 삭제돼요.
  • 외부 요청 세 가지
    Google Drive(동기화를 쓸 때만), GitHub(업데이트 확인), 그리고 Windows 앱에서 켠 경우에만 게임 이름을 찾기 위한 Steam 스토어예요. 각각 내 IP 주소를 볼 수 있어요.

휴대폰 앱이 읽는 정보

  • 앱 사용 정보 — 어떤 앱이 얼마나 오래 열려 있었는지와 화면 잠금 해제 횟수예요. Android 설정에서 Khronometr에 “사용 정보 접근”을 허용한 뒤에만 읽어요.
  • 앱별 네트워크 사용량 — 각 앱이 Wi-Fi와 모바일 데이터를 몇 바이트 썼는지, 같은 권한으로 읽어요.
  • 설치된 앱의 이름과 아이콘 — 목록에 표시하기 위해서예요. 웹사이트 버전은 이를 위해 설치된 모든 앱을 볼 수 있는 권한을 가져요.
  • 기기 모델과 내가 붙인 기기 이름 — 기기를 서로 구분하기 위해서예요.
  • 기기 식별자 — 이 휴대폰에서 Android가 Khronometr에 부여한 번호(Android ID)예요. 동기화를 켰을 때만 내 Drive 폴더의 파일 이름에 들어가요.
  • 생년월일, 입력한 경우에만 — 기록이 몇 살부터 시작되는지 보여 주려고 이 휴대폰에만 보관하고 절대 동기화하지 않아요.

메시지, 연락처, 위치, 사진, 마이크, 카메라, 입력한 내용, 다른 앱 안의 어떤 것도 읽지 않아요.

Windows 앱 (선택 사항)

Windows용 Khronometr를 설치하면 해당 PC에서 다음을 읽어요.

  • 맨 앞에 있는 창의 프로그램 이름과 그 시간
  • 화면이 잠기고 잠금 해제되는 시각
  • 내 Steam 계정 게임의 플레이 시간. 이 PC에 있는 Steam 파일에서 가져와요(켠 경우에는 Steam 스토어에서 가져온 게임 이름도 포함, 아래 참고).
  • Windows 자체 사용 기록에서 가져온 프로그램별 이전 사용 시간과 데이터 사용량. 내 Windows 사용자에 한하며, 한 번 허용한 뒤에만 가져와요.

이 정보는 앱 자신의 폴더 %LOCALAPPDATA%\Khronometr에 보관되며, 내 Google 주소(일반 텍스트)와, 로그인했다면 암호화된 로그인 토큰도 함께 들어 있어요. 창 안의 내용, 키 입력, 스크린샷, 브라우저 기록은 읽지 않아요.

Steam. 하루에 한 번쯤 이 PC에 있는 Steam 파일에서 Steam 계정의 플레이 시간을 읽어요. 내 Windows 사용자로 쓰는 계정을 읽고, 알 수 없으면 이 PC에서 마지막으로 쓴 계정을 읽어요. Steam 공개 스토어에 묻는 기능은 기본적으로 꺼져 있어요. 설정에서 켜면, 더 이상 설치되어 있지 않고 이름을 찾을 수 없는 게임에 대해 앱이 store.steampowered.com에 이름을 묻고 찾은 내용을 저장해요. 그러면 Steam은 그 게임의 ID와 내 PC의 IP 주소를 볼 수 있어요. 이 기능은 Google 로그인 없이 작동해요.

동기화를 켜면 같은 숨겨진 Drive 폴더에서 다른 기기의 데이터도 내려받아 창에 보여 줘요. 이 앱의 Drive 파일 이름에는 이 PC의 식별자(w-와 Windows 컴퓨터 ID)가 들어가고, PC 이름은 기기 이름으로 저장돼요. 또 6시간마다 pegasohlib.github.io에서 자체 업데이트를 확인하고, 제작자의 디지털 서명이 있는 파일만 설치해요. 개인 정보는 전송되지 않지만 서버는 내 IP 주소를 볼 수 있어요.

Windows 앱이 내 PC에 두는 것

내 사용자 계정에만 설치되며 관리자 권한은 필요 없어요. 다음이 추가돼요.

  • %LOCALAPPDATA%\Programs\Khronometr에 있는 프로그램
  • 시작 메뉴 바로 가기와 Windows 설치된 앱 항목
  • 자동 시작(내 사용자의 Run 항목으로, 처음 실행할 때 켜지고 설정에서 끌 수 있어요)
  • 내 사용자 계정의 예약 작업 “Khronometr Watchdog”. 앱이 실행 중이 아니면 10분마다 다시 시작해요.

Windows 기록 가져오기를 선택한 경우에만 Windows가 관리자 권한을 한 번 요청해요. 그러면 앱이 SYSTEM으로 6시간마다 실행되는 작업 “Khronometr Journal”을 만들어요. 이 작업은 Windows 자체의 cmd.exe와 esentutl.exe, 그리고 스크립트 C:\Program Files\Khronometr\journal-copy.cmd만 실행해요. 그 폴더는 SYSTEM과 관리자만 바꿀 수 있고, 그 안의 기록 사본은 그들과 설정한 사용자만 읽을 수 있어요. 이 사본은 Windows 기록 전체이므로 이 PC의 다른 모든 Windows 사용자의 사용 내역도 들어 있고, 설정한 사용자는 이를 읽을 수 있어요. 앱 자체는 그 사용자의 기록만 가져와요.

제거하면 프로그램, 바로 가기, 자동 시작, Watchdog 작업, 설치된 앱 항목이 삭제돼요. 기록 작업은 앱 폴더가 사라진 것을 알아채고 스스로, 그리고 자기 Program Files 폴더도 확인 없이 삭제해요. 보통 바로, 늦어도 다음 실행 때예요. 데이터 폴더는 남아요. “관리와 삭제”를 참고하세요.

데이터 보관 위치

모든 것은 내 기기에 저장돼요. 휴대폰에서는 앱 자체 데이터베이스에, PC에서는 앱 자체 폴더에, 그리고 동기화를 켠 경우에만 내 Drive 폴더에 저장돼요. 개발자에게는 서버가 없고 내 데이터를 받지도 않아요. Android에서는 자동 백업이 꺼져 있어서 데이터가 Google 휴대폰 백업에 들어가지 않아요.

내보내기 파일(zip)은 내가 요청할 때만 만들어지고, 내가 고른 곳에 저장돼요. 암호화되어 있지 않고, 전체 기록과 합친 앱, 기기 ID가 들어 있어요.

Google Drive 동기화 (선택 사항)

“Google Drive 연결”을 선택하면 앱은 기록을 내 Google Drive의 숨겨진 앱 폴더에 저장해요. 권한은 drive.appdata예요. 앱은 그곳에 직접 만든 파일만 볼 수 있고, Drive의 다른 것은 볼 수 없어요.

저장되는 내용: 앱별 하루 사용 시간과 데이터 사용량, 세션, 앱 이름과 아이콘, 기기 이름, 그룹이 포함된 제한(공유 제한별로 오늘 얼마나 썼는지 포함), 합친 앱 목록(앱 식별자와 합친 시각). 파일 이름에는 그 파일을 쓴 기기의 식별자가 들어 있어요(a-와 Android ID, 또는 w-와 Windows 컴퓨터 ID). 이렇게 해서 다른 기기에서도 같은 기록이 보이고, 제한이 여러 기기에서 작동해요.

데이터는 내 기기와 Google 사이에서 암호화(HTTPS)되어 전송돼요. 개발자는 내 Drive에 접근할 수 없어요. 앱은 내 Google 이메일을 표시하기 위해 Drive에서 한 번 읽어요. 그것은 그 기기에 보관되고 다른 곳으로 전송되지 않아요.

동기화를 끄면 보내기와 받기는 멈추지만, Drive에 이미 있는 데이터는 그대로 남고 이전 기기도 목록에 남아요. 클라우드 사본을 삭제하려면 앱의 “Google Drive에서 내 사본 삭제”를 사용하세요(“내가 하는 관리와 삭제” 참고).

Khronometr가 Google API로부터 받은 정보를 사용하고 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수해요.

업데이트 (웹사이트 버전)

이 웹사이트의 버전은 하루에 두 번쯤(Windows 앱은 6시간마다) pegasohlib.github.io에서 새 버전이 있는지 확인하고 GitHub에서 내려받아요. Android는 설치 전에 같은 개발자의 서명인지 확인해요. Windows 앱은 디지털 서명이 제작자의 키와 일치하는 파일만 설치해요. 나에 관한 정보는 전송되지 않지만, 다른 웹사이트와 마찬가지로 GitHub는 내 IP 주소를 볼 수 있어요.

“자동 업데이트”가 켜져 있으면(기본값이에요) 앱이 스스로 업데이트를 설치해요. Android에서는 “출처를 알 수 없는 앱 설치”를 허용한 경우에만 그렇고, Android가 확인을 요청할 수도 있어요. 끄면 설치만 멈추고 확인은 계속해요. 그러면 앱은 새 버전이 나왔다고 알려 주기만 해요. Google Play 버전은 대신 Google Play가 업데이트해요.

GitHub는 각 파일이 몇 번 다운로드됐는지도 세요. 누가 내려받았는지에 대한 정보 없이 숫자만 있고, 웹사이트는 이를 대략적인 다운로드 수로 보여 줘요.

데이터를 받는 사람

개발자는 아무것도 받지 않아요. 서버도, 분석도, 오류 보고도 없어요. 내 데이터는 판매하거나 공유하거나 광고에 쓰지 않아요. 앱은 외부 서비스 세 곳과 직접 통신하며, 이들은 일반적인 요청에서 보이는 정보를 볼 수 있어요.

  • Google — 내 Drive. 동기화를 켠 경우에만 해당돼요.
  • GitHub와 pegasohlib.github.io — 웹사이트 버전의 업데이트 확인과 다운로드예요. 내 IP 주소를 볼 수 있어요.
  • Steam(Valve) — Windows 앱에서만, 그리고 설정에서 켠 경우에만 해당해요. PC에서 이름을 찾을 수 없는 게임에 대해 매일 하는 Steam 확인 중에 store.steampowered.com에 이름을 물어요. Google 로그인은 필요 없어요. Steam은 게임 ID와 내 PC의 IP 주소를 볼 수 있어요.

관리와 삭제

  • 동기화: 기기 탭에서 언제든 끌 수 있어요. 보내고 받는 것은 멈추지만, 이미 Drive에 있는 것은 그대로 남아요.
  • 클라우드 사본: 앱의 “Google Drive에서 내 사본 삭제”는 앱이 내 Drive에 보관하는 모든 파일을 모든 기기에 대해 삭제해요. 그러면 휴대폰은 동기화를 끄고, PC는 Google에서 로그아웃해요. 동기화가 아직 켜져 있는 기기는 그 기기에서도 동기화를 끄지 않으면 데이터를 다시 업로드해요. 각 기기에 이미 있는 데이터는 그대로 남아요. Google Drive → 설정 → 앱 관리 → Khronometr → 숨겨진 앱 데이터 삭제에서도 삭제할 수 있어요.
  • 휴대폰: 앱 저장 공간을 지우거나 앱을 제거하세요. 휴대폰에 있는 모든 것이 사라져요. Android 백업에는 사본이 없어요.
  • PC: Windows 설정 → 앱 → 설치된 앱 → Khronometr → 제거. 데이터 폴더 %LOCALAPPDATA%\Khronometr(기록, 설정, 내 Google 주소)는 남아요. 없애고 싶다면 직접 삭제하세요. 기록 작업은 스스로 삭제돼요.
  • 내보내기 파일은 내 파일이에요. 다른 파일처럼 지우면 돼요.

보안

Google과 주고받는 모든 데이터는 HTTPS를 사용해요. 휴대폰에서는 Google Play 서비스가 로그인을 처리하고, PC에서는 로그인 토큰을 Windows(DPAPI)로 내 사용자 계정 전용으로 암호화해요. 앱은 비밀번호를 묻거나 저장하지 않아요.

Windows의 기록 작업은 SYSTEM 권한으로 실행되므로, Windows 자체 프로그램과 관리자만 바꿀 수 있는 폴더 안의 스크립트 하나만 시작해요. PC의 데이터 폴더와 내보내기 파일은 암호화되지 않아요.
