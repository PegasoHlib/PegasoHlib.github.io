如何安裝

  1. 1

    下載並執行

    用上面的按鈕下載檔案並執行。Khronometr 會提示安裝自己，只為你的使用者安裝，不需要管理員權限。它會出現在開始功能表中。

  2. 2

    如果 Windows 發出警告

    如果 Windows 顯示「Windows 已保護您的電腦」，請按一下其他資訊，然後按一下仍要執行。沒有付費簽章的應用程式都會這樣。Khronometr 會在你的電腦上新增什麼，下面的問答裡有列出。

  3. 3

    用 Google 登入

    在 Khronometr 視窗中按一下登入，使用與手機上相同的帳戶。之後你的手機和平板電腦也會顯示在這裡。

  4. 4

    完成

    關閉視窗後，Khronometr 仍會繼續統計：它會常駐在時鐘旁邊（系統匣），並隨 Windows 啟動。你可以在設定中關閉這一點。

它能做什麼

完整統計

日、週、月、年和全部時間：圖表、類別、每個應用程式單獨查看——所有裝置合併或逐部查看。

你的完整歷史

包括你的手機和平板的使用時間、更早的 Android 歷史記錄，以及 Steam 遊戲時數。如果你允許，Windows 內建的記錄還可以補充大約最近一兩個月的時間和流量。

這裡也能設限制

直接在電腦上建立和修改限制。登入後，這些限制在你的手機上也有效；不登入則只在這台電腦上生效。「時間到了」畫面隨時可以關閉。

紀錄和流量

你使用最多的一天、最長的一次使用、歷來常用程式排行，以及每個程式的流量。匯入 Windows 記錄後才會顯示流量，這需要一次管理員權限。

自動更新

每 6 小時尋找一次新版本並自動安裝；沒有作者數位簽章的檔案絕不會被安裝。

只用你的 Google 雲端硬碟

同步透過你自己雲端硬碟中的隱藏資料夾進行。沒有伺服器，沒有廣告。

常見問題

Windows 的警告長什麼樣子？

一個藍色視窗，標題為「Windows 已保護您的電腦」，內容為「Microsoft Defender SmartScreen 已阻止無法辨識的應用程式啟動……」。按一下文字下方的其他資訊，然後按一下仍要執行，而不是不要執行。

它會在我的電腦上新增什麼？

它只為你的使用者安裝，不需要管理員權限：程式位於 %LOCALAPPDATA%\Programs\Khronometr，另有開始功能表捷徑、「已安裝的應用程式」中的一項和開機自動啟動。它還會建立一個屬於你的使用者的工作「Khronometr Watchdog」，如果程式沒有在執行，每 10 分鐘就會重新啟動它。只有當你選擇匯入 Windows 記錄時，Windows 才會要求一次管理員權限，並建立一個工作「Khronometr Journal」；它每 6 小時把記錄複製到 Program Files 中的一個資料夾，只有管理員和你可以讀取該資料夾。

我一定要用 Google 登入嗎？

不必。統計、紀錄和限制在這台電腦上不登入也能用。登入後可以在這裡看到你的手機和平板，並與它們共用限制。

如何解除安裝？

Windows 設定 → 應用程式 → 已安裝的應用程式 → Khronometr → 解除安裝。這會移除程式、捷徑、自動啟動、Watchdog 工作和「已安裝的應用程式」中的項目。如果你建立過記錄工作，它會自行發現並刪除自己和它在 Program Files 中的資料夾，通常是立刻刪除，最遲在下次執行時，不會有任何提示。你的歷史記錄保留在 %LOCALAPPDATA%\Khronometr 中：要刪除它，請手動刪除該資料夾；如果你用過同步，還請在 Google 雲端硬碟設定中刪除雲端副本。
