Khronometr สำหรับ Windows

เวลาหน้าจอทั้งหมดของคุณ — บนพีซีด้วย

แอปตัวจริงสำหรับคอมพิวเตอร์ของคุณ: เวลาในโปรแกรมและเกม ประวัติจากโทรศัพท์และแท็บเล็ต การจำกัดเวลาและสถิติสูงสุด — ในหน้าต่างเดียว

ดาวน์โหลดสำหรับ Windows

นโยบายความเป็นส่วนตัว

Windows 10 / 11 แบบ 64 บิตเท่านั้น · 70.3 MB · ฟรี · 27 ภาษา
ตรวจหาอัปเดตทุก 6 ชั่วโมงและติดตั้งเอง เว้นแต่คุณจะปิดไว้ ทุกอัปเดตได้รับการตรวจสอบด้วยลายเซ็นดิจิทัล

วิธีติดตั้ง

  1. 1

    ดาวน์โหลดและเรียกใช้

    ดาวน์โหลดไฟล์ด้วยปุ่มด้านบนแล้วเปิดใช้งาน Khronometr จะเสนอให้ติดตั้งตัวเอง เฉพาะผู้ใช้ของคุณและไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ แอปจะปรากฏในเมนู Start

  2. 2

    หาก Windows แจ้งเตือน

    หาก Windows แจ้งว่า “Windows protected your PC” ให้คลิก ข้อมูลเพิ่มเติม แล้วคลิก เรียกใช้อยู่ดี เรื่องนี้เกิดกับแอปที่ไม่มีลายเซ็นแบบเสียเงิน สิ่งที่ Khronometr เพิ่มลงในพีซีของคุณมีระบุไว้ในคำถามด้านล่าง

  3. 3

    ลงชื่อเข้าใช้ด้วย Google

    ในหน้าต่าง Khronometr คลิกลงชื่อเข้าใช้ด้วยบัญชีเดียวกับในโทรศัพท์ จากนั้นโทรศัพท์และแท็บเล็ตของคุณจะแสดงที่นี่ด้วย

  4. 4

    เสร็จแล้ว

    Khronometr นับต่อไปแม้ปิดหน้าต่างแล้ว: แอปอยู่ข้างนาฬิกา (ในถาดระบบ) และเริ่มทำงานพร้อม Windows คุณปิดได้ในการตั้งค่า

ทำอะไรได้

สถิติครบทุกด้าน

วัน สัปดาห์ เดือน ปี และตลอดกาล: กราฟ หมวดหมู่ แต่ละแอปแยกกัน — ทุกอุปกรณ์รวมกันหรือทีละเครื่อง

ประวัติทั้งหมดของคุณ

เวลาจากโทรศัพท์และแท็บเล็ตของคุณ ประวัติ Android เก่า และเวลาเล่นบน Steam หากคุณอนุญาต บันทึกของ Windows เองสามารถเพิ่มเวลาและปริมาณข้อมูลย้อนหลังได้ราวหนึ่งถึงสองเดือนล่าสุด

จำกัดเวลาได้ที่นี่ด้วย

สร้างและแก้ไขการจำกัดได้ตรงบนพีซี เมื่อลงชื่อเข้าใช้ การจำกัดจะทำงานบนโทรศัพท์ของคุณด้วย หากไม่ลงชื่อเข้าใช้ จะมีผลเฉพาะบนพีซีเครื่องนี้ หน้าจอ “หมดเวลาแล้ว” ปิดได้เสมอ

สถิติสูงสุดและปริมาณข้อมูล

วันที่คุณใช้มากที่สุด เซสชันที่ยาวที่สุด โปรแกรมยอดนิยมตลอดกาล และปริมาณข้อมูลต่อโปรแกรม ปริมาณข้อมูลจะปรากฏหลังจากคุณนำเข้าบันทึกของ Windows ซึ่งจะขอสิทธิ์ผู้ดูแลระบบหนึ่งครั้ง

อัปเดตตัวเอง

ระบบมองหาเวอร์ชันใหม่ทุก 6 ชั่วโมงและติดตั้งให้เอง ไฟล์ที่ไม่มีลายเซ็นดิจิทัลของผู้พัฒนาจะไม่ถูกติดตั้งเด็ดขาด

เฉพาะ Google Drive ของคุณ

การซิงค์ผ่านโฟลเดอร์ที่ซ่อนอยู่ใน Drive ของคุณเอง ไม่มีเซิร์ฟเวอร์ ไม่มีโฆษณา

คำถาม

คำเตือนของ Windows หน้าตาเป็นอย่างไร?

หน้าต่างสีน้ำเงินที่มีหัวข้อ “Windows ป้องกันพีซีของคุณแล้ว” และข้อความ “Microsoft Defender SmartScreen ป้องกันไม่ให้แอปที่ไม่รู้จักเริ่มทำงาน…” คลิกข้อมูลเพิ่มเติมใต้ข้อความ แล้วคลิกเรียกใช้อยู่ดี ไม่ใช่ไม่ต้องเรียกใช้

ฉันมี Khronometr รุ่นเก่าสำหรับพีซีอยู่แล้ว

แค่เรียกใช้ไฟล์ใหม่แล้วคลิกอัปเดต แอปใหม่จะแทนที่รุ่นเก่า ส่วนประวัติ การจำกัด การลงชื่อเข้าใช้ Google และการเริ่มอัตโนมัติยังอยู่ครบ

แอปเพิ่มอะไรลงในพีซีของฉันบ้าง

แอปติดตั้งเฉพาะผู้ใช้ของคุณ โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ: โปรแกรมอยู่ใน %LOCALAPPDATA%\Programs\Khronometr ทางลัดในเมนู Start รายการใน “แอปที่ติดตั้ง” และการเริ่มอัตโนมัติ นอกจากนี้ยังสร้างงานของผู้ใช้คุณชื่อ “Khronometr Watchdog” ที่เริ่มแอปใหม่ทุก 10 นาทีหากแอปไม่ได้ทำงานอยู่ เฉพาะเมื่อคุณเลือกนำเข้าบันทึกของ Windows เท่านั้น Windows จะขอสิทธิ์ผู้ดูแลระบบหนึ่งครั้ง และจะมีการสร้างงาน “Khronometr Journal” ซึ่งคัดลอกบันทึกทุก 6 ชั่วโมงไปยังโฟลเดอร์ใน Program Files ที่มีเพียงผู้ดูแลระบบและคุณเท่านั้นที่อ่านได้

ฉันต้องลงชื่อเข้าใช้ด้วย Google ไหม

ไม่ต้อง การนับ สถิติสูงสุด และการจำกัดทำงานบนพีซีเครื่องนี้ได้โดยไม่ต้องลงชื่อเข้าใช้ ลงชื่อเข้าใช้เมื่อต้องการดูโทรศัพท์และแท็บเล็ตของคุณที่นี่ และแชร์การจำกัดกับเครื่องเหล่านั้น

ถอนการติดตั้งอย่างไร?

การตั้งค่า Windows → แอป → แอปที่ติดตั้ง → Khronometr → ถอนการติดตั้ง วิธีนี้จะลบโปรแกรม ทางลัด การเริ่มอัตโนมัติ งาน Watchdog และรายการใน “แอปที่ติดตั้ง” ส่วนงานบันทึก หากคุณเคยสร้างไว้ จะรับรู้เองแล้วลบตัวเองพร้อมโฟลเดอร์ใน Program Files โดยปกติทันที และอย่างช้าที่สุดตอนรันครั้งถัดไป โดยไม่ถามอะไร ประวัติของคุณยังอยู่ใน %LOCALAPPDATA%\Khronometr: ลบโฟลเดอร์นั้นด้วยตัวเองหากต้องการลบประวัติ และลบสำเนาใน Drive ที่การตั้งค่า Google Drive หากคุณใช้การซิงค์

ฉันถอนการติดตั้งเวอร์ชันที่เก่ากว่า 1.2.2

เวอร์ชันเหล่านั้นทิ้งงาน Khronometr\JournalCopy ไว้ ให้ลบทิ้ง: งานนี้จะรันไฟล์จากโฟลเดอร์ผู้ใช้ด้วยสิทธิ์ผู้ดูแลระบบ เปิด Task Scheduler แล้วลบ หรือรันในเทอร์มินัลผู้ดูแลระบบ: schtasks /Delete /TN "Khronometr\JournalCopy" /F

มีอะไรใหม่: 1.2.2

แก้ไขด้านความปลอดภัย: ตอนนี้บันทึก (journal) ของ Windows ถูกคัดลอกโดยงานระบบที่ได้รับการป้องกัน งานนี้จะแทนที่งานเก่าเอง และจะหายไปเมื่อคุณถอนการติดตั้งแอป

ข้อมูลของคุณยังเป็นของคุณ

ไม่มีเซิร์ฟเวอร์ของ Khronometr ไม่มีโฆษณา ไม่มีการติดตาม ทุกอย่างเก็บไว้ในอุปกรณ์ของคุณ และหากคุณต้องการ ก็อยู่ในโฟลเดอร์ที่ซ่อนอยู่ใน Google Drive ของคุณเอง นโยบายความเป็นส่วนตัวระบุคำขอภายนอกไม่กี่รายการที่แอปส่งออกไป
