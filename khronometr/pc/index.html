Khronometr for Windows

Time in programs and games on your computer — together with your phone.

⬇  Download for Windows

Windows 10 / 11 · 0.3 MB · free

🧭How to install

  1. Download the file with the button above and run it.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway. This happens to apps without a paid signature; Khronometr installs nothing outside its own folder.
    Windows protected your PC
    Microsoft Defender SmartScreen prevented an unrecognised app from starting…
    More info
    Run anywayDon’t run
  3. Khronometr appears next to the clock (in the tray). Click its icon → Sign in with Google… with the same account as on your phone.
  4. Done: the PC shows up on the phone in the Devices tab. It starts with Windows by itself.

What it does

🖥️

Counts every program

Time in each program and game while its window is in front.

🎮

Steam and traffic

Adds your Steam playtime and network use per program from Windows’ journal.

⏳

Your limits apply here too

When time is up, a “Time’s up” screen covers the window — you can always close it.

☁️

Only your Google Drive

It syncs through a hidden folder on your own Drive. No servers, no ads.

The PC app’s menu is in English or Ukrainian, depending on your Windows language.

🗑️How to remove it

Tray icon → Exit, switch off Start with Windows, then delete %LOCALAPPDATA%\Programs\Khronometr and its data %LOCALAPPDATA%\Khronometr.
