如何安装

  1. 1

    下载并运行

    用上面的按钮下载文件并运行。Khronometr 会提示安装自己，只为你的用户安装，不需要管理员权限。它会出现在开始菜单中。

  2. 2

    如果 Windows 发出警告

    如果 Windows 显示“Windows 已保护你的电脑”，请点击更多信息，然后点击仍要运行。没有付费签名的应用都会这样。Khronometr 会在你的电脑上添加什么，下面的问答里有列出。

  3. 3

    用 Google 登录

    在 Khronometr 窗口中点击登录，使用与手机上相同的账号。之后你的手机和平板也会显示在这里。

  4. 4

    完成

    关闭窗口后，Khronometr 仍会继续统计：它会驻留在时钟旁边（系统托盘），并随 Windows 启动。你可以在设置中关闭这一点。

直接在电脑上创建和修改限制。登录后，这些限制在你的手机上也有效；不登录则只在这台电脑上生效。“时间到了”界面随时可以关闭。

纪录和流量

你使用最多的一天、最长的一次使用、全部时间的常用程序排行，以及每个程序的流量。导入 Windows 日志后才会显示流量，这需要一次管理员权限。

每 6 小时查找一次新版本并自动安装；没有作者数字签名的文件绝不会被安装。

常见问题

Windows 的警告是什么样子的？

一个蓝色窗口，标题为“Windows 已保护你的电脑”，文字为“Microsoft Defender SmartScreen 阻止了无法识别的应用启动……”。点击文字下方的更多信息，然后点击仍要运行，而不是不运行。

我已经装有旧版 Khronometr 电脑版

直接运行新文件并点击更新：它会替换旧版，你的历史记录、限制、Google 登录和开机自启动都会保留。

它会在我的电脑上添加什么？

它只为你的用户安装，不需要管理员权限：程序位于 %LOCALAPPDATA%\Programs\Khronometr，另有开始菜单快捷方式、“已安装的应用”中的一项和开机自启动。它还会创建一个属于你的用户的任务“Khronometr Watchdog”，如果程序没有在运行，每 10 分钟就会重新启动它。只有当你选择导入 Windows 日志时，Windows 才会请求一次管理员权限，并创建一个任务“Khronometr Journal”；它每 6 小时把日志复制到 Program Files 中的一个文件夹，只有管理员和你可以读取该文件夹。

我必须用 Google 登录吗？

不必。统计、纪录和限制在这台电脑上不登录也能用。登录后可以在这里看到你的手机和平板，并与它们共享限制。

如何卸载？

Windows 设置 → 应用 → 已安装的应用 → Khronometr → 卸载。这会移除程序、快捷方式、自启动、Watchdog 任务和“已安装的应用”中的条目。如果你创建过日志任务，它会自行发现并删除自己和它在 Program Files 中的文件夹，通常是立刻删除，最迟在下次运行时，不会有任何提示。你的历史记录保留在 %LOCALAPPDATA%\Khronometr 中：要删除它，请手动删除该文件夹；如果你用过同步，还请在 Google 云端硬盘设置中删除云端副本。

我卸载了 1.2.2 之前的版本

那些版本会遗留一个任务 Khronometr\JournalCopy。请删除它：它会以管理员权限运行用户文件夹中的文件。请打开任务计划程序并删除它，或在管理员终端中运行：schtasks /Delete /TN "Khronometr\JournalCopy" /F。
