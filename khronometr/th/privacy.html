Khronometr

นโยบายความเป็นส่วนตัว

อัปเดตเมื่อ 4 พฤศจิกายน 2026

Khronometr แสดงว่าคุณใช้เวลากับแอปและเกมไปเท่าไร บนโทรศัพท์ แท็บเล็ต และพีซีรวมกัน แอปนี้สร้างขึ้นเพื่อให้ข้อมูลของคุณยังเป็นของคุณ: ไม่มีเซิร์ฟเวอร์ของ Khronometr ไม่มีโฆษณา และไม่มีการติดตาม

โดยสรุป

  • อยู่ในอุปกรณ์ของคุณ
    ประวัติของคุณเก็บไว้ในแอปบนโทรศัพท์และพีซีของคุณ ไม่มีเซิร์ฟเวอร์ของ Khronometr และการสำรองข้อมูลอัตโนมัติของ Android ไม่ได้คัดลอกข้อมูลของแอป
  • เฉพาะ Google Drive ของคุณเอง
    การซิงค์เป็นตัวเลือก และจะไปยังโฟลเดอร์แอปที่ซ่อนอยู่ใน Drive ของคุณ ซึ่งมีแค่ Khronometr ที่มองเห็น
  • ไม่มีโฆษณา ไม่มีการติดตาม
    ไม่มีการวิเคราะห์ ไม่มี SDK โฆษณา ไม่มีสิ่งใดถูกขายหรือแชร์
  • เวลา ไม่ใช่เนื้อหา
    Khronometr ไม่อ่านข้อความ รูปภาพ สิ่งที่คุณพิมพ์ หรือสิ่งใดภายในแอปและหน้าต่างอื่น
  • ลบได้ทุกเมื่อ
    ลบแอปเพื่อลบข้อมูลบนอุปกรณ์นั้น สำเนาบนคลาวด์ลบได้ในการตั้งค่า Google Drive ของคุณ ในแอปไม่มีปุ่มสำหรับเรื่องนี้
  • คำขอภายนอกสามรายการ
    Google Drive (เฉพาะเมื่อคุณซิงค์) GitHub (ตรวจหาอัปเดต) และในแอป Windows คือร้านค้าของ Steam เพื่อหาชื่อเกม แต่ละรายการเห็นที่อยู่ IP ของคุณ

เนื้อหา

แอปบนโทรศัพท์อ่านอะไรบ้างสิทธิ์และเหตุผลแอป Windows (ไม่บังคับ)สิ่งที่แอป Windows วางไว้บนพีซีของคุณข้อมูลของคุณเก็บไว้ที่ไหนการซิงค์กับ Google Drive (ไม่บังคับ)การอัปเดต (เวอร์ชันจากเว็บไซต์)ใครได้รับข้อมูลของคุณการควบคุมและการลบข้อมูลความปลอดภัยเด็กการเปลี่ยนแปลงนโยบายนี้ติดต่อ

ข้อมูลอะไร อยู่ที่ไหน ใครเห็น

ข้อมูลเก็บไว้ที่ไหนใครเห็นได้
เวลาและปริมาณข้อมูลต่อแอป การปลดล็อกหน้าจอ ชื่อและไอคอนของแอป ชื่ออุปกรณ์ในแอปบนอุปกรณ์ของคุณ และเมื่อเปิดการซิงค์ ก็อยู่ในโฟลเดอร์แอปที่ซ่อนอยู่ใน Google Drive ของคุณเองด้วย ซึ่งชื่อไฟล์มีตัวระบุของอุปกรณ์ที่เขียนไฟล์นั้นคุณคนเดียว
แอป Windows: เวลาในโปรแกรม เวลาที่ล็อกหน้าจอ เวลาเล่นใน Steam ปริมาณข้อมูลต่อโปรแกรมบนพีซีเครื่องนั้น ในโฟลเดอร์ของแอปเอง เมื่อเปิดการซิงค์ จะอยู่ใน Drive ของคุณด้วยคุณคนเดียว
การจำกัดและกลุ่มบนอุปกรณ์ของคุณ เมื่อเปิดการซิงค์ จะอยู่ใน Drive ของคุณด้วยคุณคนเดียว
วันเกิด (เฉพาะเมื่อคุณกรอก)เฉพาะบนโทรศัพท์เครื่องนี้ ไม่มีการซิงค์คุณคนเดียว
อีเมลของบัญชี Googleอ่านจาก Drive หนึ่งครั้งเพื่อแสดงผล เก็บไว้บนอุปกรณ์นั้น (บนพีซีเป็นข้อความธรรมดาในโฟลเดอร์ของแอป) และไม่ส่งไปที่อื่นคุณคนเดียว
สำเนาบันทึกการใช้งานของ Windows (เฉพาะเมื่อคุณอนุญาต)บนพีซี ในโฟลเดอร์ใน Program Files ที่มีเพียงผู้ดูแลระบบและผู้ใช้ที่ตั้งค่าไว้เท่านั้นที่อ่านได้ แอปยังคัดลอกไปไว้ในโฟลเดอร์ของตัวเองเฉพาะช่วงที่กำลังอ่าน แล้วลบสำเนานั้นทิ้งเฉพาะคุณและผู้ดูแลระบบของพีซีเครื่องนั้น
รหัสเกม Steam (แอป Windows เฉพาะเกมที่หาชื่อบนพีซีไม่พบ)ส่งไปที่ store.steampowered.com ระหว่างการตรวจสอบ Steam รายวัน พร้อมที่อยู่ IP ของพีซี แม้ไม่ได้ลงชื่อเข้าใช้ GoogleSteam (Valve) เห็นรหัสเกมและที่อยู่ IP
การตรวจหาและดาวน์โหลดอัปเดต (เวอร์ชันจากเว็บไซต์)คำขอไปยัง pegasohlib.github.io และ GitHub ในคำขอไม่มีข้อมูลใด ๆ เกี่ยวกับคุณGitHub เห็นที่อยู่ IP
ไฟล์ส่งออก (zip)ในที่ที่คุณเลือกบันทึก ไม่ได้เข้ารหัส ไฟล์มีประวัติทั้งหมดของคุณและรหัสอุปกรณ์ผู้ที่คุณให้ไฟล์

แอปบนโทรศัพท์อ่านอะไรบ้าง

  • การใช้งานแอป — แอปใดเปิดอยู่ นานเท่าไร และการปลดล็อกหน้าจอ เฉพาะหลังจากคุณเปิด “การเข้าถึงการใช้งาน” ให้ Khronometr ในการตั้งค่า Android
  • การใช้เครือข่ายต่อแอป — แต่ละแอปใช้ข้อมูล Wi-Fi และอินเทอร์เน็ตมือถือไปกี่ไบต์ จากสิทธิ์เดียวกันนี้
  • ชื่อและไอคอนของแอปที่ติดตั้ง — เพื่อแสดงในรายการ เวอร์ชันจากเว็บไซต์มีสิทธิ์เห็นแอปที่ติดตั้งทั้งหมดเพื่อการนี้
  • รุ่นของอุปกรณ์ และชื่อที่คุณตั้งให้อุปกรณ์ — เพื่อแยกอุปกรณ์ของคุณออกจากกัน
  • ตัวระบุอุปกรณ์ — หมายเลขที่ Android มอบให้ Khronometr บนโทรศัพท์เครื่องนี้ (Android ID) เป็นส่วนหนึ่งของชื่อไฟล์ในโฟลเดอร์ Drive ของคุณ และมีเฉพาะเมื่อคุณเปิดการซิงค์
  • วันเกิดของคุณ เฉพาะเมื่อคุณกรอก — เก็บไว้บนโทรศัพท์เครื่องนี้เท่านั้นและไม่มีการซิงค์ เพื่อแสดงว่าประวัติของคุณเริ่มต้นตอนอายุเท่าไร

แอปไม่อ่านข้อความ รายชื่อติดต่อ ตำแหน่ง รูปภาพ ไมโครโฟน กล้อง สิ่งที่คุณพิมพ์ หรือสิ่งใดภายในแอปอื่น

แอป Windows (ไม่บังคับ)

หากคุณติดตั้ง Khronometr สำหรับ Windows แอปจะอ่านข้อมูลต่อไปนี้บนพีซีเครื่องนั้น:

  • ชื่อของโปรแกรมที่หน้าต่างอยู่ด้านหน้า และนานเท่าไร
  • เวลาที่หน้าจอถูกล็อกและปลดล็อก
  • เวลาเล่นเกมของคุณ จากไฟล์ของ Steam บนพีซีเครื่องนี้ (และชื่อเกมจากร้านค้าของ Steam ดูด้านล่าง)
  • เวลาและปริมาณข้อมูลรายโปรแกรมที่เก่ากว่า จากบันทึกการใช้งานของ Windows เอง — หลังจากคุณอนุญาตหนึ่งครั้งเท่านั้น

แอปเก็บข้อมูลนี้ไว้ในโฟลเดอร์ของตัวเอง %LOCALAPPDATA%\Khronometr พร้อมที่อยู่ Google ของคุณ (เป็นข้อความธรรมดา) และหากคุณลงชื่อเข้าใช้ ก็มีโทเค็นลงชื่อเข้าใช้ที่เข้ารหัสไว้ แอปไม่อ่านสิ่งที่อยู่ในหน้าต่าง การกดแป้นพิมพ์ ภาพหน้าจอ หรือประวัติเบราว์เซอร์

Steam วันละประมาณหนึ่งครั้ง แอปอ่านเวลาเล่นเกมของคุณจากไฟล์ของ Steam บนพีซีเครื่องนี้ สำหรับเกมที่ไม่ได้ติดตั้งแล้วและหาชื่อไม่พบที่นั่น แอปจะถามชื่อจากร้านค้าสาธารณะของ Steam (store.steampowered.com) และบันทึกสิ่งที่พบ จากนั้น Steam จะเห็นรหัสของเกมนั้นและที่อยู่ IP ของพีซีคุณ กรณีนี้เกิดขึ้นโดยไม่ต้องลงชื่อเข้าใช้ Google

เมื่อเปิดการซิงค์ แอปยังดาวน์โหลดข้อมูลจากอุปกรณ์เครื่องอื่นของคุณจากโฟลเดอร์ Drive ที่ซ่อนอยู่แห่งเดียวกัน เพื่อแสดงในหน้าต่างของแอป ไฟล์ใน Drive ของแอปนี้ตั้งชื่อด้วยตัวระบุของพีซีเครื่องนี้ (w- และรหัสเครื่อง Windows) และชื่อของพีซีถูกเก็บเป็นชื่ออุปกรณ์ แอปยังตรวจหาอัปเดตของตัวเองทุก 6 ชั่วโมงที่ pegasohlib.github.io และติดตั้งเฉพาะไฟล์ที่มีลายเซ็นดิจิทัลของผู้พัฒนา ไม่มีการส่งข้อมูลส่วนบุคคล แต่เซิร์ฟเวอร์เห็นที่อยู่ IP ของคุณ

สิ่งที่แอป Windows วางไว้บนพีซีของคุณ

แอปติดตั้งเฉพาะผู้ใช้ของคุณและไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ แอปเพิ่ม:

  • โปรแกรม ใน %LOCALAPPDATA%\Programs\Khronometr
  • ทางลัดในเมนู Start และรายการใน “แอปที่ติดตั้ง” ของ Windows
  • การเริ่มอัตโนมัติ (รายการ Run ของผู้ใช้คุณ เปิดไว้ตอนเริ่มใช้ครั้งแรก และปิดได้ในการตั้งค่า)
  • งานตามกำหนดเวลาของผู้ใช้คุณ ชื่อ “Khronometr Watchdog” ที่เริ่มแอปใหม่ทุก 10 นาทีหากแอปไม่ได้ทำงานอยู่

เฉพาะเมื่อคุณเลือกนำเข้าบันทึกของ Windows เท่านั้น Windows จะขอสิทธิ์ผู้ดูแลระบบหนึ่งครั้ง จากนั้นแอปจะสร้างงาน “Khronometr Journal” ซึ่งทำงานในฐานะ SYSTEM ทุก 6 ชั่วโมง งานนี้เริ่มเฉพาะ cmd.exe และ esentutl.exe ของ Windows เอง และสคริปต์ C:\Program Files\Khronometr\journal-copy.cmd เท่านั้น โฟลเดอร์นั้นแก้ไขได้เฉพาะ SYSTEM และผู้ดูแลระบบ และสำเนาบันทึกในโฟลเดอร์อ่านได้เฉพาะคนเหล่านั้นและผู้ใช้ที่ตั้งค่าไว้

การถอนการติดตั้งจะลบโปรแกรม ทางลัด การเริ่มอัตโนมัติ งาน Watchdog และรายการใน “แอปที่ติดตั้ง” งานบันทึกจะรับรู้ว่าโฟลเดอร์ของแอปหายไปแล้วลบตัวเองพร้อมโฟลเดอร์ใน Program Files โดยปกติทันที และอย่างช้าที่สุดตอนรันครั้งถัดไป โดยไม่ถามอะไร โฟลเดอร์ข้อมูลของคุณยังอยู่ ดู “การควบคุมและการลบข้อมูล”

เวอร์ชันก่อน 1.2.2 สร้างงาน Khronometr\JournalCopy ที่รันตัวแอปเองด้วยสิทธิ์ผู้ดูแลระบบจากโฟลเดอร์ผู้ใช้ของคุณ การอัปเดตเป็น 1.2.2 ขึ้นไปจะแทนที่งานนั้นโดยไม่ถามอะไร หากคุณถอนการติดตั้งเวอร์ชันเก่าแทน งานนั้นอาจยังอยู่และควรลบทิ้ง (ดู “การควบคุมและการลบข้อมูล”)

ข้อมูลของคุณเก็บไว้ที่ไหน

ทุกอย่างเก็บไว้ในอุปกรณ์ของคุณ: ในฐานข้อมูลของแอปเองบนโทรศัพท์ ในโฟลเดอร์ของแอปเองบนพีซี และเฉพาะเมื่อคุณเปิดการซิงค์ ก็อยู่ในโฟลเดอร์ Drive ของคุณเอง ผู้พัฒนาไม่มีเซิร์ฟเวอร์และไม่เคยได้รับข้อมูลของคุณ บน Android การสำรองข้อมูลอัตโนมัติถูกปิดอยู่ ข้อมูลจึงไม่ไปอยู่ในการสำรองข้อมูลโทรศัพท์ของ Google

ไฟล์ส่งออก (zip) จะถูกสร้างเมื่อคุณสั่งเท่านั้น และบันทึกในที่ที่คุณเลือก ไฟล์ไม่ได้เข้ารหัสและมีประวัติทั้งหมดของคุณและรหัสอุปกรณ์

การซิงค์กับ Google Drive (ไม่บังคับ)

หากคุณเลือก “ลงชื่อเข้าใช้ด้วย Google” แอปจะบันทึกประวัติไว้ในโฟลเดอร์แอปที่ซ่อนอยู่ใน Google Drive ของคุณเอง สิทธิ์ที่ใช้คือ drive.appdata: แอปมองเห็นเฉพาะไฟล์ที่แอปสร้างไว้ที่นั่น และไม่เห็นสิ่งอื่นใดใน Drive ของคุณ

สิ่งที่ไปอยู่ที่นั่น: เวลาและปริมาณข้อมูลรายวันของแต่ละแอป เซสชัน ชื่อและไอคอนของแอป ชื่ออุปกรณ์ และการจำกัดของคุณพร้อมกลุ่ม (รวมถึงว่าการจำกัดที่ใช้ร่วมกันแต่ละรายการถูกใช้ไปเท่าไรในวันนี้) ชื่อไฟล์มีตัวระบุของอุปกรณ์ที่เขียนไฟล์นั้น (a- และ Android ID หรือ w- และรหัสเครื่อง Windows) อุปกรณ์อื่น ๆ ของคุณจึงแสดงประวัติเดียวกัน และการจำกัดทำงานได้บนหลายอุปกรณ์

ข้อมูลเดินทางแบบเข้ารหัส (HTTPS) ระหว่างอุปกรณ์ของคุณกับ Google ผู้พัฒนาเข้าถึง Drive ของคุณไม่ได้ แอปอ่านอีเมล Google ของคุณจาก Drive หนึ่งครั้งเพื่อแสดงผล อีเมลนั้นเก็บไว้บนอุปกรณ์เครื่องนั้นและไม่ส่งไปที่อื่น

การปิดการซิงค์จะหยุดการส่งและรับ แต่สิ่งที่อยู่ใน Drive อยู่แล้วจะยังอยู่ที่นั่น และอุปกรณ์เก่ายังคงอยู่ในรายการ ในแอปไม่มีปุ่มลบสำเนาบนคลาวด์ ให้ใช้การตั้งค่า Google Drive (ดู “การควบคุมและการลบข้อมูล”)

การใช้และการถ่ายโอนข้อมูลที่ได้รับจาก Google API โดย Khronometr เป็นไปตามนโยบายข้อมูลผู้ใช้ของบริการ Google API รวมถึงข้อกำหนดการใช้งานแบบจำกัด

การอัปเดต (เวอร์ชันจากเว็บไซต์)

เวอร์ชันจากเว็บไซต์นี้ตรวจหาเวอร์ชันที่ใหม่กว่าที่ pegasohlib.github.io วันละประมาณสองครั้ง (แอป Windows ทุก 6 ชั่วโมง) และดาวน์โหลดจาก GitHub ก่อนติดตั้ง Android ตรวจสอบว่าลงนามโดยผู้พัฒนารายเดียวกัน ส่วนแอป Windows ติดตั้งเฉพาะไฟล์ที่ลายเซ็นดิจิทัลตรงกับกุญแจของผู้พัฒนา ไม่มีข้อมูลใด ๆ เกี่ยวกับคุณถูกส่งออกไป แต่ GitHub เห็นที่อยู่ IP ของคุณ เช่นเดียวกับเว็บไซต์ทั่วไป

เมื่อเปิด “อัปเดตอัตโนมัติ” (ค่าเริ่มต้น) แอปจะติดตั้งอัปเดตเอง บน Android เฉพาะเมื่อคุณอนุญาต “ติดตั้งแอปที่ไม่รู้จัก” และ Android อาจขอให้คุณยืนยัน การปิดจะหยุดการติดตั้ง ไม่ได้หยุดการตรวจหา: แอปจะแค่บอกคุณว่ามีเวอร์ชันใหม่ ส่วนเวอร์ชัน Google Play จะอัปเดตผ่าน Google Play แทน

GitHub ยังนับจำนวนครั้งที่แต่ละไฟล์ถูกดาวน์โหลดด้วย ซึ่งเป็นเพียงตัวเลข ไม่มีข้อมูลว่าใครดาวน์โหลด เว็บไซต์แสดงตัวเลขนี้เป็นจำนวนดาวน์โหลดโดยประมาณ

ใครได้รับข้อมูลของคุณ

ผู้พัฒนาไม่ได้รับอะไรเลย: ไม่มีเซิร์ฟเวอร์ ไม่มีระบบวิเคราะห์ และไม่มีการรายงานข้อขัดข้อง ข้อมูลของคุณไม่ถูกขาย ไม่ถูกแบ่งปัน และไม่ถูกนำไปใช้โฆษณา แอปติดต่อกับบริการภายนอกสามรายการโดยตรง ซึ่งเห็นเท่าที่คำขอทั่วไปแสดงให้เห็น:

  • Google — Drive ของคุณเอง เฉพาะเมื่อคุณเปิดการซิงค์
  • GitHub และ pegasohlib.github.io — การตรวจหาและดาวน์โหลดอัปเดตในเวอร์ชันจากเว็บไซต์ ทั้งสองเห็นที่อยู่ IP ของคุณ
  • Steam (Valve) — เฉพาะแอป Windows: สำหรับเกมที่หาชื่อบนพีซีไม่พบ แอปจะถาม store.steampowered.com ระหว่างการตรวจสอบ Steam รายวัน โดยไม่ต้องลงชื่อเข้าใช้ Google Steam เห็นรหัสเกมและที่อยู่ IP ของพีซีคุณ

การควบคุมและการลบข้อมูล

  • การซิงค์: ปิดได้ทุกเมื่อในแท็บอุปกรณ์ การปิดจะหยุดการส่งและรับ สิ่งที่อยู่ใน Drive อยู่แล้วจะยังอยู่
  • สำเนาบนคลาวด์: ในแอปไม่มีปุ่มสำหรับเรื่องนี้ ใช้ Google Drive → การตั้งค่า → จัดการแอป → Khronometr → ลบข้อมูลแอปที่ซ่อนอยู่ วิธีนี้จะลบข้อมูลของอุปกรณ์ทั้งหมดของคุณออกจากคลาวด์
  • โทรศัพท์: ล้างพื้นที่เก็บข้อมูลของแอปหรือถอนการติดตั้ง — ทุกอย่างบนโทรศัพท์จะหายไป การสำรองข้อมูลของ Android ไม่เก็บสำเนาไว้
  • พีซี: การตั้งค่า Windows → แอป → แอปที่ติดตั้ง → Khronometr → ถอนการติดตั้ง โฟลเดอร์ข้อมูล %LOCALAPPDATA%\Khronometr (ประวัติ การตั้งค่า ที่อยู่ Google ของคุณ) ยังอยู่: ลบด้วยตัวเองหากต้องการให้หายไป งานบันทึกจะลบตัวเอง
  • พีซี เวอร์ชันที่เก่ากว่า 1.2.2: หากคุณถอนการติดตั้งไปแล้ว งาน Khronometr\JournalCopy อาจยังอยู่ ให้ลบใน Task Scheduler หรือในเทอร์มินัลผู้ดูแลระบบ: schtasks /Delete /TN "Khronometr\JournalCopy" /F
  • ไฟล์ส่งออกเป็นไฟล์ของคุณเอง: ลบได้เหมือนไฟล์อื่น ๆ

ความปลอดภัย

การรับส่งข้อมูลทั้งหมดกับ Google ใช้ HTTPS บนโทรศัพท์ การลงชื่อเข้าใช้จัดการโดยบริการ Google Play บนพีซี โทเค็นการลงชื่อเข้าใช้ถูกเข้ารหัสด้วย Windows (DPAPI) สำหรับบัญชีผู้ใช้ของคุณเท่านั้น แอปไม่เคยขอหรือเก็บรหัสผ่าน

งานบันทึกบน Windows ทำงานด้วยสิทธิ์ SYSTEM จึงเริ่มเฉพาะโปรแกรมของ Windows เองและสคริปต์หนึ่งรายการในโฟลเดอร์ที่มีเพียงผู้ดูแลระบบเท่านั้นที่แก้ไขได้ โฟลเดอร์ข้อมูลบนพีซีและไฟล์ส่งออกไม่ได้เข้ารหัส
