Khronometr

隱私權政策

更新於2026年11月5日

Khronometr 顯示你在手機、平板電腦和電腦上使用應用程式和遊戲的總時間。它的設計讓你的資料始終屬於你：沒有 Khronometr 伺服器，沒有廣告，也沒有追蹤。

簡要說明

  • 留在你的裝置上
    你的歷史記錄儲存在手機和電腦上的應用程式內部。沒有 Khronometr 伺服器，Android 的自動備份也不會複製這個應用程式的資料。
  • 只用你自己的 Google 雲端硬碟
    同步是選用的，資料會存入你的雲端硬碟中一個隱藏的應用程式資料夾。其他應用程式無法開啟它，並由 Google 保存在你的帳號中。
  • 沒有廣告，沒有追蹤
    沒有分析工具，沒有廣告 SDK。不出售也不分享任何內容。
  • 只記時間，不看內容
    Khronometr 不讀取訊息、相片、你輸入的內容，也不讀取其他應用程式和視窗中的任何內容。
  • 隨時可以刪除
    解除安裝應用程式即可刪除該裝置上的資料。「從 Google 雲端硬碟刪除我的副本」會刪除雲端副本。
  • 三項外部請求
    Google 雲端硬碟（僅在你使用同步時）、GitHub（檢查更新），以及在 Windows 應用程式中、僅在你開啟後才會連線的 Steam 商店（用於查詢遊戲名稱）。它們各自都看得到你的 IP 位址。

手機應用程式讀取哪些內容

  • 應用程式使用狀況——開啟過哪些應用程式、用了多久，以及螢幕解鎖次數。僅在你於 Android 設定中為 Khronometr 開啟「使用狀況存取權」之後。
  • 每個應用程式的網路用量——每個應用程式使用了多少 Wi-Fi 和行動數據位元組，來自同一項權限。
  • 已安裝應用程式的名稱和圖示 — 用於在清單中顯示。為此，網站版本擁有查看所有已安裝應用程式的權限。
  • 裝置型號以及你為裝置取的名稱——用於區分你的各部裝置。
  • 裝置識別碼 — Android 在這支手機上指派給 Khronometr 的編號（Android ID）。它是你雲端硬碟資料夾中檔名的一部分，而且僅在你開啟同步時才會用到。
  • 你的出生日期，僅在你填寫時——只儲存在這支手機上，從不同步，用於顯示你的歷史紀錄從幾歲開始。

它不會讀取訊息、聯絡人、位置、相片、麥克風、相機、你輸入的內容，也不會讀取其他應用程式中的任何內容。

Windows 應用程式（選用）

如果你安裝了 Khronometr Windows 版，它會在該電腦上讀取：

  • 位於最前面的視窗所屬程式的名稱，以及使用時長；
  • 螢幕鎖定和解鎖的時間；
  • 你自己的 Steam 帳號中各遊戲的遊玩時間，來自這台電腦上的 Steam 檔案（如果你開啟了，還包括從 Steam 商店取得的遊戲名稱，見下文）；
  • 來自 Windows 內建使用紀錄的、每個程式較早的使用時間和流量，僅限你的 Windows 使用者，且僅在你允許一次之後。

它把這些儲存在自己的資料夾 %LOCALAPPDATA%\Khronometr 中，同時儲存你的 Google 位址（純文字），如果你登入了，還有一個加密的登入權杖。它不會讀取視窗裡的內容、按鍵、螢幕擷圖或瀏覽器歷史記錄。

Steam。大約每天一次，應用程式會從這台電腦上的 Steam 檔案中讀取你的 Steam 帳號的遊玩時間：讀取的是你的 Windows 使用者所使用的帳號，如果無法判斷，則讀取這台電腦上最後使用的帳號。向 Steam 公開商店查詢預設是關閉的。如果你在設定中開啟，那麼對於已不再安裝、且在電腦上找不到名稱的遊戲，應用程式會向 store.steampowered.com 查詢名稱，並儲存查到的結果。此時 Steam 會看到該遊戲的 ID 和你電腦的 IP 位址。這項功能不需要登入 Google 即可使用。

開啟同步後，它還會從同一個隱藏的雲端硬碟資料夾下載你其他裝置的資料，並在視窗中顯示。它在雲端硬碟中的檔案以這台電腦的識別碼命名（w- 加上 Windows 機器 ID），電腦名稱則作為裝置名稱儲存。它還會每 6 小時在 pegasohlib.github.io 上檢查自己的更新，而且只安裝帶有作者數位簽章的檔案；不會傳送任何個人資料，但伺服器看得到你的 IP 位址。

Windows 應用程式會在你的電腦上放置什麼

它只為你的使用者安裝，不需要管理員權限。它會新增：

  • 程式，位於 %LOCALAPPDATA%\Programs\Khronometr；
  • 一個開始功能表捷徑，以及 Windows「已安裝的應用程式」中的一項；
  • 自動啟動（屬於你的使用者的一個執行項目，首次啟動時開啟，可在設定中關閉）；
  • 一個屬於你的使用者的排定工作「Khronometr Watchdog」，如果應用程式沒有在執行，每 10 分鐘就會重新啟動它。

只有當你選擇匯入 Windows 記錄時，Windows 才會要求一次管理員權限。隨後應用程式會建立工作「Khronometr Journal」，它以 SYSTEM 身分每 6 小時執行一次。它只會啟動 Windows 內建的 cmd.exe 和 esentutl.exe，以及指令碼 C:\Program Files\Khronometr\journal-copy.cmd。該資料夾只有 SYSTEM 和管理員可以修改，其中的記錄副本只有他們和設定它的使用者可以讀取。這份副本是完整的 Windows 記錄，因此也包含這台電腦上所有其他 Windows 使用者的使用情況，而設定它的使用者可以讀取。應用程式本身只匯入該使用者自己的記錄。

解除安裝會移除程式、捷徑、自動啟動、Watchdog 工作和「已安裝的應用程式」中的項目。記錄工作會發現應用程式的資料夾已不存在，並刪除自己和它在 Program Files 中的資料夾，通常是立刻刪除，最遲在下次執行時，不會有任何提示。你的資料資料夾會保留；見「你的控制權與刪除」。

你的資料儲存在哪裡

所有內容都儲存在你的裝置上：在手機上儲存在應用程式自己的資料庫中，在電腦上儲存在應用程式自己的資料夾中，僅當你開啟同步時，才會儲存在你自己的雲端硬碟資料夾中。開發者沒有伺服器，也從不接收你的資料。在 Android 上，自動備份已關閉，因此資料不會進入 Google 的手機備份。

匯出檔案（zip）只在你要求時才會產生，並儲存在你選擇的位置。它們沒有加密，包含你的全部歷史記錄、你合併的應用程式和裝置 ID。

Google 雲端硬碟同步（選用）

如果你選擇「連接 Google 雲端硬碟」，應用程式會把歷史紀錄儲存在你自己的 Google 雲端硬碟的隱藏應用程式資料夾中。權限是 drive.appdata：應用程式只看得到它自己在那裡建立的檔案，看不到你雲端硬碟上的其他任何內容。

其中包括：每個應用程式每天的使用時間和流量、工作階段、應用程式名稱和圖示、裝置名稱、你的限制及其群組（以及每個共用限制今天已用了多少），還有你合併的應用程式清單（應用程式識別碼和合併時間）。檔名中包含寫入該檔案的裝置的識別碼（a- 加 Android ID，或 w- 加 Windows 裝置 ID）。這樣你的其他裝置才能顯示同樣的歷史記錄，限制才能在多台裝置上運作。

資料在你的裝置和 Google 之間以加密方式（HTTPS）傳輸。開發者無法存取你的雲端硬碟。應用程式會從雲端硬碟讀取一次你的 Google 電子郵件地址用於顯示；它儲存在該裝置上，不會傳送到其他任何地方。

關閉同步會停止傳送和接收，但已經在雲端硬碟上的內容會保留，舊裝置也仍會列在其中。要刪除雲端副本，請使用應用程式中的「從 Google 雲端硬碟刪除我的副本」（見「你的控制與刪除」）。

Khronometr 對從 Google API 取得之資訊的使用和傳輸，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

更新（網站版本）

來自本網站的版本大約每天兩次（Windows 應用程式每 6 小時）檢查 pegasohlib.github.io 是否有更新的版本，並從 GitHub 下載。Android 在安裝前會檢查它是否由同一位開發者簽署；Windows 應用程式只安裝數位簽章與作者金鑰一致的檔案。不會傳送任何關於你的資訊，但和任何網站一樣，GitHub 看得到你的 IP 位址。

「自動更新」開啟時（預設為開啟），應用程式會自行安裝更新；在 Android 上，僅當你允許了「安裝不明應用程式」時才會這樣，而且 Android 可能會要求你確認。關閉它只會停止安裝，不會停止檢查：之後應用程式只會告訴你有新版本發布。Google Play 版本則由 Google Play 負責更新。

GitHub 也會統計每個檔案被下載的次數。這只是一個數字，不包含任何關於下載者的資訊；網站會把它顯示為大致的下載量。

誰會取得你的資料

開發者什麼都不會收到：沒有伺服器，沒有數據分析，也沒有當機回報。你的資料不會被出售、分享或用於廣告。這些應用程式直接與三個外部服務通訊，它們看得到一般請求所顯示的資訊：

  • Google — 你自己的雲端硬碟，僅在你開啟同步時。
  • GitHub 和 pegasohlib.github.io — 網站版本中的更新檢查和下載；它們看得到你的 IP 位址。
  • Steam（Valve）——僅限 Windows 應用程式，且僅在你於設定中開啟之後：對於在電腦上找不到名稱的遊戲，它會在每天的 Steam 檢查期間向 store.steampowered.com 查詢名稱，不需要登入 Google。Steam 會看到遊戲 ID 和你電腦的 IP 位址。

你的控制權與刪除

  • 同步：隨時可以在「裝置」分頁中關閉。這會停止傳送和接收；已經在雲端硬碟裡的內容會保留。
  • 雲端副本：應用程式中的「從 Google 雲端硬碟刪除我的副本」會刪除應用程式存放在你雲端硬碟中的所有檔案，涵蓋你所有的裝置。之後手機會關閉同步，電腦會登出 Google。仍開啟著同步的裝置會再次上傳它的資料，除非你也在那台裝置上關閉同步。每台裝置上已有的內容會保留。你也可以使用 Google 雲端硬碟 → 設定 → 管理應用程式 → Khronometr → 刪除隱藏的應用程式資料。
  • 手機：清除應用程式的儲存空間或解除安裝它 — 手機上的所有內容都會消失。Android 的備份不會保留任何副本。
  • 電腦：Windows 設定 → 應用程式 → 已安裝的應用程式 → Khronometr → 解除安裝。資料資料夾 %LOCALAPPDATA%\Khronometr（歷史記錄、設定、你的 Google 位址）會保留：如果想徹底清除，請手動刪除。記錄工作會自行移除。
  • 匯出檔案是你自己的檔案：像刪除其他檔案一樣刪除即可。

安全性

與 Google 之間的所有通訊都使用 HTTPS。在手機上，登入由 Google Play 服務處理；在電腦上，登入權杖透過 Windows（DPAPI）加密，僅供你的使用者帳戶使用。應用程式從不要求也從不儲存密碼。

Windows 上的記錄工作以 SYSTEM 權限執行，因此它只會啟動 Windows 內建的程式，以及一個位於只有管理員才能修改的資料夾中的指令碼。電腦上的資料資料夾和匯出檔案都沒有加密。
