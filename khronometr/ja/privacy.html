フロノメトル

プライバシーポリシー

2026年11月4日更新

フロノメトルは、スマホ、タブレット、PC でアプリやゲームに使った時間をまとめて表示します。あなたのデータがあなたのものであり続けるように作られていて、フロノメトルにはサーバーも広告も追跡もありません。

概要

  • あなたのデバイスに残ります
    履歴は、スマホと PC のアプリの中に保存されます。フロノメトルのサーバーはなく、Android の自動バックアップもアプリのデータをコピーしません。
  • あなた自身の Google ドライブだけ
    同期は任意です。あなたのドライブにある、フロノメトルだけが見られる非表示のアプリ用フォルダに保存されます。
  • 広告なし、追跡なし
    アナリティクスも広告 SDK もありません。何も販売・共有しません。
  • 時間だけ、中身は見ない
    メッセージ、写真、入力した内容、他のアプリやウィンドウの中身は読み取りません。
  • いつでも削除できます
    アプリを削除すると、そのデバイス上のデータが消えます。「Google ドライブから自分のコピーを削除」を使うと、クラウド上のコピーが削除されます。
  • 外部へのリクエストは3つ
    Google ドライブ(同期する場合のみ)、GitHub(アップデートの確認)、そして Windows アプリでオンにした場合のみ、ゲーム名を調べるための Steam のストアです。いずれも IP アドレスを確認できます。

スマホアプリが読み取るもの

  • アプリの使用状況 — どのアプリをどれだけの時間開いていたか、画面のロック解除回数。Android の設定でフロノメトルの「使用状況へのアクセス」をオンにした後だけです。
  • アプリごとの通信量 — 各アプリが使った Wi-Fi とモバイルデータのバイト数。同じ権限で取得します。
  • インストールされているアプリの名前とアイコン — 一覧に表示するためです。ウェブサイト版は、このためにインストール済みのすべてのアプリを見る権限を持っています。
  • デバイスのモデルとあなたが付けたデバイス名 — デバイスを見分けるためです。
  • デバイスの識別子 — このスマホで Android がフロノメトルに割り当てる番号(Android ID)です。同期をオンにした場合に限り、Drive フォルダ内のファイル名の一部になります。
  • 生年月日（入力した場合のみ） — このスマホにだけ保存され、同期されることはありません。履歴が何歳から始まるかを表示するためです。

メッセージ、連絡先、位置情報、写真、マイク、カメラ、入力した内容、他のアプリの中身は読み取りません。

Windows アプリ(任意)

Windows 版フロノメトルをインストールすると、その PC で次の情報を読み取ります:

  • 前面にあるウィンドウのプログラム名と、その時間;
  • 画面がロック・ロック解除された時刻;
  • ご自身の Steam アカウントのゲームのプレイ時間(この PC 上の Steam のファイルから取得。オンにした場合は、Steam のストアから取得したゲーム名も含まれます。詳しくは下記をご覧ください)。
  • Windows 自身の利用履歴から取得した、プログラムごとの過去の利用時間と通信量(お使いの Windows ユーザーのみ。一度許可した場合にのみ取得します)。

これはアプリ専用のフォルダ %LOCALAPPDATA%\Khronometr に、あなたの Google アドレス(プレーンテキスト)と、ログインした場合は暗号化されたログイン トークンとともに保存されます。ウィンドウの中身、キー入力、スクリーンショット、ブラウザの履歴は読み取りません。

Steam。1日に1回ほど、この PC 上の Steam のファイルから、Steam アカウントのプレイ時間を読み取ります。対象は、お使いの Windows ユーザーで使われているアカウントで、判別できない場合は、この PC で最後に使われたアカウントです。Steam の公開ストアへの問い合わせは、初期設定ではオフです。設定でオンにすると、すでにアンインストールされていて名前が見つからないゲームについて、アプリが store.steampowered.com にゲーム名を問い合わせ、見つかった内容を保存します。このとき、Steam にはそのゲームの ID とお使いの PC の IP アドレスが伝わります。この機能は Google へのログインなしで動作します。

同期をオンにすると、同じ非表示の Drive フォルダから他のデバイスのデータもダウンロードし、ウィンドウに表示します。アプリの Drive ファイルには、この PC の識別子(w- と Windows のマシン ID)が名前に付けられ、PC の名前はデバイス名として保存されます。また、6時間ごとに pegasohlib.github.io で自身のアップデートを確認し、作者の電子署名があるファイルだけをインストールします。個人情報は送信されませんが、サーバーはあなたの IP アドレスを見ることができます。

Windows アプリが PC に置くもの

あなたのユーザーだけにインストールされ、管理者権限は不要です。次のものが追加されます。

  • プログラム本体。場所は %LOCALAPPDATA%\Programs\Khronometr。
  • スタートメニューのショートカットと、Windows のインストールされているアプリの項目。
  • 自動起動(あなたのユーザーの Run エントリ。初回起動時にオンになり、設定でオフにできます)。
  • あなたのユーザーのスケジュール タスク「Khronometr Watchdog」。アプリが実行中でなければ、10分ごとに再起動します。

Windows のジャーナルをインポートすることを選んだ場合に限り、Windows が管理者権限を一度求めます。するとアプリが、SYSTEM として6時間ごとに実行されるタスク「Khronometr Journal」を作成します。このタスクが起動するのは、Windows 自体の cmd.exe と esentutl.exe、そしてスクリプト C:\Program Files\Khronometr\journal-copy.cmd だけです。そのフォルダは SYSTEM と管理者しか変更できず、中のジャーナルのコピーも、それらと設定したユーザーしか読めません。

アンインストールすると、プログラム、ショートカット、自動起動、Watchdog タスク、インストールされているアプリの項目が削除されます。ジャーナルのタスクは、アプリのフォルダがなくなったことに気づいて、自分自身と自分の Program Files フォルダを確認なしで削除します。通常はすぐに、遅くとも次回の実行時です。データフォルダは残ります。「管理と削除」をご覧ください。

データの保存場所

すべてはあなたのデバイスに保存されます。スマホではアプリ専用のデータベースに、PC ではアプリ専用のフォルダに、そして同期をオンにした場合に限り、あなた自身の Drive フォルダに保存されます。開発者にサーバーはなく、あなたのデータを受け取ることもありません。Android では自動バックアップがオフになっているため、データは Google のスマホのバックアップに入りません。

エクスポートファイル（zip）は、あなたが操作したときだけ作られ、あなたが選んだ場所に保存されます。暗号化されておらず、履歴のすべて、まとめたアプリ、デバイスIDが含まれます。

Google ドライブ同期(任意)

「Google ドライブに接続」を選ぶと、アプリは履歴をあなた自身の Google ドライブの非表示のアプリ フォルダに保存します。権限は drive.appdata で、アプリはそこに自分で作成したファイルだけを見ることができ、ドライブ上のそれ以外のものは見られません。

保存される内容：アプリごとの1日の利用時間と通信量、セッション、アプリ名とアイコン、デバイス名、グループ付きの上限（共有上限ごとの今日の使用量を含む）、まとめたアプリの一覧（アプリ識別子とまとめた日時）。ファイル名には、書き込んだデバイスの識別子（a- と Android ID、または w- と Windows の端末ID）が含まれます。これにより、ほかのデバイスでも同じ履歴が表示され、上限が複数のデバイスで機能します。

データは、あなたのデバイスと Google の間で暗号化(HTTPS)されて送られます。開発者があなたの Drive にアクセスすることはできません。アプリは、表示のために Google のメールアドレスを Drive から一度だけ読み取ります。それはそのデバイスに保存され、ほかには送信されません。

同期をオフにすると送受信は止まりますが、すでにドライブにあるデータはそのまま残り、古いデバイスも一覧に残ります。クラウド上のコピーを削除するには、アプリの「Google ドライブから自分のコピーを削除」を使ってください(「コントロールと削除」をご覧ください)。

フロノメトルによる Google API から受け取った情報の使用および転送は、Limited Use(使用制限)の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

アップデート（ウェブサイト版）

このウェブサイトのバージョンは、1日に2回ほど(Windows アプリは6時間ごとに)pegasohlib.github.io で新しいバージョンがないか確認し、GitHub からダウンロードします。Android は、インストール前に同じ開発者の署名であることを確認します。Windows アプリは、電子署名が作者の鍵と一致するファイルだけをインストールします。あなたに関する情報は送信されませんが、ほかのウェブサイトと同様、GitHub はあなたの IP アドレスを見ることができます。

「自動で更新」がオン(初期設定ではオンです)のとき、アプリは自分でアップデートをインストールします。Android では「不明なアプリのインストール」を許可した場合に限り、Android が確認を求めることもあります。オフにすると、インストールだけが止まり、確認は続きます。その場合、アプリは新しいバージョンが出たことをお知らせするだけです。Google Play 版は、代わりに Google Play が更新します。

GitHub は各ファイルがダウンロードされた回数も数えています。これは数字だけで、誰がダウンロードしたかは含まれません。ウェブサイトではおおよそのダウンロード数として表示します。

あなたのデータを受け取る人

開発者は何も受け取りません。サーバーも、分析も、クラッシュレポートもありません。あなたのデータは販売も共有も広告への利用もされません。アプリは3つの外部サービスと直接通信し、それらは通常のリクエストで見える情報を見ることができます。

  • Google — あなた自身の Drive。同期をオンにした場合のみ。
  • GitHub と pegasohlib.github.io — ウェブサイト版のアップデートの確認とダウンロード。IP アドレスを見ることができます。
  • Steam(Valve) — Windows アプリのみ。設定でオンにした場合にのみ動作します。PC 上で名前が見つからないゲームについて、毎日の Steam の確認時に store.steampowered.com へ名前を問い合わせます。Google へのログインは不要です。Steam にはゲーム ID とお使いの PC の IP アドレスが伝わります。

管理と削除

  • 同期: 「デバイス」タブでいつでもオフにできます。送受信は止まりますが、すでに Drive にあるものは残ります。
  • クラウド上のコピー:アプリの「Google ドライブから自分のコピーを削除」を使うと、アプリがドライブに保存しているすべてのファイルが、すべてのデバイス分まとめて削除されます。その後、スマホは同期をオフにし、PC は Google からログアウトします。まだ同期がオンのデバイスは、そのデバイスでも同期をオフにしない限り、データを再びアップロードします。各デバイスにすでにあるデータは残ります。Google ドライブ → 設定 → アプリの管理 → フロノメトル → 非表示のアプリデータを削除、の手順でも削除できます。
  • スマホ: アプリのストレージを消去するか、アプリをアンインストールしてください。スマホ上のものはすべて消えます。Android のバックアップにはコピーが残りません。
  • PC: Windows の設定 → アプリ → インストールされているアプリ → フロノメトル → アンインストール。データフォルダ %LOCALAPPDATA%\Khronometr(履歴、設定、あなたの Google アドレス)は残ります。消したい場合は手動で削除してください。ジャーナルのタスクは自分で削除されます。
  • エクスポートはあなた自身のファイルです。他のファイルと同じように削除できます。

セキュリティ

Google との通信はすべて HTTPS です。スマホではログインを Google Play 開発者サービスが処理し、PC ではログイントークンを Windows(DPAPI)であなたのユーザー専用に暗号化します。アプリがパスワードを求めたり保存したりすることはありません。

Windows のジャーナルのタスクは SYSTEM 権限で実行されるため、起動するのは Windows 自体のプログラムと、管理者しか変更できないフォルダ内のスクリプト1つだけです。PC のデータフォルダとエクスポートファイルは暗号化されていません。
