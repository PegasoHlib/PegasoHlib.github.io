Khronometr

隐私政策

更新于2026年11月4日

Khronometr 显示你在手机、平板和电脑上使用应用和游戏的总时间。它的设计让你的数据始终属于你：没有 Khronometr 服务器，没有广告，也没有跟踪。

简要说明

  • 留在你的设备上
    你的历史记录保存在手机和电脑上的应用内部。没有 Khronometr 服务器，Android 的自动备份也不会复制这个应用的数据。
  • 只用你自己的 Google 云端硬盘
    同步是可选的，数据会存入你的云端硬盘中一个只有 Khronometr 能看到的隐藏应用文件夹。
  • 没有广告，没有跟踪
    没有分析工具，没有广告 SDK。不出售也不分享任何内容。
  • 只记时间，不看内容
    Khronometr 不读取消息、照片、你输入的内容，也不读取其他应用和窗口中的任何内容。
  • 随时可以删除
    卸载应用即可删除该设备上的数据。“从 Google 云端硬盘删除我的副本”会删除云端副本。
  • 三项外部请求
    Google 云端硬盘（仅在你使用同步时）、GitHub（检查更新），以及在 Windows 应用中、仅在你开启后才会访问的 Steam 商店（用于查询游戏名称）。它们各自都能看到你的 IP 地址。

手机应用读取哪些内容

  • 应用使用情况——打开过哪些应用、用了多久，以及屏幕解锁次数。仅在你于 Android 设置中为 Khronometr 开启“使用情况访问权限”之后。
  • 每个应用的网络用量——每个应用使用了多少 Wi-Fi 和移动数据字节数，来自同一项权限。
  • 已安装应用的名称和图标 — 用于在列表中显示。为此，网站版本拥有查看所有已安装应用的权限。
  • 设备型号以及你给设备起的名字——用于区分你的各台设备。
  • 设备标识符 — Android 在这部手机上分配给 Khronometr 的编号（Android ID）。它是你云端硬盘文件夹中文件名的一部分，并且仅在你开启同步时才会用到。
  • 你的出生日期，仅当你填写时——只保存在这部手机上，从不同步，用于显示你的历史记录从几岁开始。

它不会读取消息、通讯录、位置、照片、麦克风、摄像头、你输入的内容，也不会读取其他应用中的任何内容。

Windows 应用（可选）

如果你安装了 Khronometr Windows 版，它会在该电脑上读取：

  • 位于最前面的窗口所属程序的名称，以及使用时长；
  • 屏幕锁定和解锁的时间；
  • 你自己的 Steam 账号中各游戏的游玩时间，来自这台电脑上的 Steam 文件（如果你开启了，还包括从 Steam 商店获取的游戏名称，见下文）；
  • 来自 Windows 自带使用记录的、每个程序较早的使用时间和流量，仅限你的 Windows 用户，且仅在你允许一次之后。

它把这些保存在自己的文件夹 %LOCALAPPDATA%\Khronometr 中，同时保存你的 Google 地址（纯文本），如果你登录了，还有一个加密的登录令牌。它不会读取窗口里的内容、按键、屏幕截图或浏览器历史。

Steam。大约每天一次，应用会从这台电脑上的 Steam 文件中读取你的 Steam 账号的游玩时间：读取的是你的 Windows 用户所使用的账号，如果无法判断，则读取这台电脑上最后使用的账号。向 Steam 公开商店查询默认是关闭的。如果你在设置中开启，那么对于已不再安装、且在电脑上找不到名称的游戏，应用会向 store.steampowered.com 查询名称，并保存查到的结果。此时 Steam 会看到该游戏的 ID 和你电脑的 IP 地址。这项功能无需登录 Google 即可使用。

开启同步后，它还会从同一个隐藏的云端硬盘文件夹下载你其他设备的数据，并在窗口中显示。它在云端硬盘中的文件以这台电脑的标识符命名（w- 加上 Windows 机器 ID），电脑名称则作为设备名称保存。它还会每 6 小时在 pegasohlib.github.io 上检查自己的更新，并且只安装带有作者数字签名的文件；不会发送任何个人数据，但服务器能看到你的 IP 地址。

Windows 应用会在你的电脑上放置什么

它只为你的用户安装，不需要管理员权限。它会添加：

  • 程序，位于 %LOCALAPPDATA%\Programs\Khronometr；
  • 一个开始菜单快捷方式，以及 Windows“已安装的应用”中的一项；
  • 自启动（属于你的用户的一个运行项，首次启动时开启，可在设置中关闭）；
  • 一个属于你的用户的计划任务“Khronometr Watchdog”，如果应用没有在运行，每 10 分钟就会重新启动它。

只有当你选择导入 Windows 日志时，Windows 才会请求一次管理员权限。随后应用会创建任务“Khronometr Journal”，它以 SYSTEM 身份每 6 小时运行一次。它只会启动 Windows 自带的 cmd.exe 和 esentutl.exe，以及脚本 C:\Program Files\Khronometr\journal-copy.cmd。该文件夹只有 SYSTEM 和管理员可以修改，其中的日志副本只有他们和设置它的用户可以读取。

卸载会移除程序、快捷方式、自启动、Watchdog 任务和“已安装的应用”中的条目。日志任务会发现应用的文件夹已不存在，并删除自己和它在 Program Files 中的文件夹，通常是立刻删除，最迟在下次运行时，不会有任何提示。你的数据文件夹会保留；见“你的控制权与删除”。

你的数据保存在哪里

所有内容都保存在你的设备上：在手机上保存在应用自己的数据库中，在电脑上保存在应用自己的文件夹中，仅当你开启同步时，才会保存在你自己的云端硬盘文件夹中。开发者没有服务器，也从不接收你的数据。在 Android 上，自动备份已关闭，因此数据不会进入 Google 的手机备份。

导出文件（zip）只会在你要求时创建，并保存在你选择的位置。它们未加密，其中包含你的全部历史记录和设备 ID。

Google 云端硬盘同步（可选）

如果你选择“连接 Google 云端硬盘”，应用会把历史记录保存在你自己的 Google 云端硬盘的隐藏应用文件夹中。权限是 drive.appdata：应用只能看到它自己在那里创建的文件，看不到你云端硬盘上的其他任何内容。

其中包括：每个应用的每日时间和流量、使用记录、应用名称和图标、设备名称，以及你的限制和分组（外加每条共享限制今天已用了多少）。文件名包含写入该文件的设备的标识符（a- 加上 Android ID，或 w- 加上 Windows 机器 ID）。你的其他设备正是这样显示同一份历史记录，限制也是这样在多台设备上生效的。

数据在你的设备和 Google 之间以加密方式（HTTPS）传输。开发者无法访问你的云端硬盘。应用会从云端硬盘读取一次你的 Google 电子邮件地址用于显示；它保存在该设备上，不会发送到其他任何地方。

关闭同步会停止发送和接收，但已经在云端硬盘上的内容会保留，旧设备也仍会列在其中。要删除云端副本，请使用应用中的“从 Google 云端硬盘删除我的副本”（见“你的控制与删除”）。

Khronometr 对从 Google API 获取的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的“有限使用”要求。

更新（网站版本）

来自本网站的版本大约每天两次（Windows 应用每 6 小时）检查 pegasohlib.github.io 是否有更新的版本，并从 GitHub 下载。Android 在安装前会检查它是否由同一位开发者签名；Windows 应用只安装数字签名与作者密钥一致的文件。不会发送任何关于你的信息，但和任何网站一样，GitHub 能看到你的 IP 地址。

“自动更新”开启时（默认开启），应用会自行安装更新；在 Android 上，仅当你允许了“安装未知应用”时才会这样，而且 Android 可能会要求你确认。关闭它只会停止安装，不会停止检查：之后应用只会告诉你有新版本发布。Google Play 版本则由 Google Play 负责更新。

GitHub 还会统计每个文件被下载的次数。这只是一个数字，不包含任何关于下载者的信息；网站会把它显示为大致的下载量。

谁会获得你的数据

开发者什么都不会收到：没有服务器，没有数据分析，也没有崩溃报告。你的数据不会被出售、共享或用于广告。这些应用直接与三个外部服务通信，它们能看到一次普通请求所显示的信息：

  • Google — 你自己的云端硬盘，仅在你开启同步时。
  • GitHub 和 pegasohlib.github.io — 网站版本中的更新检查和下载；它们能看到你的 IP 地址。
  • Steam（Valve）——仅限 Windows 应用，且仅在你于设置中开启之后：对于在电脑上找不到名称的游戏，它会在每天的 Steam 检查期间向 store.steampowered.com 查询名称，无需登录 Google。Steam 会看到游戏 ID 和你电脑的 IP 地址。

你的控制权与删除

  • 同步：随时可以在“设备”标签页中关闭。这会停止发送和接收；已经在云端硬盘里的内容会保留。
  • 云端副本：应用中的“从 Google 云端硬盘删除我的副本”会删除应用保存在你云端硬盘中的所有文件，涉及你所有的设备。之后手机会关闭同步，电脑会退出 Google 登录。仍开启着同步的设备会再次上传它的数据，除非你也在那台设备上关闭同步。每台设备上已有的内容会保留。你也可以使用 Google 云端硬盘 → 设置 → 管理应用 → Khronometr → 删除隐藏的应用数据。
  • 手机：清除应用的存储空间或卸载它 — 手机上的所有内容都会消失。Android 的备份不会保留任何副本。
  • 电脑：Windows 设置 → 应用 → 已安装的应用 → Khronometr → 卸载。数据文件夹 %LOCALAPPDATA%\Khronometr（历史记录、设置、你的 Google 地址）会保留：如果想彻底清除，请手动删除。日志任务会自行移除。
  • 导出文件是你自己的文件：像删除其他文件一样删除即可。

安全

与 Google 之间的所有通信都使用 HTTPS。在手机上，登录由 Google Play 服务处理；在电脑上，登录令牌通过 Windows（DPAPI）加密，仅供你的用户账户使用。应用从不要求也从不保存密码。

Windows 上的日志任务以 SYSTEM 权限运行，因此它只会启动 Windows 自带的程序，以及一个位于只有管理员才能修改的文件夹中的脚本。电脑上的数据文件夹和导出文件都没有加密。
