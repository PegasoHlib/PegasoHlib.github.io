ブラウザに保存されるもの

言語を選んだりテーマを切り替えたりすると、次回も同じ表示でページが開くように、サイトはその選択をブラウザのローカルストレージに保存します。選択するまでは何も保存されません。

同意バナーがない理由

この2つの項目は Cookie ではありません。識別子を含まず、どのサーバーにも送信されず、他のウェブサイトにも引き継がれません。あなた自身が選んだ設定を保持するだけなので、サイトは同意を求めません。削除するには、ブラウザの設定でこのサイトのデータを消去してください。

ブラウザゲーム SOTY: Honeycomb Kingdoms

pegasohlib.com/soty/play/ のゲームは、あなたのブラウザの中で動きます。ゲームの続きを遊べるように、また設定を保てるように、ゲームはそれらをあなたの端末にあるこのサイトのローカルストレージに、soty. で始まる名前で保存します。また、サイトで選んだ言語で開くために siteLang を読み取ります。

これらの項目は、あなたが開いたゲームを動かすために必要で、あなたに関する情報を含まないため、ゲームも同意を求めません。これらはあなたの端末に残ります。ゲームがルームのコードとあなたの席のキーを送るのは、友だちとオンラインで遊ぶときだけで、送り先は pegasohlib.com/soty/api/ にあるゲーム独自のルームサーバーだけです。Cloudflare はそのサーバーを PegasoHlib のために運用し、各オンライン対戦を、自動的に削除されるまで EU 内に保存します。削除されるのは、最後の手から30日後、または終了から7日後です。削除するには、ゲームのポーズメニューでゲームデータを消去を使うか、ブラウザでこのサイトのデータを消去してください。詳しくはゲームのプライバシーポリシーをご覧ください。

ゲームの設定：ヒント、CPU の速度、グラフィック品質、文字サイズと動きの量、前回のゲームの設定、オンライン対戦用のプリセット名とターンタイマー。

ダウンロードと数値

ダウンロードボタンは、GitHub に保存されているファイルにつながっています。ボタンを押すと、ブラウザが GitHub に接続し、GitHub がそのファイルのカウンターを1つ増やします。PegasoHlib が見られるのはファイルごとの合計だけで、誰がダウンロードしたかは決してわかりません。

ダウンロード数の合計は、ページに表示される場合、サイトをビルドするときに追加されるため、ブラウザがそのために GitHub の API に接続することはありません。バージョン番号とファイルサイズは、この同じサイトのファイルから読み取られます。

メールを送った場合

連絡先アドレス宛てのメールは、このドメインの DNS とメール転送を運用する Cloudflare を経由します。そこで小さなプログラムがメッセージのヘッダーを読み取り、自動返信をお送りすることがあります。メッセージは Gmail のメールボックスに転送されるため、Google も処理します。PegasoHlib は、メールを読む際に Anthropic の AI アシスタント Claude を使うことがあります。PegasoHlib は、あなたのアドレスとメッセージを、お返事と、ご報告いただいた問題の修正のためだけに使い（正当な利益）、他の誰とも共有しません。いつでも削除を求めることができます。
