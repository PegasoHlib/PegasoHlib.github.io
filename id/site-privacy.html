Halaman ini tentang situs web pegasohlib.github.io: halaman utama dan halaman aplikasi. Singkatnya: tanpa akun, tanpa cookie, tanpa iklan, dan tanpa analitik. Apa yang dilakukan setiap aplikasi atau game dengan data dijelaskan di kebijakan privasinya sendiri, yang tercantum di bawah.

Sekilas

  • Situs ini tidak memasang cookie dan tidak punya iklan, analitik, atau tombol media sosial.
  • Bahasa dan tema yang kamu pilih tetap berada di browsermu sendiri dan tidak pernah dikirim ke mana pun.
  • GitHub menghosting situs ini dan mencatat alamat IP pengunjung demi keamanan.
  • File diunduh dari GitHub, sehingga GitHub melihat dan menghitung setiap unduhan.
  • Jika kamu mengirim email, isinya hanya dipakai untuk membalasmu.

Mengapa tidak ada banner persetujuan

Kedua entri ini bukan cookie. Keduanya tidak berisi pengenal, tidak dikirim ke server mana pun, dan tidak mengikutimu ke situs web lain. Keduanya hanya menyimpan pengaturan yang kamu pilih sendiri, sehingga situs tidak meminta persetujuan. Untuk menghapusnya, bersihkan data situs ini di pengaturan browsermu.

Hosting

Situs ini berjalan di GitHub Pages, layanan dari GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub mencatat alamat IP setiap pengunjung untuk tujuan keamanan, baik pengunjung itu punya akun GitHub maupun tidak. PegasoHlib tidak memiliki akses ke catatan ini. GitHub bertanggung jawab atas data ini: lihat GitHub Privacy Statement.

Unduhan dan angka

Tombol unduh mengarah ke file yang disimpan di GitHub. Saat kamu menekannya, browsermu terhubung ke GitHub, dan GitHub menambahkan satu ke penghitung file itu. PegasoHlib hanya melihat total untuk setiap file, tidak pernah siapa yang mengunduhnya.

Total unduhan, jika sebuah halaman menampilkannya, ditambahkan saat situs dibangun, jadi browsermu tidak menghubungi API GitHub untuk itu. Nomor versi dan ukuran file dibaca dari file di situs yang sama ini.
