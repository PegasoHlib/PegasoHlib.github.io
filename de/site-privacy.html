Datenschutz der Website

Zuletzt aktualisiert: 12. November 2026

Diese Seite betrifft die Website pegasohlib.com: die Hauptseite und die App-Seiten. Kurz gesagt: keine Konten, keine Cookies, keine Werbung und keine Analysen. Was jede App oder jedes Spiel mit Daten macht, steht in der eigenen Datenschutzerklärung, die unten aufgelistet ist.

Auf einen Blick

  • Die Website setzt keine Cookies und hat weder Werbung noch Analyse noch Schaltflächen für soziale Medien.
  • Deine gewählte Sprache und dein Design bleiben in deinem eigenen Browser und werden nirgendwohin gesendet.
  • Cloudflare liefert die Website aus und sieht die IP-Adressen der Besucher. GitHub speichert die Dateien und sieht deine IP-Adresse nur bei Downloads oder auf der alten Adresse.
  • Dateien werden von GitHub heruntergeladen, daher sieht und zählt GitHub jeden Download.
  • Wenn du eine E-Mail sendest, wird sie nur verwendet, um dir zu antworten.

Was in deinem Browser gespeichert wird

Wenn du eine Sprache wählst oder das Design wechselst, speichert die Website diese Auswahl im lokalen Speicher deines Browsers, damit die Seiten beim nächsten Mal genauso öffnen. Es wird nichts gespeichert, bevor du eine Auswahl triffst.

siteLang
Die Sprache, die du gewählt hast.
pegasohlib-theme
Das helle oder dunkle Design, das du gewählt hast.

Warum es kein Einwilligungsbanner gibt

Diese zwei Einträge sind keine Cookies. Sie enthalten keine Kennung, werden an keinen Server gesendet und folgen dir nicht auf andere Websites. Sie speichern nur eine Einstellung, die du selbst gewählt hast, daher fragt die Website nicht nach einer Einwilligung. Um sie zu entfernen, lösche die Daten dieser Website in den Einstellungen deines Browsers.

Das Browserspiel SOTY: Honeycomb Kingdoms

Das Spiel unter pegasohlib.com/soty/play/ läuft vollständig in deinem Browser. Damit du ein Spiel fortsetzen und deine Einstellungen behalten kannst, speichert es diese Daten im lokalen Speicher dieser Website auf deinem Gerät, unter Namen, die mit soty. beginnen. Außerdem liest es siteLang, damit es in der Sprache öffnet, die du auf der Website gewählt hast.

Diese Einträge sind nötig, damit das Spiel funktioniert, das du geöffnet hast. Sie bleiben auf deinem Gerät, werden nie an jemanden gesendet und enthalten nichts über dich, daher fragt auch das Spiel nicht nach einer Einwilligung. Um sie zu entfernen, nutze Spieldaten löschen im Pausenmenü des Spiels oder lösche die Daten dieser Website in deinem Browser. Die Einzelheiten stehen in der Datenschutzerklärung des Spiels.

soty.save
Das laufende Spiel: die Karte, die Staaten, ihre Einheiten und die Runde.
soty.prefs
Spieleinstellungen: Tipps, KI-Geschwindigkeit, Grafikstufe und die Konfiguration des letzten Spiels.
soty.sound
Ob der Ton eingeschaltet ist.
soty.lang
Die Sprache des Spiels, sobald du sie im Spiel umstellst.

Hosting

Die Website läuft auf GitHub Pages, einem Dienst von GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub protokolliert aus Sicherheitsgründen die IP-Adresse aller, die sich direkt damit verbinden, unabhängig davon, ob sie ein GitHub-Konto haben. PegasoHlib hat keinen Zugriff auf diese Protokolle. GitHub ist für diese Daten verantwortlich: siehe die GitHub Privacy Statement.

Besucher von pegasohlib.com erreichen die Website über Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA: Dein Browser verbindet sich mit Cloudflare, und Cloudflare holt die Seite von GitHub. Deshalb sieht Cloudflare deine IP-Adresse, die Seite, die du öffnest, und die technischen Angaben, die jeder Browser sendet. Cloudflare verarbeitet sie im Auftrag von PegasoHlib nach seinem Auftragsverarbeitungsvertrag, um die Website über eine sichere Verbindung auszuliefern und vor Angriffen zu schützen (berechtigtes Interesse). PegasoHlib sieht nur Gesamtzahlen und die Angaben zu einer Anfrage, die Cloudflare blockiert. Cloudflare setzt hier keine Cookies, außer wenn sein Schutz einen Besucher zu einer Sicherheitsprüfung auffordert: Dann zeigt es eine eigene Prüfseite und kann ein unbedingt erforderliches Cookie setzen, cf_clearance. GitHub erhält bei diesen Besuchen deine IP-Adresse nicht, es sieht nur Cloudflare. Direkt mit GitHub verbindet sich dein Browser nur bei Downloads und auf der alten Adresse pegasohlib.github.io. Siehe die Cloudflare Privacy Policy.

Downloads und Zahlen

Download-Schaltflächen führen zu Dateien, die auf GitHub gespeichert sind. Wenn du eine drückst, verbindet sich dein Browser mit GitHub, und GitHub erhöht den Zähler dieser Datei um eins. PegasoHlib sieht nur die Gesamtzahl pro Datei, nie, wer sie heruntergeladen hat.

Download-Summen, wo eine Seite sie zeigt, werden beim Erstellen der Website eingefügt, sodass dein Browser dafür nicht die API von GitHub kontaktiert. Versionsnummern und Dateigrößen werden aus Dateien auf derselben Website gelesen.

  • Schriften oder Skripte anderer Unternehmen: Die Schriften liefert diese Website selbst aus;
  • Konten oder Formulare.

Wenn du eine E-Mail sendest

E-Mails an die Kontaktadresse laufen über Cloudflare, das DNS und Mail-Routing dieser Domain betreibt. Ein kleines Programm dort liest die Kopfzeilen der Nachricht und kann dir eine automatische Antwort senden. Die Nachricht wird an ein Gmail-Postfach weitergeleitet, daher verarbeitet auch Google sie. PegasoHlib kann beim Lesen von E-Mails einen KI-Assistenten nutzen, Claude von Anthropic. PegasoHlib verwendet deine Adresse und deine Nachricht nur, um dir zu antworten und das zu beheben, was du meldest (berechtigtes Interesse), und gibt sie an niemanden sonst weiter. Du kannst jederzeit verlangen, dass sie gelöscht werden.
