Privacidade do site

Última atualização: 13 de novembro de 2026

Esta página é sobre o site pegasohlib.com: a página principal e as páginas das apps. Em resumo: sem contas, sem cookies, sem anúncios e sem análises. O que cada app ou jogo faz com os dados é explicado na sua própria política de privacidade, listada abaixo.

Em resumo

  • O site não define cookies e não tem anúncios, estatísticas de utilização nem botões de redes sociais.
  • O idioma e o tema que escolhes ficam no teu próprio navegador e nunca são enviados para lado nenhum.
  • A Cloudflare entrega o site e vê os endereços IP dos visitantes. O GitHub guarda os ficheiros e só vê o teu endereço IP nas transferências ou no endereço antigo.
  • Os ficheiros são transferidos a partir do GitHub, pelo que o GitHub vê e contabiliza cada transferência.
  • Se enviares um e-mail, este é usado apenas para te responder.

O que fica guardado no teu navegador

Quando escolhes um idioma ou mudas o tema, o site guarda essa escolha no armazenamento local do teu navegador, para que as páginas abram da mesma forma da próxima vez. Nada é guardado até fazeres uma escolha.

siteLang
O idioma que escolheste.
pegasohlib-theme
O tema claro ou escuro que escolheste.

Porque não há aviso de consentimento

Estas duas entradas não são cookies. Não contêm nenhum identificador, não são enviadas a nenhum servidor e não te seguem para outros sites. Apenas guardam uma definição que escolheste tu próprio, pelo que o site não pede consentimento. Para as remover, apaga os dados deste site nas definições do teu navegador.

O jogo de navegador SOTY: Honeycomb Kingdoms

O jogo em pegasohlib.com/soty/play/ funciona no teu navegador. Para que possas continuar uma partida e manter as tuas definições, guarda esses dados no armazenamento local deste site no teu dispositivo, com nomes que começam por soty.. Também lê siteLang, para abrir no idioma que escolheste no site.

Estas entradas são necessárias para o funcionamento do jogo que abriste e não contêm nada sobre ti, pelo que o jogo também não pede consentimento. Ficam no teu dispositivo. Só quando jogas online com amigos é que o jogo envia o código de uma sala e a chave do teu lugar, e apenas para o seu próprio servidor de salas, em pegasohlib.com/soty/api/. A Cloudflare gere esse servidor para a PegasoHlib e guarda cada partida online na UE até esta se apagar a si própria: 30 dias após a sua última jogada, ou 7 dias após terminar. Para as remover, usa Apagar dados do jogo no menu de pausa do jogo, ou apaga os dados deste site no teu navegador. Os pormenores estão na política de privacidade do jogo.

soty.save
A partida em curso neste dispositivo: o mapa, os Estados, as suas unidades e o turno.
soty.slots
Até três partidas guardadas nos próprios espaços de gravação do jogo, cada uma como a partida em curso.
soty.prefs
Definições do jogo: dicas, velocidade da IA, nível de gráficos, tamanho do texto e movimento, a configuração da última partida, e o nome predefinido e o temporizador de turno para as partidas online.
soty.sound
Se o som está ligado.
soty.lang
O idioma do jogo, quando o mudas no jogo.
soty.rooms
As partidas online em que tens um lugar: o código de cada sala, o teu lugar e a sua chave, o teu nome predefinido e o que lá viste da última vez.

Alojamento

O site funciona no GitHub Pages, um serviço da GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. O GitHub regista por motivos de segurança o endereço IP de quem se liga diretamente a ele, tenha ou não uma conta GitHub. A PegasoHlib não tem acesso a estes registos. O GitHub é responsável por estes dados: consulta a GitHub Privacy Statement.

Quem visita pegasohlib.com chega ao site através da Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA: o teu navegador liga-se à Cloudflare, que vai buscar a página ao GitHub. Por isso, a Cloudflare vê o teu endereço IP, a página que abres e os dados técnicos que qualquer navegador envia. Trata-os em nome da PegasoHlib, ao abrigo do seu acordo de tratamento de dados, para entregar o site por uma ligação segura e o proteger de ataques (interesse legítimo). A PegasoHlib vê apenas totais gerais, além dos detalhes de um pedido que a Cloudflare bloqueie. A Cloudflare não coloca cookies aqui, a não ser que a sua proteção peça a um visitante que passe uma verificação de segurança: nesse caso mostra a sua própria página de verificação e pode colocar um cookie estritamente necessário, cf_clearance. Nestas visitas o GitHub não recebe o teu endereço IP: vê apenas a Cloudflare. O teu navegador só se liga diretamente ao GitHub nas transferências e no endereço antigo pegasohlib.github.io. Consulta a Cloudflare Privacy Policy.

Transferências e números

Os botões de transferência levam a ficheiros guardados no GitHub. Quando carregas num, o teu navegador liga-se ao GitHub, e o GitHub acrescenta uma unidade ao contador desse ficheiro. A PegasoHlib vê apenas o total de cada ficheiro, nunca quem o transferiu.

Os totais de transferências, onde uma página os mostra, são acrescentados quando o site é gerado, por isso o teu navegador não contacta a API do GitHub para os obter. Os números de versão e os tamanhos de ficheiro são lidos de ficheiros deste mesmo site.

  • ferramentas de análise ou rastreio de visitantes;
  • botões de redes sociais ou vídeos incorporados;
  • tipos de letra ou scripts de outras empresas: os tipos de letra são servidos por este site;
  • contas ou formulários.

Se enviares um e-mail

Os e-mails enviados para o endereço de contacto passam pela Cloudflare, que gere o DNS e o encaminhamento de e-mail deste domínio. Um pequeno programa lê aí os cabeçalhos da mensagem e pode enviar-te uma resposta automática. A mensagem é reencaminhada para uma caixa de correio Gmail, pelo que a Google também a trata. A PegasoHlib pode usar um assistente de IA, o Claude da Anthropic, para ajudar a ler os e-mails. A PegasoHlib usa o teu endereço e a tua mensagem apenas para te responder e para corrigir o que comunicares (interesse legítimo), e não os partilha com mais ninguém. Podes pedir a sua eliminação a qualquer momento.

Os teus direitos e os pormenores legais

Quem é o responsável. A PegasoHlib, uma pessoa singular que desenvolve estas aplicações, é responsável pelos dados descritos aqui. Contacto: support@pegasohlib.com.

Quem recebe os dados, e transferências para fora da UE. O GitHub aloja os ficheiros deste site e vê o endereço IP de quem se liga diretamente a ele. A Cloudflare gere o DNS deste domínio e reencaminha os e-mails enviados para o endereço de contacto, a Google guarda-os numa caixa de correio Gmail e a Anthropic pode tratá-los quando o assistente de IA ajuda a lê-los. As quatro empresas estão sediadas nos Estados Unidos. Essas transferências baseiam-se no Quadro de Proteção de Dados UE-EUA, quando a empresa participa nele, ou nas cláusulas contratuais-tipo da empresa. As mesmas garantias aplicam-se à Cloudflare quando entrega este site e vê os endereços IP dos visitantes, e quando gere o servidor de salas do SOTY: Honeycomb Kingdoms, que guarda as partidas online na UE.

Durante quanto tempo são conservados. Os e-mails que enviares são conservados até o assunto ficar encerrado, e no máximo durante 2 anos. As partidas online do SOTY: Honeycomb Kingdoms são apagadas 30 dias após a sua última jogada, ou 7 dias após terminarem. O GitHub conserva os seus registos segundo as suas próprias regras. A Cloudflare faz o mesmo.

Os teus direitos. Podes pedir o acesso aos teus dados, a retificação, o apagamento, a limitação do tratamento e uma cópia para levares para outro lado (portabilidade), e podes opor-te ao tratamento. Escreve para o endereço acima. Receberás uma resposta no prazo de um mês. A PegasoHlib só detém dados pessoais teus se enviaste um e-mail, jogas ZORYT ou jogas SOTY: Honeycomb Kingdoms online; as respetivas políticas de privacidade explicam o que guardam. Quanto aos dados de alojamento e de transferências, contacta o GitHub. Quanto aos dados que a Cloudflare guarda ao entregar o site, escreve para o endereço acima e a PegasoHlib encaminhará o teu pedido.

Reclamações. Podes apresentar reclamação à autoridade de proteção de dados do teu país.

Língua. As traduções desta página são feitas com a ajuda de IA. Se uma tradução diferir do texto em inglês, aplica-se a versão que for mais favorável para ti.
