Oberih

개인정보 처리방침

마지막 업데이트: 2026년 11월 5일

Oberih는 PegasoHlib이 만든 무료 Windows 앱으로, Windows에 기본 제공되는 백신인 Microsoft Defender의 상태를 보여 주고, 설정을 관리하며, 보안 팁을 알려 줘요. 이 방침은 Oberih가 데이터를 어떻게 다루는지 설명해요. 요약하면, 모든 것은 내 PC에 남고 개발자에게는 아무것도 전송되지 않아요.

한눈에 보기

  • Oberih는 PC에서 바로 Windows의 보호 상태를 읽어요. 이 정보는 컴퓨터 밖으로 나가지 않아요.
  • Oberih에는 서버, 계정, 분석 도구가 없어요. 개발자는 어떤 데이터도 받지 않아요.
  • 업데이트를 확인하고 GitHub에서 내려받을 때만 온라인에 접속해요. 자동 확인은 기본으로 켜져 있으며 끌 수 있어요.
  • 설정, 오류 로그, 짧은 사운드 파일은 내 PC의 %LOCALAPPDATA%\Oberih에 보관돼요.
  • 관리자 권한은 잠금 해제를 누를 때만 요청하며, 창을 닫을 때까지 유지돼요.
  • Microsoft Defender 자체가 Microsoft로 보내는 정보는 Oberih가 아니라 Microsoft 개인정보처리방침의 적용을 받아요.

Oberih가 PC에서 읽는 정보

보호 상태를 보여 주기 위해 Oberih는 창이 열려 있는 동안에만 PC 안에서 다음을 읽어요.

  • Microsoft Defender의 상태, 설정, 위협(영향을 받은 파일의 경로와 관련된 프로그램 포함), 탐지 기록, 격리를 Windows 자체 인터페이스(WMI와 MpCmdRun.exe)를 통해 읽어요.
  • Oberih 밖에서 시작된 검사를 알아차리기 위한 Defender 이벤트 로그
  • 그 밖의 Windows 보안 설정: 방화벽, Windows 보안에 등록된 다른 백신이나 방화벽 앱, 사용자 계정 컨트롤, SmartScreen, 메모리 무결성, 시스템 드라이브 암호화, 마지막 Windows 업데이트 날짜

이 정보는 화면에 표시될 뿐, 저장하거나 복사하거나 어디로도 보내지 않아요. 검사 시간을 예측하기 위해 Oberih는 드라이브의 사용 공간과, 검사하려고 선택한 폴더나 파일의 크기도 읽어요.

Oberih가 PC에 저장하는 정보

Oberih는 작은 설정 파일 하나, %LOCALAPPDATA%\Oberih\settings.json을 저장해요. 들어 있는 내용은 다음과 같아요.

  • 언어, 테마, 글자 크기, 소리 설정
  • 읽음으로 표시한 팁, 환영 화면과 설치 제안을 이미 봤는지 여부
  • 업데이트를 자동으로 확인할지 여부와 건너뛰기로 한 버전
  • 진행률 예측을 위한, 이 PC에서 이전 검사에 걸린 시간

기술적인 오류 메시지(예를 들어 링크를 열 수 없었거나 앱이 중단되었을 때)는 같은 폴더의 error.log에 기록돼요.

Oberih에는 짧은 효과음도 내장되어 있어요. 기본으로 켜져 있으며, 소리가 처음 재생될 때 파일이 %LOCALAPPDATA%\Oberih\sounds에 앱 버전마다 폴더 하나씩 복사돼요. 소리는 설정에서 끌 수 있어요.

내려받은 파일을 실행하면 .NET이 그 일부를 Windows의 임시 파일 폴더(%TEMP%\.net\Oberih)에 풀 수 있어요. 이 폴더는 앱 자체 데이터의 일부가 아니며 제거해도 삭제되지 않아요. 직접 삭제해도 돼요.

다른 관리자 계정으로 Oberih의 잠금을 풀면 Windows는 그 계정으로 Oberih를 실행하고, 위의 폴더는 그 계정의 프로필에 생겨요.

이 파일들은 내 PC에 남으며 Oberih는 이를 어디로도 보내지 않아요. Oberih 설정에서 이 폴더를 열 수 있어요.

설치

Oberih를 설치하기로 하면 스스로를 %LOCALAPPDATA%\Programs\Oberih에 복사하고, 시작 메뉴 바로 가기와 바탕 화면 바로 가기(바탕 화면 것은 삭제해도 돼요)를 만들고, Windows 설치된 앱 목록에(레지스트리의 내 사용자 영역에) 항목을 추가해요. 이를 위해 관리자 권한은 필요 없어요. Oberih는 Windows와 함께 시작하지 않으며 예약 작업도 추가하지 않아요.

인터넷: 업데이트에만 사용

Oberih가 온라인에 접속하는 것은 한 가지, 자체 업데이트를 위해서예요. 기본적으로 시작하고 몇 초 뒤, 그리고 창이 열려 있는 동안 12시간마다 가장 새로운 버전의 번호가 담긴 작은 파일 pegasohlib.github.io/oberih/update.json을 읽어요. 더 새로운 버전이 있으면 Oberih가 버튼을 표시하고, 내가 누를 때만 GitHub(github.com과 그 다운로드 서버)에서 새 버전을 내려받아요. 설치 전에 Oberih는 업데이트 정보에 있는 제작자의 서명과 파일의 체크섬 및 버전을 확인해요. 새 파일은 잠시 앱 파일 옆에 저장되었다가 그것을 대체해요.

이 요청에는 나나 내 PC에 관한 데이터가 들어 있지 않아요. 표준 “User-Agent” 헤더에 있는 Oberih의 버전 번호와, 오래된 캐시 사본이 반환되지 않도록 주소에 덧붙인 시간 값뿐이에요. 다른 웹사이트와 마찬가지로 GitHub는 내 IP 주소를 볼 수 있으며, GitHub 자체의 개인정보 보호정책이 적용돼요. Oberih 설정 → 업데이트에서 자동 확인을 끌 수 있어요. 거기 있는 “확인” 버튼은 눌렀을 때 여전히 작동해요.

“열기” 같은 버튼은 내 PC의 Windows 보안이나 Windows 설정으로 연결돼요. 두 버튼은 누를 때만 웹 브라우저를 열어요. 개인정보 처리방침(pegasohlib.github.io)과 라이선스 목록의 링크(github.com)예요. 그러면 그 사이트의 자체 방침이 적용돼요. 팁에 언급된 웹사이트는 일반 텍스트예요. Oberih는 이를 열거나 접속하지 않아요.

GitHub는 각 파일이 몇 번 다운로드됐는지도 집계해요. 누가 내려받았는지에 대한 정보 없이 숫자만 있으며, 웹사이트에서는 이를 대략적인 다운로드 수로 보여 줘요.

Microsoft Defender와 Microsoft

모든 검사와 보호는 Windows의 일부인 Microsoft Defender가 맡아요. Defender의 일부 기능은 Microsoft와 통신해요. 클라우드 제공 보호는 의심스러운 파일 정보를 보내고, 샘플 제출은 분석을 위해 의심스러운 파일을 보낼 수 있으며, 정의 업데이트는 Microsoft에서 내려받아요. 이는 Defender 자체의 동작이며 Microsoft 개인정보처리방침의 적용을 받아요. Oberih는 이 설정들을 보여 주고, 요청할 때만 바꿔요. 이 데이터는 Oberih에 전혀 전달되지 않아요.

관리자 권한

Oberih는 일반 권한으로 시작해요. 프로그램 파일은 Windows에 더 많은 권한을 요청하지 않아요. Defender 설정을 바꾸거나, 제외 항목을 관리하거나, 위협을 허용하거나, 격리를 보거나 복원하거나, 오프라인 검사를 시작하거나, 실행 중인 검사를 중지하려면 잠금 해제를 눌러요. 그러면 Windows가 확인을 요청한 뒤 Oberih가 관리자 권한으로 다시 시작하고, 그 권한은 창을 닫을 때까지만 유지돼요. Oberih는 백그라운드 서비스를 설치하지 않으며, 창이 닫혀 있으면 실행되지 않아요. 권한을 요청하기 전에 자기 파일이 시작된 뒤 바뀌지 않았는지 확인해요.

Oberih가 내 PC에서 사용하는 것:

Oberih가 하지 않는 일

  • 개발자 계정도, 자체 서버도 없어요
  • 분석, 광고, 추적이 없고 충돌 보고서도 어디로도 보내지 않아요
  • 파일, 검사 결과, 위협 목록을 업로드하지 않아요
  • 어떤 데이터도 판매하거나 공유하지 않아요
  • 변조 방지나 다른 Windows 보호 기능을 우회하지 않아요

Oberih와 데이터 삭제

Oberih를 제거하면(Windows 설정 → 앱에서, 또는 Oberih 설정의 버튼으로) 앱, 바로 가기, 앱 목록의 항목, 그리고 설정, 오류 로그, 사운드 파일이 있는 %LOCALAPPDATA%\Oberih 폴더가 삭제돼요. 앱 자체가 있는 폴더는 Oberih가 종료되고 몇 초 뒤에 삭제돼요. Microsoft Defender와 그 모든 설정은 그대로 남으며, Oberih를 통해 설정한 제외 항목과 허용한 위협, 격리에서 복원한 파일도 마찬가지예요. 위에서 설명한 임시 폴더는 직접 삭제하지 않으면 남아요. 설치하지 않고 내려받은 파일만 실행했다면 그 파일과 그 폴더를 직접 삭제하세요.
