Microsoft Defender 的得力助手

使用方法

Defender 负责防护，Oberih 让它更好用。

  1. 1

    下载并运行

    用上方的按钮下载文件并运行。如果 Windows 发出警告，点击更多信息，然后点击仍要运行。

  2. 2

    安装

    Oberih 会提示自行安装：开始菜单和桌面快捷方式、Windows 应用列表中的一项、应用内更新。不需要管理员权限。

  3. 3

    查看状态

    “概览”会立刻显示电脑是否受到保护以及需要修复什么。这些按钮会运行扫描和更新病毒库；点“解锁”之后，它们还会开启相应的设置。

  4. 4

    解锁后再修改

    要修改设置，请按解锁：Windows 只会请求一次许可，权限只在你关闭窗口之前有效。

功能

状态一目了然

一面显示防护状态的盾牌，以及实时保护和云提供的保护、篡改防护、防火墙、内存完整性、病毒定义、Windows 更新、SmartScreen 等磁贴。

带进度的扫描

快速扫描、全盘扫描、自定义扫描（文件夹或文件）和离线扫描。Defender 不报告进度，所以百分比和剩余时间是估算值。在别处启动的扫描也会显示出来。

威胁和历史记录

Defender 发现了什么、涉及哪个程序、检测历史记录，以及你允许的威胁。在做任何有风险的操作之前，都会先给出清晰的警告。

每项设置都有说明

30 多项 Microsoft Defender 设置集中在一处，用通俗的语言表述：云、不需要的应用、网络、扫描、计划、排除项。“推荐”标出安全的选择。

附带现成修复方案的提示

Oberih 会检查这台电脑，告诉你可以改进什么，并提供一个按钮来开启相应功能或打开对应的位置。另有 16 条关于密码、双重验证、网络钓鱼、游戏作弊器和诈骗的建议。

勒索软件防护

Oberih 可以开启 Defender 的受控文件夹访问，它能阻止未知应用更改“文档”“图片”和其他文件夹。

你的语言，你的外观

27 种语言，浅色、深色或跟随 Windows 的主题，文字大小可在 90 到 150 % 之间调整。

安全的自动更新

它打开期间，会在启动时以及每 12 小时检查一次新版本，并且只有当你按下按钮时才会安装。更新由作者的密钥签名：Oberih 不会安装伪造的更新。

常见问题

Windows 提示“Windows 已保护你的电脑”，这正常吗？

是的。Windows 会对它不太了解的文件显示这个提示，比如没有付费代码签名证书的应用，而 Oberih 没有这样的证书。请点击文字下方的更多信息，然后点击仍要运行，而不是不运行。Oberih 自己的更新用作者的密钥签名，并在安装前经过检查。

Oberih 是杀毒软件吗？

不是。所有扫描和防护工作都由 Windows 内置的杀毒软件 Microsoft Defender 完成。Oberih 显示它的状态、管理它的设置，并用通俗的语言加以解释。如果由其他杀毒软件负责防护，Defender 会处于待命状态，Oberih 也会告诉你这一点。

为什么它需要管理员权限？

查看功能不需要它们，但排除列表和隔离区除外。更改设置和排除项、允许威胁、从隔离区恢复、离线扫描以及停止扫描都需要它们。点击解锁，Windows 会询问一次，这些权限会持续到你关闭窗口为止。Oberih 没有可能应他人要求更改设置的后台服务，并且在解锁前会检查自己的文件自启动以来是否被更改过。

如果篡改防护阻止了某项设置怎么办？

Oberih 不会绕过它。受其保护的设置会显示一把锁，只能在「Windows 安全中心」中修改。这是好事：病毒同样无法关闭防护。

如何卸载？

在 Windows 设置 → 应用中找到 Oberih 并选择卸载，或者使用 Oberih 设置中的按钮。应用、它的快捷方式和它的设置都会被移除；Microsoft Defender 及其所有设置保持原样。你在 Defender 中所做的更改，比如排除项，也会保留。如果你只是运行了下载的文件而没有安装，请删除它和文件夹 %LOCALAPPDATA%\Oberih。

更新是怎么工作的？

Oberih 打开期间，如果自动检查已开启（默认开启），它会在启动时以及每 12 小时从 pegasohlib.github.io 读取一个小文件。如果有更新的版本，就会出现一个按钮。只有当你按下它时，才会从 GitHub 下载文件，检查它的签名和校验和，然后 Oberih 会以新版本重新启动。
