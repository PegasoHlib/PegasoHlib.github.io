Oberih

隐私政策

最后更新：2026年11月4日

Oberih 是 PegasoHlib 推出的一款免费 Windows 应用，用于显示 Windows 内置杀毒软件 Microsoft Defender 的状态、管理其设置并提供安全建议。本政策说明 Oberih 如何处理数据。简而言之：一切都留在你的电脑上，不会向开发者发送任何内容。

要点速览

  • Oberih 直接在你的电脑上从 Windows 读取防护状态。这些信息都不会离开这台电脑。
  • Oberih 没有服务器、没有账户，也没有分析统计。开发者从不接收任何数据。
  • 它只在检查更新和从 GitHub 下载更新时才会联网。自动检查默认开启，可以关闭。
  • 它的设置、错误日志和简短的音效文件保存在你的电脑上，位于 %LOCALAPPDATA%\Oberih。
  • 只有当你点击“解锁”时才会请求管理员权限，这些权限会持续到你关闭窗口为止。
  • Microsoft Defender 自身向 Microsoft 发送的内容受 Microsoft 隐私声明约束，而不是由 Oberih 决定。

Oberih 在你的电脑上读取什么

为了显示防护状态，Oberih 仅在其窗口打开时于本地读取：

  • Microsoft Defender 的状态、设置、威胁（包括受影响文件的路径和涉及的程序）、检测历史记录和隔离区，通过 Windows 自带的接口（WMI 和 MpCmdRun.exe）读取；
  • Defender 的事件日志，用于发现在 Oberih 之外启动的扫描；
  • 其他 Windows 安全设置：防火墙、在「Windows 安全中心」中注册的其他杀毒软件或防火墙应用、用户账户控制、SmartScreen、内存完整性、系统盘加密以及上次 Windows 更新的日期。

这些信息只显示在屏幕上，不会被保存、复制或发送到任何地方。为了估算扫描所需时间，Oberih 还会读取你各个驱动器的已用空间，以及你选择扫描的文件夹或文件的大小。

Oberih 在你的电脑上保存什么

Oberih 保存一个小的设置文件 %LOCALAPPDATA%\Oberih\settings.json，其中包含：

  • 语言、主题、文字大小和声音设置；
  • 你标记为已读的建议，以及你是否已看过欢迎页面和安装提议；
  • 是否自动检查更新，以及你选择跳过的版本；
  • 这台电脑上以往扫描所用的时长，用于估算进度。

技术性的错误信息（例如链接无法打开或应用崩溃时）会写入同一文件夹中的 error.log。

Oberih 还内置了简短的音效。它们默认开启；第一次播放声音时，这些文件会被复制到 %LOCALAPPDATA%\Oberih\sounds，每个应用版本一个文件夹。声音可以在“设置”中关闭。

你运行下载的文件时，.NET 可能会把其中一部分解压到 Windows 的临时文件文件夹（%TEMP%\.net\Oberih）。该文件夹不属于应用自己的数据，卸载时也不会被移除；你可以手动删除它。

如果你用另一个管理员账号解锁 Oberih，Windows 会以该账号运行它，此时上面的文件夹就位于该账号的用户配置文件中。

这些文件留在你的电脑上，Oberih 绝不会把它们发送到任何地方。你可以在 Oberih 的“设置”中打开该文件夹。

安装

如果你选择安装 Oberih，它会把自己复制到 %LOCALAPPDATA%\Programs\Oberih，创建一个开始菜单快捷方式和一个桌面快捷方式（后者你可以删除），并在 Windows 已安装应用列表中添加一项（在注册表中属于你的用户的部分）。这些操作不需要管理员权限。Oberih 不会随 Windows 启动，也不会添加任何计划任务。

联网：仅用于更新

Oberih 联网只为一件事：它自己的更新。默认情况下，它在启动几秒钟后，以及之后窗口打开期间每 12 小时，会读取一个小文件 pegasohlib.github.io/oberih/update.json，其中包含最新版本的编号。如果有更新的版本，Oberih 会显示一个按钮，只有当你按下它时，才会从 GitHub（github.com 及其下载服务器）下载新版本。安装之前，Oberih 会检查更新信息上的作者签名，以及文件的校验和与版本。新文件会先暂时保存在应用文件旁边，然后替换它。

这些请求不带有任何关于你或你的电脑的数据：只有标准“User-Agent”标头中的 Oberih 版本号，以及添加在地址后面的一个时间值，用来避免返回旧的缓存副本。和任何网站一样，GitHub 能看到你的 IP 地址，并适用 GitHub 自己的隐私声明。你可以在 Oberih 的“设置”→“更新”中关闭自动检查；那里的“检查”按钮在你按下时仍然有效。

诸如“打开”之类的按钮会通向你电脑上的 Windows 安全中心或 Windows 设置。有两个按钮会打开你的网络浏览器，且仅在你按下时才会打开：隐私政策（pegasohlib.github.io）和许可证列表中的链接（github.com）。这时适用该网站自己的政策。提示中提到的网站只是纯文本：Oberih 不会打开或联系它们。

GitHub 还会统计每个文件的下载次数。这只是一个数字，不包含任何关于下载者的信息；网站会将其显示为大致的下载量。

Microsoft Defender 与 Microsoft

所有扫描和防护工作都由 Windows 的组成部分 Microsoft Defender 完成。它的部分功能会与 Microsoft 通信：云提供的保护会发送可疑文件的详细信息，样本提交功能可能会发送可疑文件以供分析，病毒定义更新从 Microsoft 下载。这是 Defender 自身的行为，受 Microsoft 隐私声明约束。Oberih 会显示这些设置，并且只在你要求时才修改它们。Oberih 不会收到其中任何数据。

管理员权限

Oberih 以普通权限启动；它的程序文件不会向 Windows 请求更多权限。要更改 Defender 设置、管理排除项、允许威胁、查看或恢复隔离区、启动离线扫描或停止正在运行的扫描，你需要点击解锁：在 Windows 请你确认之后，Oberih 会以管理员权限重新启动，这些权限只持续到你关闭窗口为止。Oberih 不安装后台服务，窗口关闭时也不会运行。在请求权限之前，它会检查自己的文件自启动以来是否被更改过。

Oberih 在你的电脑上使用什么：

普通权限
读取 Defender 的状态、扫描、病毒库更新、Defender 事件日志、Windows 安全设置（防火墙、UAC、SmartScreen、内存完整性、驱动器加密、最近一次 Windows 更新），以及你自己的用于设置和安装的文件夹。
管理员权限，仅在解锁之后
更改 Defender 设置和排除项、允许威胁、隔离区、离线扫描以及停止扫描。
Windows 注册表
只写入它自己在已安装应用列表中的条目，位于你的用户部分。其他一切都是只读的。
互联网
只有上面描述的更新检查和下载。

Oberih 不会做的事

  • 不设开发者账户，也没有自己的服务器；
  • 没有分析统计、没有广告、没有跟踪，不会向任何地方发送崩溃报告；
  • 不上传你的文件、扫描结果或威胁列表；
  • 不出售或分享任何数据；
  • 不绕过篡改防护或任何其他 Windows 防护。

删除 Oberih 及其数据

卸载 Oberih（在 Windows 设置 → 应用中，或使用 Oberih 设置中的按钮）会移除应用、它的快捷方式、它在应用列表中的条目，以及包含设置、错误日志和音效文件的 %LOCALAPPDATA%\Oberih 文件夹。包含应用本身的文件夹会在 Oberih 关闭几秒钟后被删除。Microsoft Defender 及其所有设置保持原样，包括你通过 Oberih 设置的排除项和允许的威胁，以及你从隔离区恢复的文件。上面描述的临时文件夹会保留，除非你把它删除。如果你只是运行了下载的文件而没有安装，请自行删除它和那个文件夹。

儿童

Oberih 不向任何人收集个人数据，包括儿童。它没有账户、没有聊天，也没有分享功能。

本政策的变更

如果应用开始以新的方式处理数据，本页面会先行更新，并在顶部注明新的日期。
