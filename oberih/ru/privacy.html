Обериг

Политика кон­фи­ден­ци­аль­ности

Последнее обновление: 4 ноября 2026 года

Обериг — бесплатное приложение для Windows от PegasoHlib: оно показывает состояние Microsoft Defender, встроенного антивируса Windows, управляет его настройками и даёт советы по безопасности. Эта политика объясняет, что Обериг делает с данными. Коротко: всё остаётся на твоём ПК, и разработчику ничего не отправляется.

Коротко

  • Состояние защиты Обериг читает из Windows прямо на твоём ПК. Ничего из этого не покидает компьютер.
  • У Оберига нет серверов, аккаунтов и аналитики. Разработчик не получает никаких данных.
  • Он выходит в интернет только чтобы проверить обновления и скачать их с GitHub. Автоматическая проверка включена по умолчанию и может быть выключена.
  • Его настройки, журнал ошибок и короткие звуковые файлы хранятся на твоём компьютере, в %LOCALAPPDATA%\Oberih.
  • Права администратора запрашиваются только когда ты нажимаешь «Разблокировать» и действуют, пока не закроется окно.
  • Что сам Microsoft Defender отправляет в Microsoft, регулирует заявление Microsoft о конфиденциальности, а не Обериг.

Что Обериг читает на твоём ПК

Чтобы показать состояние защиты, Обериг читает — локально и только пока его окно открыто:

  • состояние, настройки, угрозы Microsoft Defender (с путями затронутых файлов и затронутой программой), история обнаружений и карантин — через собственные интерфейсы Windows (WMI и MpCmdRun.exe);
  • журнал событий Defender — чтобы заметить проверку, запущенную не через Обериг;
  • другие настройки безопасности Windows: брандмауэр, другие антивирусы или брандмауэры, зарегистрированные в «Безопасности Windows», контроль учётных записей (UAC), SmartScreen, целостность памяти, шифрование системного диска и дату последнего обновления Windows.

Эти сведения показываются на экране. Они не сохраняются, не копируются и никуда не отправляются. Чтобы оценить длительность проверки, Обериг также смотрит, сколько места занято на дисках и какой размер у папки или файла, выбранных для проверки.

Что Обериг хранит на твоём ПК

Обериг хранит один маленький файл настроек, %LOCALAPPDATA%\Oberih\settings.json, в котором:

  • язык, тема, размер текста и настройки звуков;
  • какие советы отмечены прочитанными и показаны ли уже приветствие и предложение установки;
  • проверять ли обновления автоматически и версия, которую решено пропустить;
  • сколько длились прошлые проверки на этом ПК — для оценки прогресса.

Технические сообщения об ошибках (например, когда не удалось открыть ссылку или приложение аварийно завершилось) записываются в error.log в той же папке.

В Обериг также встроены короткие звуковые эффекты. По умолчанию они включены; при первом воспроизведении звука файлы копируются в %LOCALAPPDATA%\Oberih\sounds, по одной папке на версию приложения. Звуки можно выключить в настройках.

Когда ты запускаешь скачанный файл, .NET может распаковать его части в папку временных файлов Windows (%TEMP%\.net\Oberih). Эта папка не входит в собственные данные приложения и не удаляется при удалении; её можно удалить вручную.

Если разблокировать Обериг другой учётной записью администратора, Windows запускает его от имени этой учётной записи, и тогда указанная выше папка находится в её профиле.

Эти файлы остаются на твоём компьютере, и Обериг никогда никуда их не отправляет. Открыть папку можно из настроек Оберига.

Установка

Если ты решишь установить Обериг, он копирует себя в %LOCALAPPDATA%\Programs\Oberih, создаёт ярлык в меню «Пуск» и ярлык на рабочем столе (последний можно удалить) и добавляет запись в список установленных приложений Windows (в пользовательской части реестра). Права администратора для этого не нужны. Обериг не запускается вместе с Windows и не добавляет запланированных задач.

Интернет: только для обновлений

Обериг выходит в интернет ради одного: собственных обновлений. По умолчанию через несколько секунд после запуска и затем каждые 12 часов, пока открыто его окно, он читает небольшой файл pegasohlib.github.io/oberih/update.json с номером новейшей версии. Если есть более новая, Обериг показывает кнопку, и только когда ты нажимаешь её, новая версия скачивается с GitHub (github.com и его серверов загрузки). Перед установкой Обериг проверяет подпись автора на сведениях об обновлении, а также контрольную сумму и версию файла. Новый файл ненадолго сохраняется рядом с файлом приложения, а затем заменяет его.

Эти запросы не содержат данных о тебе или твоём компьютере: только номер версии Оберига в стандартном заголовке «User-Agent» и значение времени, добавленное к адресу, чтобы не вернулась старая кэшированная копия. Как любой сайт, GitHub видит твой IP-адрес, и действует собственное заявление GitHub о конфиденциальности. Автоматические проверки можно выключить в настройках Оберига → «Обновления»; кнопка «Проверить» там по-прежнему работает, когда ты её нажимаешь.

Кнопки вроде «Открыть» ведут в Безопасность Windows или Параметры Windows на твоём компьютере. Две кнопки открывают браузер, только когда ты их нажимаешь: политика конфиденциальности (pegasohlib.github.io) и ссылки в списке лицензий (github.com). Тогда действует собственная политика этого сайта. Сайты, упомянутые в советах, — просто текст: Обериг их не открывает и к ним не обращается.

GitHub также считает, сколько раз скачали каждый файл. Это только число, без каких-либо данных о том, кто скачал; сайт показывает его как примерное количество загрузок.

Microsoft Defender и Microsoft

Всю проверку и защиту выполняет Microsoft Defender, часть Windows. Некоторые его функции связываются с Microsoft: облачная защита отправляет сведения о подозрительных файлах, отправка образцов может передавать подозрительные файлы на анализ, а базы обновляются с серверов Microsoft. Это собственное поведение Defender, которое регулирует Заявление Microsoft о конфиденциальности. Обериг показывает эти настройки и меняет их только по твоей просьбе. Никаких из этих данных он не получает.

Права администратора

Обериг запускается с обычными правами; его программный файл не просит у Windows больше. Чтобы изменить настройки Defender, управлять исключениями, разрешать угрозы, смотреть или восстанавливать карантин, запускать автономную проверку или останавливать идущую проверку, нажми Разблокировать: Обериг перезапускается с правами администратора после того, как Windows попросит подтверждения, и права действуют только до закрытия окна. Обериг не устанавливает фоновую службу и не работает при закрытом окне. Перед запросом прав он проверяет, что его собственный файл не изменился с момента запуска.

Что Обериг использует на твоём компьютере:

Обычные права
Чтение состояния Defender, проверок, обновлений определений, журнала событий Defender, настроек безопасности Windows (брандмауэр, UAC, SmartScreen, целостность памяти, шифрование дисков, последнее обновление Windows) и твоих собственных папок для настроек и установки.
Права администратора, только после «Разблокировать»
Изменение настроек и исключений Defender, разрешение угроз, карантин, автономная проверка и остановка проверки.
Реестр Windows
Записывает только собственную запись в списке установленных приложений, в пользовательской части. Всё остальное — только чтение.
Интернет
Только проверка и загрузка обновлений, описанные выше.

Чего Обериг не делает

  • никаких аккаунтов у разработчика и собственных серверов;
  • никакой аналитики, рекламы, слежки и отчётов о сбоях, которые куда-то отправляются;
  • никакой выгрузки твоих файлов, результатов проверок или списков угроз;
  • никакой продажи или передачи каких-либо данных;
  • никакого обхода защиты от подделки или другой защиты Windows.

Удаление Оберига и его данных

Удаление Оберига (в Параметрах Windows → Приложения или кнопкой в настройках Оберига) убирает приложение, его ярлыки, запись в списке приложений и папку %LOCALAPPDATA%\Oberih с настройками, журналом ошибок и звуковыми файлами. Папка с самим приложением удаляется через несколько секунд после закрытия Оберига. Microsoft Defender и все его настройки остаются как есть, включая исключения и разрешённые угрозы, заданные через Обериг, и файлы, восстановленные из карантина. Описанная выше временная папка остаётся, пока её не удалить. Если файл был только запущен без установки, удали его и эту папку вручную.

Дети

Обериг не собирает персональных данных ни у кого, в том числе у детей. В нём нет аккаунтов, чата и обмена данными.

Изменения этой политики

Если приложение начнёт делать с данными что-то новое, сначала обновится эта страница — с новой датой вверху.
