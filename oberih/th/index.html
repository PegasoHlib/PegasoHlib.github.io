Oberih

ผู้ช่วยใช้งานสะดวกสำหรับ Microsoft Defender

Microsoft Defender ซึ่งเป็นแอนติไวรัสที่มีอยู่ใน Windows ทำหน้าที่ปกป้อง ส่วน Oberih แสดงสถานะของมัน เริ่มการสแกน อธิบายทุกการตั้งค่าด้วยภาษาที่เข้าใจง่าย และแนะนำวิธีให้ปลอดภัยยิ่งขึ้น

ทำงานอย่างไร

Defender ปกป้อง ส่วน Oberih ทำให้ใช้งานได้ง่ายขึ้น

  1. 1

    ดาวน์โหลดและเรียกใช้

    ดาวน์โหลดไฟล์ด้วยปุ่มด้านบนแล้วเรียกใช้ หาก Windows แสดงคำเตือน ให้คลิก ข้อมูลเพิ่มเติม แล้วคลิก เรียกใช้ต่อไป

  2. 2

    ติดตั้ง

    Oberih เสนอให้ติดตั้งตัวเอง: ทางลัดในเมนู Start และบนเดสก์ท็อป รายการในรายการแอปของ Windows และการอัปเดตจากในแอป ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

  3. 3

    ดูสถานะ

    ภาพรวมแสดงทันทีว่าพีซีได้รับการป้องกันหรือไม่ และต้องแก้อะไร ปุ่มต่าง ๆ สั่งสแกนและอัปเดตนิยาม หลังจากปลดล็อก ปุ่มจะเปิดการตั้งค่าที่เหมาะสมด้วย

  4. 4

    ปลดล็อกเพื่อเปลี่ยนแปลง

    หากต้องการเปลี่ยนอะไร ให้กด ปลดล็อก: Windows จะขออนุญาตหนึ่งครั้ง และสิทธิ์จะใช้ได้จนกว่าคุณจะปิดหน้าต่าง

ทำอะไรได้บ้าง

เห็นสถานะได้ในพริบตา

โล่แสดงสถานะการป้องกัน และไทล์สำหรับการป้องกันแบบเรียลไทม์และผ่านคลาวด์ การป้องกันการดัดแปลง ไฟร์วอลล์ ความสมบูรณ์ของหน่วยความจำ คำจำกัดความ Windows Update SmartScreen และอื่น ๆ

สแกนพร้อมแสดงความคืบหน้า

สแกนด่วน สแกนเต็ม สแกนกำหนดเอง (โฟลเดอร์หรือไฟล์) และสแกนออฟไลน์ Defender ไม่รายงานความคืบหน้า ดังนั้นเปอร์เซ็นต์และเวลาที่เหลือจึงเป็นค่าประมาณ การสแกนที่เริ่มจากที่อื่นก็แสดงด้วย

ภัยคุกคามและประวัติ

สิ่งที่ Defender พบ โปรแกรมที่เกี่ยวข้อง ประวัติการตรวจพบ และภัยคุกคามที่คุณอนุญาต มีคำเตือนที่ชัดเจนก่อนทำสิ่งที่เสี่ยง

อธิบายทุกการตั้งค่า

การตั้งค่า Microsoft Defender มากกว่า 30 รายการในที่เดียว เป็นคำง่าย ๆ: คลาวด์ แอปที่ไม่ต้องการ เครือข่าย การสแกน ตารางเวลา ข้อยกเว้น “แนะนำ” ระบุตัวเลือกที่ปลอดภัย

เคล็ดลับพร้อมวิธีแก้ที่เตรียมไว้

Oberih ตรวจพีซีเครื่องนี้และบอกว่าควรปรับปรุงอะไร พร้อมปุ่มที่เปิดใช้งานหรือพาไปยังตำแหน่งที่ถูกต้อง และยังมีคำแนะนำ 16 ข้อเกี่ยวกับรหัสผ่าน 2FA ฟิชชิง การโกงเกม และการหลอกลวง

ป้องกันแรนซัมแวร์

Oberih เปิดการเข้าถึงโฟลเดอร์ที่ควบคุมของ Defender ได้ ซึ่งกันไม่ให้แอปที่ไม่รู้จักเปลี่ยนแปลง Documents, Pictures และโฟลเดอร์อื่น

ภาษาของคุณ หน้าตาของคุณ

27 ภาษา ธีมสว่างหรือมืดหรือตาม Windows และขนาดข้อความตั้งแต่ 90 ถึง 150 %

อัปเดตตัวเองอย่างปลอดภัย

ขณะที่เปิดอยู่ แอปตรวจหาเวอร์ชันใหม่ตอนเริ่มและทุก 12 ชั่วโมง และติดตั้งเฉพาะเมื่อคุณกดปุ่ม การอัปเดตลงนามด้วยกุญแจของผู้พัฒนา: Oberih จะไม่ติดตั้งของปลอม

สิ่งเล็ก ๆ ที่ช่วยได้

คะแนนตั้งแต่ 0 ถึง 100

Oberih เปลี่ยนสิ่งที่พบบนพีซีเครื่องนี้ให้เป็นตัวเลขเดียว คุณจึงเห็นได้ทันทีว่าได้รับการป้องกันแค่ไหน

เตือนเมื่อมีภัยคุกคามใหม่

หาก Defender จับอะไรได้ขณะที่ Oberih เปิดอยู่ คุณจะเห็นคำเตือนและได้ยินเสียง แอปไม่เฝ้าดูเมื่อปิดหน้าต่าง

ทำเครื่องหมายข้อยกเว้นที่เสี่ยง

แอปเตือนคุณเมื่อมีการสั่งให้ Defender ข้ามทั้งไดรฟ์ โฟลเดอร์ผู้ใช้ของคุณ Downloads หรือประเภทโปรแกรม เช่น .exe และ .ps1

ใช้ได้โดยไม่ต้องติดตั้ง

เปิดไฟล์ที่ดาวน์โหลดได้เลยตามที่เป็น: ไม่ต้องติดตั้ง .NET ไม่ต้องทำอะไรเลย การติดตั้งเพียงเพิ่มทางลัดและการอัปเดตจากในแอป

ฟรี · ไม่มีโฆษณา ไม่มีการติดตาม · ไม่มีบริการเบื้องหลัง ไม่มีการเริ่มอัตโนมัติ

คำถาม

Windows แจ้งว่า “Windows ป้องกันพีซีของคุณแล้ว” แบบนี้ปกติไหม?

ใช่ Windows แสดงข้อความนี้กับไฟล์ที่ไม่รู้จักดีนัก เช่น แอปที่ไม่มีใบรับรองลงนามโค้ดแบบเสียเงิน และ Oberih ไม่มี คลิก ข้อมูลเพิ่มเติม ใต้ข้อความ แล้วคลิก เรียกใช้อยู่ดี ไม่ใช่ ไม่เรียกใช้ การอัปเดตของ Oberih เองลงนามด้วยกุญแจของผู้พัฒนาและถูกตรวจสอบก่อนติดตั้ง

Oberih เป็นแอนติไวรัสหรือเปล่า?

ไม่ใช่ การสแกนและการปกป้องทั้งหมดเป็นหน้าที่ของ Microsoft Defender ซึ่งเป็นแอนติไวรัสที่มีอยู่ใน Windows Oberih แสดงสถานะของมัน จัดการการตั้งค่า และอธิบายด้วยภาษาที่เข้าใจง่าย หากมีแอนติไวรัสตัวอื่นทำงานอยู่ Defender จะอยู่ในโหมดสแตนด์บาย และ Oberih จะบอกให้คุณทราบ

ทำไมต้องขอสิทธิ์ผู้ดูแลระบบ?

การดูใช้ได้โดยไม่ต้องมีสิทธิ์เหล่านี้ ยกเว้นรายการข้อยกเว้นและการกักกัน การเปลี่ยนการตั้งค่าและข้อยกเว้น การอนุญาตภัยคุกคาม การกู้คืนจากการกักกัน การสแกนออฟไลน์ และการหยุดการสแกน ต้องใช้สิทธิ์เหล่านี้ กด ปลดล็อก Windows จะถามหนึ่งครั้ง และสิทธิ์จะอยู่จนกว่าคุณจะปิดหน้าต่าง Oberih ไม่มีบริการเบื้องหลังที่จะเปลี่ยนการตั้งค่าตามคำขอของคนอื่นได้ และก่อนปลดล็อก แอปจะตรวจสอบว่าไฟล์ของตัวเองไม่เปลี่ยนแปลงตั้งแต่เริ่มทำงาน

ถ้าการป้องกันการดัดแปลงบล็อกการตั้งค่าล่ะ?

Oberih ไม่หลบเลี่ยงมัน การตั้งค่าที่มันปกป้องจะแสดงพร้อมรูปกุญแจ และเปลี่ยนได้เฉพาะในความปลอดภัยของ Windows เท่านั้น ซึ่งเป็นเรื่องดี เพราะไวรัสก็ปิดการป้องกันไม่ได้เช่นกัน

จะลบแอปออกได้อย่างไร?

ในการตั้งค่า Windows → แอป ค้นหา Oberih แล้วเลือก ถอนการติดตั้ง หรือใช้ปุ่มในการตั้งค่าของ Oberih แอป ทางลัด และการตั้งค่าของแอปจะถูกลบ ส่วน Microsoft Defender และการตั้งค่าทั้งหมดของมันยังคงเดิม การเปลี่ยนแปลงที่คุณทำใน Defender เช่น ข้อยกเว้น ก็ยังอยู่ด้วย หากคุณเพียงเปิดไฟล์ที่ดาวน์โหลดโดยไม่ติดตั้ง ให้ลบไฟล์นั้นและโฟลเดอร์ %LOCALAPPDATA%\Oberih

การอัปเดตทำงานอย่างไร

ขณะที่ Oberih เปิดอยู่ แอปจะอ่านไฟล์เล็ก ๆ จาก pegasohlib.com ตอนเริ่มและทุก 12 ชั่วโมง หากเปิดการตรวจสอบอัตโนมัติ (เปิดไว้เป็นค่าเริ่มต้น) หากมีเวอร์ชันใหม่กว่า จะมีปุ่มปรากฏ เฉพาะเมื่อคุณกดปุ่มนั้น ไฟล์จึงจะถูกดาวน์โหลดจาก GitHub ตรวจลายเซ็นและเช็กซัมของไฟล์ แล้ว Oberih รีสตาร์ตเป็นเวอร์ชันใหม่

มีอะไรใหม่: 0.3.6

หน้าภาพรวมตอนนี้แสดง “ไม่พบปัญหา” แทน “ได้รับการป้องกัน” นับการตั้งค่า Defender มากขึ้น อ่านสถานะของโปรแกรมป้องกันไวรัสอื่น และแสดง “ยังไม่ได้ตรวจสอบ” สำหรับสิ่งที่อ่านไม่ได้ การเปลี่ยนแปลงที่เสี่ยงมากขึ้นจะถามก่อน หน้าต่างติดตั้งมีลิงก์ความเป็นส่วนตัวและข้อความการยอมรับ
