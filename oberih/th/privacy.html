Oberih

นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 4 พฤศจิกายน 2026

Oberih เป็นแอป Windows ฟรีจาก PegasoHlib ที่แสดงสถานะของ Microsoft Defender ซึ่งเป็นโปรแกรมป้องกันไวรัสที่มาพร้อมกับ Windows จัดการการตั้งค่า และให้คำแนะนำด้านความปลอดภัย นโยบายนี้อธิบายว่า Oberih ทำอะไรกับข้อมูลบ้าง โดยสรุปคือ ทุกอย่างอยู่ในพีซีของคุณ และไม่มีอะไรถูกส่งไปให้ผู้พัฒนา

สรุปสั้น ๆ

  • Oberih อ่านสถานะการป้องกันจาก Windows บนพีซีของคุณโดยตรง ข้อมูลเหล่านี้ไม่ออกไปนอกเครื่อง
  • Oberih ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชี และไม่มีระบบวิเคราะห์ ผู้พัฒนาไม่ได้รับข้อมูลใด ๆ เลย
  • แอปออนไลน์เฉพาะเพื่อตรวจหาอัปเดตและดาวน์โหลดจาก GitHub การตรวจสอบอัตโนมัติเปิดไว้เป็นค่าเริ่มต้นและปิดได้
  • การตั้งค่า บันทึกข้อผิดพลาด และไฟล์เสียงสั้น ๆ เก็บไว้บนพีซีของคุณใน %LOCALAPPDATA%\Oberih
  • สิทธิ์ผู้ดูแลระบบถูกขอเฉพาะเมื่อคุณกดปลดล็อก และอยู่จนกว่าคุณจะปิดหน้าต่าง
  • ข้อมูลที่ Microsoft Defender ส่งให้ Microsoft เองอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Microsoft ไม่ใช่ของ Oberih

ในหน้านี้

สิ่งที่ Oberih อ่านบนพีซีของคุณสิ่งที่ Oberih เก็บไว้บนพีซีของคุณการติดตั้งอินเทอร์เน็ต: เพื่อการอัปเดตเท่านั้นMicrosoft Defender และ Microsoftสิทธิ์ผู้ดูแลระบบสิ่งที่ Oberih ไม่ทำการลบ Oberih และข้อมูลของแอปเด็กการเปลี่ยนแปลงนโยบายนี้ติดต่อ

ข้อมูลอะไร เก็บที่ไหน และใครเห็นได้

ข้อมูลเก็บไว้ที่ไหนใครเห็นได้
สถานะการป้องกัน การตั้งค่า Defender ภัยคุกคาม ประวัติการตรวจพบ การกักกัน เหตุการณ์การสแกนใน Windows บนพีซีของคุณ Oberih อ่านขณะเปิดอยู่และไม่เก็บสำเนาเฉพาะคุณ
การตั้งค่า Oberih: ภาษา ธีม ขนาดตัวอักษร เสียง เคล็ดลับที่อ่านแล้ว ตัวเลือกการอัปเดต เวลาที่การสแกนใช้ ไฟล์เสียงสั้น ๆใน settings.json และโฟลเดอร์ sounds ใน %LOCALAPPDATA%\Oberih บนพีซีของคุณเฉพาะคุณ
ข้อความแสดงข้อผิดพลาดทางเทคนิคใน error.log ในโฟลเดอร์เดียวกันเฉพาะคุณ
สิ่งที่คุณเปลี่ยน: การตั้งค่า Defender การยกเว้น แอปและภัยคุกคามที่อนุญาตใน Microsoft Defender บนพีซีของคุณ เหมือนกับเปลี่ยนในความปลอดภัยของ Windowsเฉพาะคุณ
การตรวจหาและดาวน์โหลดการอัปเดตไม่มีการเก็บอะไร ยกเว้นไฟล์แอปใหม่เอง อ่านไฟล์เล็ก ๆ จาก pegasohlib.github.io เวอร์ชันใหม่มาจาก GitHubGitHub เห็นที่อยู่ IP ของคุณ เหมือนเว็บไซต์ทั่วไป

สิ่งที่ Oberih อ่านบนพีซีของคุณ

เพื่อแสดงสถานะการป้องกัน Oberih จะอ่านข้อมูลต่อไปนี้ภายในเครื่อง และเฉพาะขณะที่หน้าต่างเปิดอยู่:

  • สถานะของ Microsoft Defender การตั้งค่า ภัยคุกคาม (พร้อมเส้นทางของไฟล์ที่ได้รับผลกระทบและโปรแกรมที่เกี่ยวข้อง) ประวัติการตรวจพบ และการกักกัน ผ่านอินเทอร์เฟซของ Windows เอง (WMI และ MpCmdRun.exe)
  • บันทึกเหตุการณ์ของ Defender เพื่อรู้ว่ามีการสแกนที่เริ่มจากภายนอก Oberih
  • การตั้งค่าความปลอดภัยอื่น ๆ ของ Windows: ไฟร์วอลล์ แอปป้องกันไวรัสหรือไฟร์วอลล์อื่นที่ลงทะเบียนในความปลอดภัยของ Windows การควบคุมบัญชีผู้ใช้ SmartScreen ความสมบูรณ์ของหน่วยความจำ การเข้ารหัสไดรฟ์ระบบ และวันที่อัปเดต Windows ครั้งล่าสุด

ข้อมูลเหล่านี้แสดงบนหน้าจอเท่านั้น ไม่ถูกบันทึก คัดลอก หรือส่งไปที่ใด เพื่อประมาณว่าการสแกนจะใช้เวลานานเท่าใด Oberih ยังอ่านพื้นที่ที่ใช้ไปบนไดรฟ์ของคุณ และขนาดของโฟลเดอร์หรือไฟล์ที่คุณเลือกสแกนด้วย

สิ่งที่ Oberih เก็บไว้บนพีซีของคุณ

Oberih เก็บไฟล์การตั้งค่าเล็ก ๆ ไฟล์เดียว คือ %LOCALAPPDATA%\Oberih\settings.json ซึ่งมี:

  • ภาษา ธีม ขนาดข้อความ และการตั้งค่าเสียง
  • คำแนะนำที่คุณทำเครื่องหมายว่าอ่านแล้ว และคุณเคยเห็นหน้าต้อนรับและข้อเสนอให้ติดตั้งแล้วหรือยัง
  • จะให้ตรวจหาการอัปเดตโดยอัตโนมัติหรือไม่ และเวอร์ชันที่คุณเลือกข้าม
  • ระยะเวลาที่การสแกนครั้งก่อน ๆ ใช้บนพีซีเครื่องนี้ เพื่อใช้ประมาณความคืบหน้า

ข้อความข้อผิดพลาดทางเทคนิค (เช่น เมื่อเปิดลิงก์ไม่ได้หรือแอปล่ม) ถูกเขียนลงใน error.log ในโฟลเดอร์เดียวกัน

Oberih ยังมีเอฟเฟกต์เสียงสั้น ๆ ในตัว เปิดไว้เป็นค่าเริ่มต้น เมื่อเสียงเล่นครั้งแรก ไฟล์จะถูกคัดลอกไปที่ %LOCALAPPDATA%\Oberih\sounds หนึ่งโฟลเดอร์ต่อหนึ่งเวอร์ชันของแอป ปิดเสียงได้ในการตั้งค่า

เมื่อคุณเปิดไฟล์ที่ดาวน์โหลด .NET อาจแตกบางส่วนของไฟล์ไปยังโฟลเดอร์ไฟล์ชั่วคราวของ Windows (%TEMP%\.net\Oberih) โฟลเดอร์นั้นไม่ใช่ส่วนหนึ่งของข้อมูลของแอปเองและไม่ถูกลบเมื่อถอนการติดตั้ง คุณลบด้วยตัวเองได้

หากคุณปลดล็อก Oberih ด้วยบัญชีผู้ดูแลระบบอื่น Windows จะเรียกใช้ในฐานะบัญชีนั้น และโฟลเดอร์ข้างต้นจะอยู่ในโปรไฟล์ของบัญชีนั้น

ไฟล์เหล่านี้อยู่บนพีซีของคุณ และ Oberih ไม่เคยส่งไปที่ใด คุณเปิดโฟลเดอร์ได้จากการตั้งค่าของ Oberih

การติดตั้ง

หากคุณเลือกติดตั้ง Oberih แอปจะคัดลอกตัวเองไปที่ %LOCALAPPDATA%\Programs\Oberih สร้างทางลัดในเมนู Start และทางลัดบนเดสก์ท็อป (ลบอันหลังได้) และเพิ่มรายการลงในรายการแอปที่ติดตั้งของ Windows (ในส่วนผู้ใช้ของคุณในรีจิสทรี) ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ Oberih ไม่เริ่มทำงานพร้อม Windows และไม่เพิ่มงานตามกำหนดเวลา

อินเทอร์เน็ต: เพื่อการอัปเดตเท่านั้น

Oberih ออนไลน์เพื่อเรื่องเดียว: การอัปเดตของตัวเอง โดยค่าเริ่มต้น ไม่กี่วินาทีหลังเริ่มทำงาน แล้วทุก 12 ชั่วโมงขณะที่หน้าต่างเปิดอยู่ แอปอ่านไฟล์เล็ก ๆ pegasohlib.github.io/oberih/update.json ซึ่งมีหมายเลขเวอร์ชันล่าสุด หากมีเวอร์ชันที่ใหม่กว่า Oberih จะแสดงปุ่ม และเฉพาะเมื่อคุณกดปุ่มนั้น เวอร์ชันใหม่จึงจะถูกดาวน์โหลดจาก GitHub (github.com และเซิร์ฟเวอร์ดาวน์โหลดของ GitHub) ก่อนติดตั้ง Oberih ตรวจลายเซ็นของผู้พัฒนาบนข้อมูลการอัปเดต รวมถึงเช็กซัมและเวอร์ชันของไฟล์ ไฟล์ใหม่ถูกบันทึกไว้ข้างไฟล์แอปชั่วครู่ แล้วแทนที่ไฟล์นั้น

คำขอเหล่านี้ไม่มีข้อมูลเกี่ยวกับคุณหรือพีซีของคุณ มีเพียงหมายเลขเวอร์ชันของ Oberih ในส่วนหัว “User-Agent” มาตรฐาน และค่าเวลาที่เพิ่มต่อท้ายที่อยู่ เพื่อไม่ให้ได้สำเนาเก่าที่แคชไว้กลับมา เช่นเดียวกับเว็บไซต์ทั่วไป GitHub เห็นที่อยู่ IP ของคุณ และประกาศเกี่ยวกับความเป็นส่วนตัวของ GitHub เองมีผลบังคับใช้ คุณปิดการตรวจสอบอัตโนมัติได้ในการตั้งค่าของ Oberih → การอัปเดต ปุ่ม “ตรวจสอบ” ที่นั่นยังใช้งานได้เมื่อคุณกด

ปุ่มอย่าง “เปิด” นำไปยังความปลอดภัยของ Windows หรือการตั้งค่า Windows บนพีซีของคุณ มีสองปุ่มที่เปิดเว็บเบราว์เซอร์ของคุณ เฉพาะเมื่อคุณกด: นโยบายความเป็นส่วนตัว (pegasohlib.github.io) และลิงก์ในรายการใบอนุญาต (github.com) จากนั้นนโยบายของเว็บไซต์นั้นเองมีผล เว็บไซต์ที่กล่าวถึงในเคล็ดลับเป็นข้อความธรรมดา: Oberih ไม่เปิดหรือติดต่อเว็บไซต์เหล่านั้น

GitHub ยังนับจำนวนครั้งที่แต่ละไฟล์ถูกดาวน์โหลดด้วย ซึ่งเป็นเพียงตัวเลข ไม่มีข้อมูลว่าใครเป็นผู้ดาวน์โหลด เว็บไซต์แสดงตัวเลขนี้เป็นจำนวนดาวน์โหลดโดยประมาณ

Microsoft Defender และ Microsoft

การสแกนและการป้องกันทั้งหมดทำโดย Microsoft Defender ซึ่งเป็นส่วนหนึ่งของ Windows ฟีเจอร์บางอย่างของ Defender สื่อสารกับ Microsoft: การป้องกันบนคลาวด์ส่งรายละเอียดของไฟล์ที่น่าสงสัย การส่งตัวอย่างอาจส่งไฟล์ที่น่าสงสัยไปวิเคราะห์ และการอัปเดตคำจำกัดความดาวน์โหลดจาก Microsoft นี่คือการทำงานของ Defender เอง ซึ่งอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Microsoft Oberih แสดงการตั้งค่าเหล่านี้และเปลี่ยนเฉพาะเมื่อคุณสั่งเท่านั้น และไม่ได้รับข้อมูลเหล่านั้นเลย

สิทธิ์ผู้ดูแลระบบ

Oberih เริ่มทำงานด้วยสิทธิ์ปกติ ไฟล์โปรแกรมไม่ขอสิทธิ์เพิ่มจาก Windows หากต้องการเปลี่ยนการตั้งค่า Defender จัดการข้อยกเว้น อนุญาตภัยคุกคาม ดูหรือกู้คืนจากการกักกัน เริ่มการสแกนออฟไลน์ หรือหยุดการสแกนที่กำลังทำงาน คุณกด ปลดล็อก: Oberih จะรีสตาร์ตด้วยสิทธิ์ผู้ดูแลระบบหลังจาก Windows ขอให้คุณยืนยัน และสิทธิ์จะอยู่เพียงจนกว่าคุณจะปิดหน้าต่าง Oberih ไม่ติดตั้งบริการเบื้องหลังและไม่ทำงานเมื่อหน้าต่างปิด ก่อนขอสิทธิ์ แอปตรวจสอบว่าไฟล์ของตัวเองไม่เปลี่ยนแปลงตั้งแต่เริ่มทำงาน

สิ่งที่ Oberih ใช้บนพีซีของคุณ:

สิทธิ์ปกติ
การอ่านสถานะของ Defender การสแกน การอัปเดตนิยาม บันทึกเหตุการณ์ของ Defender การตั้งค่าความปลอดภัยของ Windows (ไฟร์วอลล์ UAC SmartScreen ความสมบูรณ์ของหน่วยความจำ การเข้ารหัสไดรฟ์ การอัปเดต Windows ครั้งล่าสุด) และโฟลเดอร์ของคุณเองสำหรับการตั้งค่าและการติดตั้ง
สิทธิ์ผู้ดูแลระบบ เฉพาะหลังปลดล็อก
การเปลี่ยนการตั้งค่าและข้อยกเว้นของ Defender การอนุญาตภัยคุกคาม การกักกัน การสแกนออฟไลน์ และการหยุดการสแกน
รีจิสทรีของ Windows
เขียนเฉพาะรายการของตัวเองในรายการแอปที่ติดตั้ง ในส่วนผู้ใช้ของคุณ นอกนั้นอ่านอย่างเดียว
อินเทอร์เน็ต
เฉพาะการตรวจหาและดาวน์โหลดอัปเดตตามที่อธิบายข้างต้น

สิ่งที่ Oberih ไม่ทำ

  • ไม่มีบัญชีกับผู้พัฒนาและไม่มีเซิร์ฟเวอร์ของตัวเอง
  • ไม่มีการวิเคราะห์ ไม่มีโฆษณา ไม่มีการติดตาม และไม่ส่งรายงานข้อขัดข้องไปที่ใด
  • ไม่อัปโหลดไฟล์ ผลการสแกน หรือรายการภัยคุกคามของคุณ
  • ไม่ขายหรือแบ่งปันข้อมูลใด ๆ
  • ไม่หลบเลี่ยงการป้องกันการดัดแปลงหรือการป้องกันอื่นใดของ Windows

การลบ Oberih และข้อมูลของแอป

การถอนการติดตั้ง Oberih (ในการตั้งค่า Windows → แอป หรือด้วยปุ่มในการตั้งค่าของ Oberih) จะลบแอป ทางลัด รายการในรายการแอป และโฟลเดอร์ %LOCALAPPDATA%\Oberih พร้อมการตั้งค่า บันทึกข้อผิดพลาด และไฟล์เสียง โฟลเดอร์ที่มีตัวแอปเองจะถูกลบไม่กี่วินาทีหลังจาก Oberih ปิด Microsoft Defender และการตั้งค่าทั้งหมดของมันยังคงเดิม รวมถึงข้อยกเว้นและภัยคุกคามที่อนุญาตซึ่งคุณตั้งผ่าน Oberih และไฟล์ที่คุณกู้คืนจากการกักกัน โฟลเดอร์ชั่วคราวที่อธิบายข้างต้นจะยังอยู่หากคุณไม่ลบ หากคุณเพียงเปิดไฟล์ที่ดาวน์โหลดโดยไม่ติดตั้ง ให้ลบไฟล์นั้นและโฟลเดอร์นั้นเอง

เด็ก

Oberih ไม่เก็บข้อมูลส่วนบุคคลจากใครเลย รวมถึงเด็กด้วย แอปไม่มีบัญชี ไม่มีแชต และไม่มีการแชร์

การเปลี่ยนแปลงนโยบายนี้

หากแอปเริ่มทำสิ่งใหม่กับข้อมูล หน้านี้จะได้รับการอัปเดตก่อน พร้อมวันที่ใหม่ที่ด้านบน
