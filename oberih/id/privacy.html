Oberih

Kebijakan privasi

Terakhir diperbarui: 6 November 2026

Oberih adalah aplikasi Windows gratis dari PegasoHlib yang menampilkan status Microsoft Defender, antivirus bawaan Windows, mengelola pengaturannya, dan memberi kiat keamanan. Kebijakan ini menjelaskan apa yang dilakukan Oberih dengan data. Singkatnya: semuanya tetap di PC-mu, dan tidak ada yang dikirim ke pengembang.

Sekilas

  • Oberih membaca status perlindungan dari Windows langsung di PC-mu. Tidak ada yang keluar dari komputer.
  • Oberih tidak punya server, akun, maupun analitik. Pengembang tidak pernah menerima data apa pun.
  • Aplikasi hanya online untuk memeriksa pembaruan dan mengunduhnya dari GitHub. Pemeriksaan otomatis aktif secara default dan bisa dimatikan.
  • Pengaturan, log error, dan file suara pendeknya disimpan di PC-mu, di %LOCALAPPDATA%\Oberih.
  • Hak administrator diminta hanya saat kamu menekan Buka Kunci, dan berlaku sampai kamu menutup jendela.
  • Apa yang dikirim Microsoft Defender sendiri ke Microsoft diatur oleh pernyataan privasi Microsoft, bukan oleh Oberih.

Apa yang dibaca Oberih di PC-mu

Untuk menampilkan status perlindungan, Oberih membaca, secara lokal dan hanya selama jendelanya terbuka:

  • Status, pengaturan, ancaman Microsoft Defender (dengan jalur file yang terdampak dan program yang terlibat), riwayat deteksi, dan karantina, lewat antarmuka bawaan Windows (WMI dan MpCmdRun.exe);
  • log peristiwa Defender, untuk mengetahui pemindaian yang dimulai di luar Oberih;
  • pengaturan keamanan Windows lainnya: firewall, antivirus atau firewall lain yang terdaftar di Keamanan Windows, Kontrol Akun Pengguna (UAC), SmartScreen, integritas memori, enkripsi drive sistem, dan tanggal pembaruan Windows terakhir.

Informasi ini ditampilkan di layar. Informasi ini tidak disimpan, tidak disalin, dan tidak dikirim ke mana pun. Untuk memperkirakan lama pemindaian, Oberih juga membaca berapa banyak ruang yang terpakai di drive-mu dan ukuran folder atau file yang kamu pilih untuk dipindai.

Apa yang disimpan Oberih di PC-mu

Oberih menyimpan satu file pengaturan kecil, %LOCALAPPDATA%\Oberih\settings.json, berisi:

  • bahasa, tema, ukuran teks, dan pengaturan suara;
  • kiat mana yang sudah ditandai dibaca, dan apakah sambutan serta tawaran pemasangan sudah ditampilkan;
  • apakah pembaruan diperiksa otomatis, dan versi yang dipilih untuk dilewati;
  • berapa lama pemindaian sebelumnya di PC ini, untuk memperkirakan kemajuan.

Pesan error teknis (misalnya saat tautan tidak bisa dibuka atau aplikasi mogok) ditulis ke error.log di folder yang sama.

Oberih juga memiliki efek suara pendek bawaan. Aktif secara default; saat suara diputar pertama kali, file disalin ke %LOCALAPPDATA%\Oberih\sounds, satu folder per versi aplikasi. Suara bisa dimatikan di Pengaturan.

Saat kamu menjalankan file yang diunduh, .NET mungkin mengekstrak sebagian isinya ke folder file sementara Windows (%TEMP%\.net\Oberih). Folder itu bukan bagian dari data aplikasi sendiri dan tidak dihapus saat kamu mencopot pemasangan; kamu bisa menghapusnya secara manual.

Jika kamu membuka kunci Oberih dengan akun administrator lain, Windows menjalankannya sebagai akun itu, dan folder di atas lalu berada di profil akun tersebut.

File-file ini tetap di PC-mu, dan Oberih tidak pernah mengirimnya ke mana pun. Kamu bisa membuka folder itu dari Pengaturan Oberih.

Pemasangan

Jika kamu memilih memasang Oberih, aplikasi menyalin dirinya ke %LOCALAPPDATA%\Programs\Oberih, membuat pintasan menu Start dan pintasan desktop (yang terakhir bisa kamu hapus), dan menambahkan entri ke daftar aplikasi terpasang Windows (di bagian pengguna pada registry). Untuk ini tidak diperlukan hak administrator. Oberih tidak mulai bersama Windows dan tidak menambahkan tugas terjadwal.

Internet: hanya untuk pembaruan

Oberih online hanya untuk satu hal: pembaruannya sendiri. Secara default, beberapa detik setelah dimulai lalu setiap 12 jam selama jendelanya terbuka, aplikasi membaca file kecil, pegasohlib.github.io/oberih/update.json, berisi nomor versi terbaru. Jika ada yang lebih baru, Oberih menampilkan tombol, dan hanya saat kamu menekannya versi baru diunduh dari GitHub (github.com dan server unduhannya). Sebelum memasang, Oberih memeriksa tanda tangan pembuat pada informasi pembaruan serta checksum dan versi file. File baru disimpan sebentar di samping file aplikasi, lalu menggantikannya.

Permintaan ini tidak membawa data tentangmu atau PC-mu: hanya nomor versi Oberih pada header “User-Agent” standar, dan nilai waktu yang ditambahkan ke alamat agar salinan cache lama tidak dikembalikan. Seperti situs web mana pun, GitHub melihat alamat IP-mu, dan pernyataan privasi GitHub sendiri berlaku. Kamu bisa mematikan pemeriksaan otomatis di Pengaturan Oberih → Pembaruan; tombol “Periksa” di sana tetap berfungsi saat kamu menekannya.

Tombol seperti “Buka” mengarah ke Keamanan Windows atau Pengaturan Windows di PC-mu. Dua tombol membuka browser webmu, hanya saat kamu menekannya: kebijakan privasi (pegasohlib.github.io) dan tautan di daftar lisensi (github.com). Kebijakan situs itu sendiri lalu berlaku. Situs web yang disebut di tips hanyalah teks biasa: Oberih tidak membuka atau menghubunginya.

GitHub juga menghitung berapa kali setiap file diunduh. Itu hanya angka, tanpa informasi apa pun tentang siapa yang mengunduh; situs web menampilkannya sebagai perkiraan jumlah unduhan.

Microsoft Defender dan Microsoft

Semua pemindaian dan perlindungan dilakukan oleh Microsoft Defender, bagian dari Windows. Beberapa fiturnya berkomunikasi dengan Microsoft: perlindungan cloud mengirim info tentang file mencurigakan, pengiriman sampel dapat mengirim file mencurigakan untuk dianalisis, dan definisi diunduh dari Microsoft. Ini adalah perilaku Defender sendiri, yang diatur oleh Pernyataan Privasi Microsoft. Oberih menampilkan pengaturan ini dan hanya mengubahnya saat kamu memintanya. Oberih tidak menerima data tersebut sama sekali.

Hak administrator

Oberih mulai dengan hak normal; file programnya tidak meminta hak lebih kepada Windows. Untuk mengubah pengaturan Defender, mengelola pengecualian, mengizinkan ancaman, melihat atau memulihkan karantina, memulai pemindaian offline, atau menghentikan pemindaian yang berjalan, kamu menekan Buka Kunci: Oberih dimulai ulang dengan hak administrator setelah Windows memintamu mengonfirmasi, dan hak itu berlaku hanya sampai kamu menutup jendela. Oberih tidak memasang layanan latar belakang dan tidak berjalan saat jendelanya ditutup. Sebelum meminta hak, aplikasi memeriksa bahwa filenya sendiri tidak berubah sejak dimulai.

Yang dipakai Oberih di PC-mu:

Hak normal
Membaca status Defender, pemindaian, pembaruan definisi, log peristiwa Defender, pengaturan keamanan Windows (firewall, UAC, SmartScreen, integritas memori, enkripsi drive, pembaruan Windows terakhir) dan folder milikmu sendiri untuk pengaturan dan pemasangan.
Hak administrator, hanya setelah Buka Kunci
Mengubah pengaturan dan pengecualian Defender, mengizinkan ancaman, karantina, pemindaian offline, dan menghentikan pemindaian.
Registry Windows
Hanya menulis entrinya sendiri di daftar aplikasi terpasang, di bagian penggunamu. Semua yang lain hanya dibaca.
Internet
Hanya pemeriksaan dan unduhan pembaruan yang dijelaskan di atas.

Yang tidak dilakukan Oberih

  • tidak ada akun pada pengembang dan tidak ada server sendiri;
  • tidak ada analitik, iklan, pelacakan, atau laporan crash yang dikirim ke mana pun;
  • tidak ada pengunggahan file, hasil pemindaian, atau daftar ancamanmu;
  • tidak ada penjualan atau pembagian data apa pun;
  • tidak ada pengakalan perlindungan perusakan atau perlindungan Windows lainnya.

Menghapus Oberih dan datanya

Mencopot Oberih (di Pengaturan Windows → Aplikasi, atau dengan tombol di Pengaturan Oberih) menghapus aplikasi, pintasannya, entrinya di daftar aplikasi, dan folder %LOCALAPPDATA%\Oberih beserta pengaturan, log error, dan file suara. Folder aplikasi itu sendiri dihapus beberapa detik setelah Oberih ditutup. Microsoft Defender dan semua pengaturannya tetap seperti semula, termasuk pengecualian dan ancaman yang diizinkan yang kamu atur lewat Oberih, dan file yang kamu pulihkan dari karantina. Folder sementara yang dijelaskan di atas tetap ada kecuali kamu menghapusnya. Jika kamu hanya menjalankan file yang diunduh tanpa memasang, hapus file itu dan folder tersebut sendiri.

Berapa lama disimpan. Data di dalam aplikasi tetap ada sampai kamu menghapusnya atau menghapus aplikasinya. Salinan di penyimpanan cloud milikmu tetap ada sampai kamu menghapusnya. E-mail yang kamu kirim disimpan sampai urusannya selesai, dan tidak lebih dari 2 tahun.

Hakmu. Kamu dapat meminta akses ke datamu, koreksi, penghapusan, pembatasan, salinan untuk dibawa ke tempat lain (portabilitas), dan kamu dapat menolak pemrosesan atau menarik persetujuan kapan saja. Tulislah ke alamat di atas. Kamu akan mendapat jawaban dalam waktu satu bulan. Sebagian besar data hanya ada di perangkatmu, jadi biasanya kamu bisa melakukannya sendiri di dalam aplikasi.

Pengaduan. Kamu dapat mengajukan pengaduan ke otoritas perlindungan data di negaramu.

Usia. Kamu harus berusia setidaknya 15 tahun untuk menggunakan aplikasi sendiri. Jika usiamu lebih muda, mintalah persetujuan orang tua atau wali terlebih dahulu.
