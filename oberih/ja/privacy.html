オベリフ

プライバシーポリシー

最終更新: 2026年11月6日

オベリフは PegasoHlib が提供する Windows 用の無料アプリで、Windows に組み込まれたウイルス対策ソフト Microsoft Defender の状態を表示し、その設定を管理し、セキュリティのヒントを提供します。このポリシーでは、オベリフがデータをどう扱うかを説明します。要するに、すべてはあなたの PC に残り、開発者には何も送られません。

概要

  • オベリフは保護の状態を、あなたの PC 上で Windows から読み取ります。その情報がコンピューターの外に出ることはありません。
  • オベリフにはサーバーもアカウントも分析もありません。開発者がデータを受け取ることは一切ありません。
  • オンラインに接続するのは、アップデートを確認して GitHub からダウンロードするときだけです。自動確認は初期設定でオンで、オフにできます。
  • 設定、エラーログ、短いサウンドファイルは、あなたの PC の %LOCALAPPDATA%\Oberih に保存されます。
  • 管理者権限が求められるのは、ロック解除を押したときだけで、ウィンドウを閉じるまで続きます。
  • Microsoft Defender 自体が Microsoft に送る情報は、オベリフではなく Microsoft のプライバシーに関する声明に従います。

オベリフが PC で読み取るもの

保護の状態を表示するため、オベリフはウィンドウが開いている間だけ、ローカルで次の情報を読み取ります。

  • Microsoft Defender の状態、設定、脅威(影響を受けたファイルのパスと関係したプログラムを含む)、検出の履歴、隔離を、Windows 自体のインターフェース(WMI と MpCmdRun.exe)を通じて読み取ります。
  • Defender のイベント ログ（オベリフ以外から始まったスキャンに気づくため）
  • Windows のその他のセキュリティ設定：ファイアウォール、「Windows セキュリティ」に登録されたほかのウイルス対策ソフトやファイアウォール、ユーザー アカウント制御（UAC）、SmartScreen、メモリ整合性、システム ドライブの暗号化、Windows の最終更新日

これらの情報は画面に表示されるだけです。保存、コピー、送信されることはありません。スキャンにかかる時間を見積もるため、オベリフはドライブの使用容量と、スキャンに選んだフォルダーやファイルのサイズも読み取ります。

オベリフが PC に保存するもの

オベリフは小さな設定ファイル %LOCALAPPDATA%\Oberih\settings.json を 1 つ保存します。内容は次のとおりです。

  • 言語、テーマ、文字サイズ、サウンドの設定
  • 既読にしたヒント、ようこそ画面とインストールの案内を表示済みかどうか
  • 更新を自動で確認するかどうか、スキップすると決めたバージョン
  • 進み具合を見積もるための、この PC での過去のスキャンの所要時間

技術的なエラーメッセージ(たとえば、リンクを開けなかったときや、アプリがクラッシュしたとき)は、同じフォルダの error.log に書き込まれます。

オベリフには短い効果音も内蔵されています。初期設定でオンで、サウンドが初めて再生されるときに、ファイルが %LOCALAPPDATA%\Oberih\sounds に、アプリのバージョンごとに1つのフォルダとしてコピーされます。サウンドは設定でオフにできます。

ダウンロードしたファイルを実行すると、.NET がその一部を Windows の一時ファイルのフォルダ(%TEMP%\.net\Oberih)に展開することがあります。このフォルダはアプリ自体のデータではなく、アンインストールしても削除されません。手動で削除できます。

別の管理者アカウントでオベリフのロックを解除すると、Windows はそのアカウントとしてオベリフを実行し、上記のフォルダはそのアカウントのプロファイルにできます。

これらのファイルはあなたの PC に残り、オベリフがどこかに送ることはありません。オベリフの設定からこのフォルダを開けます。

インストール

オベリフをインストールすることを選ぶと、自分自身を %LOCALAPPDATA%\Programs\Oberih にコピーし、スタートメニューのショートカットとデスクトップのショートカット(後者は削除できます)を作成し、Windows のインストールされているアプリの一覧(レジストリのあなたのユーザー部分)に項目を追加します。このために管理者権限は不要です。オベリフは Windows と一緒には起動せず、スケジュールされたタスクも追加しません。

インターネット：更新のためだけ

オベリフがオンラインに接続するのは、自分自身のアップデートというひとつの目的のためだけです。初期設定では、起動の数秒後と、ウィンドウが開いている間は12時間ごとに、最新バージョンの番号が書かれた小さなファイル pegasohlib.github.io/oberih/update.json を読み取ります。より新しいものがあれば、オベリフはボタンを表示し、あなたがそれを押したときだけ、新しいバージョンが GitHub(github.com とそのダウンロードサーバー)からダウンロードされます。インストールの前に、オベリフはアップデート情報にある作者の署名と、ファイルのチェックサムおよびバージョンを確認します。新しいファイルは、しばらくアプリのファイルの隣に保存され、その後それと置き換えられます。

これらのリクエストには、あなたや PC に関するデータは含まれません。標準の「User-Agent」ヘッダーにあるオベリフのバージョン番号と、古いキャッシュのコピーが返されないようにアドレスに加えられた時刻の値だけです。どのウェブサイトとも同様に、GitHub はあなたの IP アドレスを見ることができ、GitHub 自身のプライバシーに関する声明が適用されます。オベリフの設定 → アップデートで自動確認をオフにできます。そこにある「確認」ボタンは、押したときには引き続き動作します。

「開く」などのボタンは、あなたの PC の Windows セキュリティや Windows の設定につながります。2つのボタンは、押したときだけウェブブラウザを開きます。プライバシーポリシー(pegasohlib.github.io)と、ライセンス一覧のリンク(github.com)です。その場合は、そのサイト自身のポリシーが適用されます。ヒントに出てくるウェブサイトはただのテキストで、オベリフがそれらを開いたり、接続したりすることはありません。

GitHub は各ファイルがダウンロードされた回数も数えています。これは数字だけで、誰がダウンロードしたかは含まれません。ウェブサイトではおおよそのダウンロード数として表示します。

Microsoft Defender と Microsoft

スキャンと保護はすべて、Windows の一部である Microsoft Defender が行います。その機能の一部は Microsoft と通信します。クラウド提供の保護は疑わしいファイルの情報を送り、サンプルの自動送信は疑わしいファイルを分析のために送ることがあり、定義ファイルは Microsoft からダウンロードされます。これは Defender 自身の動作で、Microsoft のプライバシーに関する声明に従います。オベリフはこれらの設定を表示し、あなたが求めたときだけ変更します。これらのデータをオベリフが受け取ることはありません。

管理者権限

オベリフは通常の権限で起動し、プログラムファイルが Windows にこれ以上の権限を求めることはありません。Defender の設定の変更、除外の管理、脅威の許可、隔離の表示や復元、オフラインスキャンの開始、実行中のスキャンの停止を行うには、ロック解除を押します。Windows が確認を求めたあと、オベリフが管理者権限で再起動し、その権限はウィンドウを閉じるまでだけ続きます。オベリフはバックグラウンドサービスをインストールせず、ウィンドウが閉じているときは動作しません。権限を求める前に、自分のファイルが起動後に変更されていないか確認します。

オベリフがしないこと

  • 開発者のアカウントも、独自のサーバーもありません
  • 分析、広告、追跡、クラッシュ レポートの送信はありません
  • あなたのファイル、スキャン結果、脅威の一覧をアップロードしません
  • データの販売や共有は一切しません
  • 改ざん防止など、Windows の保護を回避することはしません

オベリフとそのデータの削除

オベリフをアンインストールすると(Windows の設定 → アプリ、またはオベリフの設定にあるボタンで)、アプリ、ショートカット、アプリ一覧の項目、そして設定、エラーログ、サウンドファイルが入った %LOCALAPPDATA%\Oberih フォルダが削除されます。アプリ本体のフォルダは、オベリフが閉じた数秒後に削除されます。Microsoft Defender とそのすべての設定は、オベリフを通じて設定した除外や許可した脅威、隔離から復元したファイルも含め、そのまま残ります。上で説明した一時フォルダは、削除しない限り残ります。インストールせずにダウンロードしたファイルを実行しただけの場合は、そのファイルとそのフォルダを自分で削除してください。
