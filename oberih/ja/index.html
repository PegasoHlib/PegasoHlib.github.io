オベリフ

Microsoft Defender 向けの独立したアプリ

PC を守っているのは、Windows に組み込まれたウイルス対策ソフト Microsoft Defender です。オベリフはその状態を表示し、スキャンを実行し、すべての設定をわかりやすく説明して、より安全に使うためのヒントを提案します。

しくみ

守るのは Defender、オベリフはそれを使いやすくします。

  1. 1

    ダウンロードして実行

    上のボタンでファイルをダウンロードして実行します。Windows の警告が出たら、詳細情報をクリックし、次に実行をクリックします。

  2. 2

    インストール

    オベリフは自分自身のインストールを提案します。スタートメニューとデスクトップのショートカット、Windows のアプリ一覧の項目、アプリ内からのアップデートが加わります。Program Files へのインストール時と各アップデートの前に、Windows が許可を求めます。

  3. 3

    状態を確認

    概要画面では、PC が保護されているかどうか、何を直すべきかが一目でわかります。ボタンでスキャンを実行し、定義を更新します。ロック解除のあとは、適切な設定もオンにします。

  4. 4

    ロック解除して変更

    何かを変更するにはロック解除を押します。Windows が一度だけ許可を求め、権限はウィンドウを閉じるまで有効です。

できること

状態がひと目でわかる

保護の状態を示すシールドと、リアルタイム保護、クラウド提供の保護、改ざん防止、ファイアウォール、メモリ整合性、定義ファイル、Windows Update、SmartScreen などのタイル。

進み具合がわかるスキャン

クイック、フル、カスタム(フォルダまたはファイル)、オフラインのスキャンがあります。Defender は進行状況を報告しないため、パーセントと残り時間は推定です。ほかの場所で開始されたスキャンも表示されます。

脅威と履歴

Defender が見つけたもの、関係したプログラム、検出の履歴、あなたが許可した脅威を表示します。危険なことをする前には、はっきりした警告が出ます。

すべての設定を解説

Microsoft Defender の30以上の設定を、わかりやすい言葉で1か所にまとめています。クラウド、不要なアプリ、ネットワーク、スキャン、スケジュール、除外などです。「推奨」は安全な選択を示します。

すぐ直せるヒント

オベリフがこの PC をチェックして改善点を伝え、ボタンで設定をオンにしたり適切な画面を開いたりします。さらにパスワード、2FA、フィッシング、チート、詐欺についての 16 のヒント。

ランサムウェア防止

オベリフは、Defender のコントロールされたフォルダー アクセスをオンにできます。これは、不明なアプリがドキュメント、ピクチャなどのフォルダを変更するのを防ぎます。

言語も見た目も自由に

27 言語、ライト・ダーク・Windows と同じテーマ、文字サイズは 90〜150 %。

安全な自動アップデート

開いている間は、起動時と12時間ごとに新しいバージョンを確認し、ボタンを押したときだけインストールします。アップデートは作者の鍵で署名されています。オベリフは偽造されたものをインストールしません。

ちょっと助かる機能

0から100のスコア

オベリフは、この PC で見つけたものをひとつの数字にまとめるので、どのくらい守られているかが一目でわかります。

新しい脅威の通知

オベリフが開いている間に Defender が何かを検出すると、警告が表示され、音が鳴ります。ウィンドウが閉じているときは監視しません。

危険な除外を警告

Defender がドライブ全体、あなたのユーザーフォルダ、ダウンロード、または .exe や .ps1 などのプログラムの種類をスキップするように設定されていると、警告します。

インストールなしで実行

ダウンロードしたファイルをそのまま実行できます。インストールする .NET も、あなたがすることも不要です。インストールすると、ショートカットとアプリ内アップデートが加わるだけです。

無料 · 広告・追跡なし · バックグラウンドサービスも、自動起動もありません

よくある質問

「Windows によって PC が保護されました」と表示されます。大丈夫？

はい。Windows は、有料のコード署名証明書がないアプリなど、よく知らないファイルに対してこれを表示します。オベリフにはその証明書がありません。文章の下の詳細情報をクリックし、実行しないではなく実行をクリックしてください。オベリフ自身のアップデートは作者の鍵で署名されており、インストール前に検証されます。

オベリフはウイルス対策ソフトですか？

いいえ。スキャンと保護はすべて、Windows に組み込まれたウイルス対策ソフト Microsoft Defender が行います。オベリフはその状態を表示し、設定を管理し、わかりやすく説明します。ほかのウイルス対策ソフトが使われている場合、Defender は待機状態になり、オベリフがそれを知らせます。

なぜ管理者権限を求めるのですか？

除外リストと隔離を除き、表示するだけなら不要です。設定や除外の変更、脅威の許可、隔離からの復元、オフラインスキャン、スキャンの停止には必要です。ロック解除を押すと、Windows が一度確認し、その権限はウィンドウを閉じるまで続きます。オベリフには、他人の要求で設定を変更できるようなバックグラウンドサービスはなく、ロックを解除する前に、自分のファイルが起動後に変更されていないか確認します。

改ざん防止が設定をブロックしたら？

オベリフはそれを回避しません。改ざん防止で守られている設定は鍵マークで表示され、「Windows セキュリティ」でのみ変更できます。これは良いことで、ウイルスも保護をオフにできません。

削除するには？

Windows の設定 → アプリでオベリフを探してアンインストールを選ぶか、オベリフの設定にあるボタンを使ってください。アプリ、ショートカット、設定が削除され、Microsoft Defender とそのすべての設定はそのまま残ります。除外など、Defender であなたが行った変更も残ります。インストールせずにダウンロードしたファイルを実行しただけの場合は、そのファイルとフォルダ %LOCALAPPDATA%\Oberih を削除してください。

アップデートはどのように行われますか？

オベリフが開いている間、自動確認がオン(初期設定ではオンです)であれば、起動時と12時間ごとに pegasohlib.com から小さなファイルを読み取ります。より新しいバージョンがあると、ボタンが表示されます。あなたがそのボタンを押したときだけ、GitHub からファイルがダウンロードされ、署名とチェックサムが確認されたあと、オベリフが新しいバージョンとして再起動します。
