使用方式

Defender 負責防護，Oberih 讓它更好用。

  1. 1

    下載並執行

    用上方的按鈕下載檔案並執行。如果 Windows 發出警告，請點一下其他資訊，再點一下仍要執行。

  2. 2

    安裝

    Oberih 會提示自行安裝：開始功能表和桌面捷徑、Windows 應用程式清單中的一項、應用程式內更新。不需要管理員權限。

  3. 3

    查看狀態

    「概覽」會立刻顯示電腦是否受到保護以及需要修復什麼。這些按鈕會執行掃描和更新病毒碼；點「解鎖」之後，它們還會開啟相應的設定。

  4. 4

    解鎖後再變更

    要變更設定，請按解鎖：Windows 只會請求一次許可，權限只在你關閉視窗前有效。

狀態一目了然

一面顯示防護狀態的盾牌，以及即時保護和雲端提供的保護、竄改防護、防火牆、記憶體完整性、病毒碼、Windows Update、SmartScreen 等磚塊。

附進度的掃描

快速掃描、完整掃描、自訂掃描（資料夾或檔案）和離線掃描。Defender 不回報進度，所以百分比和剩餘時間是估算值。在別處啟動的掃描也會顯示出來。

威脅和歷史記錄

Defender 發現了什麼、涉及哪個程式、偵測歷史記錄，以及你允許的威脅。在做任何有風險的操作之前，都會先給出清楚的警告。

每項設定都有說明

30 多項 Microsoft Defender 設定集中在一處，用淺顯的語言表述：雲端、不需要的應用程式、網路、掃描、排程、排除項目。「建議」標出安全的選擇。

附帶現成修復方案的提示

Oberih 會檢查這台電腦，告訴你可以改進什麼，並提供一個按鈕來開啟相應功能或開啟對應的位置。另有 16 則關於密碼、兩步驟驗證、網路釣魚、遊戲外掛和詐騙的建議。

常見問題

Windows 顯示「Windows 已保護您的電腦」，這正常嗎？

是的。Windows 會對它不太了解的檔案顯示這個提示，例如沒有付費程式碼簽署憑證的應用程式，而 Oberih 沒有這樣的憑證。請按一下文字下方的其他資訊，然後按一下仍要執行，而不是不要執行。Oberih 自己的更新用作者的金鑰簽署，並在安裝前經過檢查。

Oberih 是防毒軟體嗎？

不是。所有掃描和防護工作都由 Windows 內建的防毒軟體 Microsoft Defender 負責。Oberih 會顯示它的狀態、管理它的設定，並用淺白的話加以說明。如果由其他防毒軟體負責防護，Defender 會處於待命狀態，Oberih 也會告訴你這一點。

為什麼需要系統管理員權限？

檢視功能不需要它們，但排除清單和隔離區除外。變更設定和排除項目、允許威脅、從隔離區復原、離線掃描以及停止掃描都需要它們。按一下解鎖，Windows 會詢問一次，這些權限會持續到你關閉視窗為止。Oberih 沒有可能應他人要求變更設定的背景服務，並且在解鎖前會檢查自己的檔案自啟動以來是否被變更過。

如果竄改防護擋下了某項設定怎麼辦？

Oberih 不會繞過它。受其保護的設定會顯示一個鎖頭，只能在「Windows 安全性」中變更。這是好事：病毒同樣無法關閉防護。

如何解除安裝？

在 Windows 設定 → 應用程式中找到 Oberih 並選擇解除安裝，或者使用 Oberih 設定中的按鈕。應用程式、它的捷徑和它的設定都會被移除；Microsoft Defender 及其所有設定保持原樣。你在 Defender 中所做的變更，例如排除項目，也會保留。如果你只是執行了下載的檔案而沒有安裝，請刪除它和資料夾 %LOCALAPPDATA%\Oberih。

更新是如何運作的？

Oberih 開啟期間，如果自動檢查已開啟（預設為開啟），它會在啟動時以及每 12 小時從 pegasohlib.com 讀取一個小檔案。如果有更新的版本，就會出現一個按鈕。只有當你按下它時，才會從 GitHub 下載檔案，檢查它的簽章和檢查碼，然後 Oberih 會以新版本重新啟動。
