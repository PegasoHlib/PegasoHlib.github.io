Oberih

隱私權政策

最後更新：2026年11月4日

Oberih 是 PegasoHlib 推出的一款免費 Windows 應用程式，用來顯示 Windows 內建防毒軟體 Microsoft Defender 的狀態、管理其設定並提供安全建議。本政策說明 Oberih 如何處理資料。簡單來說：一切都留在你的電腦上，不會傳送任何內容給開發者。

重點摘要

  • Oberih 直接在你的電腦上從 Windows 讀取防護狀態。這些資訊都不會離開這台電腦。
  • Oberih 沒有伺服器、沒有帳號，也沒有分析統計。開發者從不接收任何資料。
  • 它只在檢查更新和從 GitHub 下載更新時才會連上網路。自動檢查預設為開啟，可以關閉。
  • 它的設定、錯誤記錄和簡短的音效檔案儲存在你的電腦上，位於 %LOCALAPPDATA%\Oberih。
  • 只有當你按一下「解鎖」時才會要求管理員權限，這些權限會持續到你關閉視窗為止。
  • Microsoft Defender 本身傳送給 Microsoft 的內容受 Microsoft 隱私權聲明約束，而不是由 Oberih 決定。

Oberih 在你的電腦上讀取什麼

為了顯示防護狀態，Oberih 只在其視窗開啟時於本機讀取：

  • Microsoft Defender 的狀態、設定、威脅（包括受影響檔案的路徑和涉及的程式）、偵測歷史記錄和隔離區，透過 Windows 內建的介面（WMI 和 MpCmdRun.exe）讀取；
  • Defender 的事件記錄，用來發現在 Oberih 以外啟動的掃描；
  • 其他 Windows 安全性設定：防火牆、在「Windows 安全性」中註冊的其他防毒軟體或防火牆應用程式、使用者帳戶控制、SmartScreen、記憶體完整性、系統磁碟機加密，以及上次 Windows 更新的日期。

這些資訊只會顯示在螢幕上，不會被儲存、複製或傳送到任何地方。為了估算掃描所需的時間，Oberih 也會讀取你各個磁碟機的已用空間，以及你選擇掃描的資料夾或檔案的大小。

Oberih 在你的電腦上儲存什麼

Oberih 會儲存一個小的設定檔 %LOCALAPPDATA%\Oberih\settings.json，其中包含：

  • 語言、主題、文字大小和聲音設定；
  • 你標示為已讀的建議，以及你是否已看過歡迎頁面和安裝提議；
  • 是否自動檢查更新，以及你選擇略過的版本；
  • 這台電腦上以往掃描所花的時間，用來估算進度。

技術性的錯誤訊息（例如連結無法開啟或應用程式當機時）會寫入同一資料夾中的 error.log。

Oberih 還內建了簡短的音效。它們預設為開啟；第一次播放聲音時，這些檔案會被複製到 %LOCALAPPDATA%\Oberih\sounds，每個應用程式版本一個資料夾。聲音可以在「設定」中關閉。

你執行下載的檔案時，.NET 可能會把其中一部分解壓縮到 Windows 的暫存檔資料夾（%TEMP%\.net\Oberih）。該資料夾不屬於應用程式自己的資料，解除安裝時也不會被移除；你可以手動刪除它。

如果你用另一個管理員帳戶解鎖 Oberih，Windows 會以該帳戶執行它，此時上面的資料夾就位於該帳戶的使用者設定檔中。

這些檔案留在你的電腦上，Oberih 絕不會把它們傳送到任何地方。你可以在 Oberih 的「設定」中開啟該資料夾。

安裝

如果你選擇安裝 Oberih，它會把自己複製到 %LOCALAPPDATA%\Programs\Oberih，建立一個開始功能表捷徑和一個桌面捷徑（後者你可以刪除），並在 Windows 已安裝應用程式清單中新增一項（在登錄中屬於你的使用者的部分）。這些操作不需要管理員權限。Oberih 不會隨 Windows 啟動，也不會新增任何排定的工作。

連上網路：僅用於更新

Oberih 連上網路只為一件事：它自己的更新。預設情況下，它在啟動幾秒鐘後，以及之後視窗開啟期間每 12 小時，會讀取一個小檔案 pegasohlib.github.io/oberih/update.json，其中包含最新版本的編號。如果有更新的版本，Oberih 會顯示一個按鈕，只有當你按下它時，才會從 GitHub（github.com 及其下載伺服器）下載新版本。安裝之前，Oberih 會檢查更新資訊上的作者簽章，以及檔案的檢查碼與版本。新檔案會先暫時儲存在應用程式檔案旁邊，然後取代它。

這些請求不帶有任何關於你或你的電腦的資料：只有標準「User-Agent」標頭中的 Oberih 版本號，以及附加在位址後面的一個時間值，用來避免傳回舊的快取副本。和任何網站一樣，GitHub 看得到你的 IP 位址，並適用 GitHub 自己的隱私權聲明。你可以在 Oberih 的「設定」→「更新」中關閉自動檢查；那裡的「檢查」按鈕在你按下時仍然有效。

諸如「開啟」之類的按鈕會通往你電腦上的 Windows 安全性或 Windows 設定。有兩個按鈕會開啟你的網頁瀏覽器，且僅在你按下時才會開啟：隱私權政策（pegasohlib.github.io）和授權清單中的連結（github.com）。這時適用該網站自己的政策。提示中提到的網站只是純文字：Oberih 不會開啟或聯絡它們。

GitHub 也會統計每個檔案的下載次數。這只是一個數字，不包含任何關於下載者的資訊；網站會將它顯示為大致的下載量。

Microsoft Defender 與 Microsoft

所有掃描和防護工作都由 Windows 的組成部分 Microsoft Defender 負責。它的部分功能會與 Microsoft 通訊：雲端提供的保護會傳送可疑檔案的詳細資訊，範例提交功能可能會傳送可疑檔案供分析，病毒碼更新則從 Microsoft 下載。這是 Defender 本身的行為，受 Microsoft 隱私權聲明約束。Oberih 會顯示這些設定，並且只在你要求時才變更它們。Oberih 不會收到其中任何資料。

系統管理員權限

Oberih 以一般權限啟動；它的程式檔案不會向 Windows 要求更多權限。要變更 Defender 設定、管理排除項目、允許威脅、檢視或復原隔離區、啟動離線掃描或停止正在執行的掃描，你需要按一下解鎖：在 Windows 請你確認之後，Oberih 會以管理員權限重新啟動，這些權限只持續到你關閉視窗為止。Oberih 不安裝背景服務，視窗關閉時也不會執行。在要求權限之前，它會檢查自己的檔案自啟動以來是否被變更過。

Oberih 不會做的事

  • 沒有開發者帳號，也沒有自己的伺服器；
  • 沒有分析統計、沒有廣告、沒有追蹤，不會將當機報告傳送到任何地方；
  • 不會上傳你的檔案、掃描結果或威脅清單；
  • 不會販售或分享任何資料；
  • 不會繞過竄改防護或任何其他 Windows 防護。

刪除 Oberih 及其資料

解除安裝 Oberih（在 Windows 設定 → 應用程式中，或使用 Oberih 設定中的按鈕）會移除應用程式、它的捷徑、它在應用程式清單中的項目，以及包含設定、錯誤記錄和音效檔案的 %LOCALAPPDATA%\Oberih 資料夾。包含應用程式本身的資料夾會在 Oberih 關閉幾秒鐘後被刪除。Microsoft Defender 及其所有設定保持原樣，包括你透過 Oberih 設定的排除項目和允許的威脅，以及你從隔離區復原的檔案。上面描述的暫存資料夾會保留，除非你把它刪除。如果你只是執行了下載的檔案而沒有安裝，請自行刪除它和那個資料夾。

兒童

Oberih 不會向任何人收集個人資料，包括兒童。它沒有帳號、沒有聊天，也沒有分享功能。

本政策的變更

如果應用程式開始以新的方式處理資料，本頁面會先行更新，並在頂端註明新的日期。
