Integritet på webbplatsen

Senast uppdaterad: 12 november 2026

Den här sidan handlar om webbplatsen pegasohlib.com: huvudsidan och appsidorna. Kort sagt: inga konton, inga cookies, ingen reklam och ingen analys. Vad varje app eller spel gör med data förklaras i dess egen integritetspolicy, som listas nedan.

I korthet

  • Webbplatsen sätter inga cookies och har varken reklam, analys eller knappar för sociala medier.
  • Ditt valda språk och tema stannar i din egen webbläsare och skickas ingenstans.
  • Cloudflare levererar webbplatsen och ser besökares IP-adresser. GitHub lagrar filerna och ser din IP-adress bara vid nedladdning eller på den gamla adressen.
  • Filer laddas ned från GitHub, så GitHub ser och räknar varje nedladdning.
  • Om du skickar ett e-postmeddelande används det bara för att svara dig.

Vad som sparas i din webbläsare

När du väljer språk eller byter tema sparar webbplatsen ditt val i webbläsarens lokala lagring, så att sidorna öppnas på samma sätt nästa gång. Inget sparas förrän du gör ett val.

siteLang
Det språk du valde.
pegasohlib-theme
Det ljusa eller mörka tema du valde.

Varför det inte finns någon samtyckesbanner

Dessa två poster är inte cookies. De innehåller ingen identifierare, skickas inte till någon server och följer dig inte till andra webbplatser. De sparar bara en inställning som du själv valt, så webbplatsen ber inte om samtycke. För att ta bort dem rensar du den här webbplatsens data i webbläsarens inställningar.

Webbläsarspelet SOTY: Honeycomb Kingdoms

Spelet på pegasohlib.com/soty/play/ körs helt i din webbläsare. För att du ska kunna fortsätta ett spel och behålla dina inställningar sparar det dem i den här webbplatsens lokala lagring på din enhet, under namn som börjar med soty.. Det läser också siteLang, så att det öppnas på det språk du valt på webbplatsen.

Dessa poster behövs för att spelet du öppnade ska fungera. De stannar på din enhet, skickas aldrig till någon och innehåller inget om dig, så inte heller spelet ber om samtycke. För att ta bort dem använder du Radera speldata i spelets pausmeny eller rensar den här webbplatsens data i webbläsaren. Detaljerna finns i spelets integritetspolicy.

soty.save
Det pågående spelet: kartan, staterna, deras trupper och omgången.
soty.prefs
Spelinställningar: tips, AI-hastighet, grafiknivå och uppsättningen för det senaste spelet.
soty.sound
Om ljudet är på.
soty.lang
Spelets språk, när du byter det i spelet.

Webbhotell

Webbplatsen körs på GitHub Pages, en tjänst från GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub loggar av säkerhetsskäl IP-adressen för alla som ansluter direkt till det, oavsett om de har ett GitHub-konto. PegasoHlib har ingen tillgång till dessa loggar. GitHub ansvarar för dessa data: se GitHub Privacy Statement.

Besökare på pegasohlib.com når webbplatsen via Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA: din webbläsare ansluter till Cloudflare, som hämtar sidan från GitHub. Därför ser Cloudflare din IP-adress, sidan du öppnar och de tekniska uppgifter som alla webbläsare skickar. Cloudflare behandlar dem för PegasoHlibs räkning enligt sitt personuppgiftsbiträdesavtal, för att leverera webbplatsen över en säker anslutning och skydda den mot attacker (berättigat intresse). PegasoHlib ser bara sammanlagda siffror, samt uppgifterna om en begäran som Cloudflare blockerar. Cloudflare sätter inga cookies här, om inte dess skydd ber en besökare att klara en säkerhetskontroll: då visar det en egen kontrollsida och kan sätta en strikt nödvändig cookie, cf_clearance. Vid dessa besök får GitHub inte din IP-adress: det ser bara Cloudflare. Din webbläsare ansluter direkt till GitHub bara vid nedladdningar och på den gamla adressen pegasohlib.github.io. Se Cloudflare Privacy Policy.

Nedladdningar och siffror

Nedladdningsknapparna leder till filer som ligger på GitHub. När du trycker på en ansluter din webbläsare till GitHub, och GitHub lägger till ett på filens räknare. PegasoHlib ser bara totalen för varje fil, aldrig vem som laddade ned den.

Nedladdningssummor, där en sida visar dem, läggs till när webbplatsen byggs, så din webbläsare kontaktar inte GitHubs API för dem. Versionsnummer och filstorlekar läses från filer på samma webbplats.

Vad webbplatsen inte använder

  • cookies;
  • reklam;
  • analysverktyg eller spårning av besökare;
  • knappar för sociala medier eller inbäddade videor;
  • typsnitt eller skript från andra företag: typsnitten levereras av den här webbplatsen;
  • konton eller formulär.

Om du skickar ett e-postmeddelande

E-post till kontaktadressen går via Cloudflare, som sköter domänens DNS och e-postroutning. Ett litet program där läser meddelandets rubriker och kan skicka dig ett automatiskt svar. Meddelandet vidarebefordras till en Gmail-brevlåda, så Google hanterar det också. PegasoHlib kan använda en AI-assistent, Claude från Anthropic, som hjälp att läsa e-post. PegasoHlib använder din adress och ditt meddelande bara för att svara dig och för att åtgärda det du rapporterar (berättigat intresse), och delar dem inte med någon annan. Du kan när som helst begära att de raderas.

Dina rättigheter och de juridiska detaljerna

Vem som är ansvarig. PegasoHlib, en privatperson som utvecklar dessa appar, är ansvarig för de data som beskrivs här. Kontakt: support@pegasohlib.com.

Vem som tar emot data, och överföringar utanför EU. GitHub är värd för webbplatsens filer och ser IP-adressen för alla som ansluter direkt till det. Cloudflare sköter domänens DNS och vidarebefordrar e-post till kontaktadressen, Google förvarar den i en Gmail-brevlåda och Anthropic kan behandla den när AI-assistenten hjälper till att läsa den. Alla fyra har sitt säte i USA. Dessa överföringar bygger på EU–USA-ramverket för dataskydd (Data Privacy Framework) där företaget deltar i det, eller på företagets standardavtalsklausuler. Samma skyddsåtgärder gäller för Cloudflare när det levererar den här webbplatsen och ser besökares IP-adresser.

Hur länge data sparas. E-post du skickar sparas tills ärendet är avslutat och i högst 2 år. GitHub sparar sina loggar enligt egna regler. Det gör även Cloudflare.

Dina rättigheter. Du kan begära tillgång till dina data, rättelse, radering, begränsning, en kopia att ta med dig någon annanstans (dataportabilitet), och du kan invända mot behandling. Skriv till adressen ovan. Du får svar inom en månad. PegasoHlib har personuppgifter om dig bara om du har skickat e-post eller spelar ZORYT, vars integritetspolicy förklarar vad spelet sparar. För hosting- och nedladdningsdata, kontakta GitHub. För data som Cloudflare har när det levererar webbplatsen, skriv till adressen ovan så vidarebefordrar PegasoHlib din begäran.

Klagomål. Du kan lämna in klagomål till dataskyddsmyndigheten i ditt land.

Språk. Översättningar av den här sidan görs med hjälp av AI. Om en översättning avviker från den engelska texten gäller den version som är mest förmånlig för dig.
