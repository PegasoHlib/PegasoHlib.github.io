网站隐私

最后更新：2026 年 11 月 13 日

本页涉及网站 pegasohlib.com：主页和各个应用的页面。简而言之：没有账号，没有 Cookie，没有广告，也没有数据分析。每个应用或游戏如何处理数据，在它自己的隐私政策中有说明，列在下方。

要点速览

  • 本网站不设置 Cookie，没有广告、分析统计或社交媒体按钮。
  • 你选择的语言和主题只保存在你自己的浏览器中，绝不会发送到任何地方。
  • Cloudflare 负责分发网站，能看到访问者的 IP 地址。GitHub 保存文件，只有在你下载或使用旧地址时才能看到你的 IP 地址。
  • 文件从 GitHub 下载，因此 GitHub 会看到并统计每次下载。
  • 如果你发送电子邮件，邮件仅用于回复你。

浏览器中保存了什么

当你选择语言或切换主题时，本网站会把你的选择保存在浏览器的本地存储中，以便下次打开页面时保持一致。在你做出选择之前，不会保存任何内容。

siteLang
你选择的语言。
pegasohlib-theme
你选择的浅色或深色主题。

为什么没有同意横幅

这两项不是 Cookie。它们不含任何标识符，不会发送到任何服务器，也不会跟随你访问其他网站。它们只是保存你自己选择的设置，因此本网站不会征求同意。如需删除，请在浏览器设置中清除本网站的数据。

浏览器游戏 SOTY: Honeycomb Kingdoms

pegasohlib.com/soty/play/ 上的游戏在你的浏览器中运行。为了让你可以继续游戏并保留设置，它会把这些内容保存在你设备上本网站的本地存储中，名称均以 soty. 开头。它还会读取 siteLang，以便用你在本网站上选择的语言打开。

这些条目是你打开的游戏正常运行所必需的，也不包含任何关于你的信息，因此游戏同样不会征求同意。它们留在你的设备上。只有当你和朋友在线游玩时，游戏才会发送房间代码和你的席位密钥，而且只发送到它自己位于 pegasohlib.com/soty/api/ 的房间服务器。Cloudflare 为 PegasoHlib 运行该服务器，并将每局在线对局保存在欧盟境内，直到它自行删除：在最后一步之后 30 天，或在对局结束后 7 天。如需删除，请使用游戏暂停菜单中的清除游戏数据，或在浏览器中清除本网站的数据。详见游戏的隐私政策。

soty.save
这台设备上正在进行的游戏：地图、各个国家及其部队和当前回合。
soty.prefs
游戏设置：提示、电脑行动速度、画质等级、文字大小和动态效果、上一局的设置，以及在线对局的预设名称和回合计时器。
soty.sound
声音是否开启。
soty.lang
游戏语言，在你于游戏中切换后保存。
soty.rooms
你拥有席位的在线对局：每个房间的代码、你的席位及其密钥、你的预设名称，以及你上次在那里看到的状态。

托管

本网站运行在 GitHub Pages 上，这是 GitHub, Inc. 的一项服务，地址：GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA。无论是否拥有 GitHub 账户，GitHub 都会出于安全目的记录每位直接连接到 GitHub 的人的 IP 地址。PegasoHlib 无法访问这些日志。GitHub 对这些数据负责：请参阅 GitHub Privacy Statement。

访问 pegasohlib.com 的人通过 Cloudflare, Inc.（101 Townsend St., San Francisco, CA 94107, USA）到达本网站：你的浏览器连接到 Cloudflare，再由 Cloudflare 从 GitHub 获取页面。因此，Cloudflare 能看到你的 IP 地址、你打开的页面以及任何浏览器都会发送的技术信息。它根据自己的数据处理协议，代表 PegasoHlib 处理这些信息，以便通过安全连接分发网站并保护网站免受攻击（正当利益）。PegasoHlib 只能看到总体数字，以及被 Cloudflare 拦截的请求的详情。Cloudflare 在这里不设置 Cookie，除非其防护要求访问者通过安全检查：此时它会显示自己的检查页面，并可能设置一个绝对必要的 Cookie，即 cf_clearance。这类访问中 GitHub 收不到你的 IP 地址，只能看到 Cloudflare。只有下载文件和使用旧地址 pegasohlib.github.io 时，你的浏览器才会直接连接到 GitHub。详见 Cloudflare Privacy Policy。

下载与数字

下载按钮指向存放在 GitHub 上的文件。你点击按钮时，浏览器会连接到 GitHub，GitHub 会为该文件的计数器加一。PegasoHlib 只能看到每个文件的总数，永远看不到是谁下载的。

下载总数（在页面显示它们的地方）是在网站构建时加入的，所以你的浏览器不会为此联系 GitHub 的 API。版本号和文件大小是从本网站上的文件中读取的。

如果你发送电子邮件

发到联系地址的邮件会经过 Cloudflare，它负责本域名的 DNS 和邮件路由。那里的一个小程序会读取邮件标头，并可能向你发送自动回复。邮件会转发到一个 Gmail 邮箱，因此 Google 也会处理。PegasoHlib 可能会使用 Anthropic 的 AI 助手 Claude 来协助阅读邮件。PegasoHlib 仅为回复你和解决你反馈的问题而使用你的地址和邮件内容（正当利益），不会与任何其他人分享。你可以随时要求删除。
