本页涉及网站 pegasohlib.github.io：主页和各个应用的页面。简而言之：没有账号，没有 Cookie，没有广告，也没有数据分析。每个应用或游戏如何处理数据，在它自己的隐私政策中有说明，列在下方。

要点速览

  • 本网站不设置 Cookie，没有广告、分析统计或社交媒体按钮。
  • 你选择的语言和主题只保存在你自己的浏览器中，绝不会发送到任何地方。
  • GitHub 托管本网站，并出于安全目的记录访问者的 IP 地址。
  • 文件从 GitHub 下载，因此 GitHub 会看到并统计每次下载。
  • 如果你发送电子邮件，邮件仅用于回复你。

浏览器中保存了什么

当你选择语言或切换主题时，本网站会把你的选择保存在浏览器的本地存储中，以便下次打开页面时保持一致。在你做出选择之前，不会保存任何内容。

siteLang
你选择的语言。
pegasohlib-theme
你选择的浅色或深色主题。

为什么没有同意横幅

这两项不是 Cookie。它们不含任何标识符，不会发送到任何服务器，也不会跟随你访问其他网站。它们只是保存你自己选择的设置，因此本网站不会征求同意。如需删除，请在浏览器设置中清除本网站的数据。

托管

本网站运行在 GitHub Pages 上，这是 GitHub, Inc. 的一项服务，地址：GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA。无论访问者是否拥有 GitHub 账户，GitHub 都会出于安全目的记录每位访问者的 IP 地址。PegasoHlib 无法访问这些日志。GitHub 对这些数据负责：请参阅 GitHub Privacy Statement。

下载与数字

下载按钮指向存放在 GitHub 上的文件。你点击按钮时，浏览器会连接到 GitHub，GitHub 会为该文件的计数器加一。PegasoHlib 只能看到每个文件的总数，永远看不到是谁下载的。

下载总数（在页面显示它们的地方）是在网站构建时加入的，所以你的浏览器不会为此联系 GitHub 的 API。版本号和文件大小是从本网站上的文件中读取的。
