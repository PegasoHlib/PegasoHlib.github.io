Kadr

개인정보 처리방침

마지막 업데이트: 2026년 11월 4일

Kadr는 PegasoHlib이 만든 Windows용 무료 동영상·사진 편집기예요. 이 방침은 Kadr가 데이터를 어떻게 다루는지 설명해요. 요약하면, 동영상, 사진, 프로젝트는 내 컴퓨터에 남고 개발자에게는 아무것도 전송되지 않아요.

한눈에 보기

  • 내 동영상, 사진, 프로젝트, 내보내기 파일은 내 컴퓨터에 남고, 배경 제거와 AI 화질 개선도 컴퓨터에서 실행돼요. Kadr는 이를 업로드하지 않아요.
  • 계정도, 광고도, 분석도 없어요. 개발자는 어떤 데이터도 받지 않아요. “그래픽 카드로 AI 실행”은 기본으로 켜져 있으며, 그러면 Microsoft DirectML이 내 Windows 설정에 따라 Microsoft에 진단 데이터를 보낼 수 있어요.
  • Kadr는 시작할 때와 6시간마다 업데이트를 확인해요. 이 확인에는 스위치가 없고, 자동 다운로드만 끌 수 있어요. AI 모델은 GitHub에서 한 번 내려받아요.
  • 자동 자막은 선택 사항이에요. 직접 시작할 때만 클립의 오디오가 내 API 키로 ElevenLabs에 전송돼요.
  • 설정, 최근 프로젝트 경로, 암호화된 ElevenLabs 키는 Windows 레지스트리에 있어요. 자동 저장, 캐시, 썸네일, 모델, 마지막으로 내려받은 설치 프로그램은 %LOCALAPPDATA%\Kadr에 있어요.
  • 제거해도 레지스트리 키와 그 폴더는 삭제되지 않아요. 삭제하는 방법은 Kadr 제거 항목에 나와 있어요.

내 동영상, 사진, 프로젝트

Kadr는 내가 프로젝트에 추가한 동영상, 사진, 음악과 사진 편집기에서 연 사진을 열어서 내 컴퓨터에서 바로 작업해요. 프로젝트(.kadr, .kadrimg), 내보낸 MP4, GIF, MP3 파일과 사진은 내가 고른 곳에 저장돼요. 프로젝트 파일에는 내 미디어 파일의 경로가 들어 있고, 사진 프로젝트에는 레이어가 들어 있어요. Kadr는 이들을 업로드하지 않고, 다른 곳에 복사하지 않고, 개발자에게 보내지도 않아요. 내보내는 동안에는 Windows 임시 폴더에 임시 파일을 쓰고, 끝나면 삭제해요.

Kadr가 PC에 저장하는 정보

  • Windows 레지스트리의 HKCU\Software\PegasoHlib\Kadr 아래에: 설정(테마, 글자 크기, 언어, 업데이트 자동 다운로드, 그래픽 카드로 AI 실행), 최근 프로젝트 최대 20개의 경로, 마지막으로 사용한 폴더, 창 위치, 그리고 입력했다면 내 ElevenLabs API 키가 있어요. 이 키는 이 PC의 내 Windows 사용자만 해독할 수 있도록 Windows DPAPI로 암호화돼요.
  • %LOCALAPPDATA%\Kadr에: 열려 있는 동영상 프로젝트의 자동 저장(중단 후 복구용이며, 사진 프로젝트는 자동 저장되지 않아요), 프레임 썸네일과 오디오 파형의 캐시, 최근 프로젝트의 작은 미리보기 이미지, 내려받은 AI 모델, 마지막으로 내려받은 설치 프로그램이 있어요.

이전 버전의 앱은 %LOCALAPPDATA%\PegasoCut 폴더를 사용했어요. Kadr가 이 폴더를 새 위치로 알아서 옮겨요.

설치 프로그램은 내 Windows 사용자에게만 Kadr를 설치하고, 관리자 권한이 필요 없으며, 내 사용자 영역에만 써요. 옵션을 선택하면 내 사용자에게 .kadr와 .kadrimg 파일도 등록해요. Kadr는 특별한 권한을 선언하지 않으며 기기 식별자도 없어요. 파일 이름에 내 PC에서 가져온 것은 아무것도 없어요.

인터넷: 업데이트

Kadr는 시작하고 30초 뒤, 그리고 실행되는 동안 6시간마다 작은 파일 pegasohlib.github.io/kadr/update.json을 읽어요. 이 확인은 끌 수 없어요. “업데이트 자동 설치” 설정은 다운로드만 제어해요. 켜져 있고(기본값이에요) 더 새로운 버전이 있으면 설치 프로그램을 GitHub(github.com)에서 백그라운드로 내려받아 Kadr를 닫을 때 설치해요. 설치 전에 Kadr는 디지털 서명과 대조해 확인하므로, 위조된 업데이트는 설치되지 않아요.

이 요청에는 개인 데이터가 들어 있지 않아요. 다른 웹사이트와 마찬가지로 호스트인 GitHub는 내 IP 주소와 표준 요청 데이터를 받으며, GitHub 개인정보 보호정책이 적용돼요.

GitHub는 각 파일이 몇 번 다운로드됐는지도 집계해요. 누가 내려받았는지에 대한 정보 없이 숫자만 있으며, 웹사이트에서는 이를 대략적인 다운로드 수로 보여 줘요.

배경 제거와 화질 개선

배경 제거는 BiRefNet AI 모델(MIT 라이선스)로 내 컴퓨터에서 바로 이루어져요. 약 115MB인 모델 파일은 GitHub에서 한 번만 내려받으며, 업데이트 때와 마찬가지로 GitHub는 IP 주소와 일반적인 요청 데이터를 받아요. 사진 자체는 어디에도 전송되지 않아요. GitHub에도, 개발자에게도, 다른 누구에게도요.

화질 개선(사진 편집기의 ×2 또는 ×4, 그리고 4K로 동영상을 내보낼 때의 AI 업스케일링)도 Real-ESRGAN AI 모델(BSD-3 라이선스)로 내 컴퓨터에서 바로 실행돼요. 각 모델 파일(2–5 MB)은 처음 사용할 때 같은 방식으로 GitHub에서 한 번 내려받아요. 내 사진, 동영상, 그 프레임은 내 컴퓨터에 남아요. Kadr는 이 모델을 실행하는 엔진인 ONNX Runtime의 원격 측정을 꺼요.

그래픽 카드로 AI 실행: Microsoft DirectML

“그래픽 카드로 AI 실행” 설정은 기본으로 켜져 있어요. 그러면 배경 제거와 AI 업스케일링이 Microsoft가 만든 구성 요소이며 오픈 소스가 아닌 Microsoft DirectML을 통해 내 그래픽 카드에서 실행돼요. 내 사진과 동영상은 여전히 내 컴퓨터에서만 처리돼요.

Microsoft의 라이선스 조건에 따라 DirectML은 진단 데이터를 수집해 Windows 진단 데이터 설정에 맞게 Microsoft에 보낼 수 있으며, Microsoft 개인정보처리방침이 적용돼요. 원하지 않으면 Kadr의 설정 → AI에서 GPU 사용을 끄세요. 그러면 AI는 프로세서에서만 실행돼요.

ElevenLabs를 통한 자동 자막

자동 자막은 선택 사항이며 내 ElevenLabs API 키가 있을 때만 작동해요. 내가 시작할 때만 선택한 클립의 오디오(모노, 16 kHz MP3로 변환)가 ElevenLabs로 전송되고, ElevenLabs가 음성을 텍스트로 바꿔 자막을 돌려 보내요. 이것은 내 키로, 내 ElevenLabs 계정으로 이루어지며, ElevenLabs 개인정보 처리방침이 적용돼요. 개발자는 아무것도 받지 않아요. 키가 없거나 자동 자막을 시작하지 않으면 ElevenLabs로는 아무것도 전송되지 않아요. .srt 파일의 가져오기와 내보내기는 오프라인에서 작동해요.

Kadr가 하지 않는 일

  • 계정도, 자체 서버도 없어요.
  • 자체 분석, 광고, 추적, 원격 측정(텔레메트리)이 없어요.
  • 내 동영상, 사진, 프로젝트, 내보낸 파일을 업로드하지 않아요.
  • 어떤 데이터도 판매하거나 공유하지 않아요.

Kadr와 데이터 삭제

Windows 설정 → 앱에서 Kadr를 제거하세요. 제거 프로그램은 프로그램과 파일 연결을 삭제하지만, 레지스트리 키 HKCU\Software\PegasoHlib\Kadr(설정, 최근 프로젝트 경로, 암호화된 ElevenLabs 키)와 폴더 %LOCALAPPDATA%\Kadr(자동 저장, 캐시, 미리보기, 모델, 마지막 설치 프로그램)는 삭제하지 않아요.

이것들도 삭제하려면 그 폴더를 삭제하고, 레지스트리 편집기(regedit)에서 레지스트리 키를 삭제하세요. ElevenLabs 키만 지우고 싶다면 Kadr 설정에서 지울 수도 있어요. 내 동영상, 사진, 프로젝트, 내보낸 파일은 내가 삭제하기 전까지 내가 저장한 곳에 남아요.

어린이

Kadr는 어린이를 포함해 누구의 개인정보도 수집하지 않아요. 계정, 채팅, 공유 기능이 없어요.
