Kadr

隱私權政策

最後更新：2026年11月4日

Kadr 是 PegasoHlib 開發的一款免費 Windows 影片與相片編輯器。本政策說明 Kadr 如何處理資料。簡單來說：你的影片、相片和專案留在你的電腦上，不會傳送任何內容給開發者。

重點摘要

  • 你的影片、相片、專案和匯出檔案都留在你的電腦上，背景移除和 AI 增強也在電腦上執行。Kadr 不會上傳它們。
  • 沒有帳號，沒有廣告，沒有數據分析。開發者從不會收到任何資料。「在顯示卡上執行 AI」預設為開啟，此時 Microsoft DirectML 可能會依你的 Windows 設定向 Microsoft 傳送診斷資料。
  • Kadr 在啟動時以及每 6 小時檢查一次更新。這項檢查沒有開關；只有自動下載可以關閉。AI 模型只會從 GitHub 下載一次。
  • 自動字幕是選用的：只有在你啟動時，片段的音訊才會使用你自己的 API 金鑰傳送給 ElevenLabs。
  • 設定、最近專案的路徑和加密的 ElevenLabs 金鑰儲存在 Windows 登錄中。自動儲存、快取、縮圖、模型和最近下載的安裝程式位於 %LOCALAPPDATA%\Kadr。
  • 解除安裝不會移除登錄機碼或該資料夾。關於移除 Kadr 的章節說明了如何刪除它們。

你的影片、相片和專案

Kadr 會開啟你新增到專案中的影片、相片和音樂，以及你在相片編輯器中開啟的相片，並直接在你的電腦上處理它們。專案（.kadr、.kadrimg）、匯出的 MP4、GIF 和 MP3 檔案以及圖片，都儲存在你選擇的位置。專案檔案包含你的媒體檔案的路徑，相片專案包含圖層。Kadr 不會上傳它們，不會把它們複製到其他任何地方，也不會把它們傳送給開發者。匯出時，它會在 Windows 暫存資料夾中使用暫存檔，並在之後刪除它們。

Kadr 在你的電腦上儲存什麼

  • 在 Windows 登錄的 HKCU\Software\PegasoHlib\Kadr 下：設定（主題、文字大小、語言、更新的自動下載、在顯示卡上執行 AI）、最多 20 個最近專案的路徑、你最近使用的資料夾、視窗位置，以及（如果你輸入了的話）你的 ElevenLabs API 金鑰，它用 Windows DPAPI 加密，只有這台電腦上你的 Windows 使用者才能解密；
  • 在 %LOCALAPPDATA%\Kadr 中：開啟的影片專案的自動儲存（用於當機後復原；相片專案不會自動儲存）、畫面縮圖和音訊波形的快取、你最近專案的小預覽圖、已下載的 AI 模型，以及最近下載的安裝程式。

舊版的應用程式使用資料夾 %LOCALAPPDATA%\PegasoCut；Kadr 會自動把它移到新的位置。

安裝程式只為你的 Windows 使用者安裝 Kadr，不需要管理員權限，只寫入你自己的使用者區域。如果你勾選了該選項，它還會為你的使用者註冊 .kadr 和 .kadrimg 檔案。Kadr 不宣告任何特殊權限，也沒有裝置識別碼：它的檔名中沒有任何內容來自你的電腦。

連上網路：更新

Kadr 在啟動 30 秒後，以及之後執行期間每 6 小時，會讀取一個小檔案 pegasohlib.github.io/kadr/update.json。這項檢查無法關閉。「自動安裝更新」設定只控制下載：它開啟時（預設為開啟），如果有更新的版本，安裝程式會在背景從 GitHub（github.com）下載，並在你關閉 Kadr 時安裝。安裝之前，Kadr 會對照數位簽章進行檢查，所以偽造的更新不會被安裝。

這些請求不帶有任何個人資料。和任何網站一樣，作為代管方的 GitHub 會收到你的 IP 位址和標準的請求資料，並適用 GitHub 隱私權聲明。

GitHub 也會統計每個檔案的下載次數。這只是一個數字，不包含任何關於下載者的資訊；網站會將它顯示為大致的下載量。

移除背景和畫質提升

移除背景直接在你的電腦上進行，使用 BiRefNet AI 模型（MIT 授權）。大約 115 MB 的模型檔案只會從 GitHub 下載一次；和更新時一樣，GitHub 會收到你的 IP 位址和標準要求資料。你的相片本身絕不會被傳送到任何地方：不會傳給 GitHub，不會傳給開發者，也不會傳給其他任何人。

畫質增強（相片編輯器中的 ×2 或 ×4，以及以 4K 匯出影片時的 AI 放大）同樣直接在你的電腦上執行，使用 Real-ESRGAN AI 模型（BSD-3 授權）。每個 2–5 MB 的模型檔案，會在你第一次使用時以同樣的方式從 GitHub 下載一次。你的相片、影片及其畫面都留在你的電腦上。Kadr 會關閉執行這些模型的引擎 ONNX Runtime 的遙測功能。

用顯示卡執行 AI：Microsoft DirectML

「在顯示卡上執行 AI」設定預設為開啟。此時，背景移除和 AI 放大會透過 Microsoft DirectML 在你的顯示卡上執行，它是 Microsoft 製作的元件，不是開放原始碼的。你的相片和影片仍然只在你的電腦上處理。

依據 Microsoft 的授權條款，DirectML 可能會收集診斷資料，並依照你的 Windows 診斷資料設定傳送給 Microsoft；適用 Microsoft 隱私權聲明。如果你不希望這樣，可以在 Kadr 的 設定 → AI 中關閉 GPU 使用，AI 就只會在處理器上執行。

透過 ElevenLabs 產生自動字幕

自動字幕是選用的，只能配合你自己的 ElevenLabs API 金鑰使用。只有當你啟動它時，所選片段的音訊（轉換為單聲道、16 kHz 的 MP3）才會傳送到 ElevenLabs，由它把語音轉換成文字，再把字幕傳回來。這是用你的金鑰、在你的 ElevenLabs 帳戶下完成的，並適用 ElevenLabs 隱私權政策。開發者不會收到任何內容。如果沒有金鑰，或者你從不啟動自動字幕，就不會向 ElevenLabs 傳送任何內容。匯入和匯出 .srt 檔案可以離線進行。

Kadr 不會做的事

  • 沒有帳號，也沒有自己的伺服器；
  • 沒有自身的分析、廣告、追蹤和遙測；
  • 不會上傳你的影片、相片、專案或匯出的檔案；
  • 不會出售或分享任何資料。

刪除 Kadr 及其資料

在 Windows 設定 → 應用程式中解除安裝 Kadr。解除安裝程式會移除程式和檔案關聯，但不會移除登錄機碼 HKCU\Software\PegasoHlib\Kadr（設定、最近專案的路徑和加密的 ElevenLabs 金鑰）或資料夾 %LOCALAPPDATA%\Kadr（自動儲存、快取、預覽圖、模型、最近的安裝程式）。

要把它們也一併移除，請刪除該資料夾，並在登錄編輯程式（regedit）中刪除該登錄機碼。如果你只想讓它忘記 ElevenLabs 金鑰，也可以在 Kadr 的「設定」中清除它。你自己的影片、相片、專案和匯出檔案會留在你儲存的位置，直到你把它們刪除。
