為 Shorts 和 YouTube 打造的免費影片與相片編輯器

使用方式

從第一個片段或第一張相片到完成的檔案，只要四個步驟。

  1. 1

    安裝

    執行安裝程式。它只為你的 Windows 使用者安裝，不需要管理員權限。如果 Windows 發出警告，請按一下其他資訊，然後按一下仍要執行。

  2. 2

    建立專案

    製作影片時，選擇一種格式：9:16、16:9、1:1 或 4:5。製作圖片時，開啟一張相片或選擇現成的畫布尺寸。

  3. 3

    編輯

    把影片片段、相片和音樂放到時間軸上，剪輯它們，新增標題、轉場和濾鏡。在相片編輯器中，可以新增圖層和文字，以及移除背景。

  4. 4

    匯出

    影片可儲存為 MP4（480p 到 4K）、GIF 或 MP3，圖片可儲存為 PNG、JPG 或 WebP。

影片編輯器

多軌時間軸

多條影片和音訊軌道，附有縮圖和波形。支援分割、修剪、複製、吸附和標記。

標題

樣式預設、你電腦上的任何字型、外框、背景框和動畫出現效果。

轉場和速度

溶解、淡入黑場、滑動和縮放。速度從 0.1× 到 8×，並保持音高，還有片段內部的速度曲線。

直式取景

適應或填滿，在預覽中拖曳圖層，以及為相片和影片提供緩慢的縮放和平移。

色彩

六種濾鏡，以及亮度、對比、飽和度、銳利度和底片顆粒。

聲音

分離音訊，音量最高可達 200%。選用的逐片段設定能在有其他聲音時壓低某條軌道，匯出時還可以把響度調平到 −14 LUFS。節拍標記在節奏穩定的音樂上效果最好。

字幕

匯入和匯出 .srt。選用的自動字幕透過 ElevenLabs 實現，使用你自己的 API 金鑰。

匯出

MP4，解析度 480p、720p、1080p、1440p 或 4K，幀率 24–60 fps，也可匯出 GIF 或 MP3。對於 4K，你可以選擇快速縮放或 AI 放大，在沒有支援的顯示卡時 AI 放大會很慢。

相片編輯器

適用於 YouTube 縮圖、拼貼和貼文。

圖層和畫布尺寸

相片和文字都作為圖層。提供縮圖、方形貼文和限時動態的現成尺寸。

背景移除

一鍵完成，在你的電腦上執行。約 115 MB 的模型只需下載一次。另有模糊筆刷和模糊背景。

AI 增強 ×2 或 ×4

2–5 MB 的 Real-ESRGAN 模型，只需下載一次。你的相片絕不會被上傳。

筆刷、形狀和剪貼簿

筆刷、橡皮擦、箭頭和形狀。Ctrl+V 貼上螢幕擷圖，Ctrl+Shift+C 複製結果。

常見問題

Windows 顯示「Windows 已保護您的電腦」，這正常嗎？

對於沒有付費程式碼簽署憑證的應用程式，Windows 會顯示這個提示，而 Kadr 沒有這樣的憑證。請按一下其他資訊，然後按一下仍要執行。Kadr 自己的更新在安裝前會對照數位簽章進行檢查。

我的影片或相片會被上傳到哪裡嗎？

不會。它們留在你的電腦上，背景移除和增強也在電腦上執行。唯一的例外是自動字幕，而且僅在你啟動它時：所選片段的音訊會透過你自己的 API 金鑰傳送到 ElevenLabs。

Kadr 為什麼需要連上網路？

用於檢查更新（在 Kadr 啟動時以及每 6 小時）、下載更新，以及每個 AI 模型下載一次。檢查本身無法關閉；在「設定」→「更新」中，你只能關閉自動下載。如果你使用自動字幕，它也會連上網路。

AI 需要效能強的顯示卡嗎？

不需要，但沒有顯示卡時會慢得多。DirectML 開啟時（預設為開啟），AI 會使用顯示卡；背景移除可能佔用約 5 GB 的顯示記憶體。在「設定」→「AI」中，你可以切換為只使用處理器。

如果 Kadr 或電腦當機了怎麼辦？

影片專案每 45 秒自動儲存一次，Kadr 會在下次啟動時提示復原。相片專案不會自動儲存，所以請自己儲存。

怎麼解除安裝，會留下什麼？

在 Windows 設定 → 應用程式中解除安裝 Kadr。你的設定、最近專案的路徑和加密的 ElevenLabs 金鑰會保留在登錄中，自動儲存、快取和模型會保留在 %LOCALAPPDATA%\Kadr 中。隱私權政策說明了如何刪除它們。

更新內容

2.9.0
相片編輯器加入模糊：獨立的「模糊」滑桿（比以前強得多）、只模糊塗抹之處的「模糊」筆刷，以及「模糊背景」：人物或物體保持清晰，背後的背景像手機人像模式一樣被虛化（輕、中、強；在本機執行）。
2.8.0
速度曲線：片段的速度可以平滑變化——在適當時刻慢動作、加速或「跳切」。現成預設（加速、減速、英雄、子彈、蒙太奇、跳切）以及自訂曲線：上下拖曳點，按兩下新增點。預覽、分割和匯出都嚴格依照曲線進行，聲音加速時音調不變。
2.7.2
「關於」頁面更簡潔了：第三方函式庫原始碼的連結現在只在「授權」視窗中。
2.7.1
全新的設定與「關於」頁面：附開關的卡片，語言集中在一個附國旗的清單裡，連結改為磚塊。細節更精緻：頂部列的標誌，時間軸片段顏色更柔和並有選取框，圖釘形狀的播放頭，以及空專案中的提示。

你的影片和相片留在你的電腦上

Kadr 沒有帳號，沒有廣告，沒有數據分析，開發者也不會收到任何資料。它會為了更新、一次性下載 AI 模型而連上網路，並且在你啟動自動字幕時也會連上網路。DirectML 開啟時，Microsoft 可能會依你的 Windows 設定收到診斷資料。
