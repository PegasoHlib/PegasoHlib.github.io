Kadr

นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 6 พฤศจิกายน 2026

Kadr คือโปรแกรมตัดต่อวิดีโอและแต่งรูปฟรีสำหรับ Windows โดย PegasoHlib นโยบายนี้อธิบายว่า Kadr ทำอะไรกับข้อมูลบ้าง โดยสรุป: วิดีโอ รูปภาพ และโปรเจกต์ของคุณอยู่บนคอมพิวเตอร์ของคุณ และไม่มีสิ่งใดถูกส่งไปยังผู้พัฒนา

สรุปสั้น ๆ

  • วิดีโอ รูปภาพ โปรเจกต์ และไฟล์ส่งออกของคุณอยู่บนคอมพิวเตอร์ของคุณ และการลบพื้นหลังกับการปรับปรุงด้วย AI ก็ทำงานบนเครื่องนั้น Kadr ไม่อัปโหลดไฟล์เหล่านั้น
  • ไม่มีบัญชี ไม่มีโฆษณา ไม่มีระบบวิเคราะห์ ผู้พัฒนาไม่เคยได้รับข้อมูลใด ๆ “AI บนการ์ดจอ” เปิดไว้เป็นค่าเริ่มต้น และ Microsoft DirectML อาจส่งข้อมูลวินิจฉัยไปยัง Microsoft ตามการตั้งค่า Windows ของคุณ
  • Kadr ตรวจหาอัปเดตเมื่อเริ่มทำงานและทุก 6 ชั่วโมง การตรวจสอบนี้ไม่มีสวิตช์ ปิดได้เฉพาะการดาวน์โหลดอัตโนมัติ โมเดล AI ดาวน์โหลดจาก GitHub เพียงครั้งเดียว
  • คำบรรยายอัตโนมัติเป็นตัวเลือกเสริม: เฉพาะเมื่อคุณสั่งเริ่ม เสียงของคลิปจะถูกส่งไปยัง ElevenLabs ด้วยคีย์ API ของคุณเอง
  • การตั้งค่า เส้นทางโปรเจกต์ล่าสุด และคีย์ ElevenLabs ที่เข้ารหัสอยู่ในรีจิสทรีของ Windows ส่วนการบันทึกอัตโนมัติ แคช ภาพขนาดย่อ โมเดล และตัวติดตั้งที่ดาวน์โหลดล่าสุดอยู่ใน %LOCALAPPDATA%\Kadr
  • การถอนการติดตั้งไม่ลบคีย์รีจิสทรีหรือโฟลเดอร์นั้น หัวข้อเรื่องการลบ Kadr บอกวิธีลบ

ในหน้านี้

วิดีโอ รูปภาพ และโปรเจกต์ของคุณสิ่งที่ Kadr เก็บไว้บนพีซีของคุณอินเทอร์เน็ต: การอัปเดตการลบพื้นหลังและการเพิ่มคุณภาพAI บนการ์ดจอ: Microsoft DirectMLคำบรรยายอัตโนมัติผ่าน ElevenLabsสิ่งที่ Kadr ไม่ทำการลบ Kadr และข้อมูลของแอปการเปลี่ยนแปลงนโยบายนี้สิทธิของคุณและรายละเอียดทางกฎหมายติดต่อ

ข้อมูลอะไร เก็บที่ไหน และใครเห็นได้

ข้อมูลเก็บไว้ที่ไหนใครเห็นได้
วิดีโอ รูปภาพ เพลง โปรเจกต์ และไฟล์ที่ส่งออกของคุณบนคอมพิวเตอร์ของคุณ ในที่ที่คุณเก็บไว้เฉพาะคุณ
รูปที่คุณลบพื้นหลังหรือเพิ่มคุณภาพ และเฟรมวิดีโอที่ขยายเป็น 4Kประมวลผลด้วยโมเดล AI บนคอมพิวเตอร์ของคุณ ไม่ถูกอัปโหลดเลยเฉพาะคุณ
การตั้งค่า รายการโปรเจกต์ล่าสุดและโฟลเดอร์ที่คุณใช้ ตำแหน่งหน้าต่างในรีจิสทรีของ Windows HKCU\Software\PegasoHlib\Kadr ยังอยู่หลังถอนการติดตั้งเฉพาะคุณ
คีย์ API ของ ElevenLabs หากคุณป้อนไว้ในคีย์รีจิสทรีเดียวกัน เข้ารหัสด้วย Windows (DPAPI) สำหรับผู้ใช้ Windows ของคุณบนพีซีเครื่องนี้ ยังอยู่หลังถอนการติดตั้งเฉพาะคุณ คีย์จะถูกส่งไปยัง ElevenLabs เท่านั้น พร้อมกับคำขอของคุณ
การบันทึกอัตโนมัติของโปรเจกต์วิดีโอที่เปิดอยู่ ภาพขนาดย่อของเฟรม รูปคลื่นเสียง ภาพตัวอย่างโปรเจกต์ โมเดล AI อัปเดตที่ดาวน์โหลดล่าสุดใน %LOCALAPPDATA%\Kadr ยังอยู่หลังถอนการติดตั้งเฉพาะคุณ
การตรวจหาและดาวน์โหลดอัปเดตตัวติดตั้งเก็บไว้ใน %LOCALAPPDATA%\Kadr\updates อ่านไฟล์เล็ก ๆ จาก pegasohlib.github.io ตัวติดตั้งมาจาก GitHubGitHub เห็นที่อยู่ IP ของคุณ เช่นเดียวกับเว็บไซต์ทั่วไป
โมเดล AI: การลบพื้นหลัง (BiRefNet ประมาณ 115 MB) และการปรับปรุงภาพ (Real-ESRGAN แต่ละตัว 2–5 MB)แต่ละตัวดาวน์โหลดจาก GitHub หนึ่งครั้งเมื่อใช้ครั้งแรก และเก็บไว้บนพีซีของคุณGitHub เห็นที่อยู่ IP ของคุณ เช่นเดียวกับตอนอัปเดต
ข้อมูลวินิจฉัยของ Microsoft DirectML ขณะที่เปิด “AI บนการ์ดจอ” อยู่ (ค่าเริ่มต้น)DirectML ส่งตามการตั้งค่าข้อมูลการวินิจฉัยของ Windows ของคุณMicrosoft ภายใต้ข้อกำหนดของตนเอง
เสียงของคลิปสำหรับคำบรรยายอัตโนมัติ เฉพาะเมื่อคุณสั่งเริ่มส่งไปยัง ElevenLabs ด้วยคีย์ API ของคุณElevenLabs ตามนโยบายความเป็นส่วนตัวของ ElevenLabs เอง

วิดีโอ รูปภาพ และโปรเจกต์ของคุณ

Kadr เปิดวิดีโอ รูปภาพ และเพลงที่คุณเพิ่มลงในโปรเจกต์ และรูปภาพที่คุณเปิดในโปรแกรมแก้ไขรูปภาพ แล้วทำงานกับไฟล์เหล่านั้นบนคอมพิวเตอร์ของคุณโดยตรง โปรเจกต์ (.kadr, .kadrimg) ไฟล์ MP4, GIF และ MP3 ที่ส่งออก และรูปภาพ จะถูกบันทึกในที่ที่คุณเลือก ไฟล์โปรเจกต์มีเส้นทางของไฟล์สื่อของคุณ และโปรเจกต์รูปภาพมีเลเยอร์ Kadr ไม่อัปโหลดไฟล์เหล่านี้ ไม่คัดลอกไปที่อื่น และไม่ส่งให้ผู้พัฒนา ขณะส่งออก แอปใช้ไฟล์ชั่วคราวในโฟลเดอร์ temp ของ Windows และลบทิ้งหลังจากนั้น

สิ่งที่ Kadr เก็บไว้บนพีซีของคุณ

  • ในรีจิสทรีของ Windows ภายใต้ HKCU\Software\PegasoHlib\Kadr: การตั้งค่า (ธีม ขนาดตัวอักษร ภาษา การดาวน์โหลดอัปเดตอัตโนมัติ AI บนการ์ดจอ) เส้นทางของโปรเจกต์ล่าสุดได้ถึง 20 รายการ โฟลเดอร์ล่าสุดที่คุณใช้ ตำแหน่งหน้าต่าง และหากคุณใส่ ก็มีคีย์ API ของ ElevenLabs ที่เข้ารหัสด้วย Windows DPAPI เพื่อให้เฉพาะผู้ใช้ Windows ของคุณบนพีซีเครื่องนี้ถอดรหัสได้
  • ใน %LOCALAPPDATA%\Kadr: การบันทึกอัตโนมัติของโปรเจกต์วิดีโอที่เปิดอยู่ (สำหรับกู้คืนหลังแอปล่ม โปรเจกต์รูปภาพไม่ถูกบันทึกอัตโนมัติ) แคชของภาพขนาดย่อของเฟรมและรูปคลื่นเสียง ภาพตัวอย่างขนาดเล็กของโปรเจกต์ล่าสุดของคุณ โมเดล AI เมื่อดาวน์โหลดแล้ว และตัวติดตั้งที่ดาวน์โหลดล่าสุด

แอปเวอร์ชันเก่าใช้โฟลเดอร์ %LOCALAPPDATA%\PegasoCut และ Kadr จะย้ายโฟลเดอร์นั้นไปยังตำแหน่งใหม่ให้เอง

ตัวติดตั้งติดตั้ง Kadr เฉพาะผู้ใช้ Windows ของคุณ ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และเขียนเฉพาะในพื้นที่ผู้ใช้ของคุณเอง หากคุณเลือกตัวเลือก ตัวติดตั้งจะลงทะเบียนไฟล์ .kadr และ .kadrimg ให้ผู้ใช้ของคุณด้วย Kadr ไม่ประกาศสิทธิ์พิเศษใด ๆ และไม่มีตัวระบุอุปกรณ์: ไม่มีสิ่งใดในชื่อไฟล์ที่มาจากพีซีของคุณ

อินเทอร์เน็ต: การอัปเดต

Kadr อ่านไฟล์เล็ก ๆ pegasohlib.github.io/kadr/update.json 30 วินาทีหลังเริ่มทำงาน แล้วทุก 6 ชั่วโมงขณะที่ทำงานอยู่ การตรวจสอบนี้ปิดไม่ได้ การตั้งค่า “ติดตั้งการอัปเดตอัตโนมัติ” ควบคุมเฉพาะการดาวน์โหลด: เมื่อเปิดอยู่ (ค่าเริ่มต้น) และมีเวอร์ชันใหม่กว่า ตัวติดตั้งจะถูกดาวน์โหลดจาก GitHub (github.com) ในเบื้องหลังและติดตั้งเมื่อคุณปิด Kadr ก่อนติดตั้ง Kadr ตรวจสอบกับลายเซ็นดิจิทัล ดังนั้นการอัปเดตปลอมจะไม่ถูกติดตั้ง

คำขอเหล่านี้ไม่มีข้อมูลส่วนบุคคล เช่นเดียวกับเว็บไซต์ทั่วไป GitHub ในฐานะผู้ให้บริการโฮสต์ ได้รับที่อยู่ IP ของคุณและข้อมูลคำขอมาตรฐาน และประกาศเกี่ยวกับความเป็นส่วนตัวของ GitHubมีผลบังคับใช้

GitHub ยังนับจำนวนครั้งที่แต่ละไฟล์ถูกดาวน์โหลดด้วย ซึ่งเป็นเพียงตัวเลข ไม่มีข้อมูลว่าใครเป็นผู้ดาวน์โหลด เว็บไซต์แสดงตัวเลขนี้เป็นจำนวนดาวน์โหลดโดยประมาณ

การลบพื้นหลังและการเพิ่มคุณภาพ

การลบพื้นหลังทำงานบนคอมพิวเตอร์ของคุณโดยตรง ด้วยโมเดล AI BiRefNet (สัญญาอนุญาต MIT) ไฟล์โมเดลขนาดประมาณ 115 MB จะถูกดาวน์โหลดจาก GitHub เพียงครั้งเดียว และเช่นเดียวกับตอนอัปเดต GitHub จะได้รับที่อยู่ IP ของคุณและข้อมูลคำขอมาตรฐาน รูปของคุณจะไม่ถูกส่งไปที่ใดเลย ไม่ว่าจะเป็น GitHub ผู้พัฒนา หรือใครก็ตาม

การปรับปรุงคุณภาพ (×2 หรือ ×4 ในโปรแกรมแก้ไขรูปภาพ และการอัปสเกลด้วย AI เมื่อส่งออกวิดีโอเป็น 4K) ก็ทำงานบนคอมพิวเตอร์ของคุณโดยตรงเช่นกัน ด้วยโมเดล AI Real-ESRGAN (ใบอนุญาต BSD-3) ไฟล์โมเดลแต่ละไฟล์ขนาด 2–5 MB ดาวน์โหลดจาก GitHub หนึ่งครั้งเมื่อคุณใช้ครั้งแรก ในลักษณะเดียวกัน รูปภาพ วิดีโอ และเฟรมของคุณอยู่บนคอมพิวเตอร์ของคุณ Kadr ปิดการส่งข้อมูลทางไกลของ ONNX Runtime ซึ่งเป็นเอนจินที่รันโมเดลเหล่านี้

AI บนการ์ดจอ: Microsoft DirectML

การตั้งค่า “AI บนการ์ดจอ” เปิดไว้เป็นค่าเริ่มต้น เมื่อเปิด การลบพื้นหลังและการอัปสเกลด้วย AI จะทำงานบนการ์ดจอของคุณผ่าน Microsoft DirectML ซึ่งเป็นส่วนประกอบที่ Microsoft สร้างและไม่ใช่โอเพนซอร์ส รูปภาพและวิดีโอของคุณยังคงถูกประมวลผลบนคอมพิวเตอร์ของคุณเท่านั้น

ภายใต้ข้อกำหนดสิทธิ์การใช้งานของ Microsoft นั้น DirectML อาจเก็บข้อมูลการวินิจฉัยและส่งไปยัง Microsoft ตามการตั้งค่าข้อมูลการวินิจฉัยของ Windows ของคุณ โดยใช้ คำชี้แจงสิทธิ์ส่วนบุคคลของ Microsoft หากคุณไม่ต้องการ ให้ปิดการใช้ GPU ใน การตั้งค่า → AI ของ Kadr แล้ว AI จะทำงานบนโปรเซสเซอร์เท่านั้น

คำบรรยายอัตโนมัติผ่าน ElevenLabs

คำบรรยายอัตโนมัติเป็นตัวเลือกและทำงานเฉพาะกับคีย์ API ของ ElevenLabs ของคุณเอง เฉพาะเมื่อคุณเริ่ม เสียงของคลิปที่เลือก (แปลงเป็น MP3 โมโน 16 kHz) จะถูกส่งไปที่ ElevenLabs ซึ่งแปลงเสียงพูดเป็นข้อความและส่งคำบรรยายกลับมา การทำงานนี้ใช้คีย์ของคุณ ภายใต้บัญชี ElevenLabs ของคุณ และนโยบายความเป็นส่วนตัวของ ElevenLabsมีผลบังคับใช้ ผู้พัฒนาไม่ได้รับอะไรเลย หากไม่มีคีย์ หรือหากคุณไม่เคยเริ่มคำบรรยายอัตโนมัติ จะไม่มีอะไรถูกส่งไปที่ ElevenLabs การนำเข้าและส่งออกไฟล์ .srt ทำงานแบบออฟไลน์

สิ่งที่ Kadr ไม่ทำ

  • ไม่มีบัญชีและไม่มีเซิร์ฟเวอร์ของตัวเอง
  • ไม่มีการวิเคราะห์ข้อมูล ไม่มีโฆษณา ไม่มีการติดตาม ไม่มีการส่งข้อมูลการใช้งาน (telemetry) ของตัวเอง
  • ไม่อัปโหลดวิดีโอ รูปภาพ โปรเจกต์ หรือไฟล์ที่ส่งออกของคุณ
  • ไม่ขายหรือแชร์ข้อมูลใด ๆ

การลบ Kadr และข้อมูลของแอป

ถอนการติดตั้ง Kadr ในการตั้งค่า Windows → แอป ตัวถอนการติดตั้งลบโปรแกรมและการเชื่อมโยงไฟล์ แต่ไม่ลบคีย์รีจิสทรี HKCU\Software\PegasoHlib\Kadr (การตั้งค่า เส้นทางโปรเจกต์ล่าสุด และคีย์ ElevenLabs ที่เข้ารหัส) หรือโฟลเดอร์ %LOCALAPPDATA%\Kadr (การบันทึกอัตโนมัติ แคช ภาพตัวอย่าง โมเดล ตัวติดตั้งล่าสุด)

หากต้องการลบสิ่งเหล่านั้นด้วย ให้ลบโฟลเดอร์นั้น และลบคีย์รีจิสทรีในตัวแก้ไขรีจิสทรี (regedit) หากคุณเพียงต้องการให้ลืมคีย์ ElevenLabs คุณก็ล้างได้ในการตั้งค่าของ Kadr วิดีโอ รูปภาพ โปรเจกต์ และไฟล์ที่ส่งออกของคุณเองจะอยู่ในที่ที่คุณบันทึกไว้จนกว่าคุณจะลบ

การเปลี่ยนแปลงนโยบายนี้

หากแอปเริ่มทำสิ่งใหม่กับข้อมูล หน้านี้จะได้รับการอัปเดตก่อน พร้อมวันที่ใหม่ที่ด้านบน

ประโยชน์โดยชอบด้วยกฎหมาย: ตอบคุณ (มาตรา 6(1)(f))

ผู้ที่ได้รับข้อมูล และการโอนข้อมูลออกนอกสหภาพยุโรป GitHub (การตรวจสอบอัปเดต การอัปเดต และโมเดล AI) และเฉพาะเมื่อคุณใช้ ElevenLabs (คำบรรยายอัตโนมัติ) Microsoft อาจได้รับข้อมูลการวินิจฉัยจาก DirectML ตามการตั้งค่า Windows ของคุณ อีเมลที่ส่งมาจะผ่าน Cloudflare และ Google เก็บไว้ในกล่องจดหมาย Gmail และ Anthropic อาจประมวลผลเมื่อผู้ช่วย AI ช่วยอ่าน บริษัทเหล่านี้บางแห่งตั้งอยู่ในสหรัฐอเมริกาหรือประเทศอื่นนอกสหภาพยุโรป การโอนข้อมูลดังกล่าวอาศัยกรอบความเป็นส่วนตัวของข้อมูลสหภาพยุโรป–สหรัฐอเมริกา (EU–US Data Privacy Framework) หากบริษัทนั้นเข้าร่วม หรืออาศัยข้อสัญญามาตรฐาน (standard contractual clauses) ของบริษัทนั้น

ระยะเวลาที่เก็บข้อมูล ข้อมูลในแอปจะอยู่จนกว่าคุณจะลบหรือถอนการติดตั้งแอป สำเนาในที่เก็บข้อมูลบนคลาวด์ของคุณเองจะอยู่จนกว่าคุณจะลบ อีเมลที่คุณส่งมาจะเก็บไว้จนกว่าเรื่องจะเสร็จสิ้น และไม่เกิน 2 ปี

สิทธิของคุณ คุณขอเข้าถึงข้อมูลของคุณ ขอแก้ไข ลบ จำกัดการประมวลผล ขอสำเนาเพื่อนำไปใช้ที่อื่น (การโอนย้ายข้อมูลได้) และคัดค้านการประมวลผลหรือถอนความยินยอมได้ทุกเมื่อ เขียนมาที่ที่อยู่ข้างต้น คุณจะได้รับคำตอบภายในหนึ่งเดือน ข้อมูลส่วนใหญ่อยู่บนอุปกรณ์ของคุณเท่านั้น คุณจึงมักทำเรื่องเหล่านี้เองได้ในแอป

การร้องเรียน คุณร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลในประเทศของคุณได้

อายุ คุณต้องมีอายุอย่างน้อย 15 ปีจึงจะใช้แอปด้วยตนเองได้ หากคุณอายุน้อยกว่านั้น โปรดขอให้ผู้ปกครองหรือผู้ดูแลตามกฎหมายยินยอมก่อน
