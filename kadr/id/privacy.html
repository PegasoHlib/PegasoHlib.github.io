Kadr

Kebijakan privasi

Terakhir diperbarui: 4 November 2026

Kadr adalah editor video dan foto gratis untuk Windows dari PegasoHlib. Kebijakan ini menjelaskan apa yang dilakukan Kadr dengan data. Singkatnya: video, foto, dan proyek Anda tetap di komputer Anda, dan tidak ada yang dikirim ke pengembang.

Sekilas

  • Video, foto, proyek, dan hasil ekspormu tetap di komputermu, dan penghapusan latar belakang serta peningkatan dengan AI juga berjalan di sana. Kadr tidak mengunggahnya.
  • Tanpa akun, tanpa iklan, tanpa analitik. Pengembang tidak pernah menerima data apa pun. “AI di kartu grafis” aktif secara default, dan Microsoft DirectML kemudian mungkin mengirim data diagnostik ke Microsoft sesuai pengaturan Windows-mu.
  • Kadr memeriksa pembaruan saat dimulai dan setiap 6 jam. Pemeriksaan ini tidak punya sakelar; hanya unduhan otomatis yang bisa dimatikan. Model AI diunduh sekali dari GitHub.
  • Subtitel otomatis bersifat opsional: hanya saat Anda memulainya, audio klip dikirim ke ElevenLabs dengan kunci API Anda sendiri.
  • Pengaturan, jalur proyek terbaru, dan kunci ElevenLabs terenkripsi ada di registry Windows. Simpan otomatis, cache, thumbnail, model, dan penginstal terakhir yang diunduh ada di %LOCALAPPDATA%\Kadr.
  • Mencopot pemasangan tidak menghapus kunci registry atau folder itu. Bagian tentang menghapus Kadr menjelaskan cara menghapusnya.

Video, foto, dan proyek Anda

Kadr membuka video, foto, dan musik yang kamu tambahkan ke proyek, serta foto yang kamu buka di editor foto, dan mengerjakannya langsung di komputermu. Proyek (.kadr, .kadrimg), file MP4, GIF, dan MP3 hasil ekspor, serta gambar disimpan di tempat yang kamu pilih. File proyek berisi jalur file media-mu, dan proyek foto berisi lapisan-lapisannya. Kadr tidak mengunggahnya, tidak menyalinnya ke tempat lain, dan tidak mengirimnya ke pengembang. Saat mengekspor, aplikasi memakai file sementara di folder temp Windows dan menghapusnya setelahnya.

Apa yang disimpan Kadr di PC Anda

  • Di registry Windows, di bawah HKCU\Software\PegasoHlib\Kadr: pengaturan (tema, ukuran teks, bahasa, unduhan otomatis pembaruan, AI di kartu grafis), jalur hingga 20 proyek terbaru, folder terakhir yang kamu pakai, posisi jendela dan, jika kamu memasukkannya, kunci API ElevenLabs-mu, dienkripsi dengan Windows DPAPI sehingga hanya pengguna Windows-mu di PC ini yang bisa mendekripsinya;
  • di %LOCALAPPDATA%\Kadr: simpan otomatis proyek video yang terbuka (untuk pemulihan setelah mogok; proyek foto tidak disimpan otomatis), cache thumbnail frame dan bentuk gelombang audio, gambar pratinjau kecil proyek terbaru, model AI setelah diunduh, dan penginstal terakhir yang diunduh.

Versi lama aplikasi ini memakai folder %LOCALAPPDATA%\PegasoCut; Kadr memindahkannya sendiri ke tempat yang baru.

Penginstal memasang Kadr hanya untuk pengguna Windows-mu, tidak memerlukan hak administrator, dan hanya menulis ke area penggunamu sendiri. Jika kamu mencentang opsinya, penginstal juga mendaftarkan file .kadr dan .kadrimg untuk penggunamu. Kadr tidak menyatakan izin khusus dan tidak punya pengenal perangkat: tidak ada dalam nama filenya yang diturunkan dari PC-mu.

Internet: pembaruan

Kadr membaca file kecil, pegasohlib.github.io/kadr/update.json, 30 detik setelah dimulai lalu setiap 6 jam selama berjalan. Pemeriksaan ini tidak bisa dimatikan. Pengaturan “Pasang pembaruan otomatis” hanya mengatur unduhan: saat aktif (default) dan ada versi yang lebih baru, penginstal diunduh dari GitHub (github.com) di latar belakang dan dipasang saat kamu menutup Kadr. Sebelum memasang, Kadr memeriksanya dengan tanda tangan digital, sehingga pembaruan palsu tidak dipasang.

Permintaan ini tidak membawa data pribadi. Seperti situs web mana pun, GitHub, sebagai host, menerima alamat IP-mu dan data permintaan standar, dan Pernyataan Privasi GitHub berlaku.

GitHub juga menghitung berapa kali setiap file diunduh. Itu hanya angka, tanpa informasi apa pun tentang siapa yang mengunduh; situs web menampilkannya sebagai perkiraan jumlah unduhan.

Penghapusan latar belakang dan peningkatan kualitas

Penghapusan latar belakang berjalan langsung di komputer Anda, dengan model AI BiRefNet (lisensi MIT). File model, sekitar 115 MB, diunduh sekali dari GitHub; seperti saat pembaruan, GitHub menerima alamat IP Anda dan data permintaan standar. Foto Anda tidak pernah dikirim ke mana pun: tidak ke GitHub, tidak ke pengembang, dan tidak ke siapa pun.

Peningkatan kualitas (×2 atau ×4 di editor foto, dan peningkatan skala AI saat kamu mengekspor video dalam 4K) juga berjalan langsung di komputermu, dengan model AI Real-ESRGAN (lisensi BSD-3). Setiap file model, 2–5 MB, diunduh sekali dari GitHub saat pertama kamu memakainya, dengan cara yang sama. Foto, video, dan frame-nya tetap di komputermu. Kadr mematikan telemetri ONNX Runtime, mesin yang menjalankan model-model ini.

AI di kartu grafis: Microsoft DirectML

Pengaturan “AI di kartu grafis” aktif secara default. Dengan itu, penghapusan latar belakang dan peningkatan skala AI berjalan di kartu grafismu lewat Microsoft DirectML, komponen buatan Microsoft yang bukan open source. Foto dan videomu tetap diproses hanya di komputermu.

Berdasarkan ketentuan lisensi Microsoft, DirectML dapat mengumpulkan data diagnostik dan mengirimkannya ke Microsoft sesuai pengaturan data diagnostik Windows Anda; Pernyataan Privasi Microsoft berlaku. Jika Anda tidak menginginkannya, matikan penggunaan kartu grafis di Pengaturan Kadr → AI, maka AI hanya berjalan di prosesor.

Subtitel otomatis melalui ElevenLabs

Subtitel otomatis bersifat opsional dan hanya bekerja dengan kunci API ElevenLabs milikmu sendiri. Hanya saat kamu memulainya, audio klip yang dipilih (dikonversi ke MP3 mono 16 kHz) dikirim ke ElevenLabs, yang mengubah ucapan menjadi teks dan mengirim subtitelnya kembali. Ini dilakukan dengan kuncimu, di bawah akun ElevenLabs-mu, dan Kebijakan Privasi ElevenLabs berlaku. Pengembang tidak menerima apa pun. Tanpa kunci, atau jika kamu tidak pernah memulai subtitel otomatis, tidak ada yang dikirim ke ElevenLabs. Mengimpor dan mengekspor file .srt bekerja secara offline.

Apa yang tidak dilakukan Kadr

  • tidak ada akun dan tidak ada server sendiri;
  • tidak ada analitik, iklan, pelacakan, atau telemetri miliknya sendiri;
  • tidak mengunggah video, foto, proyek, atau hasil ekspor Anda;
  • tidak menjual atau membagikan data apa pun.

Menghapus Kadr dan datanya

Copot pemasangan Kadr di Pengaturan Windows → Aplikasi. Pencopot menghapus program dan asosiasi file, tetapi tidak menghapus kunci registry HKCU\Software\PegasoHlib\Kadr (pengaturan, jalur proyek terbaru, dan kunci ElevenLabs terenkripsi) atau folder %LOCALAPPDATA%\Kadr (simpan otomatis, cache, pratinjau, model, penginstal terakhir).

Untuk menghapusnya juga, hapus folder itu, dan hapus kunci registry di Registry Editor (regedit). Jika kamu hanya ingin melupakan kunci ElevenLabs, kamu juga bisa menghapusnya di Pengaturan Kadr. Video, foto, proyek, dan file hasil ekspormu sendiri tetap di tempat kamu menyimpannya sampai kamu menghapusnya.
