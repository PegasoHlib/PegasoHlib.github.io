Кадр

Политика кон­фи­ден­ци­аль­ности

Последнее обновление: 6 ноября 2026 года

Кадр — бесплатный видео- и фоторедактор для Windows от PegasoHlib. Эта политика объясняет, что Кадр делает с данными. Коротко: твои видео, фото и проекты остаются на твоём компьютере, а разработчику ничего не отправляется.

Коротко

  • Твои видео, фото, проекты и экспортированные файлы остаются на твоём компьютере, и удаление фона с улучшением с помощью ИИ тоже выполняются на нём. Кадр их не загружает.
  • Без аккаунта, без рекламы, без аналитики. Разработчик никогда не получает никаких данных. «ИИ на видеокарте» включён по умолчанию, и тогда Microsoft DirectML может отправлять диагностические данные в Microsoft в соответствии с твоими настройками Windows.
  • Кадр проверяет обновления при запуске и каждые 6 часов. У этой проверки нет переключателя; выключить можно только автоматическую загрузку. Модели ИИ скачиваются один раз с GitHub.
  • Автосубтитры — по желанию: только когда ты их запускаешь, звук клипа отправляется в ElevenLabs с твоим собственным API-ключом.
  • Настройки, пути недавних проектов и зашифрованный ключ ElevenLabs находятся в реестре Windows. Автосохранение, кэш, миниатюры, модели и последний скачанный установщик — в %LOCALAPPDATA%\Kadr.
  • Удаление не убирает ключ реестра и эту папку. В разделе об удалении Кадра сказано, как их удалить.

Твои видео, фото и проекты

Кадр открывает видео, фото и музыку, которые ты добавляешь в проект, и фото, которые ты открываешь в фоторедакторе, и работает с ними прямо на твоём компьютере. Проекты (.kadr, .kadrimg), экспортированные файлы MP4, GIF и MP3 и картинки сохраняются там, где ты укажешь. В файле проекта есть пути к твоим медиафайлам, а фотопроект содержит слои. Кадр не загружает их, не копирует никуда ещё и не отправляет разработчику. При экспорте он использует временные файлы в папке temp Windows и потом удаляет их.

Что Кадр хранит на твоём ПК

  • В реестре Windows, в HKCU\Software\PegasoHlib\Kadr: настройки (тема, размер текста, язык, автоматическая загрузка обновлений, ИИ на видеокарте), пути до 20 недавних проектов, последние использованные папки, положение окна и, если ты его введёшь, твой ключ API ElevenLabs, зашифрованный средствами Windows DPAPI так, что расшифровать его может только твой пользователь Windows на этом компьютере;
  • в %LOCALAPPDATA%\Kadr: автосохранение открытого видеопроекта (для восстановления после сбоя; фотопроекты не автосохраняются), кэш миниатюр кадров и звуковых волн, небольшие картинки предпросмотра недавних проектов, уже скачанные модели ИИ и последний скачанный установщик.

Более старые версии приложения использовали папку %LOCALAPPDATA%\PegasoCut; Кадр сам переносит её на новое место.

Установщик ставит Кадр только для твоего пользователя Windows, не требует прав администратора и пишет только в твою пользовательскую область. Если отметить эту опцию, он также регистрирует файлы .kadr и .kadrimg для твоего пользователя. Кадр не заявляет особых разрешений и не имеет идентификатора устройства: ничто в именах его файлов не получено из твоего компьютера.

Интернет: обновления

Кадр читает небольшой файл pegasohlib.github.io/kadr/update.json через 30 секунд после запуска и затем каждые 6 часов, пока работает. Эту проверку выключить нельзя. Настройка «Устанавливать обновления автоматически» управляет только загрузкой: когда она включена (по умолчанию) и есть более новая версия, установщик скачивается с GitHub (github.com) в фоне и устанавливается, когда ты закрываешь Кадр. Перед установкой Кадр проверяет его по цифровой подписи, поэтому поддельное обновление не будет установлено.

Эти запросы не содержат личных данных. Как любой сайт, GitHub как хостинг получает твой IP-адрес и стандартные данные запроса, и действует Заявление GitHub о конфиденциальности.

GitHub также считает, сколько раз скачан каждый файл. Это только число, без каких-либо сведений о том, кто скачивал; сайт показывает его как примерное количество скачиваний.

Удаление фона и улучшение качества

Фон убирается прямо на твоём компьютере — ИИ-моделью BiRefNet (лицензия MIT). Файл модели, около 115 МБ, скачивается с GitHub один раз; как и при обновлениях, GitHub получает твой IP-адрес и стандартные данные запроса. Сами фото никуда не отправляются: ни в GitHub, ни разработчику, ни кому-либо ещё.

Улучшение качества (×2 или ×4 в фоторедакторе и масштабирование с помощью ИИ при экспорте видео в 4K) тоже выполняется прямо на твоём компьютере с помощью моделей ИИ Real-ESRGAN (лицензия BSD-3). Каждый файл модели, 2–5 МБ, один раз скачивается с GitHub при первом использовании, так же. Твои фото, видео и их кадры остаются на твоём компьютере. Кадр отключает телеметрию ONNX Runtime — движка, который запускает эти модели.

ИИ на видеокарте: Microsoft DirectML

Настройка «ИИ на видеокарте» включена по умолчанию. Тогда удаление фона и масштабирование с помощью ИИ выполняются на твоей видеокарте через Microsoft DirectML — компонент, созданный Microsoft, с закрытым кодом. Твои фото и видео по-прежнему обрабатываются только на твоём компьютере.

Согласно условиям лицензии Microsoft, DirectML может собирать диагностические данные и отправлять их в Microsoft в соответствии с твоими настройками диагностических данных Windows; действует Заявление о конфиденциальности Microsoft. Если это нежелательно, выключи использование видеокарты в Настройках Кадра → ИИ, и тогда ИИ будет работать только на процессоре.

Автосубтитры через ElevenLabs

Автосубтитры необязательны и работают только с твоим собственным ключом API ElevenLabs. Только когда ты их запускаешь, звук выбранного клипа (преобразованный в моно MP3 16 кГц) отправляется в ElevenLabs, который превращает речь в текст и присылает субтитры обратно. Это происходит с твоим ключом, в твоём аккаунте ElevenLabs, и действует Политика конфиденциальности ElevenLabs. Разработчик ничего не получает. Без ключа или если ты никогда не запускаешь автосубтитры, в ElevenLabs ничего не отправляется. Импорт и экспорт файлов .srt работают офлайн.

Чего Кадр не делает

  • никаких аккаунтов и собственных серверов;
  • никакой аналитики, рекламы, слежки и собственной телеметрии;
  • никакой загрузки твоих видео, фото, проектов или экспортированных файлов;
  • никакой продажи или передачи каких-либо данных.

Как удалить Кадр и его данные

Удали Кадр в Параметрах Windows → Приложения. Деинсталлятор убирает программу и сопоставления файлов, но не убирает раздел реестра HKCU\Software\PegasoHlib\Kadr (настройки, пути недавних проектов и зашифрованный ключ ElevenLabs) и папку %LOCALAPPDATA%\Kadr (автосохранение, кэш, предпросмотры, модели, последний установщик).

Чтобы убрать и их, удали эту папку и удали раздел реестра в редакторе реестра (regedit). Если нужно только забыть ключ ElevenLabs, его можно также стереть в настройках Кадра. Твои собственные видео, фото, проекты и экспортированные файлы остаются там, где они сохранены, пока ты их не удалишь.
