使用方法

从第一个片段或第一张照片到成品文件，只需四步。

  1. 1

    安装

    运行安装程序。它只为你的 Windows 用户安装，不需要管理员权限。如果 Windows 发出警告，请点击更多信息，然后点击仍要运行。

  2. 2

    新建项目

    制作视频时，选择一种格式：9:16、16:9、1:1 或 4:5。制作图片时，打开一张照片或选择现成的画布尺寸。

  3. 3

    编辑

    把视频片段、照片和音乐放到时间线上，剪辑它们，添加标题、转场和滤镜。在照片编辑器中，可以添加图层和文字，以及移除背景。

  4. 4

    导出

    视频可保存为 MP4（480p 到 4K）、GIF 或 MP3，图片可保存为 PNG、JPG 或 WebP。

视频编辑器

多轨时间线

多条视频和音频轨道，带有缩略图和波形。支持分割、修剪、复制、吸附和标记。

标题

样式预设、你电脑上的任何字体、描边、背景框和动画出现效果。

转场和速度

溶解、淡入黑场、滑动和缩放。速度从 0.1× 到 8×，并保持音高，还有片段内部的速度曲线。

竖屏取景

适应或填充，在预览中拖动图层，以及为照片和视频提供缓慢的缩放和平移。

色彩

六种滤镜，以及亮度、对比度、饱和度、锐度和胶片颗粒。

声音

分离音频，音量最高可达 200%。可选的逐片段设置能在有其他声音时压低某条轨道，导出时还可以把响度调平到 −14 LUFS。节拍标记在节奏稳定的音乐上效果最好。

字幕

导入和导出 .srt。可选的自动字幕通过 ElevenLabs 实现，使用你自己的 API 密钥。

导出

MP4，分辨率 480p、720p、1080p、1440p 或 4K，帧率 24–60 fps，也可导出 GIF 或 MP3。对于 4K，你可以选择快速缩放或 AI 放大，在没有受支持的显卡时 AI 放大会很慢。

照片编辑器

适用于 YouTube 封面图、拼图和帖子。

图层和画布尺寸

照片和文字都作为图层。提供缩略图、方形帖子和快拍（Story）的现成尺寸。

背景移除

一键完成，在你的电脑上运行。约 115 MB 的模型只需下载一次。另有模糊画笔和模糊背景。

AI 增强 ×2 或 ×4

2–5 MB 的 Real-ESRGAN 模型，只需下载一次。你的照片绝不会被上传。

画笔、形状和剪贴板

画笔、橡皮擦、箭头和形状。Ctrl+V 粘贴屏幕截图，Ctrl+Shift+C 复制结果。

常见问题

Windows 提示“Windows 已保护你的电脑”，这正常吗？

对于没有付费代码签名证书的应用，Windows 会显示这个提示，而 Kadr 没有这样的证书。请点击更多信息，然后点击仍要运行。Kadr 自己的更新在安装前会对照数字签名进行检查。

我的视频或照片会被上传到哪里吗？

不会。它们留在你的电脑上，背景移除和增强也在电脑上运行。唯一的例外是自动字幕，而且仅在你启动它时：所选片段的音频会通过你自己的 API 密钥发送到 ElevenLabs。

Kadr 为什么需要联网？

用于检查更新（在 Kadr 启动时以及每 6 小时）、下载更新，以及每个 AI 模型下载一次。检查本身无法关闭；在“设置”→“更新”中，你只能关闭自动下载。如果你使用自动字幕，它也会联网。

AI 需要性能强的显卡吗？

不需要，但没有显卡时会慢得多。DirectML 开启时（默认开启），AI 会使用显卡；背景移除可能占用约 5 GB 的显存。在“设置”→“AI”中，你可以切换为只使用处理器。

如果 Kadr 或电脑崩溃了怎么办？

视频项目每 45 秒自动保存一次，Kadr 会在下次启动时提示恢复。照片项目不会自动保存，所以请自己保存。

Kadr 是用什么做的？

它使用 FFmpeg、Qt 等开源组件，以及闭源的 Microsoft DirectML。每个组件及其许可证都列在应用的“关于 → 许可证”中。按照这些许可证的要求，可下载开源组件的源代码。

怎么卸载，会留下什么？

在 Windows 设置 → 应用中卸载 Kadr。你的设置、最近项目的路径和加密的 ElevenLabs 密钥会保留在注册表中，自动保存、缓存和模型会保留在 %LOCALAPPDATA%\Kadr 中。隐私政策说明了如何删除它们。
