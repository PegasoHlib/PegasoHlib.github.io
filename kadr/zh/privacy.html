Kadr

隐私政策

最后更新：2026年11月5日

Kadr 是 PegasoHlib 开发的一款免费 Windows 视频和照片编辑器。本政策说明 Kadr 如何处理数据。简而言之：你的视频、照片和项目留在你的电脑上，不会向开发者发送任何内容。

要点速览

  • 你的视频、照片、项目和导出文件都留在你的电脑上，背景移除和 AI 增强也在电脑上运行。Kadr 不会上传它们。
  • 没有账号，没有广告，没有数据分析。开发者从不会收到任何数据。“在显卡上运行 AI”默认开启，此时 Microsoft DirectML 可能会根据你的 Windows 设置向 Microsoft 发送诊断数据。
  • Kadr 在启动时以及每 6 小时检查一次更新。这项检查没有开关；只有自动下载可以关闭。AI 模型只会从 GitHub 下载一次。
  • 自动字幕是可选的：只有在你启动时，片段的音频才会使用你自己的 API 密钥发送给 ElevenLabs。
  • 设置、最近项目的路径和加密的 ElevenLabs 密钥保存在 Windows 注册表中。自动保存、缓存、缩略图、模型和最近下载的安装程序位于 %LOCALAPPDATA%\Kadr。
  • 卸载不会移除注册表项或该文件夹。关于移除 Kadr 的章节说明了如何删除它们。

你的视频、照片和项目

Kadr 会打开你添加到项目中的视频、照片和音乐，以及你在照片编辑器中打开的照片，并直接在你的电脑上处理它们。项目（.kadr、.kadrimg）、导出的 MP4、GIF 和 MP3 文件以及图片，都保存在你选择的位置。项目文件包含你的媒体文件的路径，照片项目包含图层。Kadr 不会上传它们，不会把它们复制到其他任何地方，也不会把它们发送给开发者。导出时，它会在 Windows 临时文件夹中使用临时文件，并在之后删除它们。

Kadr 在你的电脑上保存什么

  • 在 Windows 注册表的 HKCU\Software\PegasoHlib\Kadr 下：设置（主题、文字大小、语言、更新的自动下载、在显卡上运行 AI）、最多 20 个最近项目的路径、你最近使用的文件夹、窗口位置，以及（如果你输入了的话）你的 ElevenLabs API 密钥，它用 Windows DPAPI 加密，只有这台电脑上你的 Windows 用户才能解密；
  • 在 %LOCALAPPDATA%\Kadr 中：打开的视频项目的自动保存（用于崩溃后恢复；照片项目不会自动保存）、画面缩略图和音频波形的缓存、你最近项目的小预览图、已下载的 AI 模型，以及最近下载的安装程序。

旧版本的应用使用文件夹 %LOCALAPPDATA%\PegasoCut；Kadr 会自动把它移到新位置。

安装程序只为你的 Windows 用户安装 Kadr，不需要管理员权限，只写入你自己的用户区域。如果你勾选了该选项，它还会为你的用户注册 .kadr 和 .kadrimg 文件。Kadr 不声明任何特殊权限，也没有设备标识符：它的文件名中没有任何内容来自你的电脑。

联网：更新

Kadr 在启动 30 秒后，以及之后运行期间每 6 小时，会读取一个小文件 pegasohlib.github.io/kadr/update.json。这项检查无法关闭。“自动安装更新”设置只控制下载：它开启时（默认开启），如果有更新的版本，安装程序会在后台从 GitHub（github.com）下载，并在你关闭 Kadr 时安装。安装之前，Kadr 会对照数字签名进行检查，所以伪造的更新不会被安装。

这些请求不带有任何个人数据。和任何网站一样，作为托管方的 GitHub 会收到你的 IP 地址和标准的请求数据，并适用 GitHub 隐私声明。

GitHub 还会统计每个文件的下载次数。这只是一个数字，不包含任何关于下载者的信息；网站会将其显示为大致的下载量。

去除背景和画质增强

去除背景直接在你的电脑上进行，使用 BiRefNet AI 模型（MIT 许可证）。大约 115 MB 的模型文件只从 GitHub 下载一次；和更新时一样，GitHub 会收到你的 IP 地址和标准请求数据。你的照片本身绝不会被发送到任何地方：不会发给 GitHub，不会发给开发者，也不会发给任何其他人。

画质增强（照片编辑器中的 ×2 或 ×4，以及以 4K 导出视频时的 AI 放大）同样直接在你的电脑上运行，使用 Real-ESRGAN AI 模型（BSD-3 许可证）。每个 2–5 MB 的模型文件，会在你第一次使用时以同样的方式从 GitHub 下载一次。你的照片、视频及其画面都留在你的电脑上。Kadr 会关闭运行这些模型的引擎 ONNX Runtime 的遥测功能。

用显卡运行 AI：Microsoft DirectML

“在显卡上运行 AI”设置默认开启。此时，背景移除和 AI 放大会通过 Microsoft DirectML 在你的显卡上运行，它是 Microsoft 制作的组件，不是开源的。你的照片和视频仍然只在你的电脑上处理。

根据 Microsoft 的许可条款，DirectML 可能会收集诊断数据，并按照你的 Windows 诊断数据设置发送给 Microsoft；适用 Microsoft 隐私声明。如果你不希望这样，可以在 Kadr 的 设置 → AI 中关闭 GPU 使用，AI 就只会在处理器上运行。

通过 ElevenLabs 生成自动字幕

自动字幕是可选的，只能配合你自己的 ElevenLabs API 密钥使用。只有当你启动它时，所选片段的音频（转换为单声道、16 kHz 的 MP3）才会发送到 ElevenLabs，由它把语音转换成文字，再把字幕发回来。这是用你的密钥、在你的 ElevenLabs 账号下完成的，并适用 ElevenLabs 隐私政策。开发者不会收到任何内容。如果没有密钥，或者你从不启动自动字幕，就不会向 ElevenLabs 发送任何内容。导入和导出 .srt 文件可以离线进行。

Kadr 不会做的事

  • 没有账户，也没有自己的服务器；
  • 没有自身的分析、广告、跟踪和遥测；
  • 不会上传你的视频、照片、项目或导出的文件；
  • 不会出售或分享任何数据。

删除 Kadr 及其数据

在 Windows 设置 → 应用中卸载 Kadr。卸载程序会移除程序和文件关联，但不会移除注册表项 HKCU\Software\PegasoHlib\Kadr（设置、最近项目的路径和加密的 ElevenLabs 密钥）或文件夹 %LOCALAPPDATA%\Kadr（自动保存、缓存、预览图、模型、最近的安装程序）。

要把它们也一并移除，请删除该文件夹，并在注册表编辑器（regedit）中删除该注册表项。如果你只想让它忘记 ElevenLabs 密钥，也可以在 Kadr 的“设置”中清除它。你自己的视频、照片、项目和导出文件会留在你保存的位置，直到你把它们删除。
