Kadr

Shorts と YouTube のための無料動画・写真編集ソフト

TikTok、ショート、リール向けの縦型動画や通常の YouTube 動画をカットし、サムネイル、コラージュ、投稿を作れます。背景の除去と写真の AI 高画質化は、あなたの PC 上で実行されます。

しくみ

最初のクリップや写真から完成したファイルまで、4 ステップ。

  1. 1

    インストール

    インストーラーを実行してください。あなたの Windows ユーザーにインストールされ、管理者権限は不要です。Windows が警告を表示したら、詳細情報をクリックし、実行をクリックしてください。

  2. 2

    プロジェクトを作成

    動画は、9:16、16:9、1:1、4:5 から形式を選びます。画像は、写真を開くか、用意されたキャンバスサイズを選びます。

  3. 3

    編集

    クリップ、写真、音楽をタイムラインに置いてカットし、タイトル、トランジション、フィルターを追加できます。写真エディターでは、レイヤーとテキストを追加して背景を除去できます。

  4. 4

    書き出し

    動画は MP4(480p から 4K まで)、GIF、MP3 として、画像は PNG、JPG、WebP として保存できます。

動画エディター

マルチトラックのタイムライン

サムネイルと波形付きの、複数の動画・音声トラック。分割、トリミング、コピー、スナップ、マーカー。

タイトル

スタイルのプリセット、PC にあるすべてのフォント、縁取り、背景ボックス、アニメーション付きの登場効果。

トランジションと速度

ディゾルブ、暗転、スライド、ズーム。音の高さを保ったまま 0.1× から 8× の速度、そしてクリップ内の速度カーブ。

縦型のフレーミング

フィットまたはフィル、プレビューでのレイヤーのドラッグ、写真と動画のゆっくりしたズームとパン。

色

6種類のフィルター、明るさ、コントラスト、彩度、シャープネス、フィルムグレイン。

サウンド

音声の分離、最大200%の音量。クリップごとの任意の設定で、ほかの音の下でトラックの音量を下げることができ、書き出しでは音量を −14 LUFS にそろえられます。ビートマーカーは、テンポが一定の音楽でいちばんよく機能します。

字幕

.srt のインポートとエクスポート。任意で、あなた自身の API キーを使った ElevenLabs による自動字幕。

書き出し

24〜60 fps の 480p、720p、1080p、1440p、4K の MP4、GIF、MP3。4K では、高速な拡大と AI アップスケーリングから選べ、AI アップスケーリングは、対応するグラフィックスカードがないと遅くなります。

写真エディター

YouTube のサムネイル、コラージュ、投稿画像に。

レイヤーとキャンバスサイズ

レイヤーとしての写真とテキスト。サムネイル、正方形の投稿、ストーリー用に用意されたサイズ。

背景の除去

ワンクリックで、あなたの PC 上で。約115 MB のモデルは一度だけダウンロードされます。ぼかしブラシと背景をぼかすもあります。

AI 高画質化 ×2 または ×4

2〜5 MB の Real-ESRGAN モデルを一度だけダウンロードします。あなたの写真がアップロードされることは決してありません。

ブラシ、図形、クリップボード

ブラシ、消しゴム、矢印、図形。Ctrl+V でスクリーンショットを貼り付け、Ctrl+Shift+C で結果をコピーします。

よくある質問

「Windows によって PC が保護されました」と表示されます。大丈夫？

Windows は、有料のコード署名証明書がないアプリに対してこれを表示します。Kadr にはその証明書がありません。詳細情報をクリックし、実行をクリックしてください。Kadr 自身のアップデートは、インストール前に電子署名で検証されます。

動画や写真がどこかにアップロードされますか？

いいえ。コンピューター上に残り、背景の除去と高画質化もコンピューター上で実行されます。唯一の例外は自動字幕で、あなたが開始したときだけです。選んだクリップの音声が、あなた自身の API キーで ElevenLabs に送信されます。

Kadr は何のためにインターネットを必要としますか？

アップデートの確認(Kadr の起動時と6時間ごと)、アップデートのダウンロード、そして AI モデルごとに一度のダウンロードのためです。確認そのものはオフにできません。設定 → アップデートでオフにできるのは、自動ダウンロードだけです。自動字幕も、使う場合はオンラインに接続します。

AI には高性能なグラフィックスカードが必要ですか？

いいえ。ただし、ないとずっと遅くなります。DirectML がオン(初期設定ではオンです)の場合、AI はグラフィックスカードを使い、背景の除去では、ビデオメモリを約5 GB 使うことがあります。設定 → AI で、プロセッサだけを使うように切り替えられます。

Kadr や PC がクラッシュしたらどうなりますか？

動画プロジェクトは45秒ごとに自動保存され、次回 Kadr が復元を提案します。写真プロジェクトは自動保存されないので、自分で保存してください。

Kadr は何でできていますか？

FFmpeg や Qt などのオープンソースの部品と、クローズドな Microsoft DirectML を使っています。すべての部品とそのライセンスは、アプリの「情報 → ライセンス」に一覧があります。これらのライセンスの要件に従い、オープンソース部品のソースコードをダウンロードできます。

どうやって削除しますか？ 何が残りますか？

Windows の設定 → アプリで Kadr をアンインストールしてください。設定、最近のプロジェクトのパス、暗号化された ElevenLabs のキーはレジストリに残り、自動保存、キャッシュ、モデルは %LOCALAPPDATA%\Kadr に残ります。削除の方法はプライバシーポリシーに書かれています。
