Kadr

プライバシーポリシー

最終更新: 2026年11月5日

Kadr は、PegasoHlib が作った Windows 向けの無料動画・写真編集ソフトです。このポリシーでは、Kadr がデータをどう扱うかを説明します。要するに、動画、写真、プロジェクトはあなたのコンピューターに残り、開発者には何も送られません。

概要

  • あなたの動画、写真、プロジェクト、書き出しはコンピューター上に残り、背景の除去と AI 高画質化もコンピューター上で実行されます。Kadr がそれらをアップロードすることはありません。
  • アカウントも、広告も、分析もありません。開発者がデータを受け取ることは決してありません。「グラフィックスカードで AI を実行」は初期設定でオンで、その場合、Microsoft DirectML が、あなたの Windows の設定に従って、Microsoft に診断データを送信することがあります。
  • Kadr は、起動時と6時間ごとにアップデートを確認します。この確認にはスイッチがなく、オフにできるのは自動ダウンロードだけです。AI モデルは GitHub から一度だけダウンロードされます。
  • 自動字幕はオプションです。自分で開始したときだけ、クリップの音声が自分の API キーで ElevenLabs に送られます。
  • 設定、最近のプロジェクトのパス、暗号化された ElevenLabs のキーは、Windows レジストリにあります。自動保存、キャッシュ、サムネイル、モデル、最後にダウンロードしたインストーラーは、%LOCALAPPDATA%\Kadr にあります。
  • アンインストールしても、レジストリのキーとそのフォルダは削除されません。削除の方法は、Kadr の削除に関する項目に書かれています。

あなたの動画、写真、プロジェクト

Kadr は、プロジェクトに追加した動画、写真、音楽と、写真エディターで開いた写真を開き、あなたのコンピューター上でそのまま処理します。プロジェクト(.kadr、.kadrimg)、書き出した MP4、GIF、MP3 のファイルと画像は、あなたが選んだ場所に保存されます。プロジェクトファイルにはメディアファイルのパスが、写真プロジェクトにはレイヤーが含まれます。Kadr がそれらをアップロードしたり、ほかの場所にコピーしたり、開発者に送信したりすることはありません。書き出し中は、Windows の一時フォルダに一時ファイルを使い、終わったら削除します。

Kadr が PC に保存するもの

  • Windows レジストリの HKCU\Software\PegasoHlib\Kadr に: 設定(テーマ、文字サイズ、言語、アップデートの自動ダウンロード、グラフィックスカードでの AI)、最近のプロジェクト最大20件のパス、最後に使ったフォルダ、ウィンドウの位置、そして入力した場合は ElevenLabs の API キー。このキーは、この PC のあなたの Windows ユーザーだけが復号できるよう、Windows DPAPI で暗号化されます。
  • %LOCALAPPDATA%\Kadr に: 開いている動画プロジェクトの自動保存(クラッシュ後の復元用です。写真プロジェクトは自動保存されません)、フレームのサムネイルと音声の波形のキャッシュ、最近のプロジェクトの小さなプレビュー画像、一度ダウンロードした AI モデル、最後にダウンロードしたインストーラー。

以前のバージョンのアプリは %LOCALAPPDATA%\PegasoCut フォルダーを使っていました。Kadr はこれを自動で新しい場所に移します。

インストーラーは、あなたの Windows ユーザーにだけ Kadr をインストールし、管理者権限は不要で、あなた自身のユーザー領域にしか書き込みません。オプションにチェックを入れると、あなたのユーザー用に .kadr と .kadrimg ファイルも関連付けます。Kadr は特別な権限を宣言せず、デバイスの識別子も持ちません。ファイル名に、あなたの PC から得られたものは何もありません。

インターネット：更新

Kadr は、起動の30秒後と、動作中は6時間ごとに、小さなファイル pegasohlib.github.io/kadr/update.json を読み取ります。この確認はオフにできません。「アップデートを自動でインストール」の設定が制御するのはダウンロードだけです。オン(初期設定ではオンです)で、より新しいバージョンがある場合、インストーラーは GitHub(github.com)からバックグラウンドでダウンロードされ、Kadr を閉じるときにインストールされます。インストール前に、Kadr は電子署名と照合して確認するため、偽造されたアップデートはインストールされません。

これらのリクエストには個人データは含まれません。どのウェブサイトとも同様に、ホストである GitHub は、あなたの IP アドレスと標準のリクエストデータを受け取り、GitHub のプライバシーに関する声明が適用されます。

GitHub は各ファイルがダウンロードされた回数も数えています。これは数字だけで、誰がダウンロードしたかは含まれません。ウェブサイトではおおよそのダウンロード数として表示します。

背景削除と高画質化

背景削除は、BiRefNet AI モデル（MIT ライセンス）により、あなたのコンピューター上で直接行われます。約 115 MB のモデルファイルは GitHub から一度だけダウンロードされます。更新のときと同じく、GitHub は IP アドレスと標準的なリクエストデータを受け取ります。写真そのものはどこにも送られません。GitHub にも、開発者にも、ほかの誰にもです。

高画質化(写真エディターの ×2 または ×4 と、動画を 4K で書き出すときの AI アップスケーリング)も、Real-ESRGAN の AI モデル(BSD-3 ライセンス)で、あなたのコンピューター上でそのまま実行されます。各モデルファイル(2〜5 MB)は、初めて使うときに同じ方法で GitHub から一度ダウンロードされます。あなたの写真、動画、そのフレームはコンピューター上に残ります。Kadr は、これらのモデルを実行するエンジンである ONNX Runtime のテレメトリをオフにします。

グラフィックカードで AI：Microsoft DirectML

「グラフィックスカードで AI を実行」の設定は、初期設定でオンです。その場合、背景の除去と AI アップスケーリングは、Microsoft が作ったオープンソースではないコンポーネントである Microsoft DirectML を通じて、あなたのグラフィックスカード上で実行されます。あなたの写真と動画は、引き続きあなたのコンピューター上だけで処理されます。

Microsoft のライセンス条項により、DirectML は診断データを収集し、Windows の診断データの設定に従って Microsoft に送信することがあります。これには Microsoft プライバシー ステートメントが適用されます。望まない場合は、Kadr の設定 → AI で GPU の使用をオフにしてください。AI はプロセッサーだけで動くようになります。

ElevenLabs による自動字幕

自動字幕は任意で、あなた自身の ElevenLabs の API キーがある場合にのみ動作します。あなたが開始したときだけ、選んだクリップの音声(モノラル、16 kHz の MP3 に変換)が ElevenLabs に送信され、ElevenLabs が音声をテキストに変換して字幕を返します。これはあなたのキーで、あなたの ElevenLabs アカウントで行われ、ElevenLabs のプライバシーポリシーが適用されます。開発者は何も受け取りません。キーがない場合や、自動字幕を開始しない場合は、ElevenLabs には何も送信されません。.srt ファイルのインポートとエクスポートはオフラインで動作します。

Kadr がしないこと

  • アカウントも独自のサーバーもありません。
  • 独自の分析、広告、トラッキング、テレメトリーはありません。
  • あなたの動画、写真、プロジェクト、書き出したファイルをアップロードしません。
  • データを販売したり共有したりしません。

Kadr とそのデータの削除

Windows の設定 → アプリで Kadr をアンインストールしてください。アンインストーラーは、プログラムとファイルの関連付けを削除しますが、レジストリキー HKCU\Software\PegasoHlib\Kadr(設定、最近のプロジェクトのパス、暗号化された ElevenLabs のキー)と、フォルダ %LOCALAPPDATA%\Kadr(自動保存、キャッシュ、プレビュー、モデル、最後のインストーラー)は削除しません。

これらも削除するには、そのフォルダを削除し、レジストリエディター(regedit)でレジストリキーを削除してください。ElevenLabs のキーだけを消したい場合は、Kadr の設定で消去することもできます。あなた自身の動画、写真、プロジェクト、書き出したファイルは、あなたが削除するまで、保存した場所に残ります。
