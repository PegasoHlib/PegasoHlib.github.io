網站隱私

最後更新：2026 年 11 月 5 日

本頁涉及網站 pegasohlib.com：主頁和各個應用程式的頁面。簡而言之：沒有帳號，沒有 Cookie，沒有廣告，也沒有數據分析。每個應用程式或遊戲如何處理資料，在它自己的隱私權政策中有說明，列在下方。

重點摘要

  • 本網站不設定 Cookie，沒有廣告、分析統計或社群媒體按鈕。
  • 你選擇的語言和佈景主題只儲存在你自己的瀏覽器中，絕不會傳送到任何地方。
  • GitHub 代管本網站，Cloudflare 負責傳送，因此兩者都可能看到訪客的 IP 位址。
  • 檔案從 GitHub 下載，因此 GitHub 會看到並統計每次下載。
  • 如果你寄送電子郵件，郵件僅用於回覆你。

為什麼沒有同意橫幅

這兩項不是 Cookie。它們不含任何識別碼，不會傳送到任何伺服器，也不會跟著你到其他網站。它們只是儲存你自己選擇的設定，因此本網站不會徵求同意。如需移除，請在瀏覽器設定中清除本網站的資料。

代管

本網站運行在 GitHub Pages 上，這是 GitHub, Inc. 的一項服務，地址：GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA。無論訪客是否擁有 GitHub 帳號，GitHub 都會出於安全目的記錄每位訪客的 IP 位址。PegasoHlib 無法存取這些記錄。GitHub 對這些資料負責：請參閱 GitHub Privacy Statement。

造訪 pegasohlib.com 的人會透過 Cloudflare, Inc.（101 Townsend St., San Francisco, CA 94107, USA）到達本網站：你的瀏覽器連線到 Cloudflare，再由 Cloudflare 從 GitHub 取得頁面。因此，Cloudflare 能看到你的 IP 位址、你開啟的頁面，以及任何瀏覽器都會傳送的技術資訊。它依其資料處理協議，代表 PegasoHlib 處理這些資訊，以便透過安全連線傳送網站並保護網站免受攻擊（正當利益）。PegasoHlib 只能看到整體數字，以及被 Cloudflare 封鎖的請求的詳細資料。Cloudflare 在這裡不設定 Cookie，除非其防護要求訪客通過安全檢查：此時它會顯示自己的檢查頁面，並可能設定一個絕對必要的 Cookie，即 cf_clearance。下載檔案和舊地址 pegasohlib.github.io 會讓你的瀏覽器直接連線到 GitHub。詳見 Cloudflare Privacy Policy。

下載與數字

下載按鈕指向存放在 GitHub 上的檔案。你按下按鈕時，瀏覽器會連線到 GitHub，GitHub 會為該檔案的計數器加一。PegasoHlib 只能看到每個檔案的總數，永遠看不到是誰下載的。

下載總數（在頁面顯示它們的地方）是在網站建置時加入的，所以你的瀏覽器不會為此聯絡 GitHub 的 API。版本號碼和檔案大小是從本網站上的檔案中讀取的。

如果你寄送電子郵件

寄到聯絡地址的郵件會經過 Cloudflare，它負責本網域的 DNS 和郵件路由。那裡的一個小程式會讀取郵件標頭，並可能向你發送自動回覆。郵件會轉寄到一個 Gmail 信箱，因此 Google 也會處理。PegasoHlib 可能會使用 Anthropic 的 AI 助理 Claude 來協助閱讀郵件。PegasoHlib 僅為回覆你和處理你回報的問題而使用你的地址和郵件內容（正當利益），不會與任何其他人分享。你可以隨時要求刪除。
