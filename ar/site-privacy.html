باختصار

  • لا يضع الموقع ملفات تعريف ارتباط، وليس فيه إعلانات ولا أدوات تحليل ولا أزرار وسائل التواصل الاجتماعي.
  • تبقى اللغة والمظهر اللذان تختارانهما في متصفحكم فقط، ولا يُرسَلان إلى أي جهة.
  • توصل Cloudflare الموقع إلى الزوّار وترى عناوين IP الخاصة بهم. وتخزّن GitHub الملفات ولا ترى عنوان IP الخاص بكم إلا عند التنزيل أو على العنوان القديم.
  • تُنزَّل الملفات من GitHub، لذا ترى GitHub كل عملية تنزيل وتحتسبها.
  • إذا أرسلتم رسالة بريد إلكتروني، فتُستخدم للرد عليكم فقط.

التنزيلات والأرقام

تقود أزرار التنزيل إلى ملفات مخزَّنة على GitHub. وعند الضغط على أحدها يتصل متصفحكم بـGitHub، وتضيف GitHub واحدًا إلى عدّاد ذلك الملف. ولا ترى PegasoHlib سوى المجموع لكل ملف، ولا ترى أبدًا من نزّله.

تُضاف إجماليات التنزيل، حيثما تعرضها الصفحة، عند بناء الموقع، فلا يتصل متصفحك بواجهة GitHub البرمجية من أجلها. وتُقرأ أرقام الإصدارات وأحجام الملفات من ملفات على الموقع نفسه.

ما لا يستخدمه الموقع

  • ملفات تعريف الارتباط؛
  • الإعلانات؛
  • أدوات التحليل أو تتبّع الزوّار؛
  • أزرار وسائل التواصل الاجتماعي أو مقاطع الفيديو المضمَّنة؛
  • خطوطًا أو برمجيات نصية من شركات أخرى: فالخطوط تُقدَّم من هذا الموقع نفسه؛
  • الحسابات أو النماذج.

إذا أرسلتم بريدًا إلكترونيًا

تمر الرسائل المرسلة إلى عنوان التواصل عبر Cloudflare التي تدير نظام DNS وتوجيه البريد لهذا النطاق. ويقرأ برنامج صغير هناك ترويسات الرسالة وقد يرسل إليكم ردًا تلقائيًا. وتُحوَّل الرسالة إلى صندوق بريد Gmail، لذا تعالجها Google أيضًا. وقد تستخدم PegasoHlib مساعدًا بالذكاء الاصطناعي، هو Claude من Anthropic، للمساعدة في قراءة البريد. وتستخدم PegasoHlib عنوانكم ورسالتكم فقط للرد عليكم ولمعالجة ما تبلّغون عنه (المصلحة المشروعة)، ولا تشاركهما مع أي جهة أخرى. ويمكنكم طلب حذفهما في أي وقت.

حقوقكم والتفاصيل القانونية

من يتلقى البيانات، وعمليات النقل خارج الاتحاد الأوروبي. يستضيف GitHub ملفات هذا الموقع ويرى عنوان IP لكل من يتصل به مباشرةً. وتدير Cloudflare نظام DNS لهذا النطاق وتمرّر الرسائل المرسلة إلى عنوان التواصل، وتحفظها Google في صندوق بريد Gmail، وقد تعالجها Anthropic عندما يساعد مساعد الذكاء الاصطناعي في قراءتها. ومقرّ الشركات الأربع كلها في الولايات المتحدة. وتستند عمليات النقل هذه إلى إطار خصوصية البيانات بين الاتحاد الأوروبي والولايات المتحدة (Data Privacy Framework) إذا كانت الشركة مشاركة فيه، أو إلى البنود التعاقدية النموذجية الخاصة بالشركة. وتسري الضمانات نفسها على Cloudflare عندما توصل هذا الموقع وترى عناوين IP للزوّار.

مدة الاحتفاظ بها. تُحفظ رسائل البريد الإلكتروني التي ترسلونها إلى أن تُغلق المسألة، ولمدة لا تزيد على سنتين. ويحتفظ GitHub بسجلاته وفق قواعده الخاصة. وكذلك Cloudflare.

حقوقكم. يمكنكم طلب الاطلاع على بياناتكم وتصحيحها وحذفها وتقييد معالجتها والحصول على نسخة منها لنقلها إلى جهة أخرى (قابلية النقل)، كما يمكنكم الاعتراض على المعالجة. اكتبوا إلى العنوان المذكور أعلاه. وستصلكم الإجابة خلال شهر واحد. لا يحتفظ PegasoHlib ببيانات شخصية عنكم إلا إذا أرسلتم رسالة بريد إلكتروني أو لعبتم ZORYT، وتوضح سياسة خصوصيتها ما تحفظه. وبخصوص بيانات الاستضافة والتنزيل، تواصلوا مع GitHub. وبخصوص البيانات التي تحتفظ بها Cloudflare عند توصيل الموقع، راسلونا على العنوان أعلاه وسينقل PegasoHlib طلبكم.

الشكاوى. يمكنكم تقديم شكوى إلى هيئة لحماية البيانات، مثل الهيئة الفرنسية CNIL أو الهيئة المختصة في بلدكم.
