นโยบายความเป็นส่วนตัว

อัปเดตเมื่อ 5 พฤศจิกายน 2026

KORDON เป็นเกมกลยุทธ์สำหรับ Android สร้างโดยผู้พัฒนาคนเดียว (PegasoHlib) เกมไม่มีบัญชี ไม่มีโฆษณา และไม่มีระบบวิเคราะห์ และผู้พัฒนาไม่มีเซิร์ฟเวอร์ที่รับข้อมูลของคุณ นโยบายนี้ครอบคลุมบิลด์ทดสอบที่คุณดาวน์โหลดจากเว็บไซต์นี้

สรุปสั้น ๆ

  • เกมที่บันทึกไว้และการตั้งค่าของคุณอยู่ในโทรศัพท์ของคุณ ในพื้นที่เก็บข้อมูลส่วนตัวของเกม
  • ไม่มีโฆษณา ไม่มีระบบวิเคราะห์ ไม่มีบัญชี ไม่มีการติดตาม ไม่มีการขายข้อมูล
  • เกมติดต่อเฉพาะเว็บไซต์นี้และ GitHub เพื่อมองหาและดาวน์โหลดบิลด์ทดสอบใหม่
  • APK ทดสอบประกาศสามสิทธิ์: อินเทอร์เน็ต สถานะเครือข่าย และการติดตั้งแอป
  • ปุ่มรายงานแชร์ไฟล์เฉพาะเมื่อคุณแตะและเลือกว่าจะส่งไปที่ไหน

ในหน้านี้

เกมเก็บอะไรไว้เกมติดต่อกับอะไรการอัปเดตบิลด์ทดสอบปุ่มรายงาน (บิลด์ทดสอบ)สิทธิ์ของ APK ทดสอบการลบข้อมูลของคุณสิทธิของคุณและรายละเอียดทางกฎหมายติดต่อและการเปลี่ยนแปลง

ข้อมูลอะไร อยู่ที่ไหน ใครเห็น

ข้อมูลเก็บไว้ที่ไหนใครเห็นได้
เกมที่บันทึกไว้: โลก ประเทศของคุณ การเปลี่ยนแปลงของคุณ (บันทึกอัตโนมัติหนึ่งรายการ)ในพื้นที่เก็บข้อมูลส่วนตัวของเกมบนโทรศัพท์ของคุณคุณคนเดียว
การตั้งค่า: ภาษา รายละเอียดแผนที่ ยุคของเกมใหม่ เฟรมเรต กราฟิก เสียง ลำดับภาพหน้าจอโหลดในพื้นที่เก็บข้อมูลส่วนตัวของเกมบนโทรศัพท์ของคุณคุณคนเดียว
ไฟล์อัปเดตที่ดาวน์โหลดในโฟลเดอร์แคชของเกม จนกว่าการอัปเดตครั้งถัดไปจะมาแทนที่คุณคนเดียว
รายงานการทดสอบ: ภาพหน้าจอ รุ่นอุปกรณ์ เวอร์ชัน Android ภาษา ตัวเลขประสิทธิภาพ เกมที่บันทึกไว้ของคุณสร้างเฉพาะเมื่อคุณแตะรายงาน บันทึกในโฟลเดอร์แคช แล้วส่งให้แอปที่คุณเลือกในหน้าต่างแชร์ของ Androidเฉพาะคนที่คุณส่งให้

เกมเก็บอะไรไว้

เกมเก็บไฟล์สองไฟล์ไว้บนโทรศัพท์ของคุณ: บันทึกอัตโนมัติหนึ่งรายการของเกม (เกมใหม่จะมาแทนที่) และไฟล์การตั้งค่า (ภาษา รายละเอียดแผนที่ ยุคของเกมใหม่ เฟรมเรต ความละเอียด กราฟิก เพลง ลำดับภาพหน้าจอโหลด)

ไฟล์เหล่านี้ไม่มีอะไรเกี่ยวกับตัวคุณเป็นการส่วนตัว: ไม่มีชื่อ ไม่มีอีเมล ไม่มีหมายเลขโทรศัพท์ ไม่มีตำแหน่ง ไม่มีรายชื่อติดต่อ เกมไม่ขอสิ่งเหล่านี้และไม่มีการลงชื่อเข้าใช้

ทั้งสองไฟล์อยู่ในพื้นที่เก็บข้อมูลส่วนตัวของแอป ซึ่งแอปอื่นอ่านไม่ได้ การสำรองข้อมูลอัตโนมัติของ Android ถูกปิดสำหรับเกม (allowBackup=false) ดังนั้นไฟล์จะไม่ถูกคัดลอกไปยังการสำรองข้อมูลของ Google หรือโดย adb backup บนโทรศัพท์เครื่องใหม่ คุณเริ่มโดยไม่มีเกมเก่า

เกมติดต่อกับอะไร

เฉพาะการตรวจหาอัปเดตและการดาวน์โหลดอัปเดตตามที่อธิบายด้านล่าง เกมไม่มีโฆษณา ไม่มีไลบรารีวิเคราะห์หรือรายงานข้อขัดข้อง ยังไม่มีการเล่นหลายคน และไม่มีโค้ดเครือข่ายอื่น ทุกอย่างที่เหลือ รวมถึงตัวเกมทั้งหมด ทำงานได้โดยไม่ต้องเชื่อมต่อ

การอัปเดตบิลด์ทดสอบ

APK ทดสอบจากเว็บไซต์นี้อัปเดตตัวเอง เมื่อคุณเปิดเกม เมื่อคุณกลับมาที่เกม และทุก 30 นาทีขณะที่เกมเปิดอยู่และไม่มีอัปเดตรออยู่ เกมจะอ่านไฟล์ pegasohlib.github.io/kordon/version.json ซึ่งมีหมายเลขเวอร์ชันล่าสุด ลิงก์ดาวน์โหลด SHA-256 ของไฟล์ และบันทึกประจำรุ่น ไม่มีการตรวจสอบขณะที่เกมปิดอยู่

หากมีเวอร์ชันใหม่กว่า เกมจะดาวน์โหลด APK จาก GitHub (ลิงก์ในไฟล์นั้น) บน Wi-Fi และหลังจากที่คุณอนุญาตการติดตั้งจาก KORDON ใน Android เกมจะดาวน์โหลดและติดตั้งเอง บนข้อมูลมือถือ เกมจะแสดงปุ่มก่อน ก่อนติดตั้ง เกมเทียบ SHA-256 ของไฟล์กับค่าใน version.json และ Android ตรวจลายเซ็นอีกครั้ง

เช่นเดียวกับเว็บไซต์ทั่วไป เว็บไซต์นี้และ GitHub เห็นที่อยู่ IP ของโทรศัพท์คุณและเวลาของคำขอ ตามที่อยู่ในบันทึกเซิร์ฟเวอร์ของตนเอง เกมไม่ส่งข้อมูลของตัวเองให้: ไม่มีรหัส ไม่มีไฟล์เซฟ ไม่มีการตั้งค่า GitHub ยังนับจำนวนครั้งที่ดาวน์โหลดแต่ละไฟล์ เป็นตัวเลขเท่านั้น

เวอร์ชัน Google Play เมื่อออก จะสร้างขึ้นโดยไม่มีตัวอัปเดต และนโยบายนี้จะได้รับการอัปเดตในตอนนั้น

ปุ่มรายงาน (บิลด์ทดสอบ)

บิลด์ทดสอบมีปุ่มรายงานในแถวบน สำหรับส่งรายงานข้อบกพร่องให้ผู้พัฒนา ปุ่มนี้ไม่ทำอะไรเอง เมื่อคุณแตะ เกมจะจับภาพหน้าจอ เขียนข้อความสั้น ๆ ที่มีเวอร์ชันเกม รุ่นอุปกรณ์ เวอร์ชัน Android ภาษา เฟรมเรต และตัวเลขของแผนที่ และเพิ่มเกมที่บันทึกไว้ของคุณ ไฟล์จะไปที่โฟลเดอร์แคชของเกมและหน้าต่างแชร์ของ Android จะเปิดขึ้น

ไม่มีอะไรออกจากโทรศัพท์จนกว่าคุณจะเลือกแอปแล้วส่ง ผู้ที่ได้รับเห็นภาพหน้าจอได้ ซึ่งอาจแสดงสิ่งที่อยู่บนหน้าจอเกม และเห็นเกมที่บันทึกไว้ทั้งหมด

สิทธิ์ของ APK ทดสอบ

APK ทดสอบประกาศสิทธิ์ Android เหล่านี้ ไม่มีสิทธิ์ใดเป็นคำถามขณะทำงาน: Android ไม่แสดงป๊อปอัปสำหรับสิทธิ์เหล่านี้ ยกเว้นสวิตช์การติดตั้ง

อินเทอร์เน็ต (<code>INTERNET</code>)
เพื่ออ่าน version.json และดาวน์โหลดบิลด์ใหม่ ตามที่อธิบายข้างต้น
สถานะเครือข่าย (<code>ACCESS_NETWORK_STATE</code>)
เพื่อแยก Wi-Fi จากข้อมูลมือถือ การดาวน์โหลดขนาดใหญ่จึงไม่เริ่มเองบนข้อมูลมือถือ
ติดตั้งแอป (<code>REQUEST_INSTALL_PACKAGES</code>)
เพื่อส่งอัปเดตที่ดาวน์โหลดไปให้ตัวติดตั้งของ Android Android จะถามคุณหนึ่งครั้งให้อนุญาตการติดตั้งจาก KORDON ปิดได้ในการตั้งค่า Android

การลบข้อมูลของคุณ

การถอนการติดตั้งเกมจะลบเกมที่บันทึกไว้ การตั้งค่า ไฟล์อัปเดตที่ดาวน์โหลด และไฟล์รายงานใด ๆ ออกจากโทรศัพท์ของคุณ ในการตั้งค่า Android คุณยังล้างข้อมูลหรือแคชของเกมได้โดยไม่ต้องถอนการติดตั้ง

รายงานที่คุณส่งไปแล้ว และสำเนาในแอปที่คุณแชร์ไป อยู่นอกเกม ให้ลบที่นั่น

ประโยชน์โดยชอบด้วยกฎหมาย: ตอบคุณ (มาตรา 6(1)(f))

ผู้ที่ได้รับข้อมูล และการโอนข้อมูลออกนอกสหภาพยุโรป GitHub (การตรวจสอบอัปเดตและการดาวน์โหลด) และผู้ที่คุณส่งรายงานการทดสอบให้ อีเมลที่ส่งมาจะผ่าน Cloudflare และ Google เก็บไว้ในกล่องจดหมาย Gmail และ Anthropic อาจประมวลผลเมื่อผู้ช่วย AI ช่วยอ่าน บริษัทเหล่านี้บางแห่งตั้งอยู่ในสหรัฐอเมริกาหรือประเทศอื่นนอกสหภาพยุโรป การโอนข้อมูลดังกล่าวอาศัยกรอบความเป็นส่วนตัวของข้อมูลสหภาพยุโรป–สหรัฐอเมริกา (EU–US Data Privacy Framework) หากบริษัทนั้นเข้าร่วม หรืออาศัยข้อสัญญามาตรฐาน (standard contractual clauses) ของบริษัทนั้น

ระยะเวลาที่เก็บข้อมูล ข้อมูลในแอปจะอยู่จนกว่าคุณจะลบหรือถอนการติดตั้งแอป สำเนาในที่เก็บข้อมูลบนคลาวด์ของคุณเองจะอยู่จนกว่าคุณจะลบ อีเมลที่คุณส่งมาจะเก็บไว้จนกว่าเรื่องจะเสร็จสิ้น และไม่เกิน 2 ปี

สิทธิของคุณ คุณขอเข้าถึงข้อมูลของคุณ ขอแก้ไข ลบ จำกัดการประมวลผล ขอสำเนาเพื่อนำไปใช้ที่อื่น (การโอนย้ายข้อมูลได้) และคัดค้านการประมวลผลหรือถอนความยินยอมได้ทุกเมื่อ เขียนมาที่ที่อยู่ข้างต้น คุณจะได้รับคำตอบภายในหนึ่งเดือน ข้อมูลส่วนใหญ่อยู่บนอุปกรณ์ของคุณเท่านั้น คุณจึงมักทำเรื่องเหล่านี้เองได้ในแอป

การร้องเรียน คุณร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลได้ เช่น CNIL ของฝรั่งเศส หรือหน่วยงานของประเทศคุณเอง
