Diperbarui 4 November 2026

KORDON adalah game strategi untuk Android, dibuat oleh satu pengembang (PegasoHlib). Game ini tidak punya akun, iklan, dan analitik, dan pengembang tidak punya server yang menerima datamu. Kebijakan ini mencakup versi uji coba yang kamu unduh dari situs ini.

Sekilas

  • Game yang kamu simpan dan pengaturanmu tetap di ponselmu, di penyimpanan pribadi game.
  • Tanpa iklan, tanpa analitik, tanpa akun, tanpa pelacakan, tanpa jual-beli data.
  • Game hanya menghubungi situs web ini dan GitHub, untuk mencari dan mengunduh build uji coba baru.
  • APK uji coba menyatakan tiga izin: internet, status jaringan, dan memasang aplikasi.
  • Tombol Laporkan membagikan file hanya saat kamu mengetuknya dan memilih ke mana mengirimnya.

Apa yang disimpan game

Game menyimpan dua file di ponselmu: satu simpan otomatis dari gamemu (game baru menggantikannya) dan satu file pengaturan (bahasa, detail peta, zaman game baru, frame rate, resolusi, grafis, musik, urutan gambar pemuatan).

Keduanya tidak berisi apa pun tentang dirimu secara pribadi: tanpa nama, tanpa email, tanpa nomor telepon, tanpa lokasi, tanpa kontak. Game tidak meminta satu pun dari itu dan tidak ada proses masuk.

Kedua file berada di penyimpanan pribadi aplikasi, yang tidak bisa dibaca aplikasi lain. Pencadangan otomatis Android dimatikan untuk game (allowBackup=false), jadi file tidak disalin ke cadangan Google atau oleh adb backup. Di ponsel baru, kamu mulai tanpa game lamamu.

Apa yang dihubungi game

Hanya pemeriksaan pembaruan dan unduhan pembaruan yang dijelaskan di bawah. Game tidak punya iklan, pustaka analitik atau laporan crash, belum ada multipemain, dan tidak ada kode jaringan lain. Semua yang lain, termasuk seluruh game itu sendiri, berjalan tanpa koneksi.

Pembaruan versi uji coba

APK uji coba dari situs ini memperbarui dirinya sendiri. Saat kamu membuka game, saat kamu kembali ke sana, dan setiap 30 menit selama game terbuka dan tidak ada pembaruan yang menunggu, game membaca file pegasohlib.github.io/kordon/version.json. File itu berisi nomor versi terbaru, tautan unduhan, SHA-256 file, dan catatan rilis. Tidak ada pemeriksaan saat game ditutup.

Jika ada versi yang lebih baru, game mengunduh APK dari GitHub (tautan di file itu). Di Wi-Fi dan setelah kamu mengizinkan pemasangan dari KORDON di Android, game mengunduh dan memasangnya sendiri; di data seluler, game menampilkan tombol dulu. Sebelum memasang, game membandingkan SHA-256 file dengan yang ada di version.json, dan Android memeriksa tanda tangannya lagi.

Seperti situs web mana pun, situs ini dan GitHub melihat alamat IP ponselmu dan waktu permintaan, seperti di log server mereka sendiri. Game tidak mengirimkan data miliknya sendiri kepada mereka: tanpa ID, tanpa simpanan, tanpa pengaturan. GitHub juga menghitung berapa kali setiap file diunduh, hanya sebagai angka.

Versi Google Play, saat tersedia, akan dibuat tanpa pembaru. Kebijakan ini lalu akan diperbarui.

Tombol Laporkan (versi uji coba)

Versi uji coba memiliki tombol Laporkan di baris atas, untuk mengirim laporan bug kepada pengembang. Tombol ini tidak melakukan apa-apa sendiri. Saat kamu mengetuknya, game mengambil tangkapan layar, menulis teks singkat berisi versi game, model perangkat, versi Android, bahasa, frame rate, dan angka peta, lalu menambahkan game tersimpanmu. File masuk ke folder cache game dan jendela berbagi Android terbuka.

Tidak ada yang meninggalkan ponsel sampai kamu memilih aplikasi dan mengirimnya. Orang yang menerimanya bisa melihat tangkapan layar, yang mungkin menampilkan isi layar game, dan seluruh game tersimpan.

Izin APK uji coba

APK uji coba menyatakan izin Android ini. Tidak ada yang merupakan pertanyaan saat runtime: Android tidak menampilkan pop-up untuknya, kecuali sakelar pemasangan.

Internet (<code>INTERNET</code>)
Untuk membaca version.json dan mengunduh build baru, seperti dijelaskan di atas.
Status jaringan (<code>ACCESS_NETWORK_STATE</code>)
Untuk membedakan Wi-Fi dari data seluler, agar unduhan besar tidak dimulai sendiri di data seluler.
Memasang aplikasi (<code>REQUEST_INSTALL_PACKAGES</code>)
Untuk menyerahkan pembaruan yang diunduh ke penginstal Android. Android meminta sekali untuk mengizinkan pemasangan dari KORDON; kamu bisa mematikannya di pengaturan Android.

Menghapus datamu

Mencopot game menghapus game tersimpan, pengaturan, file pembaruan yang diunduh, dan semua file laporan dari ponselmu. Di pengaturan Android kamu juga bisa menghapus data atau cache game tanpa mencopot pemasangan.

Laporan yang sudah kamu kirim, dan salinannya di aplikasi tempat kamu membagikannya, berada di luar game; hapus di sana.

Anak-anak

Game tidak mengumpulkan data pribadi dari siapa pun, jadi tidak ada data tentang anak-anak yang dikumpulkan juga.
