Privacy policy

Updated 6 November 2026

KORDON is a strategy game for Android, made by one developer (PegasoHlib). The game has no accounts, no ads and no analytics, and the developer has no server that receives your data. This policy covers the test build you download from this site.

At a glance

  • Your saved game and settings stay on your phone, in the game’s private storage.
  • No ads, no analytics, no accounts, no tracking, no selling of data.
  • The game contacts only this website and GitHub, to look for and download new test builds.
  • The test APK declares three permissions: internet, network state and installing apps.
  • The Report button shares files only when you tap it and choose where to send them.

What the game holds

The game keeps two files on your phone: one autosave of your game (a new game replaces it) and a settings file (language, map detail, era of a new game, frame rate, resolution, graphics, music, the order of the loading pictures).

They contain nothing about you personally: no name, no email, no phone number, no location, no contacts. The game does not ask for any of these and has no sign-in.

Both files are in the app’s private storage, which other apps cannot read. Android’s automatic backup is switched off for the game (allowBackup=false), so they are not copied to Google’s backup or by adb backup. On a new phone you start without your old game.

What the game contacts

Only the update check and the update download described below. The game has no ads, no analytics or crash-report libraries, no multiplayer yet, and no other network code. Everything else, including the whole game itself, works without a connection.

Updates of the test build

The test APK from this site updates itself. When you open the game, when you come back to it, and every 30 minutes while it is open and no update is waiting, it reads the file pegasohlib.github.io/kordon/version.json. It holds the newest version number, the download link, the file’s SHA-256 and the release notes. There is no check while the game is closed.

If a newer version exists, the game downloads the APK from GitHub (a link in that file). On Wi-Fi and after you allowed installs from KORDON in Android, it downloads and installs it by itself; on mobile data it shows a button first. Before installing it compares the file’s SHA-256 with the one in version.json, and Android checks the signature again.

Like any website, this site and GitHub see the IP address of your phone and the time of the request, as in their own server logs. The game sends them no data of its own: no ids, no save, no settings. GitHub also counts how many times each file was downloaded, as a number only.

The Google Play version, when it comes, will be built without the updater. This policy will then be updated.

The Report button (test build)

The test build has a Report button in the top row, for sending the developer a bug report. It does nothing by itself. When you tap it, the game takes a screenshot of the screen, writes a short text with the game version, device model, Android version, language, frame rate and map figures, and adds your saved game. The files go to the game’s cache folder and Android’s share window opens.

Nothing leaves the phone until you pick an app and send it. The people who receive it can see the screenshot, which may show what is on the game screen, and the whole saved game.

Permissions of the test APK

The test APK declares these Android permissions. None of them is a runtime question: Android shows no pop-up for them, except the install switch.

Internet (<code>INTERNET</code>)
To read version.json and download a new build, as described above.
Network state (<code>ACCESS_NETWORK_STATE</code>)
To tell Wi-Fi from mobile data, so a big download does not start by itself on mobile data.
Install apps (<code>REQUEST_INSTALL_PACKAGES</code>)
To hand the downloaded update to Android’s installer. Android asks you once to allow installs from KORDON; you can turn that off in Android settings.

Deleting your data

Uninstalling the game removes the saved game, the settings, the downloaded update file and any report files from your phone. In Android settings you can also clear the game’s data or cache without uninstalling.

Reports you already sent, and copies of them in the app you shared them to, are outside the game; delete them there.

How long it is kept. Data in the app stays until you delete it or remove the app. Copies in your own cloud storage stay until you delete them. E-mails you send are kept until the matter is closed, and for no more than 2 years.

Your rights. You can ask for access to your data, correction, deletion, restriction, a copy to take elsewhere (portability), and you can object to processing or withdraw consent at any time. Complaints. You can complain to the data protection authority of your country.

Age. You need to be at least 15 to use the app on your own. If you are younger, ask a parent or guardian to agree first.
