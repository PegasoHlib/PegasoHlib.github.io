Site privacy

Updated 4 November 2026

This page is about the website pegasohlib.github.io: the main page and the app pages. In short: no accounts, no cookies, no ads and no analytics. What each app does with data is explained in its own privacy policy, listed below.

In short

  • The site sets no cookies and has no ads, analytics or social media buttons.
  • Your chosen language and theme stay in your own browser and are never sent anywhere.
  • GitHub hosts the site and logs visitors’ IP addresses for security.
  • Files download from GitHub, so GitHub sees and counts each download.
  • If you send an email, it is used only to answer you.

What is saved in your browser

When you pick a language or switch the theme, the site saves that choice in your browser’s local storage, so the pages open the same way next time. Nothing is saved until you make a choice.

Why there is no consent banner

These two entries are not cookies. They hold no identifier, they aren’t sent to any server, and they don’t follow you to other websites. They only keep a setting you chose yourself, so the site doesn’t ask for consent. To remove them, clear this site’s data in your browser’s settings.

Hosting

The site runs on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub logs each visitor’s IP address for security purposes, whether or not the visitor has a GitHub account. PegasoHlib has no access to these logs. GitHub is responsible for this data: see the GitHub Privacy Statement.

Downloads and numbers

Download buttons lead to files stored on GitHub. When you press one, your browser connects to GitHub, and GitHub adds one to that file’s counter. PegasoHlib sees only the total for each file, never who downloaded it.

The download totals on the pages are added when the site is built, so your browser doesn’t contact GitHub’s API for them. Version numbers and file sizes are read from files on this same site.

  • cookies;
  • ads;
  • analytics or visitor statistics;
  • social media buttons or embedded videos;
  • fonts or scripts from other companies: the fonts are served by this site;
  • accounts or forms.

If you send an email

The contact address is a Gmail address, so Google handles the messages. PegasoHlib uses your address and your message only to answer you and to fix what you report (legitimate interest), and doesn’t share them with anyone else. You can ask for them to be deleted at any time.
