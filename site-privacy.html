Site privacy

Updated 5 November 2026

This page is about the website pegasohlib.com: the main page and the app pages. In short: no accounts, no cookies, no ads and no analytics. What each app or game does with data is explained in its own privacy policy, listed below.

In short

  • The site sets no cookies and has no ads, analytics or social media buttons.
  • Your chosen language and theme stay in your own browser and are never sent anywhere.
  • GitHub hosts the site and Cloudflare delivers it, so both can see visitors’ IP addresses.
  • Files download from GitHub, so GitHub sees and counts each download.
  • If you send an email, it is used only to answer you.

What is saved in your browser

When you pick a language or switch the theme, the site saves that choice in your browser’s local storage, so the pages open the same way next time. Nothing is saved until you make a choice.

siteLang
The language you picked.
pegasohlib-theme
The light or dark theme you picked.

Why there is no consent banner

These two entries are not cookies. They hold no identifier, they aren’t sent to any server, and they don’t follow you to other websites. They only keep a setting you chose yourself, so the site doesn’t ask for consent. To remove them, clear this site’s data in your browser’s settings.

Hosting

The site runs on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub logs each visitor’s IP address for security purposes, whether or not the visitor has a GitHub account. PegasoHlib has no access to these logs. GitHub is responsible for this data: see the GitHub Privacy Statement.

Visitors to pegasohlib.com reach the site through Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA: your browser connects to Cloudflare, which fetches the page from GitHub. So Cloudflare sees your IP address, the page you open and the technical details every browser sends. It handles them on PegasoHlib’s behalf, under its data processing agreement, to deliver the site over a secure connection and protect it from attacks (legitimate interest). PegasoHlib sees only overall totals, plus the details of a request that Cloudflare blocks. Cloudflare sets no cookies here unless its protection asks a visitor to pass a security check: it then shows its own check page and may set a strictly necessary cookie, cf_clearance. Downloads, and the old address pegasohlib.github.io, connect your browser to GitHub directly. See the Cloudflare Privacy Policy.

Downloads and numbers

Download buttons lead to files stored on GitHub. When you press one, your browser connects to GitHub, and GitHub adds one to that file’s counter. PegasoHlib sees only the total for each file, never who downloaded it.

Download totals, where a page shows them, are added when the site is built, so your browser doesn’t contact GitHub’s API for them. Version numbers and file sizes are read from files on this same site.

What the site doesn’t use

  • cookies;
  • ads;
  • analytics tools or tracking of visitors;
  • social media buttons or embedded videos;
  • fonts or scripts from other companies: the fonts are served by this site;
  • accounts or forms.

If you send an email

Mail to the contact address goes through Cloudflare, which runs this domain’s DNS and mail routing. A small program there reads the message headers and may send you an automatic reply. The message is forwarded to a Gmail mailbox, so Google handles it too. PegasoHlib may use an AI assistant, Claude by Anthropic, to help read mail. PegasoHlib uses your address and your message only to answer you and to fix what you report (legitimate interest), and doesn’t share them with anyone else. You can ask for them to be deleted at any time.

Your rights and the legal details

Who is responsible. PegasoHlib, a private individual who develops these apps, is responsible for the data described here. Contact: support@pegasohlib.com.

Who receives data, and transfers outside the EU. GitHub hosts this site and sees visitors’ IP addresses. Cloudflare runs this domain’s DNS and passes on mail sent to the contact address, Google keeps it in a Gmail mailbox, and Anthropic may process it when the AI assistant helps read it. All four are based in the United States. Those transfers rely on the EU–US Data Privacy Framework where the company takes part in it, or on the company’s standard contractual clauses. The same safeguards cover Cloudflare when it delivers this site and sees visitors’ IP addresses.

How long it is kept. E-mails you send are kept until the matter is closed, and for no more than 2 years. GitHub keeps its logs under its own rules. So does Cloudflare.

Your rights. You can ask for access to your data, correction, deletion, restriction, a copy to take elsewhere (portability), and you can object to processing. Write to the address above. You’ll get an answer within one month. PegasoHlib holds personal data about you only if you sent an e-mail or play ZORYT, whose privacy policy explains what it saves. For hosting and download data, contact GitHub. For data Cloudflare holds when it delivers the site, write to the address above and PegasoHlib will pass your request on.

Complaints. You can complain to a data protection authority, such as the French CNIL or the authority of your own country.

Language. Translations of this page are made with the help of AI. If a translation differs from the English text, the version more favourable to you applies.
