หน้านี้เกี่ยวกับเว็บไซต์ pegasohlib.github.io: หน้าหลักและหน้าของแอป โดยสรุป: ไม่มีบัญชี ไม่มีคุกกี้ ไม่มีโฆษณา และไม่มีระบบวิเคราะห์ สิ่งที่แต่ละแอปหรือเกมทำกับข้อมูลอธิบายไว้ในนโยบายความเป็นส่วนตัวของแอปหรือเกมนั้น ซึ่งแสดงรายการไว้ด้านล่าง

สรุปสั้น ๆ

  • เว็บไซต์ไม่ตั้งคุกกี้ และไม่มีโฆษณา ระบบวิเคราะห์ หรือปุ่มโซเชียลมีเดีย
  • ภาษาและธีมที่คุณเลือกจะอยู่ในเบราว์เซอร์ของคุณเองเท่านั้น และไม่ถูกส่งไปที่ใด
  • GitHub เป็นผู้โฮสต์เว็บไซต์และบันทึกที่อยู่ IP ของผู้เข้าชมเพื่อความปลอดภัย
  • ไฟล์ดาวน์โหลดจาก GitHub ดังนั้น GitHub จึงเห็นและนับการดาวน์โหลดแต่ละครั้ง
  • หากคุณส่งอีเมล เราจะใช้เพื่อตอบคุณเท่านั้น

ในหน้านี้

สิ่งที่บันทึกไว้ในเบราว์เซอร์ของคุณทำไมจึงไม่มีแบนเนอร์ขอความยินยอมการโฮสต์การดาวน์โหลดและตัวเลขสิ่งที่เว็บไซต์ไม่ใช้หากคุณส่งอีเมลนโยบายความเป็นส่วนตัวของแอปและเกมสิทธิของคุณและรายละเอียดทางกฎหมายการเปลี่ยนแปลงและการติดต่อ

การดาวน์โหลดและตัวเลข

ปุ่มดาวน์โหลดนำไปสู่ไฟล์ที่เก็บไว้บน GitHub เมื่อคุณกดปุ่ม เบราว์เซอร์ของคุณจะเชื่อมต่อกับ GitHub และ GitHub จะบวกหนึ่งเข้ากับตัวนับของไฟล์นั้น PegasoHlib เห็นเพียงยอดรวมของแต่ละไฟล์ ไม่เห็นว่าใครเป็นผู้ดาวน์โหลด

ยอดดาวน์โหลดรวม เมื่อหน้าใดแสดง จะถูกเพิ่มตอนสร้างเว็บไซต์ เบราว์เซอร์ของคุณจึงไม่ติดต่อ API ของ GitHub เพื่อข้อมูลนี้ หมายเลขเวอร์ชันและขนาดไฟล์อ่านจากไฟล์บนเว็บไซต์เดียวกันนี้
